# Gu 候选 A 的联合冗余区域、dither 与物理单位审计 v0.1

> 状态：可审阅的解析结果；适用于 `gu_static_hypothesis_a_v0_1`  
> 结论类别：论文事实、来源约束下的解释、解析推导三者分开记录  
> 目的：扩展单阈值 `|delta| < 1/8` 结果，并处理 Q-004/Q-006 的行为级闭环

## 1. 结论摘要

候选 A 的单阈值冗余边界可以推广为一个逐边界、可直接计算的联合条件。设相邻两个判决状态为 `q=k` 和 `q=k+1`，实际 CDAC 电平为 `a_k`、`a_(k+1)`，主路径残差增益为 `G>0`，注入到放大器前残差求和点的 dither 满足 `|d|<=d0`。把辅助路径判决边界折算到主路径输入坐标后记为 `B_k`，则下一级对这两条路径均不发生过载的充要边界条件是：

```text
a_(k+1) + d0 - 1/G <= B_k <= a_k - d0 + 1/G.       (1)
```

该式把 flash 阈值偏移、主/辅路径增益差、辅助路径 offset、主路径增益、CDAC 码相关误差和 dither 同时放进同一约束。它描述的是“冗余覆盖/仍可校正区域”，不是“无校准时输出码仍精确”。阈值或辅助路径误差在不越界时可由数字冗余吸收；主增益和 CDAC 电平误差即使不造成越界，仍会改变传输函数，必须由已知参数校正或后台校准处理。

公开材料明确给出：1-bit dither 在模拟残差端相加，其对应数字码在 PWL 校正之后相减；前两级各有一个 dither，大小为各自 backend 满量程摆幅的 `1/16`。OJSSCS 的通用校准图和 ISSCC 框图都支持这一代数方向。[^1][^2] 但材料没有给出 PRNG 的 `0/1` 到 Fig. 14 具体开关位置的真值表。因此本研究可以冻结行为级符号约定，不能声称恢复了硅实现中的物理开关极性。

在“每个 dither 符号的绝对幅度为 backend FSR 的 `1/16`”这一候选解释下，候选 A 中两个 dither 在各自放大器输入端均为 `+/-1/32` 归一化单位，在下一级输入端均造成 `+/-1/8` 的平移；对应数字副本分别为第一级 `+/-64` 个 10-bit backend 码、第二级 `+/-16` 个 8-bit backend 码。只要没有过载，两者可以同时被逐码精确抵消。

物理单位方面，OJSSCS 明确说明 Fig. 14 为便于展示只画了单端形式，而放大器和信号链实际采用差分结构；同页及下一页还给出差分端口、`0/1 V` 参考轨以及把有效参考范围从 `2 Vpp` 降到 `1 Vpp` 的开关方式。[^1] 这些证据强支持把论文的 `1 Vpp` 理解为系统差分满量程。候选 A 因而采用 `VFS,diff,pp=1 V`：一个归一化单位为 `0.5 V` 差分电压，理想放大前 residue 的 `+/-1/8` 正好对应论文的 `+/-62.5 mV`。由于正文没有逐字写出“1 Vpp differential”，该解释仍标记为 `derived_interpretation`，而非 `paper_reported`。

## 2. 来源事实与解释边界

### 2.1 可直接归为论文事实的内容

1. 前两级均为 3-bit flash 加开环 MDAC，名义级间增益约 4，并各有 1-bit redundancy。[^1]
2. 第一级主路径驱动第二级 CDAC，辅助路径驱动第二级 flash；辅助路径约有 3% 系统性增益差。[^1]
3. 前两级各注入一个 1-bit pseudo-random dither，大小为相应 backend full-scale swing 的 `1/16`。[^1][^2]
4. 通用校准框图把 `Vd` 在模拟输入/残差端相加，并在校正块后减去 `Dd`；若增益与非线性被准确校正，输出与 dither 去相关。[^1][^2]
5. Fig. 14 只画单端形式；实际放大器端口和信号路径为差分。参考轨为 `0/1 V`，通过把一半采样电容在放大相位接到 `VCM`，有效参考范围由 `2 Vpp` 降到 `1 Vpp`。[^1]
6. 对 `1 Vpp` 满量程的 3-bit 首级，论文给出的理想输入参考 residue 摆幅为 `+/-62.5 mV`。[^1]

### 2.2 仍属于候选解释的内容

- “dither magnitude = 1/16 FSR”解释为二值电平分别为 `+FSR/16` 和 `-FSR/16`，而不是总峰峰值等于 `FSR/16`。OJSSCS 的方法示例把二值 dither 写成“amplitude of `+/-0.25`”，支持按单边绝对幅度理解，但芯片段没有单独画出数值真值表。[^1]
- `1 Vpp` 解释为差分系统满量程；平衡差分半电路的每一支相应为 `0.5 Vpp`。这与 Fig. 14 的单端化说明和参考范围叙述一致，但不是正文逐字定义。
- PRNG 的正符号被定义为“向放大前 residue 加正电压”，对应 `Dd` 定义为理想 backend 产生的正码移，并在数字端相减。交换 PRNG 的物理 `0/1` 标签不会改变行为模型；实际开关真值表仍未知。

## 3. 联合模型

对某一级定义：

```text
x_aux = rho*x + o_aux
flash threshold = t_k + theta_k
B_k = (t_k + theta_k - o_aux)/rho,  rho > 0

a_q = q/4 + epsilon_q
z = G*(x - a_q + d),  |d| <= d0,  G > 0.
```

其中 `x` 是主路径归一化输入，`x_aux` 是同一信号在辅助判决路径上的值；`rho` 是辅/主路径增益比，`o_aux` 是辅助路径输入参考 offset，`theta_k` 是第 `k` 个比较器阈值偏移。`a_q` 是实际 CDAC 电平，`epsilon_q` 允许码相关误差。`z` 是下一级输入，后级可表示域为 `[-1,1)`。

该定义把“双路径误差”放到它真正作用的位置：flash 用 `x_aux` 决策，CDAC 和 residue 则使用 `x`。因此一个统一的 3% 增益因子不是附加到最终数字码，而是把所有非零阈值按 `1/rho` 移到主路径坐标。

## 4. 联合可纠正区域定理

### 4.1 内部边界

边界 `B_k` 左侧选择 `q=k`，右侧选择 `q=k+1`。左侧 residue 的最大上确界出现在 `x` 趋近 `B_k` 且 `d=+d0`：

```text
z_left,sup = G*(B_k - a_k + d0).
```

要求它不超过 `+1`，得到 `B_k <= a_k-d0+1/G`。右侧 residue 的最小值出现在 `x=B_k` 且 `d=-d0`：

```text
z_right,min = G*(B_k - a_(k+1) - d0).
```

要求它不低于 `-1`，得到 `B_k >= a_(k+1)+d0-1/G`。两式合并即式 (1)。这是在单调 thermometer 判决、正增益和静态无记忆模型下，对该相邻边界的充要条件。

将窗口写成中心与半宽更便于看误差预算：

```text
c_k = (a_k + a_(k+1))/2
h_k = 1/G - d0 - (a_(k+1)-a_k)/2
|B_k - c_k| <= h_k,  h_k >= 0.                       (2)
```

代入候选 A 的 `a_q=q/4+epsilon_q` 与 `t_k=(k+1/2)/4`：

```text
c_k = t_k + (epsilon_k + epsilon_(k+1))/2
h_k = 1/G - d0 - 1/8
      - (epsilon_(k+1)-epsilon_k)/2.                 (3)

| (t_k+theta_k-o_aux)/rho
  - t_k - (epsilon_k+epsilon_(k+1))/2 | <= h_k.      (4)
```

式 (3) 说明相邻 CDAC 误差的平均值移动安全窗口中心，而相邻电平间距误差改变窗口宽度。仅报告单个“CDAC mismatch 百分比”不足以判断冗余是否安全；必须知道它如何投影到相邻电平差。

### 4.2 两端状态与单调性

内部边界条件之外，还需检查满量程两端：

```text
a_-4 + d0 - 1/G <= -1
1 <= a_4 - d0 + 1/G.                                 (5)
```

所有折算后的 `B_k` 还必须严格递增。若比较器 offset 使阈值次序颠倒，简单 thermometer 模型已经失效；此时需要 bubble/error 模型，不能继续使用式 (1) 假装仍是九个有序状态。

### 4.3 “可纠正”不等于“无误差”

当 `G=4`、`epsilon_q=0`、dither 已精确扣除且后级不越界时，最终重构恒等式与选择了哪条相邻冗余路径无关。因此阈值、比较器 offset 和辅助路径增益差只改变路径，不改变最终理想码。

若 `G!=4` 或 `epsilon_q!=0`，式 (1) 只能证明信息没有因后级饱和而丢失。名义 `512/128/1` 权重仍会产生确定性码误差。这正是增益、CDAC 权重和 PWL 非线性校准的对象。若式 (1) 已被破坏，后级量化器饱和导致信息不可逆丢失，再精确的数字系数也不能普遍恢复原输入。

## 5. 候选 A 的数值结果

### 5.1 无 dither

名义 `G=4`、相邻 CDAC 电平间隔 `1/4`、`d0=0` 时：

```text
h = 1/4 - 1/8 = 1/8.
```

因此式 (4) 退化为已得到的单阈值边界 `|delta|<=1/8`。为避开真实电路端点、比较器等号归属和后端饱和规则，验证和规格采用严格安全条件 `|delta|<1/8`。

### 5.2 启用候选 dither

每级 backend 归一化满量程宽度为 2。若二值 dither 电平为 `+/-FSR/16`，则它在下一级输入端造成 `+/-1/8` 平移；除以名义增益 4，放大前求和点为：

```text
d0 = 1/32.
```

名义联合边界半宽变为：

```text
h = 1/4 - 1/32 - 1/8 = 3/32 = 0.09375.              (6)
```

dither 消耗了原始冗余预算的 `1/32`，但没有把窗口耗尽。若实际主增益为 `G` 而 dither 求和点幅度仍固定为 `1/32`，窗口半宽为 `1/G-5/32`，存在任何内部安全边界要求 `G<=6.4`；这是结构极限，不是建议工作点。

### 5.3 3% 辅助路径增益差

仅有辅助增益误差时，`B_k=t_k/rho`。外侧阈值 `|t|=7/8` 的偏移最大：

```text
rho = 0.97: max |B-t| = 0.0270619
rho = 1.03: max |B-t| = 0.0254854.
```

两者都显著小于启用候选 dither 后的 `3/32=0.09375`。最保守方向仍留下 `0.0666881` 个归一化单位，按候选差分电压口径约为 `33.34 mV` 的主路径输入参考余量。这验证了论文“约 3% 增益差可由冗余容忍”的结构可行性，但不是统计 yield 结论：实际随机 offset、CDAC mismatch、主增益误差和相关性尚未联合给出。

## 6. 两级 dither 的逐码精确抵消

令两个 dither 符号 `s1,s2` 均取 `{-1,+1}`，在各自放大前 residue 端注入 `s/32`：

```text
x2 = 4*x1 - q1 + s1/8
x3 = 4*x2 - q2 + s2/8.
```

候选 A 的第二、三级组合码是 `floor(512*x2)`，所以第一级 dither 造成精确的整数码移：

```text
Dd1 = 512*(s1/8) = 64*s1.
```

8-bit SAR centered code 是 `floor(128*x3)`，第二级 dither 对应：

```text
Dd2 = 128*(s2/8) = 16*s2.
```

最终重构写为：

```text
C12 = 512*q1 + 128*q2 + floor(128*x3)
      - 64*s1 - 16*s2
    = floor(2048*x1).                                (7)
```

式 (7) 利用了整数平移恒等式 `floor(y+n)=floor(y)+n`。因此在理想增益、理想 CDAC、无后级过载条件下，两个 dither 同时存在也可逐码精确消除；3% 辅助路径增益差可以改变 `q2`，但只要仍在式 (1) 的覆盖区内，不破坏该恒等式。

如果将公开语句解释为“dither 的总峰峰值等于 FSR/16”，则相应候选会变为放大前 `d0=1/64`，数字副本 `32` 和 `8`。公开材料尚未逐字排除这一较小幅度解释，所以配置必须记录采用的是哪一个解释，运行产物不能只写模糊的 `1/16 FS`。

## 7. Q-006 物理电压映射

候选 A 采用：

```text
VFS,diff,pp = 1 V
x = 2*v_diff / VFS,diff,pp
1 normalized unit = 0.5 V differential.
```

由此：

| 归一化量 | 差分物理量 | 含义 |
|---:|---:|---|
| `1/4` | `125 mV` | 相邻 CDAC 名义电平间距 |
| `1/8` | `62.5 mV` | 理想放大前 residue 峰值；无 dither 单阈值冗余半宽 |
| `1/32` | `15.625 mV` | 候选 dither 在放大前求和点的绝对幅度 |
| `4*(1/32)=1/8` | `62.5 mV` | dither 在名义后级输入端的绝对幅度，即 `1 Vpp/16` |
| `3/32` | `46.875 mV` | 启用候选 dither 后、其余名义时的阈值安全半宽 |

平衡差分实现中，每个单端分支的峰峰值是差分值的一半。所有研究代码仍以归一化差分量为规范值；只有报告物理电压时才应用本节映射。这样可避免 Fig. 14 的单端示意图与系统差分规格混用。

## 8. 验证与可证伪条件

本次新增独立理论函数和回归测试，验证：

- 式 (1) 在名义无 dither 时退化为 `+/-1/8`；
- 候选 dither 把阈值安全半宽变为 `3/32`；
- `rho=0.97/1.03` 的全部八个判决边界仍落在安全窗口；
- 带主增益、相邻 CDAC 误差和 dither 的解析窗口与 residue 端点穷举一致；
- 4096 个最终 12-bit 码中心、两个 dither 的四种符号组合、辅助增益比 `0.97/1.03` 均保持精确 12-bit 重构且后端不过载。

以下证据会修改或否决当前结论：

1. 原始开关表显示 dither 不在放大前 residue 求和点等效相加；
2. `1/16 backend full-scale` 被作者明确规定为峰峰值而非二值绝对幅度；
3. 两级 dither 数字副本不是 64/16 的等价缩放，且差异不能由代码单位定义解释；
4. 系统 `1 Vpp` 被明确说明为单端而非差分；
5. flash 存在不可忽略的 bubble/nonmonotonic 状态，使单一有序边界模型失效；
6. 实际 CDAC 电平不是候选 A 的相邻 `1/4` 基线，或 dither 与主 CDAC mismatch 强耦合。

## 9. 当前决策建议

Q-004 可在“行为级、候选 A”范围内关闭：采用模拟加、数字减，默认二值绝对幅度为 backend FSR 的 `1/16`，数字副本为 64/16；物理 PRNG 开关映射继续保持未决。Q-006 可在同一范围内采用 `1 Vpp differential` 的高置信解释，并在所有物理报告中同时写明 differential/single-ended，直到作者资料给出逐字定义。

这两个行为级决定已经足以启动 Gate A/B；它们不构成对硅内部 bit-true 开关表的宣称。Gate A/B 仍需把式 (1) 作为运行时 `correctable` 判据，并分别报告“发生传输误差但未过载”与“已过载不可逆”两类事件。

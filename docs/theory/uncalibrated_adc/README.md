# 无校准 ADC 理论

保存 ADC 本体的解析或半解析推导、算法说明、适用条件、证明和验证标准。探索性想法应明确标注状态，不与已经验证的结论混写。

## 当前推导

- `GU_STATIC_HYPOTHESIS_A_DERIVATION_V0_1.md`：用 8 阈值/9 状态候选解释 4 倍 radix、1-bit 冗余、62.5 mV 和 PWL `b0=128`，并给出 12-bit 重构恒等式。状态为强一致性候选，尚非冻结规格。
- `GU_JOINT_REDUNDANCY_AND_DITHER_AUDIT_V0_1.md`：给出阈值、主/辅路径、CDAC、主增益和 dither 的联合可纠正区域，并审计 dither 64/16 精确抵消及差分物理单位解释。

## 阶段二入口

阶段一静态行为级平台已通过验收。阶段二首个独立预测问题、输入条件、误差
口径和留出验证方案已冻结在
`docs/specifications/STAGE2_STATIC_PREDICTION_SPEC_V0_1.md`。独立区间传播和
在预设的局部分段一次模拟传输条件下，区间计算已由 EXP-015 验证，可在理想及静态非理想条件下直接预测完整传输、
DNL、INL 和不可纠正输入宽度；理论与平台共 262144 个留出点零不一致。

EXP-016 已将静态码阶梯映射到正弦输入相位区间，并用闭式积分得到连续傅里叶
系数和功率；有限相干记录的复频谱与 SNDR/SNR/THD/SFDR/ENOB 在 18 条留出
记录、589824 个平台样本上零码不一致、零频谱误差。连续周期与有限记录的口径
和误差分解见 `docs/specifications/STAGE2_STATIC_SPECTRUM_SPEC_V0_1.md`。

EXP-017 已把有限建立写成首个动态状态基线：静态残余电压是瞬时目标，相位末端
残余电压按稳定一阶关系跨样本传播，周期输入采用唯一循环稳态。论文的
11 GHz 带宽与 100 ps 建立时间在单极点假设下对应约 9.97 bit 的相位末端精度；16 条正式记录、524288 个
留出样本实现零码、零状态和零指标不一致，且静态极限严格恢复 EXP-015/016。

该结果验证的是一阶状态抽象及其传播，不证明芯片相位间保留状态。固定复位、
压摆受限和高阶动态仍是待区分的候选。下一步用更高保真瞬态或测量证据区分
这些语义，然后处理 Q-013 双路径采样时刻差和 Q-016 输入缓冲器失真。

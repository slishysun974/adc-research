# Gu 理想静态码制候选 A：推导与可证伪检查 v0.1

> 状态：强一致性候选，尚未升级为冻结规格  
> 来源类别：`derived` + `assumed`，不是论文明确给出的完整码表  
> 目的：为 Q-001、Q-002、Q-003、Q-005 提供可穷举检验的第一候选

## 1. 已知约束

Gu et al. 明确给出：

1. 前两级均称为 3-bit flash；
2. 两级标称级间增益约为 4；
3. 两级各提供 1-bit redundancy；
4. Fig. 14 画出 `Vth[7:0]`、八路比较器输出 `D[7:0]` 和 16 个采样电容的两组 `Cs[15:8]`/`Cs[7:0]`；
5. 输入满量程为 1 Vpp；
6. 文中称理想输入参考 residue 摆幅为 +/-62.5 mV，并称第二级具有 62.5 mV redundancy；
7. 第二、三级组合形成第一级校正使用的 10-bit backend raw code；其正半轴为 9 bit，4-slice 时 `b0=128`。

这些约束共同限制了候选码表，但尚不能证明芯片内部编码细节唯一。

## 2. 候选 A

在归一化输入域 `-1 <= x < 1` 中，定义第一级和第二级相同的子 ADC：

```text
thresholds = [-7/8, -5/8, -3/8, -1/8,
               1/8,  3/8,  5/8,  7/8]
q in {-4, -3, -2, -1, 0, 1, 2, 3, 4}
q = number_of_ones(D[7:0]) - 4
a(q) = q/4
```

阈值相等时按软件约定进入高索引状态。8 个比较器产生 9 个 thermometer 状态；“3-bit flash”在此解释为 8 个比较器所对应的标称分辨率标签，而不是断言芯片内部把 9 个状态压成普通 3-bit 无冗余二进制码。

名义残差为：

```text
x_next = 4 * (x - a(q)) = 4x - q.
```

## 3. 残差与 62.5 mV 的一致性

对所有内部区间，`q` 是最接近 `4x` 的整数，因此：

```text
-1/2 <= x_next < 1/2.
```

如果 `x` 的满量程 2 个归一化单位对应 1 Vpp，则一级输入的 1 个归一化单位对应 0.5 V。CDAC 相邻电平间隔为：

```text
(1/4) * 0.5 V = 125 mV.
```

判决阈值位于相邻电平中点，理想放大前 residue 为：

```text
125 mV / 2 = 62.5 mV.
```

经 4 倍放大后，名义后级输入只占 `+/-0.5` 归一化范围，而后级可表示范围为 `[-1,1)`。一个相邻错误判决会让后级 residue 平移 1 个归一化单位；因此在判决边界附近仍存在半量程的数字冗余。折算回前一级输入，阈值可偏移的理想上界为：

```text
(1/8) * 0.5 V = 62.5 mV.
```

该数值同时匹配论文对理想 residue 和 redundancy 的描述，是候选 A 的主要一致性证据。它不能单独证明 1 Vpp 的单端/差分报告口径。

## 4. 后端与 12-bit 重构恒等式

令 8-bit SAR 为归一化区间 `[-1,1)` 上的理想 offset-binary 量化器：

```text
u3 = floor(128 * (x3 + 1)),  u3 in {0,...,255}
c3 = u3 - 128 = floor(128*x3)
```

两级递推为：

```text
x2 = 4x1 - q1
x3 = 4x2 - q2 = 16x1 - 4q1 - q2.
```

定义最终 12-bit centered code：

```text
C12 = 512*q1 + 128*q2 + c3.
```

则：

```text
C12
= 512*q1 + 128*q2 + floor(128*x3)
= floor(2048*x1).
```

最终 offset-binary 输出为：

```text
U12 = C12 + 2048 = floor(2048*(x1+1)).
```

因此，候选 A 在无过载、无非理想时严格等价于区间 `[-1,1)` 上的理想 12-bit 均匀量化器。逐级权重为 512、128、1，对应有效位数 `2+2+8`。

这个恒等式还有一个重要含义：只要后级未过载，冗余区内相邻 `q1` 或 `q2` 路径会由后续码的相反变化精确抵消，最终码不依赖具体冗余路径。

### 4.1 阈值偏移的可纠正边界

考虑 `q=k` 与 `q=k+1` 之间的名义阈值：

```text
t_k = (k + 1/2)/4.
```

若实际阈值偏移 `delta`，在名义与实际阈值之间会选择相邻的另一条冗余路径。该带状区内最坏后级输入幅值趋近于：

```text
max_abs(x_next) = 1/2 + 4*abs(delta).
```

后级名义可表示范围为 `[-1,1)`，因此不依赖端点饱和细节的安全条件是：

```text
abs(delta) < 1/8.
```

在这个开区间内，只要下游未发生其他非理想，上一节的数字恒等式仍成立，错误的相邻判决由后续码精确抵消。`abs(delta)=1/8` 时 residue 触及后级满量程边界；更大的偏移产生非空过载输入区间，不能保证纠正。

按 1 Vpp 对应 2 个归一化单位换算，`1/8` 对应 62.5 mV，再次与论文数值一致。这里给出的是单一阈值偏移、其余模块理想条件下的边界；多个阈值、增益、CDAC 和路径误差联合存在时，可纠正区域会改变。

## 5. 与 PWL 数字参数的一致性

第二、三级组合对 `x2` 的 centered raw code 为：

```text
C10 = 128*q2 + c3 = floor(512*x2).
```

这正是一个 signed 10-bit 范围；其正半轴幅值使用 9 bit。将正半轴 512 个码分成 4 段得到：

```text
b0_stage1 = 512 / 4 = 128,
```

与 OJSSCS 扩展稿明确给出的 `b0=128` 完全一致。

同理，第二级只使用 8-bit SAR 作为 backend；若采用相同的 4-slice 幅值划分，则推导得到：

```text
b0_stage2 = 128 / 4 = 32.
```

`b0_stage2=32` 是候选 A 的推导结果，不是当前文献中的明确报道值。

## 6. 可证伪条件

出现以下任一证据时，应修改或否决候选 A：

- 原始设计资料显示实际有效比较器不是 8 个，或 `D[7:0]` 不是 thermometer 决策；
- CDAC 的 8 个受控单元不是等权、名义电平不是 `q/4`；
- 数字重构权重不是 512/128/1，且不能通过整体平移或等价编码变换得到；
- `b0=128` 对应的不是第一级 10-bit backend 正半轴；
- 穷举测试出现缺码、非单调或冗余路径不等价；
- 物理节点换算无法同时解释 1 Vpp、+/-62.5 mV residue 与 62.5 mV redundancy。

## 7. 当前结论

候选 A 同时解释了 8 个图示比较器、9 个冗余状态、4 倍 radix、1-bit redundancy、62.5 mV 和 `b0=128`。这使其足以作为首个命名假设进入 Gate A/B 的可执行验证，但在获得原始码表或作者确认前仍应保持 `hypothesis` 状态。

单阈值结论的联合推广、3% 辅助路径增益差、CDAC/主增益误差和 dither 预算见 `GU_JOINT_REDUNDANCY_AND_DITHER_AUDIT_V0_1.md`。该审计还证明：在候选 A 的 dither 幅度解释下，两个 dither 分别用 64 和 16 个 backend centered codes 可同时逐码精确抵消。

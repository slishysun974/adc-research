# 主辅模拟范围到最终码：静态全链路条件传播

> 2026-10-02，阶段二条件性结果。它补上[有限记录性能界限](FINITE_RECORD_PERFORMANCE_BOUNDS_V1.md)原先固定前级判决时缺少的主/辅分支。输入范围和三条模拟传输的输出区间必须由外部电路证据证明覆盖；这里的程序只负责**传播**，不从训练码或合成曲线推断芯片模拟范围。

> 2026-10-03 补充：CDAC 电平和末级 SAR 阈值也可给覆盖区间；末级阈值须在所有允许选择下保持严格有序。对应电路范围仍未取得。

## 结论和一个可核查例子

在冻结的数字校正系数、给定 dither 标签和静态无记忆条件下，若每条路径的区间函数都覆盖其声明的允许电路，则可把可能的第一级判决、独立主/辅输出、第二级判决、末级 SAR 码逐支传播，取得覆盖性的数字观测集合。对集合中的每个观测执行相同 Gu 校正及整数化，可得最终码区间；逐样本重复后可送入既有 SNDR/SFDR 界限。

候选码制中的一个例子：输入固定为 `x=-0.2`，无 dither，第一级判决为 `q1=-1`，第一级放大前电压 `w1=0.05`。主路输出固定 `0.2`；独立辅路输出只知在 `[0.10,0.15]`，跨越第二级候选阈值 `0.125`，故 `q2` 可以为 `0` 或 `1`。若第二级主路采用**人为设定**的线性增益 `4.1`，两分支的末级中心码分别为 `104` 和 `-27`；冻结单位 Gu 校正后的最终整数码分别为 `1640` 和 `1637`。两种独立辅路增益 `0.5/0.75` 的逐样本候选平台结果都被包含。这展示了为何不能只把主路电压界传给固定 `q2` 的末级枚举；数值本身没有芯片物理来源。

另一个边界例子中，辅路输出被人为设为 `1.1`，虽然第一级主路与末级输入都未过载，候选 `q2=4` 与末级中心码 `0` 会让第一级数字 PWL 的原始输入恰好达到其排除的上端点 `512`。当前软件校正对此无定义，范围计算会明确停止；若真实硬件还有端部合并或饱和规则，须先取得并建模，不能把这个可能分支忽略。

## 传播定义与覆盖证明

输入与 dither 模拟电压写成闭区间 `X, D1, D2`。此候选静态拓扑令第一级 flash 直接观察 `X`；若输入缓冲器或采样相位另有误差，须先把它计入 `X` 或增加独立的 flash 输入范围。每级有按顺序排列的阈值区间 `T_{i,j}=[l_{i,j},u_{i,j}]`，且相邻区间不相接，以保证每一种允许阈值选择仍严格有序。阈值处判为高码。对可能电压区间 `V=[a,b]`，可能的判决索引用以下闭整数区间**向外包住**：

```text
j_min = #{j : u_j <= a}
j_max = #{j : l_j <= b}
```

当阈值是固定点时，该式退化为左闭右开量化器在两个端点的判决索引。第一判决分支还把 `X` 与该分支可能的阈值胞腔相交，避免把明显属于另一分支的输入带入同一个放大区间；使用闭区间包含边界，可能多保留零测度端点，但不会漏掉结果。

令 `G1m(I)`、`G1a(I)`、`G2m(I)` 分别是第一级主路、独立辅路、第二级主路在输入区间 `I` 上的**覆盖性输出区间**。当前接口没有额外传入码态、通道或 PVT 标签；若传输依赖这些量，每个 `G` 必须覆盖所声明的全部允许条件，或把条件分组后分别运行传播。对每个可能的 `q1`，计算

```text
W1 = X_q1 - DAC1(q1) + D1
R1m = G1m(W1)               R1a = G1a(W1)
```

随后对 `R1a` 的所有可能 `q2` 分支，计算

```text
W2 = R1m - DAC2(q2) + D2
R2m = G2m(W2)
```

`DAC1(q1)` 与 `DAC2(q2)` 现在也可为区间：若输入 `V=[a,b]`、CDAC 电平 `A=[c,d]`，则 `V-A=[a-d,b-c]`。末级 SAR 若有有序阈值区间，也用前述 `j_min/j_max` 公式列出全部可能码；不提供阈值表时，沿用原候选的均匀 SAR。对每个分支逐个列出 `(q1,q2,c3)`。第一级主路与辅路共享 `W1`，但代码把它们各自的范围独立组合，可能保留同一电路不能同时达到的状态；这是保守放宽。不同 CDAC 码态或 SAR 阈值误差的物理相关性也被放宽。

末级阈值表要求每个可能选择都严格有序，因此本模型**尚不覆盖**阈值顺序翻转、缺失码或未说明的 SAR 判决/端部规则。名义后端输入范围仍用于标记可能过载。若电路资料显示这些规则不同，须先修改码制模型，不能仅扩大某一条放大器输出区间。

**覆盖证明。**取任一满足已声明区间合同的静态电路与一次真实转换。真实 `x` 位于 `X`，其 `q1` 必在上述索引范围；其 `x` 也在对应第一分支的闭输入范围内，因此真实 `w1` 位于 `W1`。由 `G1m/G1a` 的覆盖前提，真实主/辅输出分别属于 `R1m/R1a`；同理真实 `q2` 被枚举，真实 `w2` 属于对应 `W2`，真实第二级主输出属于 `R2m`，SAR 码属于所列整数范围。因此真实三字段数字观测在枚举集合中。若两路数字 dither 标签与本次模拟注入正确对齐、数字系数冻结，逐观测校正后的真实最终码落在枚举值的最小和最大之间。重复到整段记录后，[有限记录性能界限](FINITE_RECORD_PERFORMANCE_BOUNDS_V1.md)可直接使用这些最终码区间。证明不要求模拟传输为 PWL 或单调；所需的是每个 `G` 的覆盖性和已声明码制。

## 实现、验证和适用边界

- [独立理论传播器](../../src/adc_research/theory/static_observation_reachability.py)只接收区间、阈值、CDAC/后端候选几何及三条输出范围函数，不导入逐样本实验平台或 Gu 更新代码。[离线 Gu 评分连接](../../src/adc_research/evaluation/full_chain_code_envelope.py)再按 EXP-023 的最近偶数舍入与裁剪规则计算最终整数码上下界。在线算法仍只看到数字观测。
- 测试用独立逐样本平台核对了上述辅路跨阈值例子、第一判决阈值附近的 101 个输入点、两种第一阶段阈值扰动、两级 CDAC 电平端点组合及 SAR 全局阈值偏移；末级 `0` 阈值在 `[-0.001,0.001]` 时，固定末级输入 `0` 保留中心码 `-1/0`、最终码 `2047/2048`。另以 128 点相干正弦比较两条独立辅路测试曲线，逐点最终码及两条 SNDR/SFDR 都落在条件性界限内。这些检查只证明程序与指定候选相容，**不证明**区间函数覆盖真实芯片。
- 输出同时标记第一级输入、第一级主路和末级输入的可能过载，以及第二级辅路超出名义分析域。若数字校正函数仍有定义，即使模拟过载也能计算候选模型的裁剪码；该码不能被当作可校正的模拟信息。
- 若某个可能观测越过候选数字 PWL 的定义域，离线评分会报错并停止给码范围；必须先明确硬件在该状态的实际端部/饱和规则，不能丢掉该分支后继续声称覆盖。辅路超出名义分析域与主路物理过载是不同标记。
- 本传播器自身限于静态单次转换；冻结系数评分是一个用法。[短记录在线连接](STATIC_ANALOG_TO_ONLINE_CODE_BOUNDS_V1.md)现可把各次观测集合交给逐转换 Gu 候选，传播系数与整段码历史。噪声或动态历史只有在给出的 `G` 已明确覆盖它们时才可条件性使用；真实时间状态与四路抽取时序仍未建模。若 `G` 只由稀疏扫描拟合而无网格间导数/误差保证，本定理的前提尚未满足。
- 不同分支、不同采样的同一物理参数关系被放宽，因此得到的最终码及频谱范围可能很宽。若上界为无穷，应报告所缺约束，不能把两条合成曲线的最值当成芯片范围。

实际电路数据怎样获得覆盖性 `G`，见[物理范围取证门槛](../stages/02_end_to_end_theory/PHYSICAL_ENVELOPE_EVIDENCE_GATE_V1.md)。目前仓库没有满足该门槛的主辅波形、阈值和动态记录，故尚无物理 SNDR/SFDR 范围。

若已取得每条路径的有限扫描与有依据的最大斜率，[网格到连续范围](GRID_TO_ANALOG_ENVELOPE_V1.md)给出构造 `G` 的一种方法；它拒绝扫描域外的查询，不以样点间割线代替斜率证据。

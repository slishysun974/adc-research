# 两级共同零点、量化请求与局部稳定性

> 2026-10-09。接续[后级零点族](RELEASED_THIRD_ROOT_SEGMENTS_V1.md)。本轮将前级方程接入，并分别检查连续平均模型、整数平均请求、独立窗口请求与离线输出质量。原Gu核心和RTL不改。

接入前级后，内部相关量仍不能选出唯一校正系数。本轮认证17份局部曲线证书：每份范围内，两级八个相关量同时为零。量化后的对应状态却没有整数平均不动点。同一后级参数下，两个前级平均零点都局部稳定，冻结正弦SNDR仍相差16.97 dB。这些结果只属于给定数字记录及声明的候选模型。

## 1. 前级方程沿后级参数变化

后级四系数为`k₂(h)=a₂h+b₂`，第四项固定为1。前级第三、第四项也固定为1，前两项u、v自由。后级线段及其四相关量为零的性质由EXP-045另行认证。

对每条固定数字观测，前级原始码为

\[
r_{1,n}(h)=128q_{2,n}+\sum_j k_{2,j}(h)\psi_{2,j,n}-d_{2,n}
=\alpha_nh+\beta_n.
\]

在前级数字PWL分段范围内，每个基函数也是h的一次函数。若前级门集合保持，则前两个相关方程为

\[
C_{1,i}=A_{i0}(h)u+A_{i1}(h)v+b_i(h)=0,\quad i=0,1,
\]

其中A、b对h仿射。因此

\[
u(h)=\frac{A_{01}b_1-A_{11}b_0}{\Delta(h)},\qquad
v(h)=\frac{A_{10}b_0-A_{00}b_1}{\Delta(h)},
\]

\[
\Delta(h)=A_{00}A_{11}-A_{01}A_{10}.
\]

分子、分母次数至多为2。实现用`t=h−h₀`表示多项式以减少区间计算的保守性；全部系数为有理数。前两相关量的分子代入后恒为零；第三、第四相关量另检查，不能自动略去。

## 2. 整段认证条件

必须同时保证：后级h仍在已认证线段内；Δ不含零；u、v严格在(0,2)内；前级raw不进入未定义域；各数字基函数表达式保持有效；全部门按原`≥`语义保持。

基函数在分段交点连续，故有效表达式可包括相邻分段的共同端点；正满量程仍排除，负满量程遵循既有连续延伸定义。门的开／闭条件以有理函数分子和Δ的包含区间检验。恒等于门限的开门通过多项式恒等式保护，不改称普通全空间开邻域。

初始半宽为1/1024，并受后级线段端点距离限制；依次尝试对称、右侧、左侧范围，最多60次减半。本轮17个种子全部在第一次对称范围通过。每个范围半宽1/1024，八个相关量恒为零，另以两端及中点共51个有理数点独立核对。

这是局部存在证明，不是全部两级解的枚举。17份证书可能属于同一曲线的重叠部分，不应称17条不同全局分支。两组直接保持没有已认证后级族，本轮没有据此判断其前级无解。

## 3. 两级同时零相关仍保留中性方向

沿认证曲线，后级第三参数h改变，前级u(h)、v(h)补偿，两级的八个经验相关量均零。故连续平均更新在曲线上每一点都保持。包含曲线上两个不同点的集合不能严格收缩到唯一点；这不判断所有其他方向的稳定性。

连续经验平均是这批拟合记录的条件模型，不是未知总体期望，也不是实际下一窗口。这里的中性方向不能直接等同于Q22状态波动或芯片的收敛失败。

## 4. 量化后并不存在同样的不动点

分别将曲线上系数舍入为Q22初始状态，再按原最近偶数规则导出Q1.10系数，以Q3数据路径计算相关量。

对每个局部曲线范围，先用有理函数区间包含八个系数值，再由单调舍入包含Q22状态和可能导出码。逐个枚举导出码的笛卡尔积会加入不可同时出现的组合，但不会漏掉曲线量化后的真实组合。

17份范围共测试60个导出组合。全部组合均排除整数平均不动状态：每组至少一坐标仍有非零实际变化，饱和端点也单独检查。因此这些曲线上的合法最近Q22初值，不能直接成为这个整数平均诊断的不动点。

该诊断把11520条记录的相关均值乘120转换的原步长，不是实际120条窗口。另一方面，每个量化种子独立冻结于原96窗口，1632组窗口全部有非零请求；首末窗口共34组另由原四路更新器核对。没有把这些请求连续提交后重新训练，也没有证明未来轨迹发散或周期长度。

## 5. 固定后级时的前级局部稳定性

在一个共同零点固定后级，仅扰动前级u、v。先证明门保持且前级高段门都闭，因此这二维方向空间在连续经验均值下封闭。其转移矩阵为

\[
M=I-\operatorname{diag}(\eta_0,\eta_1)A_F.
\]

离散线性稳定与特征值模的关系可参照[Stanford EE263，第34页](https://ee263.stanford.edu/archive/eig.pdf)。本轮针对2×2矩阵，用精确有理数检验

\[
p(1)=1-\operatorname{tr}M+\det M>0,\quad
p(-1)=1+\operatorname{tr}M+\det M>0,\quad
1-\det M>0.
\]

证明：复共轭根的模平方等于det M；实根时，前两条件分别排除跨越1和−1，第三条件排除两根都在外侧。三条件等价于两根严格在单位圆内。门邻域内映射精确仿射，因此存在足够小的初始邻域使前级扰动衰减。这个邻域不能任意等同于整个门保护矩形。

17个种子全通过此二维稳定判据。13个另有无穷范数小于1；其余4个该范数略大于1，仍不能判作不稳定。本结论仅针对固定后级的前级二维平均映射；沿共同曲线仍有中性方向，全部八状态、整数算术和时变窗口的稳定性没有因此解决。

## 6. 稳定与输出质量并非同一目标

周期复位条件的同一个后级参数`h≈1.148805727`，有两组前级系数：

| 项目 | 分支A | 分支B |
|---|---:|---:|
| 前级第一系数 | 0.966414336 | 0.227354521 |
| 前级第二系数 | 0.998817651 | 1.998622307 |
| 连续八相关量 | 全零 | 全零 |
| 前级二维局部稳定 | 是 | 是 |
| 量化冻结正弦平均绝对码误差 | 6.857031 | 49.533333 |
| 量化冻结正弦SNDR | 43.380377 dB | 26.407557 dB |

两者使用同一3840点数字正弦记录、同一后级系数及同一Q1.10／Q3评分。前级稳定性属于连续平均模型；输出属于量化冻结评分，不能把它们称作同一个整数稳定点。SNDR差16.972820 dB，且均无最终码裁剪。FFT为浮点评估，未数值认证；也未证明单位冷启动会进入较差分支。

理想目标仅用于离线评分，不进入曲线求解、稳定性或请求计算。全部种子保留，不按性能挑选最优根后宣称原更新能够选择它。

## 7. 下一项

优先解释同一后级的两组前级稳定解为何出现：分别统计门选中了哪些样本、哪些样本不读取被更新的那段系数，以及信号项与校正误差项如何抵消。随后明确区分正确目标所需的观测或输入／dither条件。暂不通过延长训练、随意换步长或提高位宽代替目标研究。

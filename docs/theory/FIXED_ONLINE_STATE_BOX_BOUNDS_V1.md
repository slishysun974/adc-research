# 定点 Gu 在线状态的整数区间传播

> 2026-10-04，阶段二条件性结果。对象是 EXP-032 明示的逐转换、Q1.10/Q3、Q22 累加器 Gu **数字候选**。本方法避免保存指数数量的短记录路径；它不证明论文芯片采用该数值规则，也不提供芯片模拟范围。

## 结论

若每次转换的五字段数字观测都在给定有限集合内，且初始八个定点系数累加器在给定整数区间内，可逐次算出覆盖所有候选历史的累加器区间和最终整数码区间。每次转换后，把不同观测分支的状态按每个累加器取最小与最大值。下一次用这个较大的状态集合继续计算。这样会加入原本不可能同时出现的系数组合，但不会丢掉任何按此候选规则运行的实际状态。

输出码区间可输入已有的[有限记录 SNDR/SFDR 界限](FINITE_RECORD_PERFORMANCE_BOUNDS_V1.md)和[逐频点 SFDR 界限](BINWISE_SFDR_BOUNDS_V1.md)。得到的是**条件性充分界限**：数字观测集合若没有物理覆盖依据，指标数字没有芯片含义；区间若太宽，界限也可能没有实际用途。

## 一次转换怎样传播

令第 `i` 个 Q22 累加器在 `[A_i^-,A_i^+]` 内。先按候选的最近偶数规则，把两端输出为 Q1.10 系数端点。由于该舍入对非负整数单调，每个真实 Q1.10 系数必落在对应端点之间。

对于一个固定原始数字码，四段数字 PWL 的校正输出对每个非负系数的**幅值**单调。若原始码也在整数区间内，分段内的校正输出对原始码单调；因此检查码区间端点、零点及每个分段边界两侧，并分别代入系数下端与上端，即可覆盖这两个区间组合下的校正结果。代码不把模拟放大器假设成 PWL：这里分段的是数字校正函数。两级依次计算后，按最近偶数舍入和整数裁剪得到本次最终码区间。

更新时，用学习输出区间的绝对值范围与更新前系数形成的门限范围判断每段门控。若门控无法确定，同时纳入“更新”和“不更新”；对可能更新的情形，以学习输出两端求有理数步长的最小、最大定点增量。与旧累加器区间相加并在候选范围内饱和，形成下一状态区间。这一步放宽了学习输出、门限和累加器之间的相关性，但每一运算均向外包含真实的整数结果。门控计数等诊断字段不进入下一次校正或更新，所以状态范围只需保留八个累加器。

**归纳证明。**初始真实状态在输入整数区间内。若第 `n` 次以前被覆盖，真实观测必是该次集合中的一个元素；本次数字校正、输出舍入、门控、增量与饱和逐步被各自的区间覆盖，故真实最终码和下一状态被该分支覆盖。所有分支取区间并后，归纳条件对下一次成立。最后的逐样本最终码区间因而覆盖整段真实候选码流，即使不同次的误差和系数高度相关。

[实现](../../src/adc_research/evaluation/fixed_online_state_bounds.py)使用 Python 整数和 `Fraction` 步长完成状态运算，不依赖浮点近似；若放宽后的任何可能分支进入候选数字 PWL **未定义域**，它报出转换编号并停止，不能跳过后继续声称覆盖。对固定四段和每次有限观测选择，计算量随记录长度线性增长；保存整段输出码上下界需要线性内存。这消除了完整历史枚举的指数存储，但不保证范围在长记录中仍窄。后续 FFT 的浮点计算也尚无数值向外舍入证书。

## 验证与可复核例子

[测试](../../tests/test_fixed_online_state_bounds.py)先在一个小整数 PWL 上穷举原始码与系数矩形，核对分段端点给出的极值；再对四条完整的两级定点在线历史逐次独立执行现有参考，实现的码区间和最终八个状态区间均包含它们。另一组 `256` 次静态模拟区间经主辅路径和末级量化，逐次给出两种候选数字观测；两条固定选择轨迹也被最终区间包含。无效数字分支会停止计算。

[EXP-033](../reports/experiments/EXP_033_FIXED_ONLINE_BOX_V1.md)用 `512` 点相干合成数字记录，每次各有两个末级码选择。记录不要求穷举最多 `2^512` 条历史；所有最终码区间仍仅宽 `1` 码。Parseval SNDR 下界为 `26.555 dB`，逐频点 SFDR 下界为 `30.891 dBc`；两条特意抽取的全程固定选择轨迹均被覆盖。该数值是对**给定数字观测集合及所选 Q22 候选**的条件计算，不是目标芯片预测。真实允许历史的性能极值没有通过两条端点轨迹确定。

## 仍缺什么

1. 当前上游只知道怎样在有覆盖性主辅模拟输出范围时生成逐次观测集合；仓库还没有符合[电路取证门槛](../stages/02_end_to_end_theory/PHYSICAL_ENVELOPE_EVIDENCE_GATE_V1.md)的芯片数据。实验的数字二选一记录由研究者设定。
2. 真实四路抽取、门控相关量聚合及系数广播周期未公开；本转移只适用于 EXP-032 的逐转换数值候选。若实际实现不同，须换状态转移和证明。
3. 每次合并会丢失同一电路参数、各系数与码历史之间的相关性。某些记录可能使状态范围跨出数字定义域或指标界限变宽，程序会报告无法继续或不足以判定；这不是实际芯片失效概率。
4. 虽然状态传播使用精确整数，来自模拟扫描的浮点区间、阈值比较和 FFT 仍需数值向外保护。还需动态历史的覆盖依据，不能将静态区间直接解释为采样建立过程。

# 数字后台校准影响理论

保存校准参数动态、统计学习假设审计、频谱/指标传播和干预分析等理论内容。该目录不用于存放运行结果。

当前已验证的基础语义：

- `gated_lms.py` 实现 Gu Eq. (5)-(7) 的浮点、下门限-only、自适应阈值更新；
- EXP-009 证明 truth slice occupancy 与 LMS 有效更新次数必须分开报告；
- 零 gate count 的系数不可辨识，必须冻结或增加受控持续激励。
- EXP-011 证明在一阶平均步长按抽取倍数归一化时，保留单个瞬时相关样本会把
  系数方差提高约一个抽取倍数；使用同长度的分块平均相关量可恢复接近逐样本
  更新的方差。该结论是局部浮点行为结果，不代表论文芯片的系数提取时序。
- EXP-012 实现论文报告的 11-bit、10 个小数位 PWL 系数和 3 个小数位校正
  数据通路。乘法缩位采用舍入到最近偶数时误差较低，但舍入规则和中间总位宽
  仍是行为级配置，不是已确认的芯片实现。
- EXP-013 将 Q1.10 系数接口与 LMS 更新累加器分开。当前步长下，10 个累加器
  小数位使全部更新舍入为零；22 和 26 个小数位的内部 Q3 MAE 分别为
  `0.31439/0.30896` code。累加器分辨率、舍入和饱和均为研究配置，不能解释为
  论文芯片的定点实现。

# 正常初值窗口更新与最终码影响

> 2026-10-10。本文给出EXP-049的有限记录恒等式。它使用既有Gu定点候选和旧系数冻结窗口，不建立总体收敛或芯片适用性结论。

## 实际门下的目标与误差分解

例如一个样本的理想整数码为2056，前级粗码为0，输出偏置为2048，则前级局部学习输出应对应8码。Q3格式用整数64表示这个目标。假如实际局部输出为10码，那么Gu相关乘积同时包含这8码目标及2码误差。

记窗口旧状态为$a_w$，窗口选样集合为$S_w$，前级Q3局部学习整数为$Y_n$，数字dither副本为$D_n$。门$G_{n,i}$由该窗口的旧导出系数决定，包括实际Q3舍入和门等值规则。离线理想整数码$c_n^*$按既定输入量化得到，定义

\[
T_n=8c_n^*-16384-4096q_{1,n},\qquad E_n=Y_n-T_n.
\]

其中$q_{1,n}$是前级粗判决。这个目标是在最终整数码口径下定义，已含理想量化，不将$E_n$全部称为模拟非线性。真实输入和$c_n^*$均不交给在线学习器。

在实际门和实际选样下有精确恒等式

\[
P_{w,i}=\sum_{n\in S_w}D_nY_nG_{n,i}
=\underbrace{\sum_{n\in S_w}D_nT_nG_{n,i}}_{P^T_{w,i}}
+\underbrace{\sum_{n\in S_w}D_nE_nG_{n,i}}_{P^E_{w,i}}.
\]

设完整聚合的$m_w=1$，点抽取的$m_w=30$，基础步长为$\mu_i$。舍入前Q22请求为

\[
U_{w,i}=-\mu_i m_w 2^{22}P_{w,i}/8^2
=U^T_{w,i}+U^E_{w,i}.
\]

最近偶数舍入后请求$R_{w,i}$，饱和后应用$A_{w,i}$。令$r=R-U$、$s=A-R$，则

\[
a_{w+1,i}-a_{w,i}=U^T_{w,i}+U^E_{w,i}+r_{w,i}+s_{w,i},\quad |r_{w,i}|\le\tfrac12.
\]

沿任意有限连续窗口求和，右侧精确复原累计状态变化。这不要求输入与dither独立，也不预设相关量归零。若$P^T$与$P^E$相反、总和又与$P^E$相反，说明实际请求方向被目标项改变；**误差相关项本身也不是最终码均方误差的梯度**，故不由此断言该步必然损害输出。

## 门支撑与抽取分别核算

前级原始Q3码为$R_n$，段宽为1024。第$i$个数字PWL基函数在$|R_n|\le i\cdot1024$时为零，其中$i=0,1,2,3$。门打开而该基函数为零，只说明在冻结原始码条件下该行不随自身段斜率改变；它仍能向该系数贡献更新，也可能影响其他系数。门变化、后级变化和Q3分段边界另行保留，不把门支撑当作完整梯度。

在同一旧状态下计算全部120条的相关和$P^{\rm all}$，再比较$mP^{\rm selected}-P^{\rm all}$。这隔离当前选样差；原完整聚合与点抽取长期使用不同状态，直接比较它们的原始相关和则还包含状态差。

## 最终整数码与冻结干预

未裁剪的输出Q3整数满足$Z_n=8c_n^*+E_n$，因此实际最终码误差为

\[
c_n-c_n^*=E_n/8+\rho_n+\ell_n,
\]

其中$\rho_n=\operatorname{round}_{\rm even}(Z_n/8)-Z_n/8$，$|\rho_n|\le1/2$；$\ell_n$是随后12位裁剪造成的差。代码直接评分最后整数码，避免用内部局部误差代替最终性能。

同一窗口分别用旧状态、仅换后级状态、两级均换新状态冻结评分。其整数误差平方和差严格相加，但前后级分项取决于干预顺序。这里没有把新状态提前投入真实闭环；这是一次更新在同一批观测上的局部检查。

对训练后的整段正弦，进一步固定同一数字观测，逐窗口构造四种状态组合：训练终点两级均固定、仅前级用实际当前状态、仅后级用当前状态、两级用当前状态。对应误差平方和为$L_{00},L_{10},L_{01},L_{11}$，有

\[
L_{11}-L_{00}=(L_{10}-L_{00})+(L_{01}-L_{00})
+(L_{11}-L_{10}-L_{01}+L_{00}).
\]

最后一项明确保留两级交互。它是指定状态干预的有限记录效应，不证明“信号污染”单独造成了全部损失，也不将SNDR分贝差作同样加法。

## 验证对象和开放部分

EXP-049从单位初值回放已有记录，再按运行前固定的八组新人工条件验证。理想目标只用于离线归因和最终评分；原数字更新、步长、位宽、RTL保持不变。独立标量实现从数字样本重算两级PWL、最近偶数舍入、实际门、请求和八状态，核对在线整数码。FFT为普通浮点近似。

新的三次曲线参数并不覆盖任意平滑传输，两个输入／dither种子不提供失效概率。有限路径没有到达较差平均根，不证明未来或其他输入不可能到达。正常路径中的信号项、选样方差、输入变化和目标偏差仍需用控制实验分别检查。

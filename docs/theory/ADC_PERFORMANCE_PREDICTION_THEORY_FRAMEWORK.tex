\begin{abstract}
本文建立一条从流水线 ADC 结构到性能指标的可解释理论链。ADC 首先被表示为
带离散判决路径和连续内部状态的混合系统；在静态极限下，逐级判决与 residue
传播与局部分段边界把输入域划分为细化路径胞腔，每个胞腔内部具有确定的仿射或
光滑映射。码宽、DNL、累计码密度偏差、单调条件下的转换电平 INL、缺失码与
不可纠正测度由这些胞腔的测度导出。对周期输入，输入胞腔
的相位原像给出精确的傅里叶系数，从而把码域边界连接到确定性谱线和 ADC 性能
泛函。动态层从连续时间建立方程推导离散状态递推、唯一周期稳态及静态极限，
并把采样时差、随机抖动、孔径和弱非线性记忆放在相互可区分的物理入口中。

阶段三把校准表示为扩展闭环。本文从随机逼近的局部误差动力学推导校准状态的
均值和协方差，再通过本项目提出的“边界--内部谱灵敏度分解”传播到谱线与性能。
该分解同时计算区域内部映射变化和判决边界移动，避免用单一光滑 Jacobian 覆盖
量化跳变。文中明确区分直接借用的成熟理论、针对流水线 ADC 的适配结果，以及
尚待外部验证的项目工作理论。
\end{abstract}

\section{问题、证据和理论架构}

\subsection{需要被预测的对象}

本课题研究的不是一个从器件参数到 SNDR 或 SFDR 的黑箱函数，而是一组按因果
顺序连接的数学对象。设连续时间输入为 $x(t)$，第 $n$ 个采样对应的外部输入为
$x_n$，固定物理参数为 $\theta$，环境或慢变参数为 $e_n$，内部模拟状态为
$z_n$，离散判决路径为 $p_n$，未启用数字后台校正时的最终码为 $y_n$。
无校准 ADC 本体写为

\begin{align}
  p_n &= \mathcal P(x_n,z_n;\theta,e_n), \label{eq:path-select}\\
  z_{n+1} &= \mathcal F_{p_n}(z_n,x_n;\theta,e_n), \label{eq:state-map}\\
  y_n &= \mathcal H_{p_n}(z_n,x_n;\theta,e_n). \label{eq:output-map}
\end{align}

输出过程 $Y=\{y_n\}$ 通过频谱算子 $\mathcal S_\Pi$ 和性能泛函
$\Psi_\Pi$ 形成

\begin{equation}
  S_Y=\mathcal S_\Pi[Y],
  \qquad
  \mathcal J=\Psi_\Pi(S_Y),
  \label{eq:metric-chain}
\end{equation}

其中 $\Pi$ 是观测协议，包含记录长度、相干条件、窗函数、积分带宽、基波与谐波
集合。IEEE 1241 给出 ADC 术语和测试方法的标准化边界
\cite{IEEE1241_2023}；但测试标准本身不是器件性能的生成理论。因此本框架始终
区分 ADC 本体 $\mathcal G_\theta=(\mathcal P,\mathcal F,\mathcal H)$ 与观测
协议 $\Pi$。

\section{已有理论的适配性审查}

\subsection{量化谱与统计量化理论}

Bennett 对量化信号频谱的经典分析说明：确定性量化误差可以形成与输入相关的谱线，
不能天然等同于白噪声 \cite{Bennett1948QuantizedSpectra}。对正弦量化，后续工作
进一步给出了谐波与 SFDR 的解析关系
\cite{Blachman1985QuantizedSinusoids,OudeAlink2009SFDR}。Widrow 等人以输入
特征函数为基础给出统计量化定理，并明确了加性均匀白噪声模型成立所需的条件
\cite{Widrow1996StatisticalQuantization,Gray1998Quantization}。

这些理论对本项目的适配关系如下。

\begin{itemize}
  \item 对相干单音和固定 ADC 参数，输出是确定性周期码序列，应先计算精确谱线；
  \item 对具有适当随机性、高分辨率或满足特征函数条件的输入，才可以使用统计量化近似；
  \item Gu 架构不是单个均匀量化器，而是多个判决、residue 与数字重构的组合，
        因此其等效阈值必须先从结构中推出，不能预先假定理想均匀阶梯。
\end{itemize}

Schuchman 条件说明，在无过载的减性 dither 量化中，适当 dither 的特征函数在
量化频率的非零整数倍处为零时，量化误差可以与输入独立
\cite{Schuchman1964Dither}。本项目中的校准 dither 同时进入模拟结构、参数观测
和数字抵消，因而不能仅凭“使用了 dither”就套用独立白噪声结论。

\subsection{分段仿射与混合系统}

Sontag 的分段线性系统以有限多面体分区上的仿射状态和输出映射描述非线性系统
\cite{Sontag1981PiecewiseLinear}。这与流水线 ADC 的判决路径天然相容：固定路径
内 residue 传播常为仿射或分段仿射，路径切换由阈值不等式决定。

但通用分段仿射理论不会自动给出：

\begin{enumerate}
  \item 逐级数字重构权重为何使不同内部路径等价；
  \item 边界移动如何改变 DNL、INL 和频谱；
  \item 可纠正域和模拟过载域如何区分；
  \item 相干采样协议如何把连续周期谱映射为有限记录指标。
\end{enumerate}

因此本文借用“胞腔内仿射、边界处切换”的语言，但路径胞腔递归、冗余等价类和
边界到频谱的映射属于针对流水线 ADC 的适配理论。

\subsection{带记忆非线性与 Volterra 理论}

Boyd 和 Chua 证明，满足连续性和衰减记忆条件的时不变非线性算子可以由 Volterra
类算子逼近 \cite{Boyd1985FadingMemory}。Kautz--Volterra 模型也已被用于 ADC
动态误差与后校正 \cite{Bjorsell2010KautzVolterraADC}。这些结果说明 Volterra
框架适合描述输入缓冲器、采样网络或放大器中的弱非线性记忆。

其直接套用于整台流水线 ADC 存在两个问题：

\begin{itemize}
  \item 理想量化器本身不连续，不满足全局光滑弱非线性假设；
  \item 判决边界附近的有限小参数变化可以触发有限码跳变，有限阶光滑核展开不能
        自动表示这种边界贡献。
\end{itemize}

因此本文只把 Volterra 或其他衰减记忆算子放在\textbf{硬判决之前的模拟子块}，
再由混合系统路径映射把其输出传入量化结构。它是动态模拟前端的候选局部模型，
不是整机理论的替代品。

\subsection{采样抖动、孔径与随机逼近}

采样抖动通过输入斜率产生误差，有限孔径相当于采样窗口滤波；两者可以共同分析
\cite{Kobayashi2002JitterAperture}。这为 SHA-less 路径的采样时差、随机抖动和
孔径效应提供成熟入口，但仍需连接到后续判决边界。

阶段三的参数更新属于随机逼近问题。Robbins--Monro 理论建立了在带噪观测下求
未知均值方程根的递推框架 \cite{Robbins1951StochasticApproximation}，Widrow
和 Hoff 的工作奠定了 LMS 自适应更新 \cite{Widrow1960AdaptiveSwitching}。
这些理论只能在均值场、持续激励、稳定性、步长和噪声条件可审计时使用。尤其是
校准系数均方误差不是 ADC 性能；还必须把系数分布穿过硬判决边界传播到频谱。

\section{流水线 ADC 的逐级数学对象}

\subsection{\texorpdfstring{一般 $L$ 级结构}{一般 L 级结构}}

设 $v_{0,n}=x_n$。前 $L-1$ 级各含辅助判决路径、主 residue 路径和可选附加
激励。第 $i$ 级定义为

\begin{align}
  s_{i,n} &= a_i v_{i-1,n}+o_i, \label{eq:aux-path}\\
  q_{i,n} &= Q_i(s_{i,n};\tau_i), \label{eq:stage-decision}\\
  u_{i,n} &= A_i\!\left(v_{i-1,n}
                -D_i(q_{i,n};\theta_{D,i})+d_{i,n};
                \theta_{A,i}\right), \label{eq:static-residue-target}\\
  v_{i,n} &= \mathcal M_i(u_{i,n},z_{i,n};\theta_{M,i}), \label{eq:dynamic-residue}\\
  z_{i,n+1} &= \mathcal T_i(u_{i,n},z_{i,n};\theta_{M,i}). \label{eq:stage-state}
\end{align}

$Q_i$ 是阈值集合 $\tau_i$ 定义的有限状态判决；$D_i$ 是 CDAC 重构；
$A_i$ 表示物理放大器未知静态传输 $g_i$ 的模型；$\mathcal M_i,\mathcal T_i$ 描述有限建立或
记忆。最后一级量化器给出 $b_n=Q_L(v_{L-1,n})$，数字输出为

\begin{equation}
  y_n=\mathcal R(q_{1,n},\ldots,q_{L-1,n},b_n)
      -\sum_{i=1}^{L-1}\Gamma_i d_{i,n}^{(\mathrm{dig})}.
  \label{eq:digital-reconstruction}
\end{equation}

式 \eqref{eq:digital-reconstruction} 中的减法是已注入模拟 dither 的数字副本，
并非要保留在输出中的附加信号。Gu 架构的前两级、后端 TI-SAR、
\emph{量化之后的数字 PWL 非线性校正}和 gated-LMS 关系由原始论文给出
\cite{Gu2026PipelinedADC,Gu2025GatedLMS}。数字校正函数 $f_i$ 与未知模拟
传输 $g_i$ 是不同对象；前者不属于放大器电路。本文使用一般 $L$ 级符号，
Gu 架构是 $L=3$ 的主要实例。

\subsection{Gu 候选 A 的理想 dither 抵消}

为看清最终码为何显式减去 dither，考虑无模拟误差、无过载和无数字裁剪的
候选 A。令两个前级模拟注入量为 $d_1,d_2$，理想 residue 与末级 centered
SAR 码满足

\begin{align}
  r_1&=4(x-q_1/4+d_1),\\
  r_2&=4(r_1-q_2/4+d_2),\\
  c_3&=\lfloor128r_2\rfloor.
\end{align}

因此

\begin{equation}
  512q_1+128q_2+c_3
  =\lfloor2048x+2048d_1+512d_2\rfloor.
  \label{eq:gu-raw-dither}
\end{equation}

冻结的 dither 档位使数字副本 $D_1^{(\mathrm{dig})}=2048d_1$、
$D_2^{(\mathrm{dig})}=512d_2$ 为整数，故利用
$\lfloor u+k\rfloor-k=\lfloor u\rfloor$，未启用数字 PWL 校正的输出为

\begin{equation}
  y^{(0)}=512q_1+128q_2+c_3-D_1^{(\mathrm{dig})}
    -D_2^{(\mathrm{dig})}+2048
  =\lfloor2048x\rfloor+2048.
  \label{eq:gu-ideal-dither-cancel}
\end{equation}

该恒等式说明：在这些明确条件下，输出不含所注入的 dither，公式中的数字减法
正是抵消步骤。非线性、校正误差、量化规则不匹配或过载会破坏这些条件，残余的
dither 相关误差成为后台校准可利用的观测量。启用数字 PWL 后，局部减法须按
校正级联的顺序进行，不能把式 \eqref{eq:gu-ideal-dither-cancel} 当作校正后链路的
一般运算式。

\subsection{判决路径与路径胞腔}

将前级判决、各级局部模拟模型分段和末级量化结果组成完整路径。令
$\sigma_i$ 为第 $i$ 级模拟静态映射 $A_i$ 在分段仿射\emph{模型}中的
局部分段标签，
$J_{i,\sigma_i}$ 为该分段的输入域，且
$w_i=v_{i-1}-D_i(q_i)+d_i$。在不需要分段的级，$\sigma_i$ 只有一个取值。
完整路径记为

\begin{equation}
  p=(q_1,\sigma_1,\ldots,q_{L-1},\sigma_{L-1},b).
\end{equation}

在静态情形 $v_i=u_i$ 下，路径 $p$ 对应的输入集合为

\begin{equation}
  \mathcal C_p(\theta)
  =
  \left\{x\in\mathcal D:\;
  \begin{aligned}
    &\tau_{i,q_i}^{-}\le a_i v_{i-1}(x;p,\theta)+o_i
      <\tau_{i,q_i}^{+},\quad
      w_i(x;p,\theta)\in J_{i,\sigma_i},\quad i<L;\\
    &\tau_{L,b}^{-}\le v_{L-1}(x;p,\theta)<\tau_{L,b}^{+}
  \end{aligned}\right\}.
  \label{eq:path-cell}
\end{equation}

这里 $v_{i-1}(x;p,\theta)$ 是假定前序路径和局部分段已固定后得到的内部值；
$\tau_{L,b}^{\pm}$ 是末级量化器的码区间端点。路径胞腔由所有后级判决及局部
分段不等式向原输入域的递归原像共同确定。同一判决码路径可能跨越所选模拟
近似模型的拐点，此时必须进一步细分，不能在未细分的整条判决路径上宣称
仿射闭包。$\sigma_i$ 不是后续数字校正函数 $f_i$ 的 PWL 段号；真实放大器
$g_i$ 也不因此被断言为物理上恰好分段线性。

\begin{definition}[结构路径胞腔]
对固定参数 $\theta$，满足式 \eqref{eq:path-cell} 的最大连通输入集合称为路径
胞腔。若不同路径在数字重构后给出同一输出码，则这些路径胞腔属于同一重构等价类。
\end{definition}

\begin{proposition}[静态路径胞腔内的仿射闭包]
若每级辅助路径、CDAC 和所选模拟放大映射模型在路径 $p$ 指定的分段内均为
仿射映射，则
对任意非空路径胞腔 $\mathcal C_p$，所有内部 residue 均是输入 $x$ 的仿射函数；
固定末级码后的未裁剪数字输出为常数。
\end{proposition}

\begin{proof}
第一级判决与局部分段固定后，$D_1(q_1)$ 为常数；所选模拟映射分段为仿射映射，因此
$v_1(x)=\alpha_{1,p}x+\beta_{1,p}$。假设第 $i-1$ 级 residue 为
$v_{i-1}(x)=\alpha_{i-1,p}x+\beta_{i-1,p}$，则第 $i$ 级 CDAC 在固定
$q_i$ 下仍为常数，所选局部分段与仿射输入的复合仍为仿射函数。由数学归纳法，
所有前级 residue 均为仿射函数。末级码 $b$ 在路径胞腔内固定，数字重构
是有限个固定码与权重的组合，因此未裁剪数字输出在该胞腔内为常数。证毕。
\end{proof}

这个命题借用了分段仿射系统的闭包性质，但“逐级路径胞腔”及其与数字冗余的结合
是本项目的结构化适配。若物理 $g_i$ 是一般平滑非线性，式
\eqref{eq:path-cell} 仍可定义原像，但上述\emph{精确}仿射闭包只适用于所选
分段仿射近似；对真实 $g_i$ 须传播非线性原像或给出近似误差界。

\subsection{数字冗余是路径等价关系}

考虑相邻两级的名义线性关系

\begin{equation}
  v_i=G_i\bigl(v_{i-1}-d_i(q_i)\bigr),
  \qquad
  y=W_i q_i+W_{i+1}\widehat v_i+\cdots .
\end{equation}

若后续数字表示 $\widehat v_i$ 的权重满足

\begin{equation}
  W_i\,\Delta q_i
  +
  W_{i+1}\,\Delta \widehat v_i
  =0
  \label{eq:redundancy-cancel}
\end{equation}

则边界两侧由不同 $q_i$ 引起的内部码变化在最终重构中抵消。式
\eqref{eq:redundancy-cancel} 是数字冗余的代数条件；模拟 residue 是否仍落入
后级量程、最终未裁剪码是否仍在允许输出范围内，则是独立的可纠正条件。于是

\begin{equation}
  \mathcal C_{\mathrm{safe}}
  =
  \bigcup_{p:\,\substack{\text{所有后级状态均未过载，}\\
                         \text{最终数字重构未裁剪}}}
  \mathcal C_p,
  \label{eq:safe-domain}
\end{equation}

而不是“所有最终码看起来连续的输入集合”。这一区分允许中间路径错误被数字冗余
吸收，同时仍显式报告冗余失效的输入测度。

\section{静态传输理论的完整推导}

\subsection{从逐级不等式得到输入分割}

在路径 $p$ 内，第 $i$ 级判决变量是

\begin{equation}
  s_i(x;p,\theta)
  =
  a_i\bigl(\alpha_{i-1,p}x+\beta_{i-1,p}\bigr)+o_i.
\end{equation}

每个前级判决条件
$\tau^-_{i,q_i}\le s_i<\tau^+_{i,q_i}$、局部分段条件
$w_i\in J_{i,\sigma_i}$ 以及末级码条件，都可在已固定的前序路径内化为关于
$x$ 的线性不等式。若
$a_i\alpha_{i-1,p}>0$，则

\begin{equation}
  \frac{\tau^-_{i,q_i}-o_i-a_i\beta_{i-1,p}}
       {a_i\alpha_{i-1,p}}
  \le x
  <
  \frac{\tau^+_{i,q_i}-o_i-a_i\beta_{i-1,p}}
       {a_i\alpha_{i-1,p}}.
  \label{eq:pullback-boundary}
\end{equation}

负斜率时不等号方向及端点开闭都会交换。一个路径胞腔是全部判决、局部分段
和输入定义域约束的交：

\begin{equation}
  \mathcal C_p
  =
  \mathcal D
  \cap
  \left(\bigcap_{i=1}^{L}\mathcal I^{(Q)}_{i,p}\right)
  \cap
  \left(\bigcap_{i=1}^{L-1}\mathcal I^{(A)}_{i,p}\right).
  \label{eq:cell-intersection}
\end{equation}

这里 $\mathcal I^{(Q)}$ 和 $\mathcal I^{(A)}$ 分别表示判决与局部模拟分段的
原像。一维输入下，$\mathcal C_p$ 是空集或区间；端点开闭由原不等式决定，
不能在负斜率扩展中一律写作左闭右开。当前已验证的静态预测器只处理正局部斜率。
含动态状态时，胞腔推广为 $(x,z)$ 空间中的多面体或分段光滑区域。
式 \eqref{eq:pullback-boundary} 说明后级阈值必须通过前级 residue 斜率反推到
原输入域。

\subsection{码区域、转换电平与码宽}

令最终整数码为 $k$，其输入原像为

\begin{equation}
  \mathcal B_k
  =
  \bigcup_{p:\,\mathcal R(p)=k}\mathcal C_p.
  \label{eq:code-preimage}
\end{equation}

在单调、无缺失码条件下，$\mathcal B_k=[T_k,T_{k+1})$，$T_k$ 是码转换
电平，码宽为

\begin{equation}
  w_k=T_{k+1}-T_k.
\end{equation}

若非单调或存在多个不相邻原像，码宽应推广为 Lebesgue 测度

\begin{equation}
  w_k=\lambda(\mathcal B_k).
  \label{eq:general-code-width}
\end{equation}

设理想 LSB 为 $\Delta$，则任意静态码映射均可定义码密度 DNL 和累计码密度偏差

\begin{align}
  \mathrm{DNL}_k
  &=\frac{w_k}{\Delta}-1, \label{eq:dnl}\\
  D_k^{(\mathrm{density})}
  &=\sum_{i<k}\mathrm{DNL}_i. \label{eq:density-cumulative}
\end{align}

仅当码区域按码序单调排列、转换电平 $T_k$ 有定义时，端点参考的转换电平 INL
才可由下式得到：
\begin{equation}
  \mathrm{INL}_k=D_k^{(\mathrm{density})}
  =\frac{T_k-T_k^{\mathrm{ideal}}}{\Delta}.
  \label{eq:inl}
\end{equation}
若另行去除 offset/gain，须明确所用参考直线。非单调传输的
$D_k^{(\mathrm{density})}$ 仍可计算，
但它不是物理转换电平 INL。例如三个等宽输入区间依次输出 $0,2,1$，累计码密度
偏差为零，却存在负向步。缺失码等价于 $w_k=0$；负向步则对应存在
$x_1<x_2$ 但 $q_\theta(x_1)>q_\theta(x_2)$。报告时必须同时列出码密度量与
单调性。

\subsection{不可纠正输入测度}

定义失效集合

\begin{equation}
  \mathcal U(\theta)
  =
  \mathcal D\setminus\mathcal C_{\mathrm{safe}}(\theta),
\end{equation}

其归一化测度

\begin{equation}
  \eta_{\mathrm{uncorr}}(\theta)
  =
  \frac{\lambda(\mathcal U(\theta))}
       {\lambda(\mathcal D)}
  \label{eq:uncorrectable-measure}
\end{equation}

是与输入网格无关的结构指标。网格实验只能估计该测度，不能定义它。这个定义也
说明“未观察到失效样本”不等于失效集合为空。

\section{从静态边界到精确频谱}

\subsection{正弦输入的相位原像}

令正弦输入为 $x(\varphi)=x_0+A\sin\varphi$，其中 $\varphi\in[0,2\pi)$。

对当前正局部斜率、左闭右开约定下的每个静态胞腔
$I_r=[\ell_r,u_r)$，定义相位原像

\begin{equation}
  \Phi_r
  =
  \{\varphi\in[0,2\pi):x(\varphi)\in I_r\}.
  \label{eq:phase-preimage}
\end{equation}

当 $|(\ell_r-x_0)/A|<1$ 时，边界相位由

\begin{equation}
  \varphi_{\ell,r}^{(1)}
  =\arcsin\frac{\ell_r-x_0}{A},
  \qquad
  \varphi_{\ell,r}^{(2)}
  =\pi-\varphi_{\ell,r}^{(1)}
  \pmod{2\pi}
\end{equation}

给出；上边界同理。将所有边界相位排序后，整个周期被划分成有限相位区间。
每个正测度区间内输出码固定为 $k_j$。单点端点不影响连续 Fourier 积分；若
扩展到负局部斜率并精确预测有限记录中恰落边界的样本，必须保留原判决的开闭规则，
不能一律以左闭右开区间查询。

\Needspace{6\baselineskip}
\subsection{傅里叶系数的闭式表达}

周期输出

\begin{equation}
  y(\varphi)=k_j,\qquad
  \varphi\in[\phi_j,\phi_{j+1})
\end{equation}

的复 Fourier 系数为

\begin{equation}
  c_m
  =
  \frac{1}{2\pi}
  \int_0^{2\pi}y(\varphi)e^{-\jj m\varphi}\dd\varphi.
  \label{eq:fourier-definition}
\end{equation}

对 $m=0$，

\begin{equation}
  c_0
  =
  \frac{1}{2\pi}
  \sum_j k_j(\phi_{j+1}-\phi_j).
  \label{eq:dc-closed}
\end{equation}

对 $m\ne0$，逐段积分得到

\begin{align}
  c_m
  &=
  \frac{1}{2\pi}
  \sum_j
  k_j
  \int_{\phi_j}^{\phi_{j+1}}
  e^{-\jj m\varphi}\dd\varphi \notag\\
  &=
  \frac{1}{2\pi\jj m}
  \sum_j
  k_j
  \left(
    e^{-\jj m\phi_j}
    -
    e^{-\jj m\phi_{j+1}}
  \right). \label{eq:fourier-closed}
\end{align}

式 \eqref{eq:fourier-closed} 是“结构边界到谱线”的核心桥梁：不需要把量化误差
假设为噪声，也不需要对输出波形作时间步进近似。相邻区间整理后还可写成跳变量形式

\begin{equation}
  c_m
  =
  \frac{1}{2\pi\jj m}
  \sum_j
  \Delta k_j e^{-\jj m\phi_j},
  \qquad
  \Delta k_j=k_j-k_{j-1},
  \quad m\ne0.
  \label{eq:jump-spectrum}
\end{equation}

因此每个谱线由所有码跳变的幅度、相位和相干叠加共同决定。单个 DNL 最大值通常
不足以预测 SFDR，因为不同边界贡献可能相消或相长。

\subsection{功率恒等式与性能泛函}

由 Parseval 恒等式，

\begin{equation}
  P_{\mathrm{tot}}
  =
  \frac{1}{2\pi}\int_0^{2\pi}|y(\varphi)|^2\dd\varphi
  =
  \sum_{m=-\infty}^{\infty}|c_m|^2.
  \label{eq:parseval}
\end{equation}

对实输出，$c_{-m}=c_m^\ast$。去除 DC 后的总交流功率为

\begin{equation}
  P_{\mathrm{ac}}=P_{\mathrm{tot}}-|c_0|^2.
\end{equation}

若基波集合为 $\mathcal F$、谐波集合为 $\mathcal H$，则连续周期口径可写为

\begin{align}
  P_{\mathrm{sig}} &= \sum_{m\in\mathcal F}|c_m|^2,\\
  P_{\mathrm{harm}} &= \sum_{m\in\mathcal H}|c_m|^2,\\
  P_{\mathrm{rest}} &= P_{\mathrm{ac}}-P_{\mathrm{sig}},\\
  \mathrm{SNDR} &= 10\log_{10}\frac{P_{\mathrm{sig}}}{P_{\mathrm{rest}}},\\
  \mathrm{THD} &= 10\log_{10}\frac{P_{\mathrm{harm}}}{P_{\mathrm{sig}}}.
  \label{eq:continuous-metrics}
\end{align}

由于阶梯函数一般含无限谱线，仅截断有限 $m$ 时不能声称得到连续全局 SFDR。
有限记录的 SFDR 必须由观测协议指定的离散频点集合定义。

\subsection{有限相干记录与连续周期的关系}

令 $M$ 点相干记录的输入为

\begin{equation}
  x_n=x_0+A\sin\left(2\pi\frac{k_0 n}{M}+\phi_0\right),
  \qquad \gcd(k_0,M)=1.
\end{equation}

若 ADC 无记忆，$n\mapsto k_0n\bmod M$ 是相位网格的排列，因此改变与 $M$
互质的 $k_0$ 不改变采样相位集合，只改变顺序。于是所有仅依赖样本多重集合的
静态统计量保持不变；DFT 谱线的位置按模 $M$ 重排。动态记忆一旦存在，顺序会
影响状态轨迹，这个频率不变性即失效。

有限记录 DFT 为

\begin{equation}
  Y_M[\ell]
  =
  \frac{1}{M}
  \sum_{n=0}^{M-1}
  y_n e^{-\jj2\pi \ell n/M}.
  \label{eq:dft}
\end{equation}

它是对连续相位积分的周期梯形求积，同时包含谐波折叠。故连续谱与有限记录谱是
两个相互关联但不等同的对象。

\subsection{何时可以使用白量化噪声}

均匀量化步长为 $\Delta$ 时，常见近似给出

\begin{equation}
  \E[e_q]=0,
  \qquad
  \Var(e_q)=\frac{\Delta^2}{12}.
  \label{eq:quant-noise}
\end{equation}

式 \eqref{eq:quant-noise} 只有在量化误差近似均匀、与输入不相关且在所关心带宽
内近似白时才可作为噪声模型。对相干正弦、少码摆幅、无 dither 或强静态 INL，
误差通常与输入相关，必须优先使用式 \eqref{eq:fourier-closed} 或
\eqref{eq:dft} 的确定性谱。由此得到本框架的双口径：

\begin{equation}
  \text{确定性周期输入}
  \Longrightarrow
  \text{精确线谱},
  \qquad
  \text{满足统计条件的随机输入}
  \Longrightarrow
  \text{谱密度与噪声功率}.
\end{equation}

\section{动态状态理论}

\subsection{从连续时间建立到离散状态}

设某一级静态 residue 目标在放大相位内保持为 $u_n$，实际输出 $r(t)$ 满足一阶
小信号建立方程

\begin{equation}
  \frac{\dd r}{\dd t}
  =
  -\omega_p\bigl(r(t)-u_n\bigr),
  \qquad 0\le t\le T_a.
  \label{eq:continuous-settling}
\end{equation}

将误差定义为 $\varepsilon(t)=r(t)-u_n$，则

\begin{equation}
  \frac{\dd\varepsilon}{\dd t}=-\omega_p\varepsilon,
  \qquad
  \varepsilon(t)=\varepsilon(0)e^{-\omega_p t}.
\end{equation}

若相位起点保持前一样本末端状态 $r_{n-1}$，则

\begin{align}
  r_n-u_n
  &=(r_{n-1}-u_n)e^{-\omega_pT_a},\\
  r_n
  &=(1-\rho)u_n+\rho r_{n-1},
  \qquad
  \rho=e^{-\omega_pT_a}.
  \label{eq:first-order-recurrence}
\end{align}

对单极点 $3$ dB 带宽 $B=\omega_p/(2\pi)$，

\begin{equation}
  \rho=e^{-2\pi BT_a},
  \qquad
  N_{\mathrm{settle}}=-\log_2\rho
  =\frac{2\pi BT_a}{\ln2}.
  \label{eq:settling-bits}
\end{equation}

Gu 主路径的 11 GHz/100 ps 报告在这一候选模型下对应约 9.97 bit 建立精度；
它们是同一终点条件的两种表达，而不是两个独立的动态识别量。

\subsection{唯一周期稳态}

对长度 $M$ 的周期目标 $u_{n+M}=u_n$，从周期开始前状态 $r_{-1}$ 出发，展开
式 \eqref{eq:first-order-recurrence} 得

\begin{equation}
  r_{M-1}
  =
  \rho^M r_{-1}
  +(1-\rho)
  \sum_{k=0}^{M-1}\rho^{M-1-k}u_k.
  \label{eq:one-cycle-map}
\end{equation}

\begin{proposition}[一阶建立的唯一循环稳态]
当 $0\le\rho<1$ 时，任意有限周期目标存在唯一循环稳态，其周期边界为

\begin{equation}
  r_{-1}^{\star}
  =
  \frac{(1-\rho)
  \sum_{k=0}^{M-1}\rho^{M-1-k}u_k}
  {1-\rho^M}.
  \label{eq:periodic-boundary}
\end{equation}
\end{proposition}

\begin{proof}
令周期首尾相等，即 $r_{M-1}=r_{-1}$，代入
\eqref{eq:one-cycle-map} 并整理得到式 \eqref{eq:periodic-boundary}。
由于 $0\le\rho<1$，故 $1-\rho^M>0$，解唯一。任意两个初值之差经过一个周期
缩小为原来的 $\rho^M$，所以该解全局渐近稳定。证毕。
\end{proof}

该命题以周期目标 $u_n$ 已给定为前提。对当前无状态反馈的前馈级联，可先求第一级
唯一周期 residue，再由它确定第二级周期目标并求第二级唯一周期 residue；逐级归纳
得到本候选模型的周期轨道。任意带状态依赖切换和反馈的混合系统未必唯一，不能由
标量命题直接推出其唯一周期解。

\subsection{线性频率响应与静态极限}

对式 \eqref{eq:first-order-recurrence} 作 $z$ 变换：

\begin{equation}
  R(z)(1-\rho z^{-1})=(1-\rho)U(z),
\end{equation}

故

\begin{equation}
  H(z)=\frac{R(z)}{U(z)}
  =\frac{1-\rho}{1-\rho z^{-1}},
  \qquad
  H(e^{\jj\omega})
  =\frac{1-\rho}{1-\rho e^{-\jj\omega}}.
  \label{eq:settling-frequency-response}
\end{equation}

当 $\rho\to0$，$r_n\to u_n$，动态理论严格回到静态路径理论；当输入为常值，
稳态 $r=u$。这些是动态模型必须满足的两个极限。

但线性 $H(e^{\jj\omega})$ 只描述“静态目标到实际 residue”的局部状态传播。
residue 随后穿过判决边界，最终 SNDR/SFDR 不必随频率单调变化。把线性幅频响应
直接等同于 ADC 指标下降会忽略混合系统的路径切换。

\subsection{级联动态成为分段仿射状态系统}

以两级前端为例，定义状态
$z_n=(r_{1,n-1},r_{2,n-1})^\mathsf T$。固定包含两级判决、
各级模拟模型局部分段及末级 SAR 码的完整路径
$p_n=(q_{1,n},\sigma_{1,n},q_{2,n},\sigma_{2,n},b_n)$ 后，

\begin{align}
  r_{1,n}
  &=(1-\rho_1)
    (\alpha_{1,p}x_n+\beta_{1,p})
    +\rho_1 r_{1,n-1},\\
  r_{2,n}
  &=(1-\rho_2)
    (\alpha_{2,p}r_{1,n}+\beta_{2,p})
    +\rho_2 r_{2,n-1}.
\end{align}

整理为

\begin{equation}
  z_{n+1}
  =
  A_p z_n+B_p x_n+c_p,
  \qquad
  y_n=\mathcal R(p)=k_p,
  \label{eq:pwa-dynamic-state}
\end{equation}

而路径 $p$ 由关于 $(x_n,z_n)$ 的前级阈值、局部分段和末级量化不等式共同决定。
状态递推在每个细化胞腔内仿射，最终整数码在该胞腔内固定；若不固定末级码，
整数输出仍是阶梯函数，不能写成单一仿射读出。因此动态流水线 ADC 是
“分段仿射状态系统加离散码读出”，而不是单一 LTI 滤波器。

\subsection{复位模型与跨样本记忆不可由终点精度区分}

若每次放大相位都从固定状态 $r_{\mathrm{reset}}$ 开始，则

\begin{equation}
  r_n
  =
  (1-\rho)u_n+\rho r_{\mathrm{reset}},
  \label{eq:reset-model}
\end{equation}

它是无记忆静态映射。式 \eqref{eq:first-order-recurrence} 与
\eqref{eq:reset-model} 在单次阶跃终点可以具有同一残余因子 $\rho$，但对同一
当前目标、不同前序状态的实验给出不同结果。

\begin{definition}[观测等价]
给定输入实验族 $\mathfrak X$ 和观测算子 $\mathcal O$，若两个动态模型
$\mathcal M_1,\mathcal M_2$ 满足

\begin{equation}
  \mathcal O[\mathcal M_1(x)]
  =
  \mathcal O[\mathcal M_2(x)],
  \qquad \forall x\in\mathfrak X,
\end{equation}

则称它们在 $(\mathfrak X,\mathcal O)$ 下观测等价。
\end{definition}

这个定义是本项目用于管理物理语义不确定性的工作理论。11 GHz/100 ps 终点锚点
使复位模型和保持模型处于同一观测等价类；加入“相同当前目标、不同前序 residue”
的瞬态观测后，两者才可能被区分。

\subsection{采样时差、随机抖动与孔径}

若第 $i$ 条路径采样时刻为 $t_n+\tau_i$，则

\begin{equation}
  x_{i,n}=x(t_n+\tau_i).
\end{equation}

对足够光滑的输入，

\begin{equation}
  x(t_n+\tau_i)
  =
  x(t_n)+\dot x(t_n)\tau_i
  +\frac{1}{2}\ddot x(t_n)\tau_i^2+\mathcal O(\tau_i^3).
  \label{eq:timing-taylor}
\end{equation}

两路径时差 $\Delta\tau=\tau_a-\tau_b$ 的一阶差异为

\begin{equation}
  \Delta x_n\approx\dot x(t_n)\Delta\tau.
  \label{eq:path-skew}
\end{equation}

对 $x(t)=A\sin(\omega t+\phi)$，精确差异为

\begin{equation}
  x(t+\tau_a)-x(t+\tau_b)
  =
  2A\sin\frac{\omega\Delta\tau}{2}
  \cos\left(\omega t+\phi+\frac{\omega(\tau_a+\tau_b)}{2}\right).
  \label{eq:sine-skew-exact}
\end{equation}

因此路径时差的等效误差随输入频率增长，并以判决输入扰动的形式移动阈值边界。

若随机抖动 $\epsilon_n$ 独立、零均值、方差 $\sigma_t^2$，一阶采样误差为

\begin{equation}
  e_{t,n}\approx\dot x(t_n)\epsilon_n.
\end{equation}

对正弦输入，平均误差功率为

\begin{equation}
  \E[e_t^2]
  \approx
  \frac{A^2\omega^2\sigma_t^2}{2},
\end{equation}

理想正弦信号功率为 $A^2/2$，故仅受抖动限制时

\begin{equation}
  \mathrm{SNR}_{\mathrm{jitter}}
  \approx
  -20\log_{10}(\omega\sigma_t).
  \label{eq:jitter-snr}
\end{equation}

式 \eqref{eq:jitter-snr} 是小抖动、无其他误差、误差与信号功率按均方分离时的
局部结果。若抖动通过不同路径进入判决，仍需把误差传入路径胞腔。

有限孔径窗口 $w_a(t)$ 使采样值成为

\begin{equation}
  x_{a,n}
  =
  \int x(t_n+\tau)w_a(\tau)\dd\tau,
  \qquad
  \int w_a(\tau)\dd\tau=1.
  \label{eq:aperture}
\end{equation}

它在判决前表现为频率响应 $W_a(\jj\omega)$。因此孔径是输入侧线性记忆，随机
抖动是随机时基，固定路径时差是确定性多路径误差，三者不应合并为一个经验
“高频失真系数”。

\subsection{弱非线性记忆的局部入口}

对满足衰减记忆且在工作域内连续的模拟子块，可写局部 Volterra 展开

\begin{equation}
  v(t)
  =
  h_0
  +\sum_{r=1}^{R}
  \int\cdots\int
  h_r(\tau_1,\ldots,\tau_r)
  \prod_{\ell=1}^{r}x(t-\tau_\ell)
  \dd\tau_1\cdots\dd\tau_r.
  \label{eq:volterra}
\end{equation}

本文只把式 \eqref{eq:volterra} 用于输入缓冲器、采样网络或放大器目标映射，
其输出仍要进入式 \eqref{eq:path-select} 的硬判决。这样既利用成熟的带记忆
非线性理论，又避免用有限阶光滑展开掩盖量化边界。

\section{项目工作理论：边界--内部谱灵敏度}

\subsection{为什么普通光滑灵敏度不够}

设参数 $\alpha$ 改变局部增益、阈值或校正系数。若输出在固定相位区间内为
$y_j(\varphi,\alpha)$，同时区间边界
$\phi_j(\alpha)$ 也随参数移动，则 Fourier 系数

\begin{equation}
  c_m(\alpha)
  =
  \frac{1}{2\pi}
  \sum_j
  \int_{\phi_j(\alpha)}^{\phi_{j+1}(\alpha)}
  y_j(\varphi,\alpha)e^{-\jj m\varphi}\dd\varphi
  \label{eq:param-fourier}
\end{equation}

同时包含两类变化：

\begin{enumerate}
  \item 区间内部映射 $y_j$ 的连续变化；
  \item 判决边界移动造成的有限跳变面积变化。
\end{enumerate}

只在固定路径内求 Jacobian 会漏掉第二项。对阶段二的最终整数码，拓扑不变的
相位区间内 $y_j=k_j$ 固定，故下式内部项严格为零；若研究未量化 residue 或
连续校正输出，内部项才可能非零。两类观测量不可混用。

\begin{proposition}[边界--内部谱灵敏度分解]
设参数在所考察点的邻域内保持有限相位区间的数目、次序和非零宽度；各边界
$\phi_j(\alpha)$ 连续可微；每个 $y_j$ 及其参数偏导在对应闭移动区间上存在
连续的单侧延拓，从而参数微分与积分可以交换。则

\begin{align}
  \frac{\dd c_m}{\dd\alpha}
  &=
  \frac{1}{2\pi}
  \sum_j
  \int_{\phi_j}^{\phi_{j+1}}
  \frac{\partial y_j}{\partial\alpha}
  e^{-\jj m\varphi}\dd\varphi \notag\\
  &\quad+
  \frac{1}{2\pi}
  \sum_j
  \left(y_{j-1}(\phi_j^-)-y_j(\phi_j^+)\right)
  e^{-\jj m\phi_j}
  \frac{\dd\phi_j}{\dd\alpha}.
  \label{eq:boundary-interior-sensitivity}
\end{align}
\end{proposition}

\begin{proof}
对式 \eqref{eq:param-fourier} 的每个积分应用 Leibniz 法则：

\begin{align}
  \frac{\dd}{\dd\alpha}
  \int_{\phi_j}^{\phi_{j+1}}f_j(\varphi,\alpha)\dd\varphi
  &=
  \int_{\phi_j}^{\phi_{j+1}}
  \frac{\partial f_j}{\partial\alpha}\dd\varphi
  +f_j(\phi_{j+1}^-)\phi_{j+1}'\notag\\
  &\quad-f_j(\phi_j^+)\phi_j'.
\end{align}

将相邻区间在共同边界 $\phi_j$ 的上端项和下端项合并，得到
$[y_{j-1}(\phi_j^-)-y_j(\phi_j^+)]e^{-\jj m\phi_j}\phi_j'$。
对全部边界求和即得式 \eqref{eq:boundary-interior-sensitivity}。证毕。
\end{proof}

式 \eqref{eq:boundary-interior-sensitivity} 使用成熟的 Leibniz 移动边界积分法则；
本项目的工作接口是把 ADC 的逐级边界、局部输出和观测谱线放入同一分解。
它不是把仿真差分拟合成 Jacobian。固定长度的整数码 DFT 对足够小的参数扰动
通常局部不变，不能直接以其小步差分检验连续相位系数的导数；应先对连续谱线
验证，再另行考察记录长度和扰动步长的联合极限。

\subsection{边界相位的隐式导数}

若第 $j$ 个边界由

\begin{equation}
  g_j(\phi_j,\alpha)=0
  \label{eq:implicit-boundary}
\end{equation}

定义，且 $\partial g_j/\partial\phi\ne0$，则隐函数定理给出

\begin{equation}
  \frac{\dd\phi_j}{\dd\alpha}
  =
  -\frac{\partial g_j/\partial\alpha}
         {\partial g_j/\partial\phi}.
  \label{eq:boundary-derivative}
\end{equation}

对正弦阈值边界
$g_j=x_0+A\sin\phi_j-T_j(\alpha)$，

\begin{equation}
  \frac{\dd\phi_j}{\dd\alpha}
  =
  \frac{\dd T_j/\dd\alpha}
       {A\cos\phi_j}.
  \label{eq:sine-boundary-derivative}
\end{equation}

当 $\cos\phi_j\to0$，边界接近正弦峰值，灵敏度放大并可能失去普通可微性。这正是
满幅附近小阈值误差可能显著改变码占用的理论原因，也给出局部线性预测失效的
明确判据。

\subsection{功率与指标的一阶传播}

谱线功率 $P_m=|c_m|^2$ 的微分为

\begin{equation}
  \dd P_m
  =
  2\operatorname{Re}\{c_m^\ast\dd c_m\}.
  \label{eq:line-power-differential}
\end{equation}

若指标是正功率集合的可微函数
$\mathcal J=\psi(P_1,\ldots,P_K)$，则

\begin{equation}
  \dd\mathcal J
  =
  \sum_{m=1}^{K}
  \frac{\partial\psi}{\partial P_m}
  2\operatorname{Re}\{c_m^\ast\dd c_m\}.
  \label{eq:metric-differential}
\end{equation}

SFDR 含最大运算，在最大杂散频点唯一且不切换时可局部求导；若两个 spur 交叉，
SFDR 只有方向导数或次梯度。因而“性能关于参数全局光滑”不是可接受的默认假设。

\section{阶段三：校准闭环理论}

\subsection{扩展闭环}

令 $d_n$ 为附加激励，$o_n$ 为可观测校准量，$a_n$ 为校准状态，
$\mathbf h_n$ 为各级未经数字校正的原始码元组，$\widetilde y_n$ 为校正输出。
扩展系统为

\begin{align}
  (z_{n+1},\mathbf h_n,o_n)
  &=\mathcal G(z_n,x_n,d_n;\theta), \label{eq:cal-plant}\\
  a_{n+1}
  &=\mathcal U(a_n,o_n,d_n), \label{eq:cal-update}\\
  \widetilde y_n
  &=\mathcal C(\mathbf h_n,a_n,d_n). \label{eq:cal-correction}
\end{align}

这里 $\mathcal C$ 作用于各级原始码，而非只作用于已把各级码相加并扣除
dither 的单个 $y_n$；否则无法表达两级数字 PWL 与局部 dither 扣除的次序。
用 Gu 候选 A 的简化码制说明，设 $f_{2,a_{2,n}}$、$f_{1,a_{1,n}}$
分别是第二级和第一级的数字 PWL 校正，$c_{3,n}$ 是末级 centered 码，则

\begin{align}
  t_{2,n}&=f_{2,a_{2,n}}(c_{3,n})-D_{2,n}^{(\mathrm{dig})},\\
  t_{1,n}&=f_{1,a_{1,n}}(128q_{2,n}+t_{2,n})
              -D_{1,n}^{(\mathrm{dig})},\\
  \widetilde y_n&=512q_{1,n}+t_{1,n}+2048.
  \label{eq:gu-nested-digital-correction}
\end{align}

最终输出仍按允许范围处理裁剪。$f_i$ 的输入是量化后的数字码，系数由
后台估计；它所尝试逆转的是模拟放大传输 $g_i$ 在码域上的影响，不能把
$f_i$ 与 $g_i$ 视为同一个 PWL 对象。若两级 $f_i$ 均为恒等映射，式
\eqref{eq:gu-nested-digital-correction} 才退化为未校正的
式 \eqref{eq:gu-ideal-dither-cancel} 左侧。真实 $g_i$ 未知，有限分段表示、
末级量化、CDAC 误差和有限字长都可能使复合映射只能近似目标线性增益。

\subsection{表示误差、估计误差和实现误差}

设校正表示族为 $\{\mathcal C_a:a\in\mathcal A\}$。即使真实物理参数
$\theta$ 已知，也未必存在 $a$ 使所有非理想完全消失。定义可实现最优状态

\begin{equation}
  a^\star(\theta)
  \in
  \arg\min_{a\in\mathcal A}
  \mathfrak L\!\left(
    \mathcal C_a\circ\mathcal G_\theta
  \right),
  \label{eq:oracle-state}
\end{equation}

其中 $\mathfrak L$ 是理论分析所用的目标泛函，不必等同于最终报告指标。于是校准
影响至少分为：

\begin{align}
  \text{表示差距}&:
  \mathcal C_{a^\star}\circ\mathcal G_\theta
  \ \text{与理想 ADC 的差异},\\
  \text{估计差距}&:
  a_n-a^\star,\\
  \text{激励直接效应}&:
  d_n\ \text{直接进入输出谱},\\
  \text{实现差距}&:
  \text{量化、舍入、饱和与有限更新速率}.
\end{align}

因此参数 MSE 只是估计差距的诊断量，不能替代最终性能。

\subsection{随机逼近的局部误差动力学}

将一类校准更新抽象为

\begin{equation}
  a_{n+1}
  =
  a_n+\mu h(a_n,\xi_n),
  \label{eq:sa-general}
\end{equation}

其中 $\xi_n$ 汇总输入、dither、判决状态和观测噪声。定义均值场

\begin{equation}
  \bar h(a)=\E[h(a,\xi_n)\mid a_n=a].
\end{equation}

若 $a^\star$ 满足 $\bar h(a^\star)=0$，令误差 $e_n=a_n-a^\star$。在局部可微
且时间尺度分离近似成立时，

\begin{equation}
  \bar h(a^\star+e)
  =
  -He+\mathcal O(\|e\|^2),
  \qquad
  H=-\left.\frac{\partial\bar h}{\partial a}\right|_{a^\star}.
\end{equation}

把零均值梯度噪声记为 $\nu_n$，得到局部线性误差模型

\begin{equation}
  e_{n+1}
  =
  (I-\mu H)e_n+\mu\nu_n.
  \label{eq:local-cal-error}
\end{equation}

若

\begin{equation}
  \spr(I-\mu H)<1,
  \label{eq:mean-stability}
\end{equation}

则均值局部稳定。在 $\nu_n$ 近似平稳、与 $e_n$ 的高阶相关可忽略时，稳态协方差
$P=\E[e_ne_n^\mathsf T]$ 满足离散 Lyapunov 方程

\begin{equation}
  P
  =
  (I-\mu H)P(I-\mu H)^\mathsf T
  +\mu^2Q,
  \qquad
  Q=\Cov(\nu_n).
  \label{eq:cal-covariance}
\end{equation}

式 \eqref{eq:local-cal-error}--\eqref{eq:cal-covariance} 是随机逼近理论在本项目
中的局部适配。若门控使均值场不光滑、激励不足使 $H$ 降秩、定点更新形成极限环，
则该近似必须缩小范围或换用有限状态 Markov 描述。

\subsection{可辨识性与持续激励}

设局部观测对参数误差的线性项为

\begin{equation}
  o_n-o_n^\star
  \approx
  \Phi_n e_n+\eta_n.
\end{equation}

定义观测信息矩阵

\begin{equation}
  R_\Phi=\E[\Phi_n^\mathsf T\Phi_n].
\end{equation}

若 $R_\Phi$ 在目标参数子空间上不满秩，则存在非零方向 $v$ 使
$\Phi_nv=0$ 几乎处处，该方向不能由现有输入、dither 和门控状态识别。持续激励
不是“出现过某个 PWL slice”，而是需要

\begin{equation}
  v^\mathsf R_\Phi v>0
  \quad
  \text{对所有待识别方向 }v\ne0.
  \label{eq:persistent-excitation}
\end{equation}

这解释了路径访问、有效更新和参数可辨识性之间的区别。

\subsection{从校准状态分布到谱线分布}

令复谱线向量为

\begin{equation}
  \bm c(a)
  =
  (c_{m_1}(a),\ldots,c_{m_K}(a))^\mathsf T.
\end{equation}

使用式 \eqref{eq:boundary-interior-sensitivity} 构造包含边界项的灵敏度矩阵

\begin{equation}
  G_c
  =
  \left.
  \frac{\partial\bm c}{\partial a^\mathsf T}
  \right|_{a^\star}.
\end{equation}

若 $\E[e_n]=b$、$\Cov(e_n)=P$ 且一阶近似有效，则

\begin{align}
  \E[\bm c(a_n)]
  &\approx
  \bm c(a^\star)+G_cb, \label{eq:spectral-mean}\\
  \Cov(\bm c(a_n))
  &\approx
  G_cPG_c^\mathsf H. \label{eq:spectral-cov}
\end{align}

对单个谱线 $c_m$，若对应行向量为 $g_m^\mathsf T$，则

\begin{equation}
  \E[|c_m(a_n)|^2]
  \approx
  |c_m^\star+g_m^\mathsf Tb|^2
  +g_m^\mathsf T P g_m^\ast.
  \label{eq:expected-line-power}
\end{equation}

式 \eqref{eq:expected-line-power} 把校准偏差和波动分别映射为相干谱线偏移与平均
谱线功率增量。随后可把这些功率代入性能泛函；若最大 spur 身份切换，则必须使用
分段或分布式 SFDR，而不能只传播均值。

\subsection{dither 的间接收益与直接代价}

dither 通过两个通道作用：

\begin{equation}
  d_n
  \longrightarrow
  \begin{cases}
    R_\Phi,Q,H & \text{改变可辨识性与校准状态分布},\\
    \widetilde Y & \text{直接产生残余谱线或噪声}.
  \end{cases}
  \label{eq:dither-two-paths}
\end{equation}

只有在减性抵消精确、无过载、dither 分布满足相应特征函数条件时，才可将量化误差
视为与输入独立。Gu 架构中的模拟注入、局部数字副本和分段门控必须分别进入
\eqref{eq:cal-plant}--\eqref{eq:cal-correction}，不能用通用 dither 定理直接
宣布“无频谱代价”。

\section{统一理论架构与项目原创接口}

\subsection{六层依赖链}

\begin{center}

  \node[block,text width=118mm] (l1)

\subsection{工作理论的可证伪条件}

\begin{enumerate}
  \item \textbf{路径胞腔理论：}若固定路径内存在未建模的非仿射、多值或随机映射，
        则仿射闭包结论失效，必须扩大状态或改变局部函数族；
  \item \textbf{边界谱灵敏度：}若边界相切、合并、产生或消失，普通导数失效，
        必须使用单侧导数或有限变化分析；
  \item \textbf{周期稳态：}若状态映射不收缩、存在多稳态或亚谐波，唯一周期解
        不再成立；
  \item \textbf{校准协方差传播：}若误差过大以致频繁跨越多个边界拓扑，局部
        一阶传播不足，必须直接传播参数分布或建立分段概率模型；
  \item \textbf{观测等价类：}只要出现一个经审查实验使两个候选模型产生可重复
        差异，它们就不再属于该实验族下的同一等价类。
\end{enumerate}

\section{验证逻辑、误差账本与当前边界}

\subsection{必须保持的极限}

\begin{itemize}
  \item $\rho_i\to0$ 时，有限建立理论回到静态路径胞腔与静态频谱；
  \item 所有非理想参数回到名义值时，结构回到理想码制和冗余恒等式；
  \item 关闭校准作用时，阶段三回到阶段二原始输出过程；
  \item $a_n=a^\star$ 时，达到所选校正表示的能力上限，而非自动达到理想 ADC；
  \item $d_n=0$ 时，dither 的直接频谱效应和相应可辨识性贡献同时消失；
  \item 当统计量化条件不满足时，白噪声近似必须退回确定性或条件谱描述；
  \item 改变记录长度、窗函数或积分带宽时，应标记为观测协议变化，而非 ADC
        本体变化。
\end{itemize}

\subsection{统一误差账本}

理论预测与参考结果的差异按来源分解为

\begin{equation}
  \Delta_{\mathrm{total}}
  \rightsquigarrow
  \left(
  \Delta_{\mathrm{structure}},
  \Delta_{\mathrm{parameter}},
  \Delta_{\mathrm{state}},
  \Delta_{\mathrm{observation}},
  \Delta_{\mathrm{approximation}},
  \Delta_{\mathrm{reference}}
  \right).
  \label{eq:error-ledger}
\end{equation}

箭头表示归因结构而非默认线性相加。结构误差来自遗漏机制；参数误差来自未知
或不确定物理量；状态误差来自初值、记忆语义或非平稳性；观测误差来自有限记录
与协议；近似误差来自截断、局部线性化或统计假设；参考误差来自行为平台、
电路仿真或测量本身。

\section{阅读顺序与后续扩展}

建议按以下顺序使用本文：

\begin{enumerate}
  \item 从第 3 节确认结构、路径、状态和数字重构对象；
  \item 用第 4 节得到静态胞腔、码域测度和可纠正域；
  \item 用第 5 节把胞腔边界变为连续谱或有限记录指标；
  \item 在存在记忆时使用第 6 节扩展状态，并检查动态语义是否可识别；
  \item 参数或校准状态变化时，用第 7 节同时传播内部项和边界项；
  \item 阶段三再用第 8 节连接校准状态分布、dither 和性能分布；
  \item 最后按第 10 节检查理论假设和证据等级。
\end{enumerate}

后续每一次阶段二或阶段三扩展都应补充四项内容：物理入口、数学对象、与既有理论
的接口、可证伪条件。具体数值方法、软件实现和运行配置仍保留在规格与实验文档中。

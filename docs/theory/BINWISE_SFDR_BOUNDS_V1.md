# 最终码区间的逐频点 SFDR 界限

> 2026-10-03，阶段二条件性结果。针对固定偶数长度、矩形窗、相干单音的有限记录。前提仍是每次转换的**最终整数码**已被可信区间覆盖；本方法不产生这些区间，也不证明芯片性能。

## 结论

已有的 [Parseval 码区间界限](FINITE_RECORD_PERFORMANCE_BOUNDS_V1.md)用一个均方根误差半径同时约束所有 FFT 频点。若只有少数样本的码不确定，它对 **SFDR**（基波与最大单根杂散谱线的幅度比）可能很宽。逐频点利用每个采样误差进入一根谱线的权重，可以在不假设各次误差独立的条件下给出更窄的充分界限。它目前只收紧 SFDR；SNDR 涉及所有非基波频点的合成能量，仍按既有 Parseval 界限处理。

## 推导

设第 `n` 个最终码满足 `L_n ≤ y_n ≤ U_n`。取区间中点 `c_n=(L_n+U_n)/2`、半宽 `h_n=(U_n-L_n)/2`，则 `y_n=c_n+u_n` 且 `|u_n|≤h_n`。中点可以是半整数；它只是证明用的参考记录，不被当作芯片输出。令 `N` 为记录长度，`F_k(c)` 为中点记录在第 `k` 个正频率的复数 DFT 系数，按仓库口径先除以 `N`。去直流不改变 `k>0` 的系数。由三角不等式，

```text
|F_k(y)-F_k(c)| ≤ (sum_n h_n)/N,      k>0.
```

普通正频率的 RMS 幅度另乘 `sqrt(2)`；Nyquist 频点不乘。分别记这一误差半径为 `η_k`，中点记录的频点 RMS 幅度为 `A_k`，基波频点为 `f`，则

```text
S_low  = max(0, A_f-η_f)             S_high = A_f+η_f
P_low  = max_{k>0,k≠f} max(0,A_k-η_k)
P_high = max_{k>0,k≠f} (A_k+η_k).
```

这里 `P_low` 是有效的下界：至少有一根中点记录中较强的杂散，不可能比其幅度减去该频点误差半径还小。若 `S_low>0` 且 `P_high>0`，SFDR 下界为 `20log10(S_low/P_high)`；若 `P_low>0`，上界为 `20log10(S_high/P_low)`，否则上界为正无穷。分子下界为零时下界为负无穷。逐点区间即使包含不可能同时发生的码组合，以上仍覆盖所有实际允许的码历史，包括在线系数更新与跨样本相关性；相关性只可能使界限进一步收紧。

这个界限依赖区间的**半宽之和**，而旧公式的误差半径依赖平方和。在只有少数样本不确定时，单根谱线的最坏扰动约按 `K/N` 缩放，而全谱能量上界约按 `sqrt(K/N)` 缩放。两种方法没有普遍的逐例大小顺序；若目标只问 SFDR，可计算两者并取其区间交集。

## EXP-020 条件性复算

[复算脚本](../../experiments/exp_020_unknown_gain_identifiability/binwise_sfdr_followup.py)保留原 EXP-020 配置：8192 点合成相干正弦、第二级主路在两条**人为指定**的静态传输之间插值、前级和冻结单位校正不变。逐样本模拟包络经候选末级 SAR 与 Gu 校正得到最终码区间，只有两处各宽 1 码。

| 计算对象 | SFDR 范围或数值 |
|---|---:|
| 原 Parseval 区间证明 | 91.655–113.201 dBc |
| 逐频点区间证明 | **96.839–97.000 dBc** |
| 两条端点曲线的评分 | 96.977、96.862 dBc |

两条端点均在新界限内。旧 [反向预算](CODE_ENVELOPE_RESOLUTION_BUDGET_V1.md)显示，按 **Parseval 公式**不能从这两个模糊码证明 SFDR ≥95 dBc；逐频点公式在这个人为曲线族上却可以。这说明“95 dBc 下不能容纳一个一位不确定样本”只是旧证明方法的限制，并非 ADC 必须满足的物理精度条件。

## 适用边界与后续

[实现](../../src/adc_research/theory/finite_record_bounds.py)接受最终码下、上界，按仓库相同的单边 FFT 归一化计算。三处整数码不确定的小记录已逐个枚举核对；EXP-020 复算也核对两个端点。但 Python 浮点 FFT 尚未给数值向外舍入证书，所以这里的数值是数学公式的软件核对，不是形式化认证的芯片极限。

真正的应用顺序仍是：先取得真实主辅放大、CDAC、比较器、末级 SAR、数字时序与在线系数状态的覆盖性证据；再传播到每次转换的最终码区间；最后同时计算 Parseval 的 SNDR 界限和逐频点 SFDR 界限。若码区间没有覆盖电路，即使本页给出很窄的 dBc 数值，也没有芯片含义。

# 四路共享系数的合并、提交和广播条件

> 2026-10-10。EXP-054的解析条件；各时序均为项目假设。来源缺口见[数字取证协议](../stages/03_gu_baseline/DIGITAL_EXTRACTION_TRACE_PROTOCOL_V1.md)。不识别Gu芯片时序。

**相同的四条样本与相同的步长，还不足以决定更新轨迹。**先合并还是先舍入、更新后哪次转换开始使用新系数，都会改变数字闭环。以下区分可证明的算术差别和需要运行验证的性能差别。

## 1. 四个明确候选

每窗口120次转换，四路各30次；学习选中全局序号`120w+[0,1,2,3]`，即每路相位0。两级各四个共享Q22累加器，导出Q1.10，数据Q3。每条选中样本的相关乘积乘30，沿用原步长；两级本地读出及门均先用本次实际可见的旧系数算出，再同时提交两个bank。

记累加器向量为$a$，导出算子为$Q$，饱和算子为$S$，实际可见版本为$v$。选中路$l$的第$j$个乘积为

\[
 p_{l,j}(v)=D_lY_l(v)G_j(Y_l(v),Q(v)).
\]

整数单位包含Q3缩放。把步长、30倍及Q22缩放合在正数$\alpha_j$中。`RN`是最近偶数舍入。

| 候选 | 数学合同 | 首次使用新系数 |
|---|---|---|
| 窗口末合并 | $a_{w+1}=S(a_w+\operatorname{RN}(-\alpha\sum_l p_l(a_w)))$ | 窗口$w+1$ |
| 每路先舍入 | $a_{w+1}=S(a_w+\sum_l\operatorname{RN}(-\alpha p_l(a_w)))$ | 窗口$w+1$ |
| 逐条立即提交 | $a_{l+1}=S(a_l+\operatorname{RN}(-\alpha p_l(a_l)))$，仅四条学习样本提交 | 提交后的下一转换 |
| 广播延迟一窗口 | $a_{w+1}=S(a_w+\operatorname{RN}(-\alpha\sum_l p_l(v_w)))$；$v_0=a_0$，$v_{w+1}=a_w$ | 此窗口提交在窗口$w+2$可见 |

逐条候选按转换序号处理四路选样，不代表四路硬件一定有这条串行依赖。它需要在后续选样被计算前完成系数转发，或者保留选样输入后串行重算；具体时钟、流水线和缓存均未验证。延迟候选把主累加状态与当前校正可见版本分开，门使用可见版本，饱和使用主累加状态。第一、二窗口都看到单位系数。

## 2. 先舍入的单次差别

固定同一可见状态、同一四路乘积。最近偶数舍入误差绝对值不超过$1/2$，所以

\[
\left|\sum_{l=0}^3\operatorname{RN}(x_l)-\operatorname{RN}(\sum_l x_l)\right|
\le 4/2+1/2=2.5.
\]

左端为整数，故最多**2个Q22累加器最小单位**。例如四个$x_l=49/100$，先舍入之和为0，合并后舍入为2，界可达到。一次共同饱和是1-Lipschitz映射，不会把这项差别扩大。

同一旧状态下，一次提交之后Q22最多差2，Q1.10导出最多差1。这里两种整数格式之间相差12个小数位；一般地，最近舍入的输入相距不超过2且量化间隔4096，最多跨过一个导出边界。

**这不是整个运行记录的2单位上界。**一旦导出系数不同，下一窗口的读出、门和乘积可能不同；反馈会再产生新差别。不能把本次界直接乘窗口数充当闭环保证。

若逐条候选在下一条学习样本到达前，两级导出码均仍等于窗口初值，乘积和门仍使用同一数字函数。若又没有中间饱和，其窗口末状态等于“每路先舍入”候选。两级任何一项导出变化，或发生中间饱和，都可能破坏这个等价。要让全部120次输出也相同，还需要所有评分转换看到相同的导出码，包括第四次提交后的其余116次。

## 3. 广播延迟怎样改变目标方向

延迟更新的相关量在可见版本$v$算出，却加到主状态$m$。这引入了“在哪里计算”和“加到哪里”的区别。

在同一数字记录、**后级和前级raw码固定**、连续前级PWL读出的条件下，令$\Phi$为前级数字基函数矩阵，$c$为其余重构项，$t$为离线目标。定义

\[
 J(k)=\|\Phi k+c-t\|_2^2,\quad
 g(k)=\Phi^T(\Phi k+c-t),\quad H=\Phi^T\Phi.
\]

于是对同一拟应用增量$\delta$，

\[
 g(m)^T\delta=g(v)^T\delta+(m-v)^TH\delta,
\]

\[
 |(m-v)^TH\delta|\le\|\Phi(m-v)\|_2\,\|\Phi\delta\|_2.
\]

若后一乘积小于$|g(v)^T\delta|$，主状态与可见状态的连续方向符号相同。这是一个有条件判据；准确的$g(v)$仍含在线不可见的$t$。后级也不同、raw分段不同、Q3或最终码舍入时，不能照用这个共同$H$公式；必须按对应数字状态重算。本轮延迟候选的局部探针是在$v$上假设立即加实际主状态增量，不是证明真实延迟激活后的输出同样改变。

## 4. 公式差别不会被合并规则自动消除

Gu式更新使用本级扣dither后的读出$D Y_{\mathrm{local}}G$，目标码平方误差方向使用最终读出误差$(Y_{\mathrm{final}}-t)\Phi$。改变舍入或生效时刻会改变样本、状态和相关量，却不会凭空提供缺失的目标交叉项$t\Phi$。因此两者没有一般恒等保证。但这一数学差别并不保证所有输入或所有时序都严重损失性能；实际重要性仍须用正常闭环和独立留出判断。

每个提交处的离线探针用真实学习版本、真实主状态应用增量、全部120条同记录数字观测，冻结该版本后级。逐条候选每窗口有四个探针，其他候选各一个；次数应按比例比较。四个探针的平方误差变化不能相加解释成真实总损失，因为它们的后级和前级基函数可能不同。继续在线的整条整数码记录才用于SNDR、SFDR及MSE。

## 5. 实现成本和取证字段

四个候选均选四条学习样本、保留八个主累加器。先舍入改变算术位置；逐条提交将一次窗口提交变成四次，并增加系数依赖与广播次数；延迟候选另需八个11位可见系数寄存器，共88位功能状态，外加版本/控制。程序保存旧Q22对象用于诊断，不意味着硬件必须复制184位Q22；校正与门只需要Q1.10可见码。共享状态比较不涵盖四路各自拥有八累加器的独立学习器，后者还需单独说明学习速度和多出三份状态的预算。

实际取证至少记录：选样转换号、路号、两级学习读出、dither对齐、门与乘积、各路舍入前后增量、主累加器版本、每次转换实际使用的系数版本、提交有效和四路生效有效。只有最终抽取输出无法区分这些合同。

可区分测试见[六项定向测试](../../tests/test_fixed_commit_broadcast.py)：同状态下的舍入差；前两窗口单位系数／第三窗口旧提交可见；当前转换先评分／下一转换生效；有顺序的饱和；不完整或重排输入拒绝。它们验证项目合同可以区分，不是芯片记录。

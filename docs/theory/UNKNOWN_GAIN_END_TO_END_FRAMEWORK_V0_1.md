## 一、谁知道什么

- **电路真实状态：**前两级主放大器的传输、第一辅路传输、动态建立、噪声、失配与 PVT。记为 $g$ 及其他物理参数；研究者可在离线测试中设置或测量，运行中的数字算法默认不知道。
- **算法可用信息：**逐级原始数字码、注入 dither 的数字标记及实际实现提供的其他信号。具体总线、时序与位宽尚需核查，不能把理想模拟输入、真实 $g$ 或 oracle 系数默认交给算法。
- **离线评分信息：**测试输入、幕后真值、Cadence 波形、理想目标码和最终频谱可以用于验证、比较与诊断，但不能倒灌到在线更新。
- **测试条件：**输入幅度、频率、分布、记录长度、噪声和 PVT。一个训练分布下的结论不能自动用于另一种输入条件。

开始每项证明或实验前，应写清这四类信息。算法可访问的集合改变，就等于换了研究问题。

## 二、完整信号链，不先规定模拟曲线的形状

以下是 Gu 候选架构的连接方向，不声称掌握芯片全部开关和时序细节。对第 $n$ 个样本，前级判决 $q_1$ 决定第一级 CDAC 电平；扣除该电平并加入校准 dither 后，得到第一级放大前电压 $w_1$。主路与辅路分别产生 $r_1^{m}$ 和 $r_1^{a}$。第二级 flash 读取**辅路**并给出 $q_2$；第二级 CDAC 用**主路**求出 $w_2$。第二级主输出经末级 SAR 形成码 $c_3$。

在无记忆静态条件下可写成：

```text
q1 = Q1(x)                          w1 = x - DAC1(q1) + d1
r1_main = g1_main(w1)               r1_aux = g1_aux(w1)
q2 = Q2(r1_aux)                     w2 = r1_main - DAC2(q2) + d2
r2_main = g2_main(w2)               c3 = Q3(r2_main)
```

若每次放大依赖起始电压、前一采样或采样时刻，上式中的 $g$ 应改为含状态与时间的映射。不能先假定它是单极点跨样本保持。一级主辅与第二级主路的状态应分别记录。量化噪声、比较器误判、通道失配和数字裁剪也须从相应位置进入，而非合并成一个“增益误差”。

最终数字校正从后级到前级进行。令 $a_n$ 是当时的校准系数，$O_n$ 是算法在本次采样实际可见的数字观测，则：

```text
本次最终码       Y_n = C(O_n, a_n)
下一次系数状态   a_(n+1) = U(a_n, O_n)
```

Gu 的数字 PWL 和 gated-LMS 是 $C,U$ 的一个实例。新算法可以更换它们，但应保持物理信号与资源约束相同。必须说明系数在本次还是下次样本生效、dither 在每级何处扣除，避免把不同更新顺序当成同一个算法。

论文的逐样本 gated-LMS 更新还要求**本次 dither 与本次校正输出的配对相关量**，高段另需由当时系数确定的门控结果。对四路抽取，单独保存块平均输出或平均 dither 不能恢复这种相关量；固定系数块更新可用每段门控相关和，但不等价于块内逐转换更新。原文式 (7) 的 `≥` 与 Fig. 10 的 `>` 存在等值歧义，见[抽取边界的信息审计](../stages/03_gu_baseline/DECIMATION_INFORMATION_REQUIREMENTS_V1.md)。[逐转换记录审计器](../stages/03_gu_baseline/DIGITAL_EXTRACTION_TRACE_PROTOCOL_V1.md)已能核对这两个明示候选，但目前仅有人工夹具；芯片真正的抽取统计量和系数生效时序仍开放。

## 三、从信号链到码和频谱：哪些关系仍然成立

即使不知道 $g$，仍可定义“哪些输入会得到码 $k$”这个集合。若给定实际电路，记最终码为 $Y_g(x,d)$，则码 $k$ 对应的输入集合是所有满足 $Y_g(x,d)=k$ 的 $x$。不同的输入区间可能产生同一码，且模拟非线性不保证这些区间只有一个。

对指定的正弦输入和校准状态，最终码随相位变化后的第 $m$ 条谱线仍按一个周期的积分定义。**这个定义不要求模拟 $g$ 是 PWL。**但是要给谱线数值，必须知道或有界确定相位上出现哪些码。测不到那些码边界时，定义并不等于预测。

接下来应分三种结果，而非统一宣称“精确预测”：

1. **条件计算：**已从独立电路资料得到传输或足够准确的边界时，计算码、谱和指标，并报告测量／插值误差。
2. **范围计算：**观测和物理条件只限定了一组可能电路时，求该组电路允许的性能范围，并验证真实留出条件是否被覆盖。
3. **无法确定：**存在两种满足所有已知信息、却给出不同测试性能的电路时，给出具体反例，指出要增加什么观测。没有可信约束时不能制造一个很窄的范围。

原理论稿的“区间内残余电压是一次函数”“阈值可由斜率加偏置直接反算”，只对**已给定并核验**的仿射或模拟 PWL 模型成立。一般 $g$ 下需研究非线性阈值条件；若连有限次阈值穿越也没有保证，原先有限段的闭式计算不能直接沿用。已知最终码区间后的傅里叶积分、理想重构恒等式和部分冗余关系仍可保留，前提必须逐条检查。

有限测试记录还有一条不要求模拟 PWL 的条件性桥梁：若已证明每个最终整数码均在一个区间内，[有限记录性能界限](FINITE_RECORD_PERFORMANCE_BOUNDS_V1.md)用 Parseval 恒等式把码区间传播到 SNDR/SFDR 区间。这里的难点是从真实主辅传输、判决阈值和系数状态**可靠取得码区间**；仅对两条合成曲线取最大最小值，不等于覆盖未知电路。

若先确定需要证明的指标下界，[最终码不确定度反向预算](CODE_ENVELOPE_RESOLUTION_BUDGET_V1.md)可量化该 Parseval 界限容许多少逐点码范围，从而安排物理资料的分辨率；预算并不证明实际电路满足所需范围。

[静态模拟范围到在线频谱的短记录连接](STATIC_ANALOG_TO_ONLINE_CODE_BOUNDS_V1.md)现将覆盖性的主辅输出范围逐次传播成数字观测集合，再与当时的 Gu 系数状态联合传播，最后形成每次最终整数码区间并使用频谱界限。它把原来分开的两个条件性步骤组合起来；同一电路跨样本的相关性被保守放宽，真实抽取时序与动态历史仍未覆盖。

对 EXP-032 的定点逐转换候选，[整数状态范围](FIXED_ONLINE_STATE_BOX_BOUNDS_V1.md)进一步用八个累加器区间逐次覆盖所有可能更新，避免短记录方法的指数路径存储。它可处理较长的候选数字记录，但合并状态可能过宽，且没有产生真实电路的观测范围；有限记录频谱界限仍以最终码确实被覆盖为条件。[精确电压组合入口](RATIONAL_STATIC_TO_FIXED_CODE_BOUNDS_V1.md)能从有理数静态扫描一路保持精确判决，直到整数在线码／状态；新增[短记录频谱认证入口](CERTIFIED_FINITE_RECORD_SPECTRUM_V1.md)又将最终整数码范围传到有理数功率比／分贝范围。整个组合仍须可信物理范围与数字时序合同；直接 DFT 的数值包含不等于长记录认证 FFT 或芯片性能证明。

现已在候选架构的一个窄条件下走通这条链：前级数字字段和冻结 Gu 系数固定时，给末级 SAR 输入电压区间，枚举可能的末级码及最终码，再求有限记录频谱范围。EXP-020 的两条合成传输插值族通过了此验证。另有[短记录在线可达集](ONLINE_COEFFICIENT_REACHABILITY_V1.md)：在**已给定覆盖性数字观测集合**的前提下，逐分支传播 Gu 候选系数和整数码。主辅判决到该观测集合的物理覆盖、真实抽取时序及长记录可计算的严格包络仍缺失。插值族和短记录例子仅检验方法，不是芯片允许传输集合。

## 四、观测能力和数字校正能力

“可辨识”指：在允许的训练输入、dither 和观测下，能不能区分两种不同的电路情况。若两种电路生成相同的可见数据，却在测试条件下产生不同频谱，任何只使用这些数据的算法都不能保证正确选中其中一种。这是要寻找的关键反例，不是假设某种算法不够聪明。

**现已得到一个有限观测反例。**EXP-020 在冻结的静态候选架构中，只改变第二级主路模拟传输：两条连续、奇对称、严格单调的曲线对 4096 个输入码中心和四种 dither 组合产生完全相同的数字训练记录；一条未见过的正弦记录却有不同的末级码、最终码和频谱指标。因此，这批训练数据不足以给该留出记录一个唯一的性能值。该结论只针对给定的有限训练集与允许局部扰动的曲线类；它不意味着增加观测或施加有电路依据的斜率／曲率约束后仍然无法预测，也不证明 Gu 在线校准在测试时无法继续适应。一般数学构造可用未访问区间内的足够小的光滑扰动；本次软件实例使用人为合成的模拟 PWL 曲线，尚未验证真实芯片的传输形状。

再问“可校正”：即使离线知道了电路真实状态，给定的数字码、字长和校正结构是否足以消掉误差？若不同理想输入产生完全相同的可见码和 dither 标记，但要求不同的目标输出，仅修改这些码的数字算法就无法同时满足两者。过载和错误判决尤其需要与函数表示误差分开检查。

[数字观测与可校正误差下限](OBSERVATION_CORRECTION_LIMITS_V1.md)将这一点写成一般结论：固定一条电路、输入条件和真实可见信息后，任意逐转换数字映射的最小平均绝对码误差，由每个观测对应的目标码条件分布决定。Gu 的实际码误差可在同一评分条件下分成观测限制、数字表示限制和训练差距。它与 EXP-020 的“不同电路拥有相同有限训练数据”是**两种不同的信息不足**；不能用一个反例直接给另一种下限数值。

数字 PWL 的基函数空间可用于分析**它能表示哪些校正映射**。这是数字函数的空间，不是模拟 $g$ 必须属于的空间。投影或“最佳系数”必须先规定输入分布、数字观测和误差目标；Gu 的去相关更新不自动等于最小码误差的投影。待研究的误差至少包括：不可区分信息造成的下限、表示误差、有限样本估计误差、dither 直接代价、量化／定点误差和遗漏的动态机制。

## 五、校准系数怎样影响最终性能

EXP-046已表明后级歧义接入前级后仍可保留。共同平均曲线上的不同点保持，但量化后没有相同的平均不动状态；固定后级的前级局部稳定也不能选择唯一的良好输出。现状用[普通语言说明](../reports/RESEARCH_STATUS_PLAIN_2026-10-09.md)，严谨条件及公式留在本轮推导。下一步重点从“是否有解”转向“内部指标为何允许明显不同的输出质量”。

EXP-044进一步处理原窗口而非合并均值：同一旧系数范围评分／门控，一次聚合提交，按实际次序包含八状态和最终码。高段请求按本段数字基函数是否为零拆分，码影响用共同冻结中间记录分成直接高段与间接低段历史项；两种分解服务于不同问题。有限状态包含不是正确目标证明，门次数也不是性能误差大小。

截至EXP-043，已能对固定经验分布的一些后级整数平均映射证明有限范围内永不停更，并给指定轨迹精确周期；Q3门移动及真实窗口越界见证均已建立。这补足连续相关根到整数行为之间的一个环节，仍未覆盖原窗口次序、高段移动、前级传播或真实芯片。对输入与dither的关系采用明示的条件零均值／门选择分解，不能将经验去相关或PRNG生成方式直接作为正确目标证明。

阶段二也包括原“阶段三”的校准理论。先针对实际可见数据写出 Gu 更新的平均方向，再检查高段有没有有效样本、局部门限移动是否使更新不光滑、噪声和抽取是否改变波动。只有在明确条件下，才能用局部线性化估计收敛速度、稳态系数波动；条件不满足时必须找反例或换分析方法。

接着把**校正后的最终码**送入同一频谱与指标协议。报告不能只停在系数均方误差或 dither 相关性。码边界移动、残余 dither、噪声与最大杂散频点切换，均可能使“系数更准”与“SFDR 更好”不等价。需要将训练阶段、稳态和输入条件改变后的跟踪阶段分开。

阶段二应为算法设计给出具体诊断：是观测根本不足、数字函数表示不了、更新过慢／发散，还是位宽和资源限制。只有定位瓶颈，第四阶段才有明确的改进目标。

[EXP-021](../reports/experiments/EXP_021_GU_CROSS_CURVE_COLD_START_V1.md) 首次让固定参数的 Gu 候选在两条非 PWL 合成模拟曲线上分别冷启动。留出码误差和频谱都改善，但其中一条曲线的验证误差先降后升。验证集单系数消融把这次回升主要定位到第一级第一段的系数变化；高段门控虽少，却不是直接解释。固定其余系数时，训练去相关量的第一段零点在验证集上也未取得较低码误差。这是目标不一致的具体行为例证，尚不是全算法稳态定理；训练分布、量化和表示误差须用控制变量分开检查，高段可激励性另行分析。

**已建立的条件性一维关系。**[EXP-022](../reports/experiments/EXP_022_K1_OBJECTIVE_AUDIT_V1.md)固定其他数字 PWL 斜率，令第一级原始码为 $R_i$，第一段宽度为 $b_0$，$\psi_i=\operatorname{sgn}(R_i)\min(|R_i|,b_0)$。在未裁剪输出码口径下，改变第一段斜率 $k$ 使最终码和第一级局部学习输出都精确增加 $(k-k_0)\psi_i$。第一段 Gu 门始终打开，故平均 dither 相关量是 $k$ 的一次函数；平均绝对码误差的最小点是逐样本零误差斜率的加权中位数，权重 $|\psi_i|$。这两种求解条件不同。在 EXP-021 的一条压缩测试曲线和同一批训练记录上，零相关点约 `1.010000`，最小误差点约 `1.002608`。因此分布变化不是该例差异的必要条件；量化、数字函数表示和 dither 的具体贡献仍未分开。该式依赖其他系数及数字观测冻结，不能当作完整 Gu 多系数稳态或真实芯片的物理结论。

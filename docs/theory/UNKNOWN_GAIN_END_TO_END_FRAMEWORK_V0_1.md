# 阶段二：未知模拟增益下的完整 ADC 与数字校准理论

本框架连接模拟输入、主辅残余电压、逐级判决、数字校正、参数更新与最终性能。它要说明：在什么信息和模型条件下，哪些关系能够证明，哪些性能只能给范围，哪些问题仍不能确定。一般未知增益理论尚未完成。

模拟传输未知于运行中的算法。研究者可以预设曲线或离线使用电路资料，在线算法只接收实际提供的数字信息；数字分段线性校正不规定模拟放大器的物理形状。

## 一、谁知道什么

- **电路真实状态：**前两级主放大器的传输、第一辅路传输、动态建立、噪声、失配与 PVT。记为 $g$ 及其他物理参数；研究者可在离线测试中设置或测量，运行中的数字算法默认不知道。
- **算法可用信息：**逐级原始数字码、注入 dither 的数字标记及实际实现提供的其他信号。具体总线、时序与位宽尚需核查，不能把理想模拟输入、真实 $g$ 或 oracle 系数默认交给算法。
- **离线评分信息：**测试输入、幕后真值、Cadence 波形、理想目标码和最终频谱可以用于验证、比较与诊断，但不能倒灌到在线更新。
- **测试条件：**输入幅度、频率、分布、记录长度、噪声和 PVT。一个训练分布下的结论不能自动用于另一种输入条件。

开始每项证明或实验前，应写清这四类信息。算法可访问的集合改变，就等于换了研究问题。

## 二、完整信号链，不先规定模拟曲线的形状

以下是 Gu 候选架构的连接方向，不声称掌握芯片全部开关和时序细节。对第 $n$ 个样本，前级判决 $q_1$ 决定第一级 CDAC 电平；扣除该电平并加入校准 dither 后，得到第一级放大前电压 $w_1$。主路与辅路分别产生 $r_1^{m}$ 和 $r_1^{a}$。第二级 flash 读取**辅路**并给出 $q_2$；第二级 CDAC 用**主路**求出 $w_2$。第二级主输出经末级 SAR 形成码 $c_3$。

在无记忆静态条件下可写成：

```text
q1 = Q1(x)                          w1 = x - DAC1(q1) + d1
r1_main = g1_main(w1)               r1_aux = g1_aux(w1)
q2 = Q2(r1_aux)                     w2 = r1_main - DAC2(q2) + d2
r2_main = g2_main(w2)               c3 = Q3(r2_main)
```

若每次放大依赖起始电压、前一采样或采样时刻，上式中的 $g$ 应改为含状态与时间的映射。不能先假定它是单极点跨样本保持。一级主辅与第二级主路的状态应分别记录。量化噪声、比较器误判、通道失配和数字裁剪也须从相应位置进入，而非合并成一个“增益误差”。

最终数字校正从后级到前级进行。令 $a_n$ 是当时的校准系数，$O_n$ 是算法在本次采样实际可见的数字观测，则：

```text
本次最终码       Y_n = C(O_n, a_n)
下一次系数状态   a_(n+1) = U(a_n, O_n)
```

Gu 的数字 PWL 和 gated-LMS 是 $C,U$ 的一个实例。新算法可以更换它们，但应保持物理信号与资源约束相同。必须说明系数在本次还是下次样本生效、dither 在每级何处扣除，避免把不同更新顺序当成同一个算法。

论文的逐样本 gated-LMS 更新还要求**本次 dither 与本次校正输出的配对相关量**，高段另需由当时系数确定的门控结果。对四路抽取，单独保存块平均输出或平均 dither 不能恢复这种相关量；固定系数块更新可用每段门控相关和，但不等价于块内逐转换更新。原文式 (7) 的 `≥` 与 Fig. 10 的 `>` 存在等值歧义，见[抽取边界的信息审计](../stages/03_gu_baseline/DECIMATION_INFORMATION_REQUIREMENTS_V1.md)。[逐转换记录审计器](../stages/03_gu_baseline/DIGITAL_EXTRACTION_TRACE_PROTOCOL_V1.md)已能核对这两个明示候选，但目前仅有人工夹具；芯片真正的抽取统计量和系数生效时序仍开放。

## 三、从信号链到码和频谱：哪些关系仍然成立

本节给出三个能够按步骤求解的条件模型：给定静态传输时反算全部输入区间；给定动态与学习规则时递推有限输出记录；只有可信参数范围时传播全部可能分支，再计算性能外界。它们共享同一主辅信号链、数字读出和指标定义。

最终码区间的存在不要求模拟PWL，但有限闭式分区需要明确的单调／求根条件。信息不足时返回未决或宽界，不能把定义当作唯一预测。数学覆盖、普通浮点计算、数值认证和芯片物理证据分别判断。短记录的数字分支实现另见[在线系数可达集](ONLINE_COEFFICIENT_REACHABILITY_V1.md)；其他实现按下文各小节定位。

### 3.1 可计算模型的输入、输出与条件

> 2026-10-19补充。以下把本节既有条件关系展开为模块二的完整计算模型，公式M2仅是本文定位号。给定传输的条件计算、指定动态的有限递推、未知传输的范围传播分别成立；不新增芯片参数或在线校准政策。

固定输入域 $\mathcal D=[x_-,x_+)$、输出码数 $K=2^B$。模拟量使用同一参考下的归一化电压，数字量使用最终输出码单位，二者之间的权重必须明确。离线模型包 $\theta$至少提供：

| 输入 | 数学内容与来源要求 | 缺失时的处理 |
|---|---|---|
| 三级判决与CDAC | 有序阈值 $\tau_{i,j}$、每格数字标签 $\nu_i(j)$、CDAC表 $D_i(q_i)$、端部／过载规则 | 不从位数猜flash编码；有可信范围则分支传播 |
| dither | 模拟注入 $d_{i,n}$、对齐的数字副本 $\mathsf D_{i,n}$与标签时序 | 数字标签不是电压；幅度／本次配对须明确 |
| 三条模拟路径 | $g_1^m,g_1^a,g_2^m$；动态时另给状态方程与初值 | 已知函数可条件计算；只有可信范围则算界；均缺时不能唯一预测 |
| 数字校正与算术 | 两组斜率 $\boldsymbol\kappa_i$、段宽 $\beta_i$、各舍入／饱和节点 | 连续参照与真实定点分别计算 |
| 测试与学习 | 输入分布或序列 $x_n$、dither序列、冻结或完整更新规则、测量位置 | 冻结转换不能代替持续后台输出 |

给量化器补入 $\tau_{i,0}=-\infty,\tau_{i,J_i}=+\infty$，阈值相等判高格，则

\[
j_i(v)=\sum_{j=1}^{J_i-1}{\bf1}\{v\ge\tau_{i,j}\},\qquad
Q_i(v)=\nu_i(j_i(v)).\tag{M2-1}
\]

已知格号 $j$就得到 $\tau_{i,j}\le v<\tau_{i,j+1}$。格号与数字标签分开，允许显式九态前端；无穷端点只定义端部码，物理有效输入范围另列。输出除最终码和指标外，还包含过载、数字越域、裁剪及未决项。

**有限求解的条件：**静态分区要求传输具有有限个已知连续单调段，段内阈值方程可求根或取得包含根的区间；恒等于阈值的整段须单独标记。仅有黑盒函数的有限采样，不能保证找全边界。有限记录前向递推只要求每次函数值及数字规则有定义，不要求能够构造整个输入域的有限分区。

### 3.2 从数字PWL的构造推到最终整数码

先把抽象的 $C$展开。令 $\operatorname{clip}_{[a,b]}(v)=\min(b,\max(a,v))$、$\operatorname{sgn}(0)=0$。对每级四个非负斜率，在数字域 $[-4\beta_i,4\beta_i)$定义累计基函数

\[
\psi_{i,j}(r)=\operatorname{sgn}(r)\operatorname{clip}_{[0,\beta_i]}(|r|-j\beta_i),
\qquad f_i(r)=\sum_{j=0}^3\kappa_{i,j}\psi_{i,j}(r).\tag{M2-2}
\]

设 $s=\min(\lfloor|r|/\beta_i\rfloor,3)$、$t=|r|-s\beta_i$。前 $s$个基函数各已累计满一段，第 $s$个只累计 $t$，后面为零，故

\[
f_i(r)=\operatorname{sgn}(r)\left(\beta_i\sum_{j<s}\kappa_{i,j}+\kappa_{i,s}t\right).\tag{M2-3}
\]

前段 $t=\beta_i$与后段 $t=0$值相同，证明连续；段内导数是非负斜率，证明单调。负满量程采用既有末段延伸到 $t=\beta_i$的候选，正满量程排除。越域且没有明确硬件规则时停止，不能丢掉该分支。

最近偶数整数舍入也写成可执行式。令 $a=\lfloor v\rfloor,t=v-a$，则

\[
R(v)=a+{\bf1}\{t>1/2\ \text{或}\ (t=1/2\text{且}a\text{为奇数})\},\qquad
Q_\Delta(v)=\Delta R(v/\Delta).\tag{M2-4}
\]

此式包含负数等值点。原Q3候选的偏移与局部乘积分别舍入，因此

\[
f_i^{Q3}(r)=\operatorname{sgn}(r)\left[
Q_{1/8}\!\left(\beta_i\sum_{j<s}\kappa_{i,j}\right)+Q_{1/8}(\kappa_{i,s}t)\right].\tag{M2-5}
\]

一般不等于整体一次 $Q_{1/8}(f_i(r))$。以 $\bar f_i$表示本次明确选定的连续或Q3函数。五字段观测 $O=(q_1,q_2,c_3,\mathsf D_1,\mathsf D_2)$通过以下顺序形成最终整数码：

\[
\begin{aligned}
v_2&=\bar f_2(c_3)-\mathsf D_2, &R_1&=128q_2+v_2,\\
v_1&=\bar f_1(R_1)-\mathsf D_1, &Z&=2048+512q_1+v_1,\\
Y&=R\!\left(\operatorname{clip}_{[0,4095]}(Z)\right).
\end{aligned}\tag{M2-6}
\]

$\beta_1=128,\beta_2=32$，$c_3$为中心化SAR码。权重和算术来自既有候选合同，不冒充Gu芯片未公开位级事实。饱和端点为整数，最后饱和与整数化数值上可交换；裁剪标记仍由未裁剪 $Z$判断。固定系数下，相同观测必有相同 $Y$。因此求全观测恒定的输入区间，就能计算整条静态转换。数字端只用 $O$和自身系数。

### 3.3 模拟递推、理想抵消与适用条件

无记忆独立主辅链为

\[
\begin{aligned}
q_1&=Q_1(x),&w_1&=x-D_1(q_1)+d_1,\\
r_1^m&=g_1^m(w_1),&r_1^a&=g_1^a(w_1),\\
q_2&=Q_2(r_1^a),&w_2&=r_1^m-D_2(q_2)+d_2,\\
r_2^m&=g_2^m(w_2),&c_3&=Q_3(r_2^m).
\end{aligned}\tag{M2-7}
\]

代入(M2-6)即可逐次求码，不要求模拟PWL。理想极限提供单位和符号的检查：取 $D_i(q_i)=q_i/4$、两主路增益4、未饱和SAR $c_3=\lfloor128r_2^m\rfloor$，直接代入得到

\[
128r_2^m=2048x-512q_1-128q_2+2048d_1+512d_2.\tag{M2-8}
\]

若数字副本 $\mathsf D_1=2048d_1,\mathsf D_2=512d_2$为整数，全部 $\kappa=1$，则(M2-2)退成恒等函数。中间读出合法且无过载／裁剪时，利用 $\lfloor a+m\rfloor=\lfloor a\rfloor+m$（整数 $m$）得

\[
Y=2048+512q_1+128q_2+c_3-\mathsf D_1-\mathsf D_2
=2048+\lfloor2048x\rfloor.\tag{M2-9}
\]

这证明dither理想抵消与冗余判决补偿。辅路改变粗判决不必改变最终码，但仍可能造成主路过载或数字越域。启用非单位校正时须保持(M2-6)的局部扣除顺序，不能把两个dither都移到全部PWL之后。

### 3.4 阈值怎样反算为全部输入区间

固定dither与系数，枚举路径 $p=(j_1,j_2,j_3)$，标签由(M2-1)给出。令 $h_i=D_i(q_i)-d_i$，路径条件完整写为

\[
\begin{split}
I_p=\mathcal D\ &\cap[\tau_{1,j_1},\tau_{1,j_1+1})\\
&\cap\{x:\tau_{2,j_2}\le g_1^a(x-h_1)<\tau_{2,j_2+1}\}\\
&\cap\{x:\tau_{3,j_3}\le g_2^m(g_1^m(x-h_1)-h_2)<\tau_{3,j_3+1}\}.
\end{split}\tag{M2-10}
\]

第一行使用第一级flash直接读输入的候选；若该节点还有变换，也须先反算。第二行沿辅路，第三行沿主路，不能用同一残余代替两者。

**连续严格递增分支：**从后级阈值 $t$逐层求逆，得到

\[
x_2(t)=h_1+(g_1^a)^{-1}(t),\qquad
x_3(t)=h_1+(g_1^m)^{-1}\!\left(h_2+(g_2^m)^{-1}(t)\right).\tag{M2-11}
\]

第二式先过第二主路逆函数、加回第二CDAC偏移，再过第一主路逆函数、加回第一偏移。上下阈值如此反算后与第一行相交，即得 $I_p$。只对当前分支输出域内的阈值求逆；域外阈值根据原不等式判整段成立或不成立，不能求不存在的根。

逆函数无闭式时，用可靠符号判定的二分法。连续严格单调函数 $H$在 $[a,b]$含根，保留端点异号的半区间，$t$步后根区间宽至多 $(b-a)2^{-t}$。要宽度不超过 $\varepsilon_x$，只需

\[
t\ge\max\!\left(0,\left\lceil\log_2\frac{b-a}{\varepsilon_x}\right\rceil\right).\tag{M2-12}
\]

函数值的包含区间跨0时须提高精度或保留未决区间，不能用近似符号剪枝。近似根不当精确边界，根区间及开闭规则须保留。

**有限单调段／仿射特例：**非单调传输按已知单调段切开，逐段求原像再取并集。递减段按原不等式翻转端点。若细分段内 $r_1^m=a_mx+b_m$、$r_1^a=a_ax+b_a$、$g_2^m(w)=a_2w+b_2$，则 $r_2^m=a_2a_mx+a_2(b_m-h_2)+b_2$。每个约束归结为 $\ell\le ax+b<u$：$a>0$时取 $[(\ell-b)/a,(u-b)/a)$；$a<0$时取 $((u-b)/a,(\ell-b)/a]$；$a=0$时按 $\ell\le b<u$返回整段或空集。这就是精确区间相交算法。

**完整性证明：**任意 $x$在每一级有唯一格号，逐级代入即满足对应路径的全部条件，故属于某个 $I_p$。不同路径的首个不同判决属于互斥半开格，因此不重复。有限单调细分只切集合而不删点。所以非空区间并集覆盖 $\mathcal D$，内部数字字段恒定，(M2-6)给常数码 $y_p$。模拟PWL近似还须在模拟拐点原像处切分才能使用一次关系；数字段不提供模拟拐点。

相邻区间在最终码及需要报告的安全标记相同时可合并；不相邻同码区间保留并集。没有有限单调覆盖或根隔离条件时，上述有限终止保证不成立，转范围方法。

### 3.5 从输入区间长度推到DNL与INL

设互不相交区间 $I_r$对应 $y_r$。码 $k$的总输入宽度与概率为

\[
W_k=\sum_{r:y_r=k}|I_r|,\qquad
\pi_k=\sum_{r:y_r=k}\int_{I_r}p_X(x)\,dx.\tag{M2-13}
\]

均匀输入宽度 $V=x_+-x_-$时 $\pi_k=W_k/V$，理想码宽 $\Delta_x=V/K$。从直方图平均计数 $N/K$得到连续码密度极限

\[
\mathrm{DNL}_k=\frac{N\pi_k}{N/K}-1=\frac{W_k}{\Delta_x}-1,\qquad
D_j^{\rm density}=\sum_{k<j}\mathrm{DNL}_k.\tag{M2-14}
\]

$\sum_kW_k=V$给 $D_K^{\rm density}=0$，可作自检。$W_k=0$是该测度下的零宽／缺码；若孤立点可达该码，另记端点可达性。只有整体按码序单调、各码区间依次相接时，$T_j=x_-+\sum_{k<j}W_k$才是单一转换边界，此时

\[
\mathrm{INL}_j=\frac{T_j-(x_-+j\Delta_x)}{\Delta_x}=D_j^{\rm density}.\tag{M2-15}
\]

非单调时(M2-14)仍可算，不能把它解释为单一边界INL。随机dither独立于输入时，可按已知标签概率加权各 $W_k(d)$；若相关，须在(M2-13)中使用实际 $p(d\mid x)$。混合码密度不等于冻结无dither转换的INL。有限均匀斜坡仍有计数误差，不能把连续宽度极限称成有限计数完全一致。

### 3.6 从输入边界推到连续谱与总失真功率

先要求静态、系数固定、dither固定或关闭。输入 $x(\varphi)=x_0+A\sin\varphi$，$A>0$，全摆幅在建模域内。每个内部边界 $b\in(x_0-A,x_0+A)$对应两个相位

\[
\phi_b^{(1)}=\arcsin\frac{b-x_0}{A}\pmod{2\pi},\qquad
\phi_b^{(2)}=\pi-\arcsin\frac{b-x_0}{A}\pmod{2\pi}.\tag{M2-16}
\]

加0和 $2\pi$、去重排序成 $0=\phi_0<\cdots<\phi_J=2\pi$；在每个开区间中点用(M2-7)、(M2-6)标记码 $y_j$。边界已列全保证整段恒码，中点仅作标记，不用有限采样代替找边界。极值恰落边界的单点不影响积分，有限采样则仍按真实判决处理。

逐段积分 $e^{-im\varphi}$，得到

\[
\begin{aligned}
c_0&=\frac1{2\pi}\sum_jy_j(\phi_{j+1}-\phi_j),\\
c_m&=\frac1{2\pi im}\sum_jy_j(e^{-im\phi_j}-e^{-im\phi_{j+1}}),\quad m\ne0,\\
P_{\rm tot}&=\frac1{2\pi}\sum_jy_j^2(\phi_{j+1}-\phi_j).
\end{aligned}\tag{M2-17}
\]

第二式来自 $\int e^{-im\varphi}d\varphi=-e^{-im\varphi}/(im)$。实输出 $c_{-m}=c_m^*$，以一阶为基波，Parseval给

\[
P_{\rm ac}=P_{\rm tot}-c_0^2,\quad P_s=2|c_1|^2,\quad
P_{n+d}=P_{\rm tot}-c_0^2-2|c_1|^2,\quad
\mathrm{SNDR}=10\log_{10}\frac{P_s}{P_{n+d}}.\tag{M2-18}
\]

因此总噪声失真由有限段平方积分直接计算，不用截断无限谐波和，也不假设白量化噪声。指定谐波集 $\mathcal H$的 $P_h=2\sum_{h\in\mathcal H}|c_h|^2$代入[指标协议](../specifications/ADC_METRICS_PROTOCOL_V1.md)，即可算THD、SNR、ENOB；其余“噪声”仍含未列出的高次谐波。

连续全频SFDR还需 $P_{\rm spur}=\sup_{m\ge2}2|c_m|^2$。以周期交界也计入的跳变量 $\Delta y_j=y_j-y_{j-1}$重排(M2-17)，有

\[
c_m=\frac1{2\pi im}\sum_j\Delta y_j e^{-im\phi_j},\qquad
|c_m|\le\frac{\sum_j|\Delta y_j|}{2\pi|m|}.\tag{M2-19}
\]

仅算有限阶不足以宣称连续全局SFDR；若另外证明全部 $m>M$的上界不超过已算最大杂散幅度，才确认全局最大值，否则只报告有限阶结果或界。尾界是分段常数函数的直接推论，本轮没有重新认证历史连续SFDR。

随机dither时 $|\mathbb Ec_m|^2\ne\mathbb E|c_m|^2$一般成立，只对标签平均曲线积分会漏掉随机残余功率。已知周期标签可在共同周期中加入切换点；非周期／随机条件用实际有限记录，或另给联合概率与完整二阶相关，不能只平均幅度。

### 3.7 同一模型怎样计算有限记录频谱

给定偶数 $N$、基波频点 $0<k_0<N/2$、初相 $\varphi_0$，取

\[
x_n=x_0+A\sin(2\pi k_0n/N+\varphi_0),\quad
\widehat Y_k=\frac1N\sum_{n=0}^{N-1}Y_ne^{-2\pi ikn/N},\quad
\lambda_k=\begin{cases}\sqrt2,&0<k<N/2,\\1,&k=N/2.\end{cases}\tag{M2-20}
\]

$Y_n$由静态区间查询或完整前向递推生成，不能用连续 $c_k$直接替代。去DC不改变 $k>0$的DFT，单边RMS幅度 $A_k=\lambda_k|\widehat Y_k|$满足

\[
\frac1N\sum_n(Y_n-\overline Y)^2=\sum_{k=1}^{N/2}A_k^2,\qquad
S=A_{k_0},\quad D=\sqrt{\sum_{k\ne k_0}A_k^2},\quad P=\max_{k\ne k_0}A_k.\tag{M2-21}
\]

求和／最大值均只取正频率 $1\le k\le N/2$。于是SNDR为 $20\log_{10}(S/D)$、SFDR为 $20\log_{10}(S/P)$。谐波 $h$先算 $r=hk_0\bmod N$再折到 $\min(r,N-r)$，重复只计一次，折到DC／基波的配置按协议拒绝。这给出有限记录的完整指标计算。

静态无记忆且dither固定时，$\gcd(k_0,N)=1$使 $k_0n\bmod N$排列整个相位网格，因此同初相的码多重集合和DFT功率集合不变，只是频点重排。动态、持续更新或时间dither会破坏此论证。连续积分与有限DFT分别包含不同的采样折叠及边界点规则，不能混为同一谱。

### 3.8 边界误差怎样进入码误差与谱误差

边界满足 $H(b(\eta),\eta)=0$，参数 $\eta$改变传输。若邻域可微且 $H_x\ne0$，对方程全微分，并对(M2-16)求导，得到

\[
\frac{db}{d\eta}=-\frac{H_\eta}{H_x},\quad
\frac{d\phi_b^{(1)}}{db}=\frac1{\sqrt{A^2-(b-x_0)^2}},\quad
\frac{d\phi_b^{(2)}}{db}=-\frac1{\sqrt{A^2-(b-x_0)^2}}.\tag{M2-22}
\]

极值附近的相位更敏感。若跳变量及边界个数／顺序保持不变，对(M2-19)求导得

\[
\frac{dc_m}{d\eta}=-\frac1{2\pi}\sum_j\Delta y_j e^{-im\phi_j}\frac{d\phi_j}{d\eta},\qquad
\frac{d(2|c_m|^2)}{d\eta}=4\operatorname{Re}\!\left(c_m^*\frac{dc_m}{d\eta}\right).\tag{M2-23}
\]

冗余抵消使某内部边界 $\Delta y=0$，其一阶输出谱作用也为0。边界贡献相干相加，所以最大DNL不能单独决定SFDR。边界碰撞、切触极值、码值改变或门跨越时，光滑条件失效，须重新分区或用包含界。

不需可微性还有有限变化界：两条冻结转换仅在输入集 $E$不同，且 $|Y'(x)-Y(x)|\le J$，则由逐点平方不等式积分有

\[
\mathbb E[(Y'-Y)^2]\le J^2\Pr\{X\in E\}.\tag{M2-24}
\]

只移动若干边界且相邻码保持时，$E$可用各旧／新边界之间的区间并集覆盖。均匀输入用其宽度除 $V$，正弦用相位长度除 $2\pi$。这是码差功率界，性能增减还含码差与原误差交叉，不能直接判改善方向。

### 3.9 动态与后台学习的可执行有限递推

令 $z_n=(z_{1,n}^m,z_{1,n}^a,z_{2,n}^m)$为本次开始的模拟状态，$a_n$为完整数字隐藏状态。指定每条动态映射 $F$后，严格按节点顺序计算：

\[
\begin{aligned}
q_{1,n}&=Q_1(x_n),&w_{1,n}&=x_n-D_1(q_{1,n})+d_{1,n},\\
(r_{1,n}^m,z_{1,n+1}^m)&=F_1^m(w_{1,n},z_{1,n}^m),&
(r_{1,n}^a,z_{1,n+1}^a)&=F_1^a(w_{1,n},z_{1,n}^a),\\
q_{2,n}&=Q_2(r_{1,n}^a),&w_{2,n}&=r_{1,n}^m-D_2(q_{2,n})+d_{2,n},\\
(r_{2,n}^m,z_{2,n+1}^m)&=F_2^m(w_{2,n},z_{2,n}^m),&c_{3,n}&=Q_3(r_{2,n}^m),\\
Y_n&=C(O_n,E(a_n)),&a_{n+1}&=U(a_n,O_n).
\end{aligned}\tag{M2-25}
\]

$E$是隐藏状态到导出斜率，$C$由(M2-2)—(M2-6)给出，$U$在下文展开。窗口候选还把相关和、槽号及必要源状态存入 $a$；仅存导出斜率不够。给定初态、输入和确定映射后，由 $n$归纳唯一生成有限记录，不代表未知 $F$已被识别。

**一阶建立特例：**若放大相位内目标 $u_n=g(w_n)$恒定、$\dot r=-\omega_p(r-u_n)$、起点保持上次输出，解微分方程得到

\[
r_n=(1-\rho)u_n+\rho r_{n-1},\quad\rho=e^{-\omega_pT_a},\quad
r_n=\rho^{n+1}r_{-1}+(1-\rho)\sum_{t=0}^n\rho^{n-t}u_t.\tag{M2-26}
\]

若目标已知且为 $N$周期、$0\le\rho<1$，令首尾相等后移项得

\[
r_{-1}^*=\frac{(1-\rho)\sum_{t=0}^{N-1}\rho^{N-1-t}u_t}{1-\rho^N}.\tag{M2-27}
\]

两个同目标解的差为 $\rho^{n+1}$乘初差，故周期解唯一且吸引。目标若依赖尚未确定的阈值切换或反馈，须先验证周期路径自洽，不能推成整个混合系统的唯一周期定理。每次复位到固定电平则是另一动态模型。

**原Gu窗口候选的 $U$：**每窗120槽，窗口内旧隐藏整数 $A_{i,j,w}$的单位为 $2^{-22}$，导出规则为

\[
K_{i,j,w}=\operatorname{clip}_{[0,2047]}R(A_{i,j,w}/4096),\qquad
\kappa_{i,j,w}=K_{i,j,w}/1024.\tag{M2-28}
\]

用同一旧导出算(M2-6)的局部 $v_i$和下门限 $b_{i,j}=Q_{1/8}(\beta_i\sum_{h<j}\kappa_{i,h})$（连续参照去掉 $Q$），$G_{i,0}=1$、$G_{i,j}={\bf1}\{|v_i|\ge b_{i,j}\}$。采用集合 $\mathcal I_w$的请求与提交为

\[
\begin{aligned}
P_{i,j,w}&=\sum_{n\in\mathcal I_w}\mathsf D_{i,n}v_{i,n}G_{i,j,n},\\
\delta A_{i,j,w}&=R(-2^{22}\mu_{i,j}m_wP_{i,j,w}),\\
A_{i,j,w+1}&=\operatorname{clip}_{[0,2047\cdot4096]}(A_{i,j,w}+\delta A_{i,j,w}).
\end{aligned}\tag{M2-29}
\]

原四字候选取 $\mathcal I_w=\{120w,120w+1,120w+2,120w+3\}$、$m_w=30$；全槽参照取全部120槽、$m_w=1$。原合同的步长、单位初态及dither尺度可以直接代入：

\[
\boldsymbol\mu_1=\frac{\lambda(1,3,6,12)}{262144000},\quad
\boldsymbol\mu_2=\frac{\lambda(1,3,6,12)}{16384000},\quad
A_{i,j,0}=2^{22},\quad
d_i=\frac{\sigma_i}{32},\quad(\mathsf D_1,\mathsf D_2)=(64\sigma_1,16\sigma_2).
\tag{M2-29a}
\]

其中 $\lambda=1$或原1/4对照，$\sigma_i\in\{-1,1\}$的完整序列须给定，不能仅凭正负各半假定其独立。名义前端标签为 $-4,\ldots,4$，内部阈值为 $(-7,-5,-3,-1,1,3,5,7)/8$，CDAC为 $q/4$；名义SAR在 $[-1,1)$内为 $\lfloor128v\rfloor$、端部饱和到 $[-128,127]$，过载另记。这是一份可代入的候选几何，非任意未知器件的默认参数。

乘30只是原始和尺度。两bank请求全部用同一旧状态，窗口末同时提交，下窗使用新导出。逐转换候选则另取每次一字／一提交，不混同窗口合同。定义来源见[基线合同§4.1](../reports/GU_ALGORITHM_EVALUATION_V1.md#41-d-126-基线合同核对与实现映射)与[独立有理数算术](../../src/adc_research/theory/static_fixed_contract.py)。

这把已批准基线写为确定递推，不新选步长／相位，也不证明相关为零等于输出最优。将(M2-28)—(M2-29)接入(M2-25)，再以(M2-20)—(M2-21)评分，已完成有限后台记录的计算闭环；一般长期稳定及在线达到性仍需第“五”节的独立条件。

### 3.10 未知传输怎样生成覆盖性码区间

$\theta$只知位于可信集合 $\Theta$时，结果须覆盖全部允许对象。先构造每条路径的输出范围：扫描点 $t_j$满足 $g(t_j)\in[\ell_j,u_j]$，全域有独立依据的Lipschitz常数 $L_g$。由 $|g(v)-g(t_j)|\le L_g|v-t_j|$同时对全部扫描点成立，得

\[
\underline g(v)=\max_j(\ell_j-L_g|v-t_j|),\quad
\overline g(v)=\min_j(u_j+L_g|v-t_j|),\quad
G(I)=\left[\inf_{v\in I}\underline g(v),\ \sup_{v\in I}\overline g(v)\right].\tag{M2-30}
\]

实际函数必在上下锥界之间，故 $G(I)$覆盖整个查询区间。这些界分段一次，极值只需检查区间端点、扫描点和一次分支交点，有限可算。数据自洽可用有限条件检查：

\[
\ell_i\le u_j+L_g|t_i-t_j|\quad\text{对全部 }i,j.\tag{M2-30a}
\]

必要性由扫描点间Lipschitz关系直接得到；充分性则取 $g=\underline g$：有限个 $L_g$-Lipschitz下锥的最大值仍为 $L_g$-Lipschitz，在每个 $t_j$至少为 $\ell_j$，由该有限条件又不超过 $u_j$。故确有一个函数满足全部扫描区间。条件失败报空模型，条件通过只说明数学自洽，不证明物理覆盖。全查询域在证据有效域内，不外推；样点割线不能证明全域 $L_g$。高效双向收紧见[网格范围构造](GRID_TO_ANALOG_ENVELOPE_V1.md)。

对电压 $V=[a,b]$及保持严格有序的阈值区间 $[\ell_j^\tau,u_j^\tau]$，格号外界为

\[
j_{\min}=\#\{j:u_j^\tau\le a\},\quad
j_{\max}=\#\{j:\ell_j^\tau\le b\},\qquad j\in\{j_{\min},\ldots,j_{\max}\}.\tag{M2-31}
\]

两端分别计必然和最多可能跨过的阈值。对每个可能 $q_1$，先与该格允许的输入外界相交，再执行

\[
W_1=X_{q_1}-\mathcal D_1(q_1)+\mathcal d_1,\quad
R_1^m=G_1^m(W_1),\quad R_1^a=G_1^a(W_1),\quad
W_2=R_1^m-\mathcal D_2(q_2)+\mathcal d_2,\quad R_2^m=G_2^m(W_2).\tag{M2-32}
\]

花体CDAC及注入是电压区间，$[a,b]-[c,d]=[a-d,b-c]$。从辅路枚举全部 $q_2$、从末级枚举全部SAR码，形成观测外集；数字标签保留允许配对。固定斜率时逐观测执行(M2-6)取码最小最大值。

后台或动态时，令 $s_n$含模拟状态、完整数字状态、窗口相关和及源状态；从初始外集开始，将(M2-25)展开的完整转移记为 $T_n$，并集传播为

\[
\begin{aligned}
\mathcal S_{n+1}&\supseteq\bigcup_{s\in\mathcal S_n,\theta\in\Theta}\{T_n(s,\theta)\},\\
[L_n,U_n]&\supseteq\{C(O_n(s,\theta),E(a(s))):s\in\mathcal S_n,\theta\in\Theta\}.
\end{aligned}\tag{M2-33}
\]

输入有范围时也作联合取值或包含性区间运算；数字有限状态可枚举，盒合并须包含全部真像。**归纳证明：**初始真状态在外集中；本次真判决由(M2-31)枚举，电压由(M2-32)包含，真实数字输出与下一状态就在并集中。所以每次 $Y_n\in[L_n,U_n]$，下一步继续成立。

允许同一参数跨样本重新任取、主辅分别取极值，会放宽不可能同时达到的组合，仍是有效外界但可能很宽。不能删除不利分支收窄。一般式不表示任意动态已有高效实现；现有[静态主辅传播](STATIC_MAIN_AUX_OBSERVATION_BOUNDS_V1.md)、[短记录在线连接](STATIC_ANALOG_TO_ONLINE_CODE_BOUNDS_V1.md)、[整数状态范围](FIXED_ONLINE_STATE_BOX_BOUNDS_V1.md)、[有理数电压组合](RATIONAL_STATIC_TO_FIXED_CODE_BOUNDS_V1.md)只覆盖各自声明的合同。未知阈值次序、数字越域或未覆盖历史，均须先补模型。

### 3.11 从码范围证明性能界与证据精度要求

取参考记录 $y^0$，可用各码区间中点（仅为证明参照），令

\[
r_n=\max(|L_n-y_n^0|,|U_n-y_n^0|),\qquad
\epsilon=\sqrt{\frac1N\sum_nr_n^2}.\tag{M2-34}
\]

所有允许记录满足 $\|Y-y^0\|_2/\sqrt N\le\epsilon$。去DC是正交投影，DFT按(M2-21)保持均方范数；基波投影、余谱投影均不增范数，故三角不等式给

\[
\begin{aligned}
S_-&=(S_0-\epsilon)_+\le S\le S_0+\epsilon=S_+,\\
D_-&=(D_0-\epsilon)_+\le D\le D_0+\epsilon=D_+,\\
P_-&=(P_0-\epsilon)_+\le P\le P_0+\epsilon=P_+.
\end{aligned}\tag{M2-35}
\]

第三行用 $|\|a\|_\infty-\|b\|_\infty|\le\|a-b\|_2$，$(v)_+=\max(v,0)$。再用比值单调性，得

\[
20\log_{10}\frac{S_-}{D_+}\le\mathrm{SNDR}\le20\log_{10}\frac{S_+}{D_-},\qquad
20\log_{10}\frac{S_-}{P_+}\le\mathrm{SFDR}\le20\log_{10}\frac{S_+}{P_-}.\tag{M2-36}
\]

分子下界为0取 $-\infty$，分母下界为0取上界 $+\infty$。若基波也可能为0，另报“基波可能缺失”，不保证指标有定义；若确定余谱为0且基波正，对应比值为 $+\infty$，全零信号不作完美性能。分子与分母端点不必同时可达，仍为有效外界。

少数点不确定时，用中点 $c_n=(L_n+U_n)/2$、半宽 $h_n=(U_n-L_n)/2$，逐项DFT三角不等式还给

\[
|\widehat Y_k-\widehat c_k|\le\frac1N\sum_nh_n,\qquad
\eta_k=\frac{\lambda_k}{N}\sum_nh_n.\tag{M2-37}
\]

所以基波范围为 $(A_{k_0}(c)-\eta_{k_0})_+$到 $A_{k_0}(c)+\eta_{k_0}$，杂散范围为 $\max_{k\ne k_0}(A_k(c)-\eta_k)_+$到 $\max_{k\ne k_0}(A_k(c)+\eta_k)$。代入SFDR比值并与(M2-36)取交集。不要求样本误差独立，见[有限记录证明](FINITE_RECORD_PERFORMANCE_BOUNDS_V1.md)、[逐频点证明](BINWISE_SFDR_BOUNDS_V1.md)。

若目标是证明SNDR至少 $T$，令 $\gamma=10^{T/20}$，要求 $S_0-\epsilon\ge\gamma(D_0+\epsilon)$，移项就得到资料精度的充分预算

\[
\epsilon\le\frac{S_0-\gamma D_0}{1+\gamma},\qquad S_0>\gamma D_0.\tag{M2-38}
\]

SFDR同类预算以 $P_0$替换 $D_0$。这只是该证明方法的充分条件，不是ADC物理必要精度。严格数值认证还须包含函数值、三角／平方根／对数及向外舍入误差，参见[反向预算](CODE_ENVELOPE_RESOLUTION_BUDGET_V1.md)与[短记录数值认证](CERTIFIED_FINITE_RECORD_SPECTRUM_V1.md)。普通浮点FFT一致性不替代包含证明。

### 3.12 可执行流程与终止条件

**算法A：冻结静态转换及连续周期预测。**

1. 固定模型包、dither和斜率。按(M2-10)—(M2-12)求全部非空输入区间；仿射特例直接相交一次不等式。
2. 每区间用(M2-6)取常数码与安全标记。检查不重叠、完整覆盖及总长度 $V$；长度相等不能代替端点归属检查。
3. 用(M2-13)—(M2-15)算静态指标，用(M2-16)—(M2-18)算连续SNDR和指定谐波。连续全局SFDR还需(M2-19)尾部控制。
4. 根未隔离、边界顺序未定或存在无定义分支，返回包含区间／未决项，转算法C，不能靠加密网格声称精确。

有限分支及固定求根精度下终止；二分上限由(M2-12)给出。已取得 $R$个区间、要求 $H$个谐波时，相位排序 $O(R\log R)$、谱求和 $O(RH)$；分区构造另依赖路径及单调段数。

**算法B：指定动态与后台学习的有限记录。**

1. 冻结完整初态、输入／dither／更新／测量时序及有限长度 $N$。
2. 依(M2-25)前向算模拟节点和原始码，再用旧导出从后到前求 $Y_n$，积累本次门控乘积。
3. 窗口边界才依(M2-28)—(M2-29)同时提交；保留过载、越域、裁剪及状态。逐转换合同按其时刻另行提交。
4. 按(M2-20)—(M2-21)评分。若测量有抽取，先对实际码流执行明确的抽取器，再按新采样率评分。

## 四、观测能力和数字校正能力

“可辨识”指：在允许的训练输入、dither 和观测下，能不能区分两种不同的电路情况。若两种电路生成相同的可见数据，却在测试条件下产生不同频谱，任何只使用这些数据的算法都不能保证正确选中其中一种。这是要寻找的关键反例，不是假设某种算法不够聪明。

**现已得到一个有限观测反例。**EXP-020 在冻结的静态候选架构中，只改变第二级主路模拟传输：两条连续、奇对称、严格单调的曲线对 4096 个输入码中心和四种 dither 组合产生完全相同的数字训练记录；一条未见过的正弦记录却有不同的末级码、最终码和频谱指标。因此，这批训练数据不足以给该留出记录一个唯一的性能值。该结论只针对给定的有限训练集与允许局部扰动的曲线类；它不意味着增加观测或施加有电路依据的斜率／曲率约束后仍然无法预测，也不证明 Gu 在线校准在测试时无法继续适应。一般数学构造可用未访问区间内的足够小的光滑扰动；本次软件实例使用人为合成的模拟 PWL 曲线，尚未验证真实芯片的传输形状。

再问“可校正”：即使离线知道了电路真实状态，给定的数字码、字长和校正结构是否足以消掉误差？若不同理想输入产生完全相同的可见码和 dither 标记，但要求不同的目标输出，仅修改这些码的数字算法就无法同时满足两者。过载和错误判决尤其需要与函数表示误差分开检查。

[数字观测与可校正误差下限](OBSERVATION_CORRECTION_LIMITS_V1.md)将这一点写成一般结论：固定一条电路、输入条件和真实可见信息后，任意逐转换数字映射的最小平均绝对码误差，由每个观测对应的目标码条件分布决定。Gu 的实际码误差可在同一评分条件下分成观测限制、数字表示限制和训练差距。它与 EXP-020 的“不同电路拥有相同有限训练数据”是**两种不同的信息不足**；不能用一个反例直接给另一种下限数值。

数字 PWL 的基函数空间可用于分析**它能表示哪些校正映射**。这是数字函数的空间，不是模拟 $g$ 必须属于的空间。投影或“最佳系数”必须先规定输入分布、数字观测和误差目标；Gu 的去相关更新不自动等于最小码误差的投影。待研究的误差至少包括：不可区分信息造成的下限、表示误差、有限样本估计误差、dither 直接代价、量化／定点误差和遗漏的动态机制。

对一个预先给定的低两有限方向δ，数字字与状态可给Bδ，未知目标仅经pδ=E[(ψℓᵀδ)(T−2048−512q1)]进入完整连续损失Bδ−2pδ。故目标投影下界超过Bδ/2即可认证该方向，不必先识别整条g；Gu相关量满秩并不自动提供这个投影，见[给定方向的信息判别](OBSERVATION_CORRECTION_LIMITS_V1.md#给定改善方向所需的目标投影与粗判决的判别限度ng-21223943补证)。一例已有均值→W的原正弦条件足够，独立粗q1目标盒即使精算仍跨零；后者是明确放松集的限度，不是完整历史物理反例。评价一个已给方向、发现方向、合法整数表示和因果达到继续分开。

## 五、校准闭环、误差机制与条件理论

> 2026-10-19整合推导。本节在第三节的信号链上，完整展开校准算法怎样改变实际系数历史、整数码误差、残余功率与最大杂散。有限记录恒等式不要求收敛；统计闭式只在列出的概率与线性条件下成立。原有NG-07／08／12／19—23／29—30／33／40—46等关系与标准平方展开、矩递推、DFT恒等式在此合并，不另称未知增益一般解。

### 5.1 比较对象、信息边界与计算次序

比较同一输入、模拟传输、主辅动态初态和dither下的两个数字政策：参考政策产生 $Y_n^0$，待分析校准政策产生 $Y_n$。参考可以是单位系数不更新、固定合法系数，或另一条明确学习轨迹。默认数字系数不反馈模拟节点，也不改变dither；因而两政策共享同一物理数字观测流 $O_n$。若政策改变模拟激励或采样，须分别重算(M2-25)的物理路径，不能沿用共享观测的归因。

设窗口长 $L=120$、$w(n)=\lfloor n/L\rfloor$，$a_w$含八个Q22隐藏状态及必要计数／源状态，$\kappa_w=E(a_w)$为当窗实际Q1.10导出。物理映射、读出 $C$、导出 $E$和提交 $U$均已在(M2-1)—(M2-7)、(M2-25)、(M2-28)—(M2-29a)展开。本次输出使用旧导出，窗口末更新。离线目标 $T_n$不进入 $U$，定义

\[
Y_n=C(O_n,\kappa_{w(n)}),\quad
Y_n^0=C(O_n,\kappa_{w(n)}^0),\quad
e_n^0=Y_n^0-T_n,\quad\delta_n=Y_n-Y_n^0,\quad
\langle v\rangle=\frac1N\sum_{n=0}^{N-1}v_n.
\tag{CAL-1}
\]

给定模型、完整初态和输入／标签序列，先计算全部 $O_n$，按各政策独立重算门、读出和请求，得到两条真实 $\kappa_w$及 $Y_n$。这给出精确比较；直接把另一条路径的请求移过来，只是保存历史上的代数诊断。相同导出也不保证隐藏状态或下一次提交相同。

### 5.2 从门控、抽取与有限字长到实际导出变化

把(M2-29)原始和改写为统一的每转换尺度。令 $\mathcal I_w$为采用槽位、$m_w$为原30或1倍缩放，按当窗自身旧状态计算向量

\[
\widehat c_{i,j,w}=\frac{m_w}{L}\sum_{n\in\mathcal I_w}
\mathsf D_{i,n}v_{i,n}G_{i,j,n},\qquad
\Lambda=L\operatorname{diag}(\mu_{i,j}).\tag{CAL-2}
\]

八维排列在本节统一为后级四坐标、前级四坐标。门依赖局部输出及当时累计门限，$\widehat c$不是理想目标误差梯度。四字和乘30与全槽和的标度对齐，但不保证样本、均值或协方差相同。

令 $h_w=2^{-22}A_w$为隐藏状态的实数单位，$\epsilon_w^e=\kappa_w-h_w$为导出误差。请求先最近偶数取整，再按隐藏状态范围饱和。定义本次请求取整误差 $\epsilon_w^r$、饱和修正 $\epsilon_w^s$，则由(M2-28)—(M2-29)精确得到

\[
\begin{aligned}
q_w:=h_{w+1}-h_w&=-\Lambda\widehat c_w+\epsilon_w^r+\epsilon_w^s,\\
\Delta\kappa_w:=\kappa_{w+1}-\kappa_w
&=-\Lambda\widehat c_w+\epsilon_w^r+\epsilon_w^s
+\epsilon_{w+1}^e-\epsilon_w^e.
\end{aligned}\tag{CAL-3}
\]

请求舍入给每坐标 $|\epsilon_w^r|\le2^{-23}$；在原合法隐藏域内 $|\epsilon_w^e|\le2^{-11}$。饱和修正不能默认是小量。导出误差是相邻两次之差，不是每窗独立噪声；累计后它只剩两端之差。请求非零、隐藏变化、导出变化和输出变化分别判断。

固定同一个状态／完整源窗口，用 $\widehat c^S$和 $\widehat c^F$表示缩放四字与全槽相关。任何概率条件下都有

\[
\widehat c^S=\widehat c^F+b_w^{\rm sel},\qquad
\mathbb E[\widehat c^S\mid\mathcal F_w]
=\mathbb E[\widehat c^F\mid\mathcal F_w]+\mathbb E[b_w^{\rm sel}\mid\mathcal F_w].
\tag{CAL-4}
\]

$\mathcal F_w$表示窗口前的完整数学历史，不表示额外授予算法的观测。只有另证条件选择律保持全槽相关均值，第二个期望项才为0。选样协方差也保留所有槽间交叉；不从计数PRNG或标签正负各半推独立。两政策自身状态不同的相关差还包含状态／门差，不能全部叫选样偏差。

### 5.3 两级系数变化怎样传到一个最终码

固定同一数字观测，取旧、新有效系数 $\kappa$、$\kappa+d$，$d=(d_2,d_1)$。先用未作Q3、最终整数化和饱和的连续读出 $Z^c$。设旧后级基函数为 $\psi_2=\psi_2(c_3)$、旧前级输入为 $R_1$、$\psi_1=\psi_1(R_1)$。后级变化导致

\[
\Delta R_1=\psi_2^Td_2.
\tag{CAL-5}
\]

若旧到新前级连续输入的整段连线处于同一数字PWL线性段，编号为 $j$，则 $\psi_1(R_1+\Delta R_1)=\psi_1(R_1)+e_j\Delta R_1$。展开新前级读出，得到有限变化的精确式

\[
\begin{aligned}
Z^c(\kappa+d)-Z^c(\kappa)&=\ell+b,\\
\ell&=J^Td,\qquad J=(\kappa_{1,j}\psi_2,\ \psi_1),\\
b&=d_{1,j}\psi_2^Td_2.
\end{aligned}\tag{CAL-6}
\]

这是将 $(\kappa_1+d_1)^T[\psi_1+e_j\psi_2^Td_2]$展开的结果。$\ell$包含两级一阶传播，$b$是两级变化的乘积；因此两级平均系数正确，也不保证平均输出等于把平均系数代入的输出。第一段穿过零点时局部线性式仍成立；其他段须检查符号及段边界。

对实际整数输出定义

\[
\eta=Y(\kappa+d)-Y(\kappa)-\ell-b,\qquad
\delta=\ell+b+\eta.\tag{CAL-7}
\]

在上述段条件内，$\eta$包含Q3、最终整数化及饱和的**旧新差**，不假设零均值或1/12功率。若跨段，直接用(M2-2)—(M2-6)算 $\delta$；也可把跨段修正纳入 $\eta$，但此时它不再是纯算术余项，不能套小舍入界。原理与证据见[两级理论§7](STATIC_CASCADE_MILLION_SUPPORT_AND_PROJECTION_V1.md#7-两级同时更新平均相关怎样连接到同记录净mse)。

### 5.4 从实际输出增量推到净MSE与目标相容条件

由 $Y-T=e^0+\delta$直接平方，任意实际轨迹都严格满足

\[
\Delta\mathcal L:=\langle(Y-T)^2\rangle-\langle(Y^0-T)^2\rangle
=2\langle e^0\delta\rangle+\langle\delta^2\rangle.
\tag{CAL-8}
\]

因此有益校准要求负的纠偏交叉项超过非负的输出变化功率。把(CAL-7)代入，便得到包括两级交互和算术的七项展开：

\[
\begin{aligned}
\Delta\mathcal L={}&2\langle e^0\ell\rangle+\langle\ell^2\rangle
+2\langle e^0b\rangle+2\langle\ell b\rangle+\langle b^2\rangle\\
&+2\langle(e^0+\ell+b)\eta\rangle+\langle\eta^2\rangle.
\end{aligned}\tag{CAL-9}
\]

前两项是一次／二次系数作用，$\ell b$、$b^2$分别需要三阶、四阶系数乘积；不能把完整两级损失压成一个系数方差。式(CAL-8)不需段保护；式(CAL-9)中的归因解释按§5.3的条件使用。

固定后级、固定评价观测且前级连续无裁剪时，输出对前级系数 $k$线性。令 $\psi$为前级基函数，$t=T-2048-512q_1+\mathsf D_1$，则

\[
\mathcal L_c(k)=\langle(\psi^Tk-t)^2\rangle,\quad
H=\langle\psi\psi^T\rangle,\quad g=Hk-\langle\psi t\rangle,\quad
\mathcal L_c(k+d)-\mathcal L_c(k)=2g^Td+d^THd.
\tag{CAL-10}
\]

这是精确二次式，$H\succeq0$；$2g$才是此连续损失的梯度，整数阶梯不取该普通导数。固定门邻域的Gu相关方程却是 $c(k)=A_c k-b_c$，其中 $A_c=\mathbb E_Q[(\mathsf D_1G)\psi^T]$、$b_c=\mathbb E_Q[\mathsf D_1^2G]$，学习规律 $Q$可以不同于评价规律。相关根 $k_G$成为该连续损失最小点的条件是 $Hk_G=\langle\psi t\rangle$；局部满秩或 $c=0$本身不提供此条件。

若更新 $d=-\Lambda_1\widehat c$，且评价记录固定、请求随机性不改变它，令 $m_c=\mathbb E\widehat c$、$V_c=\operatorname{Cov}(\widehat c)$，则(CAL-10)取期望得

\[
\mathbb E\Delta\mathcal L_c
=-2g^T\Lambda_1m_c+m_c^T\Lambda_1H\Lambda_1m_c
+\operatorname{tr}(H\Lambda_1V_c\Lambda_1).
\tag{CAL-11}
\]

改善要求整个右端为负；无偏相关估计只处理 $m_c$，不消除目标不相容或波动项。用于真实两级、门跨越、定点或训练样本自身评分时，应回到(CAL-8)—(CAL-9)，不能直接套该三项式。原[EXP-022](../reports/experiments/EXP_022_K1_OBJECTIVE_AUDIT_V1.md)的零相关点约1.010000与最小**平均绝对**码误差点约1.002608也是目标区别的条件例；其加权中位数结论不当作本节MSE最小解。

### 5.5 实际请求怎样形成有限记录的平均位置

取 $W$个完整等长窗口，参与输出的状态是 $\kappa_0,\ldots,\kappa_{W-1}$，最后提交的 $\kappa_W$没有在这段记录中读出。展开逐窗增量并交换有限求和，得到

\[
\overline\kappa=\kappa_0+
\sum_{t=0}^{W-2}\frac{W-1-t}{W}\Delta\kappa_t.
\tag{CAL-12}
\]

更直接地用实际隐藏变化 $q_t$与导出误差，有

\[
\overline\kappa-\kappa_0
=\sum_{t=0}^{W-2}\frac{W-1-t}{W}q_t
+\overline\epsilon^e-\epsilon_0^e.
\tag{CAL-13}
\]

因为 $q_t$在后面的 $W-1-t$个输出窗口生效，早期请求在平均位置中权重更大。代入(CAL-3)就从采用相关、取整、饱和接到实际位置，而不是把无权相关均值冒称其全部原因。不同窗口输出数不等时，权重改为“提交后剩余输出数／总输出数”。未来均值仅作离线诊断，不进入在线更新。

### 5.6 平均位置、持续变化与状态—输入关联

先在**同一固定评价矩阵** $\Psi$上评价 $M$个前级状态 $k_r$，后级固定且连续无裁剪。令 $\bar k=M^{-1}\sum k_r$、$\Sigma=M^{-1}\sum(k_r-\bar k)(k_r-\bar k)^T$、$H=\Psi^T\Psi/N$，则逐状态展开平方，混合项因 $\sum(k_r-\bar k)=0$消失，得

\[
\frac1M\sum_r\frac{\|\Psi k_r-t\|^2}{N}
=\frac{\|\Psi\bar k-t\|^2}{N}+\operatorname{tr}(H\Sigma).
\tag{CAL-14}
\]

无需状态独立、稳态或白噪声。第一项还可按正规方程拆成固定表示投影残差与平均位置偏差；算术变化另加 $2\langle e_c\eta\rangle+\langle\eta^2\rangle$。

但真实后台的第 $n$个状态只作用于当时的输入，不能把(CAL-14)当作真实时间轨迹。固定后级条件下，令 $d_n=\kappa_{1,w(n)}-\bar\kappa_1$、$\bar e_n=\psi_n^T\bar\kappa_1-t_n$，即使 $\langle d_n\rangle=0$，实际连续损失仍是

\[
\mathcal L_{\rm path,c}=\langle\bar e^2\rangle
+2\langle\bar e_n\psi_n^Td_n\rangle
+\langle d_n^T\psi_n\psi_n^Td_n\rangle.
\tag{CAL-15}
\]

第二项一般不消失，第三项一般也不等于固定 $H$与无权系数协方差之积。输出基函数、目标、时刻与状态相关时，持续变化既可能有益也可能有害；两级同时变化再保留(CAL-9)的乘积项。因此“平均位置正确”不自动保证实际后台性能，“所有波动必有害”也不是一般结论。

### 5.7 一个从学习率解析算到输出损失的完整特例

为真正闭合均值与二阶矩，采用已有标量控制的明确条件：$D=\pm d$、每窗 $m$条独立同分布观测、不同窗口独立且独立于旧系数；原始码 $R$可包含已指定的量化，校正 $v=kR-D$，无门、无请求取整／饱和。令 $\alpha=\mu p$，则

\[
k_{w+1}=\left(1-\alpha\sum_{i=1}^mD_iR_i\right)k_w+\alpha m d^2.
\tag{CAL-16}
\]

写 $B=\mathbb E[DR]$、$C_2=\mathbb E[(DR)^2]$、$r=1-\alpha mB$、$v_a=\alpha^2m(C_2-B^2)$、$q=r^2+v_a$、$c=\alpha md^2$。随机乘子均值为 $r$、方差为 $v_a$，与旧状态独立；对乘积取均值、用全方差展开，得到**精确闭合**的递推

\[
M_{w+1}=rM_w+c,\qquad
V_{w+1}=qV_w+v_aM_w^2.
\tag{CAL-17}
\]

$M_w=\mathbb E k_w$、$V_w=\operatorname{Var}k_w$。若 $B>0$，$k_*=d^2/B$，有限解为

\[
M_w=k_*+r^w(M_0-k_*),\qquad
V_w=q^wV_0+v_a\sum_{t=0}^{w-1}q^{w-1-t}M_t^2.
\tag{CAL-18}
\]

所以平均收敛要求 $|r|<1$，二阶收缩系数则要求 $q<1$。当 $\alpha>0$、$B>0$且相应分母正，条件分别化为

\[
0<\alpha<\frac{2}{mB},\qquad
0<\alpha<\frac{2B}{mB^2+C_2-B^2},\qquad
V_\infty=\frac{v_a k_*^2}{1-q}\quad(q<1).
\tag{CAL-19}
\]

第二式由 $q=1-2\alpha mB+\alpha^2[m^2B^2+m(C_2-B^2)]$解出。稳定均值不保证稳定二阶；恒步长且 $v_a>0$时，学习时间变长不能消除稳态方差。零方差／临界点按原递推处理，不跨分母为0的情形套极限式。

在独立评价样本上，目标为未加dither信号 $X$，令 $T'=X+D$、$J_R=\mathbb E R^2>0$、$H_R=\mathbb E[RT']$、$Q_T=\mathbb E(T')^2$。从 $(kR-T')^2$展开并完成平方，严格得到

\[
\begin{aligned}
k_{LS}&=H_R/J_R,\qquad \mathcal L_{\min}=Q_T-H_R^2/J_R,\\
\mathbb E\mathcal L_w&=\mathcal L_{\min}
+J_R\left[(M_w-k_{LS})^2+V_w\right].
\end{aligned}\tag{CAL-20}
\]

至此从给定输入／量化分布求 $B,C_2,J_R,H_R,Q_T$，经 $\alpha,m$求启动均值／方差，再求有限或稳态输出损失，已经得到一个完整解析特例。若 $R=a(X+D)$且 $D$中心化并独立于 $X$，则 $k_*=k_{LS}=1/a$；量化时 $B=ad^2+\mathbb E[D(R-a(X+D))]$，根偏差保留，减步长通常只改变到达速度和波动。

这里输出损失还不是SNDR：连续后台输入与系数相关或记录有时间相关时，必须用下文的完整时域／频域关系。不能把(CAL-17)套给Gu八状态。既有精确标量证据见[标量理论§2、8—9](MILLION_SAMPLE_SCALAR_MEAN_NOISE_AND_QUANTIZATION_V1.md)。

### 5.8 两级局部收敛与输入切换：哪些量必须另给

对连续、未饱和的两级平均映射，若在保护邻域内已证明 $\bar c(\kappa_*)=0$及可微性，设 $A_*=\partial\bar c/\partial\kappa$、$x_w=\kappa_w-\kappa_*$。把(CAL-3)写为

\[
x_{w+1}=F x_w+u_w,\quad F=I-\Lambda A_*,\qquad
x_w=F^wx_0+\sum_{t=0}^{w-1}F^{w-1-t}u_t.
\tag{CAL-21}
\]

$u_w$若包含真实非线性余项、条件相关波动及算术误差，此式是余项定义下的精确变分关系，尚未闭合；把它作为常矩阵加性噪声模型计算，必须独立证明余项范围或其联合概率律，并保证全轨迹不出保护邻域。$A_*$是相关矩导数，不默认是正定Gram矩阵。平均线性稳定要求 $\rho(F)<1$；非对称矩阵还有瞬态放大，不能只用实对称LMS步长结论。

在另一个**已明确成立的线性随机模型**中，若 $u_w$零均值、与当前状态不相关，且 $\operatorname{Cov}(u_w)=Q_w$，才得到

\[
\Sigma_{w+1}=F\Sigma_wF^T+Q_w,\qquad
\Sigma_\infty=\sum_{t=0}^\infty F^tQ(F^T)^t\quad(\rho(F)<1,Q_w=Q).
\tag{CAL-22}
\]

证明是将(CAL-21)去均值后外积取期望，交叉项在所列条件下为0。真实 $u_w$与状态相关时，应加 $F\operatorname{Cov}(x_w,u_w)+\operatorname{Cov}(u_w,x_w)F^T$，不能漏掉；这也是一般Gu二阶矩尚未闭合的具体位置。

工作条件改变使参考根成为 $\kappa_{*,w}$时，$x_w=\kappa_w-\kappa_{*,w}$的下一步另有强迫项 $-(\kappa_{*,w+1}-\kappa_{*,w})$。单次切换后若均值偏差按 $F^w$衰减，恢复速度还须接(CAL-6)及频谱评分判断；系数接近参考根、输出恢复和相对不更新有净收益是三种不同验收。

### 5.9 从真实码变化严格推出SNDR与SFDR变化

这一小节无需线性化、概率独立、收敛或数字段保持。对同一偶数长度 $N$、矩形窗相干记录，取已知基波 $k_0$的sin／cos列构成矩阵 $V_f$，令

\[
P_f=V_f(V_f^TV_f)^{-1}V_f^T,\quad
P_0=\mathbf1\mathbf1^T/N,\quad P_r=I-P_0-P_f.
\tag{CAL-23}
\]

$0<k_0<N/2$保证列独立且与DC正交，所以这些是对应正交投影。基波功率 $S(Y)=\|P_fY\|^2/N$，残余功率 $R(Y)=\|P_rY\|^2/N$，由 $Y=Y^0+\delta$分别展开得到

\[
\begin{aligned}
\Delta S&=\|P_f\delta\|^2/N+2(P_fY^0)^T(P_f\delta)/N,\\
\Delta R&=\|P_r\delta\|^2/N+2(P_rY^0)^T(P_r\delta)/N.
\end{aligned}\tag{CAL-24}
\]

这里 $S$是功率，区别于第三节同名字母的RMS幅度。原参考两功率及新功率均正时，精确dB变化为

\[
\Delta\mathrm{SNDR}
=10\log_{10}\!\left(1+\frac{\Delta S}{S(Y^0)}\right)
-10\log_{10}\!\left(1+\frac{\Delta R}{R(Y^0)}\right).
\tag{CAL-25}
\]

因此SNDR改善当且仅当 $R(Y^0)\Delta S>S(Y^0)\Delta R$。总MSE降低不充分，因为总误差可含增益与DC偏差，而SNDR只比较实测基波和其余交流功率。零分母／基波缺失按第三节的边界规则处理，不对 $\log0$使用差式。

对每个正频点，(M2-20)的归一化DFT线性给 $\widehat Y_k=\widehat Y_k^0+\widehat\delta_k$。单边功率及其变化为

\[
p_k=\lambda_k^2|\widehat Y_k|^2,\qquad
\Delta p_k=\lambda_k^2\left[2\operatorname{Re}((\widehat Y_k^0)^*\widehat\delta_k)
+|\widehat\delta_k|^2\right].\tag{CAL-26}
\]

最大杂散功率 $M(Y)=\max_{1\le k\le N/2,k\ne k_0}p_k$，故当比值有定义时

\[
\Delta\mathrm{SFDR}
=10\log_{10}\frac{S(Y)}{S(Y^0)}-10\log_{10}\frac{M(Y)}{M(Y^0)}.
\tag{CAL-27}
\]

每个杂散都须重新求值后取最大，最强杂散可以换频点。降低某根谐波不保证提高SFDR，降低总残余功率也不规定最大杂散降多少。式(CAL-24)—(CAL-27)与(CAL-8)共同完成“实际校准输出→各性能变化”的精确桥梁，原证据见[两级§6.3](STATIC_CASCADE_MILLION_SUPPORT_AND_PROJECTION_V1.md#63-净码误差与净谱变化必须保留交叉项)。

### 5.10 为什么持续更新会产生旁带，而不只是一个方差

将(CAL-6)—(CAL-7)用于逐样本实际有效差 $d_n$。令 $\widehat{J_a},\widehat d_a$为长度 $N$的归一化DFT，对时域乘积代入DFT并交换有限求和，有圆周卷积恒等式

\[
\widehat\delta_k=\sum_{a=1}^8\sum_{r=0}^{N-1}
\widehat{J_a}_r\widehat d_{a,k-r}
+\widehat b_k+\widehat\eta_k,
\qquad k-r\text{按模 }N\text{取值}.
\tag{CAL-28}
\]

所以系数误差的频率会与输入相关基函数的频率混合，两级乘积再产生额外混合。一个系数的平均值和方差不足以确定这些相位与频点。

最小连续例：若输出对某系数的基函数为 $J_n=B\sin\omega_0n$，系数变化为 $d_n=a\cos\Omega n$，则

\[
\delta_n=\frac{aB}{2}\left[\sin((\omega_0+\Omega)n)+\sin((\omega_0-\Omega)n)\right].
\tag{CAL-29}
\]

这是乘积到和差频率的直接展开；两个旁带折叠、相合或落到基波时须按实际有限DFT合并。特定周期更新可形成窄杂散，随机更新可形成分散谱，不能单凭相同码差均方就指定SFDR。

窗口保持也有明确谱权重。若 $N=WL$且 $d_{Lw+r}=d_w$，令窗口级DFT $\widehat d^{(W)}_k=W^{-1}\sum_wd_we^{-2\pi ikw/W}$，从双重求和得

\[
\widehat d^{(N)}_k=\frac{H_L(k)}L\widehat d^{(W)}_{k\bmod W},\qquad
H_L(k)=\sum_{r=0}^{L-1}e^{-2\pi ikr/N}.
\tag{CAL-30}
\]

这将提交频率／保持时刻接到实际系数谱，再经(CAL-28)接到输出。使用当前窗还是下一窗系数会改变相位和闭环轨迹，不能以同一个均值代替。式为精确有限记录关系，不假设稳定。

### 5.11 概率性能必须保留完整时间协方差

对任意已给定概率模型下的实际输出向量，令 $m=\mathbb EY$、$\Gamma=\mathbb E[(Y-m)(Y-m)^T]$。任意对称正交投影 $P$满足

\[
\mathbb E\frac{\|PY\|^2}N
=\frac{\|Pm\|^2}N+\frac{\operatorname{tr}(P\Gamma)}N.
\tag{CAL-31}
\]

证明是 $Y=m+(Y-m)$后展开，均值交叉为0，二次项用 $v^TPv=\operatorname{tr}(Pvv^T)$。取 $P_f,P_r$分别得到期望基波和残余功率。逐频点展开也有

\[
\mathbb E|\widehat Y_k|^2
=|\widehat m_k|^2+
\frac1{N^2}\sum_{n,t}\Gamma_{nt}e^{-2\pi ik(n-t)/N}.
\tag{CAL-32}
\]

后项由完整跨时刻协方差决定。只保留对角方差会丢掉周期关联、漂移及窄旁带；相同逐点方差不唯一决定频谱。此式对非平稳记录也成立，无需把真实输入／门／状态假设为独立。

一般有 $\mathbb E[10\log_{10}(S/R)]\ne10\log_{10}(\mathbb ES/\mathbb ER)$，且 $\mathbb E\max p_k\ne\max\mathbb Ep_k$。所以(CAL-31)—(CAL-32)闭合的是期望功率，不是平均dB或平均SFDR；后两者需逐条记录评分再按完整联合规律平均，或另做比值／概率界。

若给定有限支持源规律，每窗历史 $H_w$的概率为 $\pi_w(H_w)$，下一源块 $\xi_w$的已知条件概率为 $p_w(\xi_w\mid H_w)$，则

\[
\pi_{w+1}(H_w,\xi_w)=\pi_w(H_w)p_w(\xi_w\mid H_w).
\tag{CAL-33}
\]

在每条扩展历史上执行(M2-25)、(M2-28)—(M2-29)并附上实际输出，按相同完整历史合并概率，即可有限枚举得到 $m,\Gamma$或完整指标分布。若只有状态边际，虽可能算出单点码概率，却一般不足以算跨时刻谱；不能丢掉历史关联后称谱已闭合。连续源用相应积分或有保证的积分范围；历史枚举可指数增长，未知条件源律时也不能凭定义给唯一期望。

### 5.12 校准对码边界、DNL／INL及过载的影响

冻结系数后，纯数字校正不改变(M2-10)的模拟判决路径区间 $I_p$，但改变该路径的最终码标签 $y_p(\kappa)$；原来抵消的相邻路径也可能产生新的码跳变。因此校准后的码宽为

\[
W_k(\kappa)=\sum_p|I_p|\,\mathbf1\{y_p(\kappa)=k\}.
\tag{CAL-34}
\]

将其代入(M2-14)—(M2-15)就得到冻结校准DNL及满足单调条件时的INL。当输出整数标签未变时，系数小变化可使码宽暂时不变；到舍入界后离散改变。不能把数字PWL连续函数的导数直接当作整数码DNL的导数，也不能把数字校正当成移动了物理比较器阈值。

真实后台码密度则取联合分布，按条件概率分解为

\[
\Pr\{Y_n=k\}=\int
\mathbf1\{C(o,E(a))=k\}\,dP_{O_n,a_{w(n)}}(o,a).
\tag{CAL-35}
\]

其积分核来自(CAL-33)或给定源模型。输入与系数相关时，不能只按无权系数直方图混合冻结转换；自适应斜坡得到的直方图也不自动是一条静态转换的INL。主路过载不能靠输出码平滑证明已经恢复信息；数字越域、饱和和表示能力按第三、四节分别判断。

### 5.13 如何从算法参数算到性能影响

以下是统一求解顺序，所需的 $C,E,U$、目标、源模型、矩或范围均在前文定义。给定模型与实际记录时只需第一条；要概率或解析预测时才增加相应条件，不用仿真拟合补未知量。

| 计算层次 | 按顺序执行 | 得到什么；何处停止 |
|---|---|---|
| 实际有限记录，精确合同 | 同初态／同源 → 每政策独立(M2-25、28—29) → (CAL-1、3、12—13) → (CAL-8、24—27、34) | 系数历史、整数净MSE、SNDR／SFDR、冻结静态指标；无定义分支／越域或既定预算处停止 |
| 原因解释，局部条件 | 检查前级段／门保护 → (CAL-5—11、14—15) → 与完整实际差交叉核对 | 纠偏、两级交互、位置、持续变化与算术的条件关系；条件失败回精确读出，不删除失败样本 |
| 标量解析特例 | 由给定输入／量化求五个矩 → (CAL-16—20) | 学习率到有限均值／方差及独立评价MSE；不延伸为两级SNDR定理 |
| 两级局部统计 | 先证邻域及源条件 → (CAL-21—22) → 完整时刻输出矩／(CAL-28、31—32) | 有条件的状态／输出功率预测；相关或非线性余项未知则明确未闭合 |
| 完整概率或覆盖族 | 给定源条件律用(CAL-33)扩展历史，或用(M2-30—37)传播覆盖集合 | 指标分布／期望或可靠性能界；资源增长、未知联合源或覆盖缺失处停止 |

共同检查：用同一目标、时长、带宽、测量输出位置与初始化比较；保留原倍率、1/4及不更新参考。全槽有30倍学习观察，不能因公式可算而称同成本算法。静态与学习源只在已证数字系数不影响模拟链时共享；真实反馈变化必须各自完整推进。

### 5.14 手算例、验证与结论层级

**纠偏交叉的正反例。**$e^0=(1,-1)$、$\delta=(-1,1)$时，(CAL-8)为 $-2+1=-1$；改为同向 $\delta=(1,-1)$时为 $2+1=3$。同样的输出变化功率可以改善或恶化MSE。

**均值零但两级乘积不零。**合法数字字 $q_1=q_2=0,c_3=16,\mathsf D_1=-64,\mathsf D_2=-16$，旧斜率均1，输出2144。两种系数差 $(d_{2,0},d_{1,0})=(1/2,-1/4)$或 $(-1/2,1/4)$等概率，其他坐标不变，新前级raw为40／24，两种输出都为2142。每种 $\ell=0,b=-2,\eta=0$，平均系数差为0但平均输出差为−2。目标2144时净MSE加4，目标2141时从9降到1；这仅是合法数字反例，不宣称Gu实际发出这些请求。

**相同MSE改进不保证SNDR改进。**取彼此正交的相干正弦 $s,h$，各峰值1，目标 $T=10s$。参考 $Y^0=5s+h$的MSE为13、SNDR为 $20\log_{10}5$；新输出 $Y=10s+3h$的MSE为4.5、SNDR为 $20\log_{10}(10/3)$。MSE降低但SNDR降低，因增益偏差与杂散的评分方式不同。它是指标区别的确定性控制，不是新校准政策。

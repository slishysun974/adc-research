# 静态模拟范围到在线 Gu 频谱：短记录条件性连接

> 2026-10-04，阶段二。把已有的主辅模拟范围传播、逐转换系数可达集和有限记录频谱界限接成一条可运行的**条件性**链路。这里没有芯片模拟范围、实际四路抽取时序或数值严格向外舍入证书。

## 结果与前提

假设一段输入与两路 dither 的模拟电压均有逐转换闭区间，并且第一级主路、独立辅路及第二级主路的输出范围函数在声明的输入、PVT、通道与判决时刻确实覆盖真实电路。两级 flash、CDAC、末级 SAR 的候选码制也须覆盖真实数字判决。每个数字 dither 标记必须与**同一次转换**的模拟注入区间对齐；Gu 候选使用已知初始系数，且每次转换输出后更新、下次生效。

对第 `n` 次转换，[静态主辅传播](STATIC_MAIN_AUX_OBSERVATION_BOUNDS_V1.md)给出所有可能的三字段 `(q1,q2,c3)`。连同已对齐的两路 dither 标记，得到五字段集合 `O_n`。[在线可达集](ONLINE_COEFFICIENT_REACHABILITY_V1.md)把每个 `O_n` 的分支与此前系数状态一起传播，取得整段可能的最终**整数**码历史，再把各时刻的最小、最大码送入[有限记录 SNDR/SFDR 界限](FINITE_RECORD_PERFORMANCE_BOUNDS_V1.md)。

覆盖理由是两次归纳的组合。真实电路在每次转换生成的三字段必落入模拟范围传播的集合；因此真实五字段属于对应 `O_n`。初态已知时，若第 `n` 次以前的真实系数与码历史已在可达集中，候选数字校正和更新便把本次真实码及下一状态纳入。整段真实整数码由此被覆盖，有限记录的频谱界限随之适用。证明不要求各次模拟误差独立，也不要求模拟传输是 PWL。

这项连接使用[离线入口](../../src/adc_research/evaluation/static_online_reachability.py)。它接收逐转换模拟区间和 dither 标记，调用三路径静态传播器形成每次的数字观测集合，再调用已有 Gu 浮点逐转换更新可达集。模拟范围只在离线证明端使用；运行中的校准器仍只看到数字五字段。如果任何可能观测使候选数字 PWL 无定义，程序报出转换编号并停止，不丢弃该分支。若路径数超过 `max_paths`，也停止而不输出不完整的界限。

## 人为短记录核对

[集成测试](../../tests/test_static_online_reachability.py)用一条特意简化的静态链路检查组合：前两级不设 flash 阈值、三条模拟路径均为单位映射，末级 5 位候选量化器的电压胞宽为 `1.25`。模拟 dither 注入为 `±0.1`，对应数字标记的校正副本为 `±1`。首转换输入区间 `[2.49,2.51]` 跨越末级码边界；其余七次输入固定在各自码胞内部。数字校正使用一段式 PWL 与人为给定的两级更新步长。这个构造只检验链路，不代表目标 ADC 的电压、码宽或学习速度。

首转换可能的末级中心码为 `1/2`，其余转换各只有一种观测。完整在线传播得到两条最终整数码历史：

```text
(129,132,130,127,127,126,123,124)
(130,133,130,127,127,126,124,124)
```

第二次转换的模拟输入和数字观测均固定，其最终码仍为 `132/133`：前一次观测改变了本次使用的系数。测试另从首转换区间内各选一个具体电压，独立按候选量化胞计算数字观测，再逐次运行校准；两条具体轨迹都落入上述历史集合。

对这八点相干记录，两个具体轨迹的 SNDR 为 `5.248/4.382 dB`，SFDR 为 `5.279/4.481 dBc`。逐点码范围经既有 Parseval 公式给出 SNDR `[-0.471,12.414] dB`、SFDR `[-0.450,12.471] dBc`，均覆盖具体轨迹。八点玩具记录的低指标和宽界限没有芯片含义；它们只验证从模拟范围、在线状态到频谱的条件性连接。

## 尚不能推出的结论

- 当前三个模拟输出范围函数在测试中来自已知人为映射。仓库仍无满足[物理取证门槛](../stages/02_end_to_end_theory/PHYSICAL_ENVELOPE_EVIDENCE_GATE_V1.md)的芯片主辅波形、阈值、斜率和误差范围。因此不能对目标芯片给出 SNDR/SFDR 数值保证。
- 各次观测集合在传播时自由组合。若同一未知电路参数同时约束许多转换，这会加入不可能的码历史并放宽界限，但在覆盖前提下不会漏掉真实历史。路径数可能指数增长，当前只适合短记录；共享参数相关性和长记录严格状态包络仍需研究。
- 静态无记忆模型没有表达主辅建立、通道相位和前次转换残留。只有当输入范围函数另有证据覆盖这些历史时，才能把它们纳入前提；不能把静态测试称为动态保证。
- 这里沿用浮点、逐转换更新的 Gu 行为候选。EXP-032 的 Q22 RTL 是另一个**明示数值候选**，不能与浮点可达集混作位级结果。论文真实四路抽取统计量、系数广播及生效时刻仍未公开。浮点区间与 FFT 计算也没有严格向外舍入证书。

[定点在线整数状态范围](FIXED_ONLINE_STATE_BOX_BOUNDS_V1.md)现可接收同一静态观测传播器产生的五字段集合，逐次合并 Q22 候选的累加器范围，以较长记录的码上下界替代本页浮点候选的完整历史枚举。两者对应不同的数值转移，不能把一个结果当作另一个的位级证明。

下一步若取得覆盖性的电路资料，可先在短记录上使用本入口检查哪些转换及分支使码范围变宽；若资料仍缺，结果保持条件性，不以合成范围代替电路证据。

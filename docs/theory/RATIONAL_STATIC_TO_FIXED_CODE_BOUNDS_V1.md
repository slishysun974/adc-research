# 静态扫描到定点在线码范围的精确算术 v1

> 2026-10-05。条件性包含关系与实现检查已完成。电路范围、真实数字总线／四路更新及数值认证的频谱仍开放。实现：[有理数静态传播](../../src/adc_research/theory/rational_static_reachability.py)、[定点组合入口](../../src/adc_research/evaluation/static_online_reachability.py)；人工验证见 [EXP-037](../reports/experiments/EXP_037_RATIONAL_STATIC_ONLINE_V1.md)。

现有扫描验收器能用精确有理数建立三条放大器范围，但原组合入口在前后级电压加减和判决处使用浮点。新入口把**原始范围端点到最终整数码**的判决算术保持为有理数与整数，使阈值附近的细小区别不会因这段计算的舍入而消失。它不使原始测量变得精确，也不减少测量误差或未知电路造成的范围宽度。

## 一个可复算的边界例子

设一条人工静态路径为恒等映射，两级 flash 阈值都为 `1/8`，CDAC 与 dither 为零，末级为 `[-1,1)` 上的 8 位均匀量化器。取

\[
x=\frac18-10^{-80}.
\]

按“等值判高”的规则，精确判决是两级符号均为 `-1`、末级中心码为 `15`。先把这个输入转成二进制双精度浮点，所得数为 `0.125`；随后判决变为两级符号均为 `+1`、末级中心码 `16`。这只是数值表示丢失信息的反例，不表示电路能测到这样的电压精度，也不估计真实错误率。实际电压不确定时，必须给足输入区间，保留所有可能码。

## 条件与表示范围

1. 每条路径的范围函数在整个查询输入区间上覆盖所声明条件的全部静态输出。若来自扫描包，则仍需[扫描协议](../stages/02_end_to_end_theory/STATIC_SCAN_PACKAGE_PROTOCOL_V1.md)要求的斜率、误差、节点、时刻及条件依据。静态无记忆前提不能从资料检查通过中推出。
2. 输入、模拟 dither、两级阈值、CDAC 电平、末级范围或阈值表的端点都显式为 `Fraction`。原始十进制／分数字符串直接解析；不在入口处把浮点静默转换成“原始精确值”。用户若自行把已舍入浮点转为 `Fraction`，仍须自行承担此前表示误差。
3. 阈值区间严格有序；比较器等值为高。末级采用声明的均匀 SAR 规则，或严格有序的阈值区间表。未知端部码制、非单调码制不由该入口补足。
4. 数字 dither 标记与模拟注入区间为同次转换，并符合定点配置的数字副本。初始八个累加器范围覆盖真实状态。在线转移是已声明的逐转换定点候选，不是论文芯片未公开的四路抽取规则。
5. 范围回调内部必须保持精确算术，并给出可信覆盖关系。接口检查端点类型，不能凭 `Fraction` 类型认证任意回调内部是否曾使用浮点或其物理依据。扫描包的 `rational_path_envelope` 已按有理数实现审查；自定义回调须另行审查。

这些是包含结论的前提。类型检查、有限测试和文件 SHA-256 均不等于物理认证，也不是程序的全输入形式证明。

## 静态包含关系

对输入区间 $X=[x_l,x_u]$ 与第一级阈值区间 $[t_{j,l},t_{j,u}]$，所有可能的比较器计数被

\[
i_{\min}=\#\{j:t_{j,u}\le x_l\},\qquad
i_{\max}=\#\{j:t_{j,l}\le x_u\}
\]

之间的整数覆盖。给定可能区域 $i$，用前一阈值的最低位置和后一阈值的最高位置对 $X$ 作保守限制，再算

\[
W_1=X_i-DAC_{1,i}+D_1.
\]

区间加减的端点仍为有理数，因此没有运算舍入。后一阈值本应为开边界，取闭包可以增加不可能的端点，却不遗漏实际输入。

第一级主／辅范围分别包含 $g_1^m(W_1)$ 与 $g_1^a(W_1)$。沿辅路的可能比较器计数得到所有 $q_2$；沿主路计算

\[
W_2=R_1^m-DAC_{2,q_2}+D_2,
\]

再用第二级主路范围得到末级输入。主辅输出、CDAC／阈值及不同条件的相关性被放宽，可能新增组合；覆盖前提成立时不会删掉真实组合。

对均匀末级，令 $M=2^B$、$h=(v_u-v_l)/M$。单点原始码

\[
c(v)=\min\{M-1,\max\{0,\lfloor(v-v_l)/h\rfloor\}\}
\]

对 $v$ 单调，区间两端决定覆盖全部可能码的整数范围。$h$、除法与 `floor` 都在有理数上计算；非二进制有限小数的电平也不先变成浮点。显式阈值表则用与 flash 相同的计数范围。中心码扣除 $M/2$ 为整数运算。过载标记按声明的半开标称范围计算，不能自动解释为芯片故障概率。

由上述逐级包含关系，真实三字段观测属于生成集合。附上同次 dither 数字标记后，得到真实五字段观测的覆盖集合；模拟范围仍只留在离线分析中。

## 在线码与系数状态的包含关系

已有[定点在线状态范围](FIXED_ONLINE_STATE_BOX_BOUNDS_V1.md)按整数计算系数导出、两级校正、门控、有理步长更新和饱和。对本次观测集合的所有分支，先用更新前的状态范围产生最终码范围，再逐坐标合并更新后八个累加器。

若初始状态已覆盖，且本次观测集合包含真实观测，则旧状态与真实观测对应的码及新状态都属于本次结果。对转换次数作归纳，得到每次最终整数码与在线状态的包含关系。该归纳不要求保存完整码历史，也不要求模拟传输为 PWL。

该入口复用已有定点候选，不改变 Q22、步长、舍入、门控和生效顺序。可能观测或放宽后的状态进入未定义数字校正域时仍停止；扫描域不足也停止，不能跳过这些分支后宣称范围有效。状态区间合并会丢失相关性，长期范围可能很宽。

## 已验证范围与下一步

EXP-037 在人工两条件三路扫描上完成 128 次转换、两条连续电路候选轨迹的 256 组判决、最终码及每次八状态包含检查。独立逐样本平台与精确点参考的数字观测一致。另有 771 组末级阈值及饱和端点的上下／等值检查；测试包含非二进制小数 CDAC／dither、阈值区间和非均匀 SAR 表。

人工记录最终码区间仍宽 `23–101` 码。精确算术消除了此段的舍入遗漏问题，没有消除所给网格、误差、条件并集与状态合并造成的不确定性。本次记录加入 dither 和在线更新，与 EXP-036 的无 dither 冻结系数记录不同，两组宽度不能作精度改进或退步的配对比较。

覆盖性的整数码区间可以作为[有限记录频谱界限](FINITE_RECORD_PERFORMANCE_BOUNDS_V1.md)的输入，但现有 FFT／三角函数／分贝计算没有完整数值认证。因此，本结果的精确算术范围止于最终整数码及累加器范围，不能写成数值认证的 SNDR/SFDR，更不能写成芯片性能保证。真实三路资料、物理覆盖、动态状态及四路更新仍是下一证据门。

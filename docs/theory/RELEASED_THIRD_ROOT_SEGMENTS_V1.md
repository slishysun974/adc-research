# 第三系数释放后的相关零点族

> 2026-10-09。接续[原窗口与高段传播](ORDERED_WINDOW_STATE_AND_HIGH_SLOPE_PROPAGATION_V1.md)。[EXP-045](../reports/experiments/EXP_045_RELEASED_THIRD_ROOTS_V1.md)研究同一有限数字记录的连续经验相关目标，第四系数固定为1，前三系数自由。局部结果不等于三参数全域搜索，也不证明整数闭环或前级同时平衡。

第三系数释放后，后级相关零点可以是一条连续的线段。四组条件共认证五段：线段中后级四个相关量都为零，而绝大多数样本的连续数字读出仍随参数变化。相关方程没有为这些方向选出唯一系数。

## 1. 固定门时，三参数方程精确仿射

对固定数字(raw,dither,count)记录，数字PWL基函数ψ由raw确定，不随系数改变。第四系数k₄固定为1，前三参数k=(u,v,h)自由。

\[
y_n=\sum_{j=1}^3k_j\psi_{j,n}+\psi_{4,n}-d_n,
\qquad C_i=N^{-1}\sum_n m_nd_n y_nG_{i,n}.
\]

同一门集合内，

\[
C_i=A_i k+b_i,\quad
A_{ij}=N^{-1}\sum_n m_nd_n\psi_{j,n}G_{i,n},\quad
b_i=N^{-1}\sum_n m_nd_n(\psi_{4,n}-d_n)G_{i,n}.
\]

这里是从数字基函数直接求出的有理数关系，不是数值Jacobian或拟合模拟曲线。第一门恒开，其他门按原`≥`合同。

若前三行A秩为3，固定门内至多有一个三参数零点；候选求出后仍须逐样本确认门及合法域。如果秩为2、已有真正零点k*，其零空间方向n给出`k*+tn`的仿射零点线。两种情况都不能跨门跳变继续套用。

## 2. 沿零点线保护全部门

本轮秩2零空间都可按第三坐标归一化，写成

\[
k(h)=a h+c,\qquad a_3=1,\ c_3=0,\ k_4=1.
\]

逐样本输出和门限对h都是一次函数。若种子处某门闭，保持它需要两条严格条件`−B(h)<y(h)<B(h)`。若门开，保持当前正／负支路需要`s y(h)≥B(h)`，s为种子学习输出的符号。合法系数另外要求前三项严格在(0,2)内。

把全部一维半空间相交，得到该零点线在**这个固定门及符号支路**中的最大参数区间。严格条件排除端点，`≥`条件允许端点；重合边界以所有条件的交集处理。还保护第四门，便于单独检验第四相关量是否始终为零。

证明来自`A a=0`及`A c+b=0`：区间内门不变，故前三相关量恒零；第四相关量另外计算其斜率和种子值。五段中第四门也始终闭，因而四个后级相关量全部为零。

## 3. 本轮找到的五段及搜索边界

前96窗口、11520条数字观测沿用EXP-042拟合划分。第三系数取预先固定的`3/4、7/8、1、9/8、5/4`，对每个切片用既有精确分段扫描求全部前两相关零点；这些仅作为三参数局部种子。

30个切片产生15个种子。9个种子认证为线段，去除完全相同的参数式及门区间后剩五段。另5个满秩候选超出合法系数域，1个跨门后不再为零；没有认证新的孤立点。

## 4. 零相关的中性方向可以改变读出

沿零点线，单条连续数字学习输出的变化为

\[
\Delta y_n=\left(\sum_{j=1}^3a_j\psi_{j,n}\right)\Delta h.
\]

五段中，11419或11420条转换的括号非零。即使相关量都为零，校正函数仍沿该方向改变。所有系数保持正值，属于声明的数字参数域；不能因为相关矩阵秩2就把数字数据称作没有第三方向的信息。

独立核算的前三基函数数字读出Gram矩阵`N⁻¹Σmψψᵀ`在六组全部秩3，而根族的前三相关矩阵秩2。前者描述连续数字函数的参数敏感性，不是物理可观测矩阵，也不提供正确目标。这进一步区分已有数字变化与实际相关更新使用的方向。

连续固定经验均值映射在这些线段上不更新任何后级系数，所以每一点都是后级不动点。包含线段中两点的集合不可能有统一严格收缩：两点更新后的距离与原距离相等。这只证明沿族方向中性，不证明垂直方向不稳定。

第三门在所有五段都闭。第三参数却通过数字PWL输出进入前两相关量，并由前两系数的变化补偿。于是“第三门不开”与“读出不依赖第三参数”是不同命题。

## 5. 零点族未必被实际轨迹选中

EXP-042在随机复位／两相、h固定为1时无后级两参数精确根；本轮的零点族上界分别小于1约0.068084230／0.070200494。释放参数后存在别处的根，不能改写原固定h=1的无根结论。

EXP-044的两组原轨迹中第三门始终闭，第三系数一直为1。因此这160窗口没有走入上述根族。需要另外研究更新路径是否能进入其范围；不能凭根族存在推断真实Gu能够到达。

本轮不使用Q1.10导出、Q3数据或Q22状态求根。连续根族不自动成为整数停更集合。也未解前级的相关方程；后级的四个零相关量不等于两级八相关量都为零，更不等于正确最终码或最高SNDR。

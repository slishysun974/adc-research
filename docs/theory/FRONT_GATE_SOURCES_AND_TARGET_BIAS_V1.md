# 前级门控样本、相关量抵消与校正目标偏差

> 2026-10-09。接续[EXP-046共同零点](COUPLED_MEAN_ROOT_CURVES_AND_INTEGER_REQUESTS_V1.md)。本次只研究报告已指定的周期复位候选4／5，固定同一后级。数字诊断不读取理想码；理想码随后只用于离线误差分解。无训练提交、模拟波形或Gu核心／RTL修改。

**较差分支的第二段门把所有第一段样本都选入。**这些样本不使用第二段系数，却给它负相关量，推动系数增大；外段样本的正相关量与之精确抵消。较好分支也存在同样类型的抵消，只是选样数量不同。两组零点各自在自己的门集合中成立，不能把零相关等同于正确校正。

## 1. 使用同一数字raw，只有前级系数改变

固定后级后，前级数字raw为

\[
R_n=128q_{2,n}+\sum_j k_{2,j}\psi_{2,j,n}-d_{2,n}.
\]

设前级宽度为\(W=128\)，dither为\(D_n=s_nD\)，\(s_n\in\{-1,1\},D=64\)。前两系数写作\(u,v\)，第三、第四固定为1。连续数字读出及第二段更新门为

\[
Y_n=u\psi_{0,n}+v\psi_{1,n}+\psi_{2,n}+\psi_{3,n}-D_n,
\qquad G_{1,n}=1\{|Y_n|\ge Wu\}.
\]

\(\psi_j(R)=\operatorname{sgn}(R)\min(\max(|R|-jW,0),W)\)。实际门沿用原`≥`，此处尚未Q3舍入。内部相关量\(C_i=N^{-1}\sum_nG_{i,n}D_nY_n\)，第一门\(G_0=1\)。它是给定记录的统计量，不是未知总体期望。

两组前级值为A：\((u,v)\approx(0.966414336,0.998817651)\)，B：\((0.227354521,1.998622307)\)。后级完全相同。EXP-046已分别证明固定后级的二维局部平均稳定，本次不新增全部八状态或整数稳定结论。

## 2. 内段样本更新第二系数的精确条件

**恒等式。**若\(|R|\le W\)，则\(\psi_1=\psi_2=\psi_3=0\)，因此\(Y=uR-sD\)。乘以\(s\)不改变绝对值，门条件为

\[
|usR-D|\ge Wu.
\]

其中正支路要求\(sR\ge W+D/u>W\)，与内段条件矛盾。故门恰好等价于

\[
G_1=1\quad\Longleftrightarrow\quad sR\le D/u-W.
\]

所有开启的内段样本都满足

\[
D_nY_n=D(usR-D)\le-DWu<0,
\qquad \frac{\partial Y_n}{\partial v}=\psi_{1,n}=0.
\]

所以在窗口贡献中，它们推动原负相关更新的\(v\)增大，却不直接读取\(v\)。这不是普通平方误差对\(v\)的梯度：后者含\(\psi_1\)，这些行的该因子为零。不能据此否定所有相关法，只说明当前相关方向与该损失的梯度不同。

**充分条件。**若\(u\le D/(2W)=1/4\)，则\(D/u-W\ge W\)，全部内段样本开门，包括等值端点。B严格满足这一条件；A只选中满足\(sR\lesssim-61.78\)的内段样本。该证明对连续数字读出成立，不能自动套到量化门或任意dither幅值。

## 3. 两类样本怎样相消

拟合记录共11520条，内段6085条。所有贡献都除以完整记录长度，而不是各组长度。

| 第二段门的项目 | A | B |
|---|---:|---:|
| 门阈值\(Wu\) | 123.701035 | 29.101379 |
| 门开启样本总数 | 5221 | 10773 |
| 第二基函数为零且开门 | 1423 | 6085 |
| 第二基函数非零且开门 | 3798 | 4688 |
| 零基函数项\(E[G_1DY]\) | −1226.235756 | −2138.615261 |
| 非零基函数项\(E[G_1DY]\) | +1226.235756 | +2138.615261 |
| 两项之和 | 精确0 | 精确0 |

B有56.48%的开门样本不使用被更新的第二系数，A为27.26%。两组正、负dither样本的数量接近也不保证零目标相关量；还要看它们对应的信号值和门。

A的门集合是B的子集；B额外选中5552条，其中4662条为零第二基函数。两组局部矩阵都可逆，故不能把歧义归结为各自固定门中的低段秩不足。

将一组读出放进另一组的固定门，得到

| 固定门／用于读出的系数 | A读出 | B读出 |
|---|---:|---:|
| A的门 | 0 | +1203.591255 |
| B的门 | −320.138173 | 0 |

两组解只在各自选出的门中归零。固定同一门并保留可逆矩阵时，低段线性方程只有一个解；系数改变门后，整个分段方程可以有多个解。独立精确扫描本切片的711个开区间及710个交点，恰有这两个前级根，不存在零区间。此完整性只针对固定后级、固定前级高段的切片。

另有\(E[D(Y_B-Y_A)]=0\)：输出变化可以很大，却不出现在第一相关量中。这只证明一个统计方向看不到该差异，不等于全部数字观测没有信息。

## 4. 零相关并未消掉实际码误差

理想整数码只在本节以后进入独立离线评价。定义局部目标

\[
T_n=\text{ideal integer code}_n-2048-512q_{1,n},\quad e_n=Y_n-T_n.
\]

于是任意固定系数、任意门都有恒等式

\[
C_i=E[G_iDT]+E[G_iDe].
\]

这里\(E\)表示同一有限记录的平均。拟合第二门的数据为

| 项目 | A | B |
|---|---:|---:|
| 目标信号项\(E[G_1DT]\) | +105.205556 | −119.788889 |
| 实际误差项\(E[G_1De]\) | −105.205556 | +119.788889 |
| 学习相关量 | 精确0 | 精确0 |
| 连续码均方误差\(E[e^2]\) | 75.888641 | 3217.451119 |

B的均方误差约为A的42.40倍，内部统计仍全零。两种抵消须分开：第3节按数字基函数支撑分组；本节按理想目标与实际误差分组。前者完全可由数字记录计算，后者需要离线目标。

按目标值分层，信号项又精确分成

\[
E[GDT]=E[T\,E[D|T]E[G|T]]+E[T\operatorname{Cov}(D,G|T)].
\]

A两项为\(+212.357083-107.151527\)，B为\(+212.387496-332.176385\)。目标的512个分层中，仅41个dither条件均值为零。这里是经验分层，不能从发生器名称、全局符号数或该计数推断总体独立性。第一门没有选择项，仍有\(E[DT]=235.561111\)。

## 5. 误差还能分成数字表示残差和目标偏差

在同一拟合记录、同一后级、前级高段固定为1的条件下，只作离线参考，求前两系数的最小平方码误差解\(\beta_*\)。设\(\psi=(\psi_0,\psi_1)^T\)，\(H=E[\psi\psi^T]\)，以理想目标和固定高段形成右端。\(H\)精确正定，唯一解为

\[
\beta_*\approx(1.021476246,1.063737685),\qquad E[\rho_*^2]\approx0.889872393,
\]

其中\(\rho_*=Y(\beta_*)-T\)，且\(E[\psi\rho_*]=0\)。最小二乘参考用的是离线目标码；它不读取模拟曲线，但仍不是硬件可运行的校准算法。

任意低段\(\beta\)满足精确投影恒等式

\[
E[e^2]=E[\rho_*^2]+(\beta-\beta_*)^TH(\beta-\beta_*).
\]

因此这两个根的误差不能全归为数字PWL表示能力不足。固定某个根的门，设\(A_{ij}=E[G_iD\psi_j]\)，\(s_i=E[G_iDT]\)，\(r_i=E[G_iD\rho_*]\)，则

\[
C=s+r+A(\beta-\beta_*).
\]

两组\(A\)均可逆，零点偏差恰为\(-A^{-1}(s+r)\)。第二门的三项分别为A：\(105.205556+2.545362-107.750918=0\)，B：\(-119.788889+3.366181+116.422708=0\)。全部等式用有理数核对，显示小数仅便于阅读。

参考系数仅用前11520条拟合，随后按同一Q22初始化、Q1.10导出和Q3链冻结评分。既有3840条正弦中，A／B／离线参考SNDR为43.380377／26.407557／62.384290 dB，平均绝对码误差为6.857031／49.533333／0.612760。无最终码裁剪。该比较说明目标偏差在本例中有实际输出影响，不是新算法效果；正弦未参与本次参考拟合，却早已用于此前研究，不能称全项目盲测。FFT未数值认证。

## 6. 仅按raw支撑筛样还不足以修正目标

用共同数字条件\(\psi_1\ne0\)，两组均选5435条，确实去掉了零第二基函数样本。但是

\[
E[1_{\psi_1\ne0}DT]=2286.616667,
\]

两组相关量仍为2057.542014／2138.615261。raw本身包含dither及后级校正，故这个门也不能假定对dither独立。这是固定系数统计诊断，没有按新门运行算法，也没有证明新门更好或更坏。

拟合后缀与正弦的原门第二相关量，A为−80.364806／−473.007139，B为−95.419785／−521.312848。拟合的经验零点并未成为这些记录的零点；不从冻结检查推断反馈轨迹。

## 7. 哪些条件才让相关零点对应正确目标

**条件性结论。**若目标可由该数字表示精确实现，门在所考察范围固定，\(E[G_iDT]=0\)，且\(A\)可逆，则该门单元中的相关零点就是目标系数。若只能以误差界\(|s_i+r_i|\le b_i\)约束目标及表示残差，则\(|\beta-\beta_*|\le |A^{-1}|b\)。这是逐分量界；局部可逆性不保证整个系数依赖门的方程只有一个根。

条件均值\(E[D|T]=0\)只去掉信号分解的第一项，还必须控制门选择协方差。若门及目标对dither注入前的信息可测，且该条件信息下dither均值为零，信号项才必然为零；当前输出门和raw门都不自动满足。实际历史可能依赖此前dither，也必须进入条件信息。

**待研究。**下一项在明确相同信号与历史的成对dither条件下，检查公共门能消掉哪些信号项、哪些误差仍无法识别，再核对现有硬件可见信息能否满足这些条件及额外成本。不能将离线目标或反事实样本免费交给在线算法，不能凭删去零基函数项直接宣布新算法改进。

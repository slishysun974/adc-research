# 从有限电压扫描到连续模拟输出范围

> 2026-10-03，阶段二条件性构造。目标是给[静态主辅范围传播](STATIC_MAIN_AUX_OBSERVATION_BOUNDS_V1.md)提供可审查的三条模拟输出范围函数。该构造**要求**独立证据给出扫描点输出误差区间和整个输入域的最大斜率；当前仓库没有芯片级的这两类资料。

## 最小输入与结论

固定一条模拟路径、一组明确的 PVT／通道／采样时刻／初始条件。取严格递增的输入扫描点 `x0<…<xm`，每点的真实输出保证在 `Yi=[li,ui]`。另有独立依据证明，在整个 `[x0,xm]` 内，任意两个输入满足

$$|g(v)-g(w)|\le L|v-w|.$$

对于可微传输，覆盖全域的 `|g'|≤L` 是一个充分条件。**网格相邻输出的最大割线斜率不是这个条件的证明**：两个扫描点之间仍可能有窄峰。`Yi` 必须已包含仿真误差、数值误差或测量不确定性；跨 PVT/通道的范围应在每点取并集或分条件独立处理。若实际状态有历史依赖，必须证明 `Yi` 与 `L` 对所声明全部历史成立，不能直接把一次静态扫描用于动态范围。

给定这些前提，任意落在扫描域内的输入闭区间 `I` 都能求到一个覆盖所有允许输出的闭区间 `G(I)`。查询越过已扫描的输入域时明确报错，不作外推；输入资料和 `L` 互相矛盾时也报错。这给出的只是条件性电压范围，尚未给芯片 SNDR/SFDR。

## 相邻样点之间的界限

先从左到右、再从右到左传播 `|g(xi+1)-g(xi)|≤L(xi+1-xi)`，把每个 `Yi` 收紧为与**所有**扫描点相容的区间 `[Li,Ui]`。若任一步交集为空，当前数据包没有满足所声明斜率的函数，不能继续计算。

对相邻扫描点 `a=xi, b=xi+1` 和其中的任意 `w`，Lipschitz 条件同时给出

$$
\max\{L_i-L(w-a),\ L_{i+1}-L(b-w)\}
\le g(w)\le
\min\{U_i+L(w-a),\ U_{i+1}+L(b-w)\}.
$$

要覆盖查询区间 `I∩[a,b]=[s,t]`，左边的两个一次函数取最大后呈 V 形，其**最小值**出现在两线交点或 `[s,t]` 的端点；右边取最小后呈倒 V 形，其**最大值**同理。逐格取这两个极值，再对所有相交网格取并集，即得 `G(I)`。斜率上界为零时，所有样点输出必须有共同值范围，返回该交集。这个算法不假设 `g` 本身单调，也不要求它是模拟 PWL；直线只用于限制未知函数的变化幅度。

**覆盖证明。**真实 `g(xi)` 在每点原始 `Yi` 中，且满足相邻 Lipschitz 关系，故也落在双向收紧后的 `[Li,Ui]`。于是它在每格、每个 `w` 的值都满足上式；逐格极值和并集自然覆盖整个查询区间。该证明以输入资料确实覆盖真值为前提，不能由程序对数据的自洽检查反过来证明电路满足 `L`。

## 与 ADC 链路的衔接和当前证据

[实现](../../src/adc_research/theory/lipschitz_grid_envelope.py)接受扫描点、输出闭区间和 `L`，返回可直接用作 `G1m/G1a/G2m` 的函数。测试先用 `g(w)=w+0.1 sin(6w)` 的解析导数给出 `L=1.7`，验证多格区间内的留出输入被覆盖；再用人为给定的 `4w` 主路、`2w…3w` 辅路族、`4.1w` 第二级主路，通过网格范围把静态链路的两个可能末级数字观测都包含。扫描和斜率在这里来自已知合成函数，**没有物理代表性**。

一个故意针对网格盲区的测试：两个端点扫描输出均为 `0`，`L=1`，中点仍允许 `[-0.5,0.5]`；因此潜在的三角形窄峰没有被直线插值抹掉。仅从两个端点相同这一事实，不能把网格间输出设为零。

将来每条真实路径的数据包至少应列出：输入/输出电压单位与差分定义、扫描点及其输出误差区间、`L` 的电路依据和有效域、PVT/噪声/通道/采样相位标签、原始波形或测量文件版本。先冻结这些输入，再用未参与定范围的电压点和条件检查覆盖。程序以 Python 浮点数计算；若要声明严格的数值覆盖，还须为舍入误差加向外保护或使用带定向舍入的区间运算，尤其在判决阈值附近。

对于纸面论文只给出的平均增益、带宽、少量波形和 SNDR 点数，尚不能构造覆盖全域的 `Yi` 与 `L`。缺少 `L` 时可以报告经验留出覆盖率，但不能把扫描网格插值当作保证。完整的[电路资料取证门槛](../stages/02_end_to_end_theory/PHYSICAL_ENVELOPE_EVIDENCE_GATE_V1.md)仍适用。

2026-10-05 [三路扫描接入](../stages/02_end_to_end_theory/STATIC_SCAN_PACKAGE_PROTOCOL_V1.md)现复用上述构造，但给网格、输出区间和 `L` 传入精确有理数，保留原始十进制／分数的数值。实际扫描输入若有半宽 `e_i`，先将输出区间各端扩大 `Le_i`。最终适配现有浮点链路时端点向外转换；这是该范围函数的数值保护，后续浮点判决和频谱尚未整体认证。[EXP-036](../reports/experiments/EXP_036_PHYSICAL_SCAN_INTAKE_V1.md)已验证人工三次函数的独立留出与三路连接，真实斜率和误差证据仍未取得。

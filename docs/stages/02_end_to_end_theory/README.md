# 阶段二：完整链路与数字校准理论

本阶段从输入、主辅残余电压和逐级判决，连接到数字观测、更新状态、最终码和性能。当前状态看 [STATUS](../../STATUS.md)，研究顺序看 [已批准计划](../../RESEARCH_PLAN_STATIC_FIXED_POINT_DIAGNOSTICS_2026-10-10.md)，不在阶段导航中另维护“下一项”。

## 理论入口与已有证据

先读 [未知增益完整框架](../../theory/UNKNOWN_GAIN_END_TO_END_FRAMEWORK_V0_1.md)、[理论索引](../../theory/README.md)和 [结论—证据表](../../theory/STAGE2_CLAIM_EVIDENCE_LEDGER_V1.md)。模拟增益未知于算法，数字PWL不是模拟曲线假设；需要额外物理条件时须标明依据。

| 理论问题 | 当前可复用内容 | 限制 |
|---|---|---|
| 观测能区分什么、表示能校正什么 | EXP-020反例、观测／表示／训练误差分解 | 有限观测反例不能否定所有统计dither方法 |
| 模拟范围怎样进入输出性能 | 主辅范围、网格覆盖、在线状态与有限记录频谱界限 | 物理覆盖是独立前提；短记录认证不是长记录FFT或芯片保证 |
| 更新目标和状态怎样传播 | 窗口、门控、条件均值、相关根、整数状态与成对边界 | 局部／经验均值结果不能当一般在线收敛；坏根不代表正常路径会到达 |
| 长期平均、波动与量化怎样影响输出 | EXP-055原理控制、EXP-056标量统计、EXP-057静态两级支持与投影 | 平均正确仍可能输出差；两级定点／动态和完整因果分解待研究 |

## 本阶段怎样交付

按 [本地研究流程](../../../CONTRIBUTING.md)同时交付推导、验证关系和分析。每个命题写明条件、证明状态、最小例和未决问题；现有证据表索引推导与相关实验。独立理论结果不必绑定新EXP；实验不能替代证明。

当前定点阶段将在现有理论中研究码域／有效支持、舍入及门余量、平均状态与协方差对输出的影响，以及条件性的更新／停滞与频谱关系。详细任务仅维护于阶段计划，不预先宣布一般八状态定理已完成。

旧 [TeX推导](../../theory/ADC_PERFORMANCE_PREDICTION_THEORY_FRAMEWORK.tex)、读者导引和EXP-015—019是给定传输／动态假设的条件性底稿。真实适用性仍按 [物理证据要求](PHYSICAL_ENVELOPE_EVIDENCE_GATE_V1.md)核对；缺少Cadence不阻止明示条件内的研究。

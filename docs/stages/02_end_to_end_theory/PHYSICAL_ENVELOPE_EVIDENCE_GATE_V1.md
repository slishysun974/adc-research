# 从电路数据建立模拟范围：下一验证门

> 2026-10-02。目标是为[有限记录性能界限](../../theory/FINITE_RECORD_PERFORMANCE_BOUNDS_V1.md)提供**确实覆盖允许电路**的模拟和最终码范围。本页是取证协议；当前仓库尚无满足该协议的 Cadence 或芯片数据。

## 首个可执行问题

先固定一段测试输入、dither 序列和数字系数，询问：在规定 PVT、噪声和采样历史下，第二级主路送到末级 SAR 的电压能否被逐样本区间覆盖？若第一级主/辅路径与两级判决也可能改变，必须扩大到它们的全部判决分支。只测平均增益、单个频点的 SNDR 或少数电压点，不能回答这个覆盖问题。

## 最小数据包

| 数据 | 必需内容 | 用途 |
|---|---|---|
| 信号与码制 | 第一级及第二级原始比较器位、MDAC 开关状态、两路 dither 物理极性、末级 SAR 阈值与端点规则、最终码舍入/裁剪、转换编号 | 确认五字段候选接口及每个阈值分支；不能把九状态符号直接当芯片三位字 |
| 静态传输 | 第一级主/辅路径和第二级主路的放大前电压、放大后电压，注明采样/判决时刻、参考轨与差分单位；覆盖允许输入及 dither 范围 | 为每个路径建立输出区间并传播到下一级判决 |
| 条件集合 | 工艺、供电、温度、前景修调、噪声口径、输入幅度/频率、通道编号、初始状态 | 定义“所有允许电路”的范围，不混合未声明条件 |
| 时序 | 每路采样相位、主辅建立波形、flash/SAR 判决时刻、四路抽取后的相关量与系数生效时刻 | 判断静态区间是否足够，以及在线状态怎样传播 |

原始记录须保留波形或逐转换值、仿真设置和版本。输入与输出的物理单位及归一化换算要同时保存。先选一组条件建立范围，再用**未用于定范围**的输入点、相位和通道检查覆盖；发现越界即扩大范围或修正模型，不据此宣布芯片保证。

## 从有限采样到覆盖范围

电压扫描的有限网格本身不能保证网格之间的传输。若对固定状态的静态路径有独立依据证明 $|g'(w)|\le L$，相邻扫描点最大间距为 $\Delta$，且每个记录输出的绝对误差不超过 $\epsilon_{\rm sim}$，则任意网格间点可由最近样本给出半宽至少 $L\Delta/2+\epsilon_{\rm sim}$ 的区间。这里的 $L$ 必须由电路/区间分析或可信规格给出，不能只取这批扫描点的最大相邻斜率。没有这样的斜率或曲率控制时，密集扫描与留出覆盖仅提供经验检查，不能证明中间没有窄峰。

[网格到连续范围的条件性构造](../../theory/GRID_TO_ANALOG_ENVELOPE_V1.md)现把每点输出误差区间及独立斜率界输入到双向一致性检查和逐格 Lipschitz 传播，所得范围函数可直接接入静态主辅链路。它只检验**给定**资料之间的逻辑一致性；若 `L` 无电路依据、网格输出未覆盖真实误差，或查询超出扫描域，仍不能形成物理保证。

把各 PVT/通道/状态条件得到的区间取并集，保留条件标签。若辅路区间跨第二级 flash 阈值，分别传播所有可能判决；若主路或末级区间跨 SAR 阈值，保留所有可能码。物理过载与数字裁剪分别记。只有逐样本最终码区间覆盖了所声明的全部条件，才输入频谱界限计算器。

[静态全链路传播器](../../theory/STATIC_MAIN_AUX_OBSERVATION_BOUNDS_V1.md)现可分别接收两级 CDAC 电平区间与有序末级 SAR 阈值区间。数据包中的 CDAC 区间须覆盖每个允许码态的实际开关结果；末级阈值区间须注明比较器等值规则、码端点和全条件下的顺序。只给标称电平或 SAR 典型 DNL，不能自动当成最坏情况边界。

## 验收顺序与停止点

准备扫描精度和阈值余量时，可先用[最终码不确定度反向预算](../../theory/CODE_ENVELOPE_RESOLUTION_BUDGET_V1.md)对预定 SNDR/SFDR 下界求容许的 RMS 码半径。该预算只衡量现有保守频谱公式能证明什么；缺少物理覆盖时，数值预算达标也不能升格为芯片保证。

1. **接口门：**逐态核对原始判决、MDAC 和校准字；若位级信息不可得，只声明候选码制。
2. **静态门：**在冻结系数下验证第二级主路电压范围和末级码覆盖，再加入第一级主/辅的不确定分支。范围若频繁跨阈值，可报告界限无用及需要缩小的物理参数。
3. **动态门：**若输出依赖前一转换、建立时间或通道相位，为每类允许历史建立状态范围；不能把一条静态曲线用于动态保证。
4. **在线门：**若测试时 Gu 仍更新系数，联合传播可能的数字观测和系数状态。冻结系数的频谱界限只作为离线对照。

芯片位级接口、可信斜率/噪声范围及动态历史目前都缺失；因此本页尚不能转化为物理 SNDR/SFDR 数字。EXP-020 的人为插值族只验证了第 2 门中一个前级判决固定的子问题。

2026-10-05 已有可运行的[三路静态扫描接入协议](STATIC_SCAN_PACKAGE_PROTOCOL_V1.md)和验收器：原始数值、单位／条件及资料摘要先冻结，输入误差按全域斜率传播，独立留出区分完整覆盖、部分重叠与矛盾。[EXP-036](../../reports/experiments/EXP_036_PHYSICAL_SCAN_INTAKE_V1.md)的人工数据已接通静态判决和冻结 Gu 最终码；这补足软件入口，不补足本页所需的物理来源或高频动态证据。

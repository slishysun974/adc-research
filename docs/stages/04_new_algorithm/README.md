# 阶段四：新校准算法

目标是提出能经受未知模拟曲线留出测试的新数字后台校准算法。Gu评价报告已交付，用户按D-115／116进一步指定先研究Gu LMS学习率及收敛，后寻找新算法。集中依据为[Gu评价报告](../../reports/GU_ALGORITHM_EVALUATION_V1.md)，当前安排为[现有计划§13.5](../../RESEARCH_PLAN_STATIC_FIXED_POINT_DIAGNOSTICS_2026-10-10.md)及EXP-069；学习率倍率比较属于阶段三基线研究，尚无经过完整验收的新算法。

后续先从报告的已确认问题与缺口选择一个目标，说明正常输出依据、在线可见信息、收益／跟踪预测和公平成本，再形成候选及必要预检／留出。报告完成、优化方案、实验授权与算法验收分别记录。以下§10／NG-28说明保留为历史准备，不覆盖新顺序，当前不延续错开相位或其他优化分支。

2026-10-11的[阶段判断](../../reports/RESEARCH_SYNTHESIS_2026-10-10.md)已完成静态定点计划§10预定范围：有限选样的持续适应代价、相位覆盖与成本适合先进入具体方案讨论；平均目标修正须先给可实现信息条件。该筛选不授权新算法实现或闭环比较。当前尚无经过完整验收的新算法；下一接续为与用户讨论在线统计合同、可证条件、主要输出指标及独立留出预算。

NG-28已将一个四路错开／基相位轮换候选写成具体合同，见[计划§12.2](../../RESEARCH_PLAN_STATIC_FIXED_POINT_DIAGNOSTICS_2026-10-10.md)及[综合分析§26](../../reports/RESEARCH_SYNTHESIS_2026-10-10.md)。31槽几何最优与均匀参照的辅助方差降低，没有变成拟议确定性规则的稳健同字输出收益；原180窗按拟议相位代入、相对固定0仅58负／122正。该规则保留为条件控制，不进入优选算法／长期比较，不按旧分数调偏移；十项控制／488回归与原来源／数据保持，未实现候选轨迹或新增训练。下一方案优先解释实际选择造成的有效输出均值及两bank交互，并满足闭环／留出与成本门。

提交候选方案前先冻结：算法能看到的信号、输入和 PVT 测试划分、目标 SNDR/SFDR、收敛样本数、硬件吞吐率、位宽和允许的面积／功耗。对照至少包括 Gu 基线和不校准条件；若改变 dither 或增加观测硬件，计入其直接谱代价和资源成本。

候选必须经历行为仿真、有限字长、RTL 功能验证、综合与时序／功耗比较。只在预设的合成 PWL 上获益，不足以称为更优算法。尚无新算法或已验证硬件结果时，保持这一状态说明，不创建空的“成果”。

硬件目录预留在 `rtl/new_algorithm/`；它是待办入口，不是已经完成的实现。

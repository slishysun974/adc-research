# 阶段二静态传输预测规格 v0.1

> 状态：首个阶段二问题已冻结并进入验证
> 适用架构：`gu_behavioral_v1`
> 预测范围：固定物理参数、无数字后台校准、无记忆静态信号链

> 2026-09-16 审查补充：本规格中“INL”指标对单调传输可解释为物理转换电平 INL；
> 存在负向步的条件只能把累计 DNL 解释为码密度偏差。历史数值保持不变，
> 解释遵循 [指标协议](ADC_METRICS_PROTOCOL_V1.md) 的修订说明。

## 1. 首个预测问题

给定两级前端的 flash 阈值、辅助判决路径、CDAC 电平、静态增益、可选 PWL
非线性和末级 SAR 量化规则，在不调用逐样本实验平台的条件下，预测整个归一化
输入域 `[-1,1)` 上的最终 12-bit 输出码，并进一步计算：

- 每个输出码对应的输入区间总宽度；
- 均匀输入下的 DNL、码转换边界 INL 和缺失码；
- 输出码下降次数；
- 主信号路径发生 residue/SAR 过载或最终裁剪的输入区间总宽度。

第一版不预测随机噪声、有限建立、采样时刻差、输入缓冲器动态非线性、校准
系数或随机 dither 的混合分布。固定 dither 符号可作为一个确定性工作状态单独
预测，但不同符号状态不得在本规格中未经说明地平均。

## 2. 模型变量与方程

第 `s` 个前级的主输入记为 `x_s`，辅助判决输入为

```text
u_s = rho_s*x_s + o_s.
```

有效阈值为 `t_(s,k)+theta_(s,k)`；阈值区间左闭右开。判决得到符号 `q_s`
后，静态残差为

```text
z_s = G_s * (x_s - a_s(q_s) - epsilon_s(q_s) + d_s),
x_(s+1) = F_s(z_s),
```

其中 `a_s` 是名义 CDAC 电平，`epsilon_s` 是码相关 CDAC 误差，`G_s` 是
实际线性增益，`d_s` 是固定 dither 电平，`F_s` 是恒等映射或奇对称单调 PWL
映射。末级 SAR 在 `[-1,1)` 上使用 8-bit midrise、左闭右开量化。数字重构为

```text
C = 512*q1 + 128*q2 + c3 - D1 - D2 + 2048,
```

并按 `[0,4095]` 裁剪，同时保留裁剪前输出和可纠正状态。

## 3. 求解方法

预测器从完整输入区间和恒等仿射式 `x_1=x` 开始，按以下边界递归切分：

1. 将 flash 阈值经辅助路径反解到当前主输入坐标；
2. 在每个判决区间内代入对应 CDAC 电平，得到新的仿射残差；
3. 在 PWL 正负分段边界处继续切分并组合局部斜率、截距；
4. 在下一级 flash 阈值、主路径表示范围和末级 SAR 阈值处继续切分；
5. 为每个最终输入分段赋予固定的逐级码路径、最终输出码和可纠正标志；
6. 对映射到同一输出码的全部区间宽度求和，直接得到均匀输入码密度。

在所有局部斜率为正的当前范围内，各边界只有一个反解位置。该算法不需要生成
等间隔 ADC 输入样本，也不需要平台频谱、数值 Jacobian 或拟合系数。其复杂度
由实际生成的分段数决定，而不是由验证采样密度决定。

## 4. 独立性边界

- 核心实现位于 `src/adc_research/theory/static_transfer.py`，不得导入
  `adc_research.platform`；
- 理论与平台只共享经过审查的 YAML 参数及冻结的码制约定；
- 理论侧单独解析配置、反解边界、传播残差并执行数字重构；
- 平台只在实验脚本和测试中作为外部对照，不参与预测器构造；
- 指标定义沿用 `ADC_METRICS_PROTOCOL_V1.md`，但静态码宽由区间测度直接获得，
  不是由平台均匀斜坡直方图估计。

## 5. 验证设计

EXP-015 使用四类相互区分的条件：

1. **理想解析基线**：要求 4096 个等宽输出码区间、零 DNL/INL、零缺码、
   零负向步和零不可纠正宽度；
2. **轻度静态非理想留出**：启用 Gate-D 的阈值、CDAC 和线性增益误差，在
   未参与边界构造的黄金分割相位网格上逐点比较理论与平台；
3. **组合 PWL 留出**：再加入两级 PWL truth，验证分段非线性组合；
4. **冗余边界失效**：使用 EXP-004 已确认的
   `rho=0.964, o=-0.08, dither=(+1,+1)` 反例，要求理论和平台都检出
   非零不可纠正输入测度。

验证网格只用于检验，不用于确定任何理论边界或参数。必须同时报告输出码不一致、
可纠正状态不一致以及不可纠正输入宽度误差；不允许只用汇总 DNL 掩盖路径分类错误。

## 6. 首轮验收条件

- 理想链 4096 个输出码的最大绝对 DNL 和 INL 不超过 `1e-12 LSB`；
- 理想链无缺码、无负向步、无不可纠正输入区间；
- 四类条件在全部留出输入点上的输出码不一致数和可纠正状态不一致数均为零；
- 冗余边界反例的理论不可纠正输入宽度和平台估计值均大于零；
- 反例不可纠正宽度的理论值与均匀留出网格估计值之差不超过由网格分辨率给出的
  显式容限。

## 7. 当前限制和下一步

当前预测器要求 PWL 各段保持正斜率，且 PWL 定义域覆盖被访问的模拟输出。
静态预测通过后，下一步将输出码阶梯函数与正弦输入相位区间组合，直接计算有限
记录的离散频谱或周期傅里叶系数，并与平台 FFT 在留出幅度和频点上比较。动态
误差和校准参数仍不进入本轮模型。

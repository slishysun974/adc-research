# EXP-056：百万量级学习分开了平均校正、学习波动和量化偏差

> 2026-10-10。[预定协议](../../../experiments/exp_056_million_scalar_statistics/protocol.json)、[结果](../../../artifacts/runs/EXP_056/million_v1/summary.json)、[独立核对](../../../artifacts/runs/EXP_056/million_v1/verification.json)、[解析推导](../../theory/MILLION_SAMPLE_SCALAR_MEAN_NOISE_AND_QUANTIZATION_V1.md)。接续EXP-055和百万量级计划的前两步。

**在已核对的静态单斜率模型中，无量化时平均校正方向正确，百万条学习观测后仍有固定步长造成的波动。量化则能让平均校正位置随输入范围改变。**这两种现象需要分别研究：增加记录长度能消除平均瞬态，不能自动消除固定步长噪声或量化偏差。

本轮120条标量控制路径全部通过预定统计检查，362项回归通过。结果限于明示单级、无记忆、独立输入和二值dither模型；没有核实芯片，也没有完成四段／两级Gu长期收敛。

## 3. 量化偏差不会靠多学自动消失

小摆幅和直流、增益0.975时，量化读出固定为正／负dither对应的`62/-63`。这给

\[
 E[DR]=4000,\qquad k_*=64^2/4000=1.024.
\]

真实逆增益为1.025641，差约−0.001641。五种子结果稳定在解析位置附近；完整累计降低了波动，但没有消除平均位置差。

宽范围量化控制的相关误差项为`E[Dη]=-2/195`，平均位置约1.02564366，比逆增益高约`2.63e-6`。独立随机dither没有自动使量化误差独立，其偏差明显依赖输入支持。

floor中心码还保留输出直流误差；不能把`[-1,0)`码误差偷换成零均值噪声。相关均值根、数字平方误差最小系数和真实模拟逆增益分别报告，没有用离线参考替换原学习系数。

## 6. 对主线的判断与下一项

百万量级检查已给出两个可分开的原因：正确平均学习仍可能被固定步长噪声抵消；有限后端量化可能形成输入相关的平均位置差。因此短记录的不利更新比例不是充分诊断，单纯延长学习也不是通用修复。

接下来按计划冻结**静态两级和平滑非线性**的正向控制：先加后级量化，再检查后级校正误差和数字函数表示残差，保留足够学习观测、各段实际激励、同一固定步长及完整输出。Q3／Q22与主辅动态另行加入。到该门通过后，再围绕明确主要原因评估累计、数字去信号化或分阶段步长；当前不提出新算法、扩大任意参数排名或宣称Gu芯片失效。

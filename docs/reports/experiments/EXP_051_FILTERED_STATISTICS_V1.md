# EXP-051：更新方差降低，最终校正仍有条件

> 2026-10-10。正式产物：`artifacts/runs/EXP_051/filter_v1/summary.json`、`verification.json`及`filter_sum_audit.json`。[协议](../../../experiments/exp_051_filtered_statistics/protocol.json)在计算前固定。沿四点更新的实际闭环问题，比较一阶相关量平滑与小步长，不改变样本预算或追加训练。

**平滑使更新明显平稳，却没有平均输出收益；小步长有较多有限记录收益，但尚不能作为稳健修复。**24格中，小步长改善20格、平均提高4.1986 dB，最差却低3.7813 dB，未通过预定门。它仅在12格优于单位系数参考，平均与单位系数几乎持平。因此改善原Gu候选的坏轨迹，和学到更准确的校正，需要分别证明。

## 比较合同

新增两组人工三次曲线参数：压缩前后级`(0.992,-0.04)/(0.985,-0.03)`、辅路`(1,0.015)`；扩张前后级`(0.98,0.03)/(0.985,0.025)`、辅路`(1,-0.01)`。它们仍属于此前测试的三次函数类别，不代表真实放大器形状。

三个新输入／dither种子组，每组两条曲线、均匀／中心集中训练、复位／保持历史，共24格、72条路径。均匀正弦频点109、中心89，在三个组之间保持不变；组间主要改变随机流，避免上一实验种子与频点同时改变的解释混淆。跨曲线／历史共享流，24格仍不视为24次独立统计重复。

每条路径从单位系数开始，训练15360次，接入3840点正弦继续在线；相位均固定0，每窗口120条输出、只选4条更新，乘积乘30，提交160次。平台三路放大剩余因子仍`(0.002,0.04,0.002)`，跟踪因子0或1。物理及数字状态在输入切换处不复位。

## 条件理论与实现成本

[推导](../../theory/FILTERED_STATISTICS_STEP_AND_STATE_VARIANCE_V1.md)使用明确的线性标量、固定增益、白噪声条件，分别计算统计方差和闭环系数方差。平滑系数1/4在固定状态下把统计方差降到1/7；弱反馈极限中，它与原更新的系数方差比却趋向1。小步长的系数方差比趋向1/4，但均值响应约慢四倍。数学模型没有用平台灵敏度或数据拟合真实Gu增益。

若相关量含常值偏差，平滑与缩小步长均不改变该标量模型的平均零点。实际EMA轨迹另有不要求独立／平稳的有限累计恒等式：过滤统计和等于原始统计和减一个端点项、再加滤波舍入项。24格、前后级各四段、训练／正弦两部分共384组恒等式全部精确成立；它不把两条不同方法的状态轨迹当成同一条，也不自动证明目标正确。

整数EMA保留两个统计小数位。前后级四样本相关和范围为±17817600／±1113600；过滤状态范围±71270400／±4454400，分别28／24位，八段新增208位。中间分子需30／26位。原八个Q22累加器184位仍保留，功能学习状态合计392位，不含共同同步控制。

小步长不新增学习寄存器，仍改变请求算术及速度。平滑新增的状态及移位／加法／舍入不能省略；本轮无新RTL或工艺综合，不能把功能位数直接换算为面积、频率或功耗。滤波器舍入相对理想实数递推有统一范围，实际目标／误差／滤波舍入／请求舍入／裁剪逐窗口精确还原状态。

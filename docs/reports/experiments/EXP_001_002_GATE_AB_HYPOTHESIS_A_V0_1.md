# EXP-001/002：Gu 候选 A 的 residue 覆盖与联合冗余边界

> 状态：通过 Gate A/B  
> 架构假设：`gu_static_hypothesis_a_v0_1`  
> 验证对象：独立解析边界与逐样本平台实现

## 1. 结论

候选 A 通过 Gate A（量化器与 CDAC）和 Gate B（单级 residue 与冗余）的当前验收条件。8 个严格递增阈值形成 9 个 thermometer 状态；阈值相等时统一进入高索引区间；CDAC 名义电平 `q/4` 严格单调。无 dither 时，每个名义区间的放大后 residue 均位于 `[-0.5,0.5)`，因而相对后级 `[-1,1)` 保留半量程冗余。

带候选 dither 时，模拟求和点幅度为 `+/-1/32`，解析阈值安全半宽由 `1/8` 降为 `3/32`。逐样本平台在安全窗口内的两种 dither 符号均未过载；把边界移到解析窗口外会产生 `correctable=False` 和明确的过载方向。解析函数不导入实验平台，平台也不导入解析模块；二者只在测试层比较结果，避免用同一实现自证。

论文报告的约 3% 辅助路径系统性增益差，在 `rho=0.97` 和 `rho=1.03` 两个方向上均未耗尽 `3/32` 的 dither-on 冗余窗口。该结果支持“结构上可容忍”，不等同于对随机 offset、CDAC mismatch 和 PVT 联合 yield 的声明。Gu et al. 报告双路径结构、约 3% 增益差和第二级 62.5 mV redundancy；这些数值是本次边界验证的外部锚点。[^1]

## 2. EXP-001：名义 residue 覆盖

采用：

```text
thresholds = [-7/8, -5/8, -3/8, -1/8,
               1/8,  3/8,  5/8,  7/8]
q = -4,...,4
a(q) = q/4
z = 4*(x-a(q)).
```

对每个决策区间检查左端、中心和趋近右端的样本。所有状态的解析 residue 区间相同：

```text
-0.5 <= z < 0.5.
```

满量程输入端采用 `[-1,1)`，比较器阈值采用 `[lower,upper)`。平台同时保留 `region_index` 与物理 `symbol`，并单独输出输入过载标志、最近阈值距离、CDAC 名义值、码相关 mismatch、dither 项、放大前 residue 和放大后 residue。

## 4. 双 dither 与三级重构附加回归

虽然本报告验收范围是 Gate A/B，仍增加一个跨级恒等式回归作为后续 Gate C 的前置检查。对全部 4096 个 12-bit 码中心、`s1/s2` 四种 dither 组合以及 `rho=0.97/1.03`，验证：

```text
U12 = 512*q1 + 128*q2 + c3 - 64*s1 - 16*s2 + 2048
    = floor(2048*(x+1)).
```

全部组合均逐码相等，且第二级输出 `x3` 保持在 `[-1,1)`。这证明 64/16 数字副本在候选 A 中具有精确整数平移性质，也说明辅助路径增益差只要未触发过载，就不会单独破坏理想重构。

## 5. 软件验收

当前 Gate A/B 正式模块包括：

- `platform/quantizer.py`：表驱动区间判决与明确端点语义；
- `platform/cdac.py`：名义码电平、码相关 mismatch 和 dither 分项输出；
- `platform/amplifier.py`：理想静态放大与受控实际增益扫描；
- `platform/stage.py`：显式 main/aux 输入的逐样本组合；
- `theory/redundancy.py`：不依赖平台的联合边界解析式。

完整单元测试共 28 项，全部通过。其中 Gate A/B 新增 13 项，覆盖配置拒绝、阈值等号归属、CDAC 单调性、dither-off 零影响、名义 residue、联合窗口内外反例、3% 辅助增益差和双 dither 精确重构。

## 6. 限制与 Gate C 输入条件

本次通过只适用于候选 A 的静态、单调、无记忆模型。以下内容没有被本报告证明：

- Gu 芯片内部实际 flash/CDAC 开关真值表与候选 A 完全相同；
- 1/16 dither 的公开措辞必然指每个二值电平的绝对幅度，而非峰峰值；
- bubble、亚稳态、采样时间差、有限建立和随机噪声下仍满足相同静态边界；
- 未校准主增益/CDAC mismatch 在不越界时不会产生码误差。

Gate C 应复用这些平台组件，但必须新增后端 SAR、数字重构和完整 trace；同时继续保持解析预测器与逐样本链的实现独立。

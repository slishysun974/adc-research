# EXP-030：四段定点 PWL 校正的候选 RTL 逐码核对

> 2026-10-03。比较[候选组合模块](../../../rtl/gu_baseline/fixed_pwl_candidate_a.sv)与现有 Python `correct_fixed`，只证明明示数字规则下的实现一致性。

## 协议

第一级和第二级的 Q3 分段宽度分别为 `1024/256`，系数为无符号 11 位 Q1.10。分段左闭右开；负满量程 `-4b0` 延伸最后一段，正满量程 `+4b0` 越域。局部乘积先按最近偶数舍入，前面各段的系数**先相加、再乘宽度并统一舍入**，最后恢复符号；非法域输入清零且 `valid_out=0`。这些是 EXP-012/026 的候选规则，不是芯片定点规范。

[向量生成器](../../../experiments/exp_030_fixed_pwl_rtl/generate_vectors.py)对两级每种系数组合穷举全部合法 Q3 原始输入，再加四个非法端点。四组系数分别为全 1、非均匀、零与最大码混合、接近最大码；它们用于测试数值规则，不代表实际训练系数。参考值来自 Python `correct_fixed`；全 1 组另独立检查输出恒等于输入。生成文件在 `artifacts/runs/EXP_030/candidate_a_q3_q10/vectors.txt`，同目录 JSON 记录参数与覆盖计数。Icarus Verilog 10.3 运行命令见[实验入口](../../../experiments/exp_030_fixed_pwl_rtl/README.md)。

## 结果

第一级 `32784` 条、第二级 `8208` 条，共 **40992 条**，RTL 的有效标记、分段号和有符号校正码均与软件逐项一致。向量包含 `32` 次局部乘积半码舍入与 `1026` 次偏移半码舍入，并覆盖负满量程、所有段边界和非法域输入。测试平台另核对 `valid_in=0` 时输出清零。仿真输出：`fixed_pwl_candidate_a 40992 oracle vectors passed`。

这是**单级冻结系数组合功能**核对。Python 模型和 RTL 共享候选码制；它不确认实际芯片编码、系数广播、乘法器流水、溢出位置、面积或时序。RTL 输出位宽 17 位、乘积与偏移中间量 32 位是当前候选容量；进入完整链路后还需核对两级顺序、dither 和最终整数码。

# EXP-009：自适应门限 gated-LMS 与高段可辨识性

> 状态：方程级浮点原语通过；两级联合随机调度尚未实施  
> 架构配置：`gu_behavioral_v1`  
> PWL truth：`gu_gate_d_static_v0_1`  
> 正式运行：`artifacts/runs/EXP_009/adaptive_gated_lms_v1_20260915`

## 1. 结论

Gu 的 4-slice gated-LMS 不是按 raw-code slice 是否被访问来判断系数能否
更新。`k1` 使用全部样本；`k2...k4` 使用校正并扣除对应数字 dither 后的
`Dout`，只施加由前序系数形成的自适应下门限：

```text
b_n[m] = b0 * sum(k_i[m], i=1..n)
g_1[m] = Dout[m]
g_i[m] = Dout[m],  abs(Dout[m]) >= b_(i-1)[m]
       = 0,        otherwise
k_i[m+1] = clip(k_i[m] - mu_i*Dd[m]*g_i[m], 0, 2)
```

所有门限均由更新前的同一组系数计算，再同时更新系数。本实现只使用下门限；
若把 `k1` 限制在第一段并加入上门限，一对位于门限两侧的 dither 输出可被
映射为“较大输出变成 0、较小输出保留”，从而反转顺序。

默认 residue 半幅为 `0.5` 时，第一级 PWL truth 的第三段被模拟 dither
访问 119995 次，但 `k3` 的 gated-LMS 有效更新为 0；第二级第三段被访问
130150 次，`k3` 只有 13680 次有效更新。两级 `k4` 均为 0 次更新并保持
初值 1。这证明：**truth slice occupancy 不等于 adaptive identifiability**。

将扣除 dither 后的合成 residue 半幅扩展到 `0.85` 后，两级 `k4` 分别获得
106087/126622 次有效更新，四个系数均收敛到 oracle 的最大绝对误差
`0.00573/0.00682`，无校正相对自适应校正的 RMS 误差改善为
`12.25x/12.61x`。

## 2. 论文方程契约

OJSSCS 2026 Eq. (5)-(7) 和 Figs. 4、10 给出的关键语义为：

- `k1[n+1] = k1[n] - mu1*Dd[n]*Dout[n]`；
- 高段系数使用同一更新式，但 `Dout` 先经过自适应下门限 gate；
- 第二段下门限为 `b1=k1*b0`，四段依次为 `0/b1/b2/b3`；
- 不应给 `k1` 增加第一段上门限；
- DC 或小摆幅会造成高段更新不足；论文讨论的补救是额外的 2-bit
  large-signal linearization dither `+/-0.25/+/-0.75`。

本实验的普通 1-bit 校准 dither 采用放大器输出等效 `+/-0.125`，与候选 A
的数字副本 64/16 一致。`expanded_residue` 只是一项持续激励实验，不复刻
2-bit linearization dither，也不代表 mismatch/timing-skew 的硅统计分布。

## 3. 正式结果

每个案例训练 1000000 个样本。为把可辨识性与有限样本随机梯度方差分开，
每个随机基值连续施加一对顺序随机的 `+d/-d`。这是一项 antithetic
方程探针，不是四路 750 MHz 与 decimate-by-30 的硬件调度。

## 4. 对第四段的处理原则

当 `gate_count[k4]=0` 时，数据似然不含 `k4` 信息；任何 LMS 步长、训练时长
或定点精度都不能解决这一不可辨识性。工程实现必须：

1. 独立记录 raw slice occupancy 和 gated update count；
2. 无有效更新时冻结 `k4`，并把“保持初值/前景值/相邻斜率外推”标为策略，
   不能声称已经收敛；
3. 以每段有效更新次数而非全局样本数度量收敛时间；
4. 若系统要求校准稀有外段，必须增加受控持续激励，同时验证冗余余量和
   数字可消除性。

## 5. 证据边界与下一步

本实验关闭了浮点 gated-LMS 原语、自适应门限、下门限单调性约束以及高段
零占用冻结语义。尚未关闭：

- 两级系数同时更新时两个独立 PRNG 的互相关和更新串扰；
- 四路并行、decimate-by-30 的真实随机更新率与稳态方差；
- 2-bit large-signal linearization dither 的注入、折返和数字消除路径；
- 11-bit 系数与全链 3 fractional-bit 的定点极限环。

下一实验应把 stage2 校正/扣 dither 后的局部输出先用于 stage2 LMS，再按已
冻结的嵌套顺序形成 stage1 输出并更新 stage1 LMS；同时保留 oracle 基线、
每段有效样本计数和未激励系数冻结三组对照。

# EXP-043：整数停更、周期波动与门控选择

> 2026-10-09。正式产物：`artifacts/runs/EXP_043/mean_v4/summary.json`。复用 EXP-039 六组记录各前96窗口，共69120条转换；14项定向检查与全项目269项测试通过。没有新训练、模拟重跑、Cadence 或 Gu 算法修改。

本轮定位到一个具体的定点机制：**Q3舍入将raw=±47这类样本的第二门开启系数从16/15移到17/16。**两组固定记录的后级整数平均映射因此在无停更的有限范围内反复更新，指定初值的精确周期为1824和538。实际窗口存在越出同一范围的反例，故这些周期不能称作原四路算法的稳态。

[完整推导](../../theory/QUANTIZED_MEAN_DYNAMICS_AND_GATE_SELECTION_V1.md)还说明：输入与dither独立只在门和目标满足额外条件时消去信号相关项。门的选择可以重新带入信号项，稳定相关零点仍可能对应错误目标。

## 研究合同

后级第三、第四系数固定为1，前两项保留Q22状态、Q1.10最近偶数导出、Q3舍入和`≥`门。每次重复使用11520条拟合记录的相关均值，乘120转换的原步长后一次舍入。这是**固定经验分布的整数平均诊断**；N=120时才等于某个实际窗口的冻结相关和。

三组随机条件的初始中心取EXP-042第一相关量零点直线在v=16/15的交点；其余三组取唯一后级连续根。全部六组均保留。按同一顺序检查导出码中心半径1、2、4、8、16的矩形，接受第一个不变集合；全部不通过则保留半径16及反例，不报不稳定。

来源字段、全部相关和、状态范围与求根资料SHA-256在运行前后核对。理想码只用于独立离线的前级目标分解，不进入整数动力学、门或更新请求。

## 1. 连续跳点不能当作一维吸引点

三组随机记录在v=16/15左右的第二相关量分别为负／正，故v的更新向跳点。但第一相关量当前为零只使u停更，v变化后第一相关量变为A₂Δv。六个左右检查均离开原零点直线。这个求根消元直线不是实际Gu闭环的不变集合。

## 2. 门开启位置被Q3舍入提前

raw=47、dither=16时，本段乘积的Q3整数为`round_even(120*c_v/1024)`。第二门要求该值≥128。导出码1088给127.5，舍入到128后按等值门打开；1087仍关闭。

| 连续阈值 | 定点最小开启导出码 | 对应系数 | 相对连续阈值的移动 |
|---|---:|---|---|
| 16/15 | 1088 | 17/16 | −1/240 |

负号配对同样成立。该样本族在六组各出现106、103、104、112、114、113次，独立原定点PWL函数核对了门的三处取值。不是全门统一偏移，也没有取得芯片舍入证据。

## 3. 整数范围与周期

通过每个导出单元的完整整数原像及常量请求，直接验收矩形全部状态的像。以下“无停更”只针对最后检查的矩形；高段非零请求单独保留。

| 条件 | 整数平均二维矩形不变 | 矩形内停更 | 高段请求全零 | 指定初值周期 |
|---|---|---|---|---|
| 随机，复位 | 是，289单元 | 无 | 是 | 1824 |
| 随机，两相 | 是，289单元 | 无 | 是 | 538 |
| 随机，直接保持 | 是，289单元 | 无 | 否 | 未找到；到20000个事件停止 |
| 周期，复位 | 未通过 | 无 | 是 | 未认证 |
| 周期，两相 | 未通过 | 无 | 否 | 未认证 |
| 周期，直接保持 | 未通过 | 无 | 否 | 未认证 |

前两组各覆盖4,848,615,423个Q22整数状态，高段门全闭，故原后级整数平均映射也保持这些集合；任何集合内初值最终进入非平凡周期。所报具体周期只对预先确定的初值，逐步检查完整状态及周期内不重复。

指定初值进入周期后，两个自由累加器的范围为：

| 条件 | 第一累加器Q22范围 | 第二累加器Q22范围 | 第二导出码范围 |
|---|---|---|---|
| 随机，复位 | 4728820–4728837 | 4454378–4454885 | 1087–1088 |
| 随机，两相 | 4708348–4708366 | 4454381–4454873 | 1087–1088 |

例如随机复位中，第一导出码1154固定时，第二码1087／1088的前两请求分别为`(5,475)`／`(2,−15)`；第一码1155固定时为`(−5,486)`／`(−13,−22)`。第二门恰多计入106条上述样本，第二请求由正转负。周期的两个第二导出码确实跨越这个Q3门，不只是连续阈值附近的数值波动。

![固定经验均值的整数周期](../../../artifacts/runs/EXP_043/mean_v4/mean_cycles.png)

图中横轴是重复使用同一经验均值的更新次数，不能换算成原四路算法或芯片的训练时间。Q22状态有细微变化，但Q1.10导出在两个码之间切换；重复导出码并不代表完整状态已经重复。

随机直接保持的高段自身请求非零，故其二维不变结论属于人为固定高段的映射。预设搜索没有找到另三组的不变矩形，只表示当前充分条件未通过。

## 4. 原四路窗口否定了同一矩形的通用性

六组都找到实际窗口的越界见证，并用未改动的`correct_fixed_four_lane_window`核对全部四项后级请求及状态。

随机复位矩形左下角`(4671489,4438016)`，真实第0窗口请求为`(-1774,-3295)`，结果为`(4669715,4434721)`，两项均越过下界。它说明平均映射的矩形不对所有实际窗口不变；没有证明原算法从指定初值发散，也没有证明实际周期等于1824。

实际窗口平均请求还包含先舍入与后平均的差别，完整96窗口旧状态请求均已保存。各窗口的观测／相位变化必须进入后续范围证明。

## 5. 目标信号项的条件不平衡与门选择

前级离线目标定义为`T=I−2048−512q₁`。精确计算`E[DTG]`中的条件符号不平衡和门协方差。下表为第二门、码平方单位；前两类诊断分别取后级跳点／根与前级单位系数，只有周期复位使用唯一完整连续根。

| 条件 | 条件不平衡项 | 门协方差项 | 目标相关项 |
|---|---:|---:|---:|
| 随机，复位 | 121.558975 | −100.731197 | 20.827778 |
| 随机，两相 | 122.815215 | −96.554104 | 26.261111 |
| 随机，直接保持 | 122.321971 | −77.749749 | 44.572222 |
| 周期，复位完整根 | 212.207066 | −102.562621 | 109.644444 |
| 周期，两相 | 219.339159 | −74.078048 | 145.261111 |
| 周期，直接保持 | 218.378890 | −73.817779 | 144.561111 |

每组512个目标码分层中，随机三组仅37层、周期三组仅41层经验dither均值恰为零。第一门恒开，选择协方差为零；第二门会改变该信号项。精确48项恒等式核对了信号分解及与误差项的和。

周期复位完整根的第二目标项为109.644444，误差项为−109.644444，相关量因此为零。记录分解不是总体独立性或因果识别证明。

另一个手算反例让T恒为1、D独立等概率取±1，误差为D/4。门`|T+D/4|≥1`只选正dither，未门控相关量为0，门控信号项却为1/2。它说明只声明输入和dither独立不足以覆盖错误校正状态的门控相关量。

## 验证与下一项

原定点PWL与新精确公式对4134个导出码对的全部相关和／门次数一致；22163个事件段首末及两组完整周期核对通过。两个周期中的全部第二门切换样本恰为raw=±47/dither=±16，独立原函数逐行核对。六组真实窗口见证通过原更新器检查，14项定向检查、269项回归测试及236个本地文档链接检查通过。图已查看，来源和原始记录未改变。正式验收记录保存在`mean_v4/verification.json`。

经典dither量化理论对误差独立性有额外模型／分布条件，见Wannamaker[第4.3节、定理4.4](https://uwspace.uwaterloo.ca/bitstreams/fa271912-b183-4c4c-a95d-bc2f761ba345/download)。本轮以自身条件分解证明门选择关系，没有把理想减法dither定理直接用于两级非线性Gu系统。

下一项优先研究原窗口次序的相位组成与高段释放，建立实际窗口扰动可覆盖的状态范围，再把系数波动传播到前级最终码。没有开展新算法优劣比较，没有把平均周期升格为芯片结论。

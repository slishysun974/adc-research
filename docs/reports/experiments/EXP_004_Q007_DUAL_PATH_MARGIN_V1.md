# EXP-004：Q-007 双路径增益与 offset 联合余量

> 状态：Q-007 行为级审计完成  
> 架构配置：`gu_behavioral_v1`  
> 正式运行：`artifacts/runs/EXP_004/q007_v1_20260915`

## 1. 结论

OJSSCS 报告的约 3% 系统增益差应映射为第一 inter-stage 辅助输出相对
主输出的增益差：主输出驱动第二级 CDAC，辅助输出驱动第二级 flash。
因此第二级判决使用 `x_aux=rho*x_main+o`，CDAC 与 residue 继续使用
`x_main`。该失配不施加到第一级输入 flash。

默认 dither 开启时，候选 A 的单边界冗余半宽为 `3/32`。只考虑
`rho=0.97/1.03` 的系统增益差，要求全部八个候选边界同时安全时，公共
offset 容限分别为约 `+/-32.34 mV` 与 `+/-35.16 mV`。若只审计理想
第一级加 dither 时第二级名义可达的六个中间边界，容限分别为
`+/-36.09 mV` 与 `+/-38.91 mV`。

论文的 20 mV offset 和 0.3% 随机增益失配是 trimming 前 Monte Carlo
标准差，不是最大误差。把约 3% 系统项、1σ 随机增益与 1σ offset 同时取
矩形角点时，八个角点在解析边界内；完整平台对 4096 个码中心和四种双
dither 组合进行 131072 次检查，错误和不可纠正事件均为 0。

相同方法扩大到 2σ 矩形角点后，全部八边界范围内 8 个角点均不能得到
统一保证；名义可达六边界中只有 2/8 角点仍满足联合条件。码级平台确实
找到 80 个失败样本，而不是只有保守解析式报警。首个反例在
`rho=0.964`、`o=-40 mV` 时使第二级 residue 达到 `1.00390625`，产生
不可纠正事件和 1 LSB 码偏差。

论文另报告：在 27 摄氏度校准后，跨 -40 至 85 摄氏度的 offset 和 gain
漂移标准差分别低于 0.5 mV 和 0.1%。将这两个“低于”数值直接作为保守
σ 上界，并取 3σ 矩形角点，平台进行 65536 次检查，失败为 0。该结果
支持“校准后漂移相对 62.5 mV 冗余较小”的结构解释。

## 2. 解析模型

对第二级第 `k` 个 flash 边界：

```text
x_aux = rho*x_main + o
B_k = (t_k + theta_k - o)/rho
L_k <= B_k <= U_k
```

`[L_k,U_k]` 由 CDAC 相邻电平、主路径增益和 dither 的联合冗余条件给出。
反解公共 offset：

```text
t_k + theta_k - rho*U_k <= o <= t_k + theta_k - rho*L_k.
```

对所选边界求交即可得到给定 `rho` 下的公共 offset 区间。新模块
`theory/dual_path.py` 独立实现区间求交和逐边界有符号余量，不导入逐样本
平台。

## 3. 验证结果

| 场景 | 理论角点 | 平台码/dither 检查 | 平台失败 |
|---|---:|---:|---:|
| trimming 前 1σ 矩形包络 | 全边界 8/8 安全 | 131072 | 0 |
| trimming 前 2σ 矩形包络 | 全边界 0/8；名义可达边界 2/8 | 131072 | 80 |
| trimming 后温漂 3σ 矩形包络 | 4/4 安全 | 65536 | 0 |

2σ 平台失败集中在 `rho=0.964` 和 `rho=1.036` 的同向极端增益角点；
`rho=0.976/1.024` 的角点在本次码中心扫描中没有失败。这说明只报告
offset 或 gain 的单项百分比不足以判断安全，符号组合和边界位置同样
重要。

## 4. 统计解释限制

本实验没有计算良率。矩形 kσ 角点把 gain 和 offset 同时放在各自极端，
既未假设联合正态，也未使用相关系数；“1σ 通过”不等于 68%、84% 或任何
其他良率数字，“2σ 出现反例”也不代表实际失败概率。

当前 offset 是辅助路径公共输入参考项。论文所述 comparator trimming 可
对不同阈值分别补偿，因此后续若研究前景校准残差与 yield，需要扩展到
逐比较器 offset、相关性、trim 量化步长和 PVT 漂移分布。

物理换算继续采用候选 A 的 `1 Vpp differential` 高置信解释；若该口径被
新证据推翻，归一化边界不变，但报告的 mV 数值必须重算。

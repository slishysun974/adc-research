# EXP-033：512 点数字二选一记录的在线状态范围

> 2026-10-04。正式摘要：`artifacts/runs/EXP_033/fixed_box_sine_v1/summary.json`。实验仅验证 EXP-032 的 Q22 逐转换数字候选及[整数状态范围方法](../../theory/FIXED_ONLINE_STATE_BOX_BOUNDS_V1.md)；没有模拟电路或芯片记录。

## 协议

记录长度为 `512`，相干基波频点为 `19`。第 `n` 次的 dither 标签预先固定：一级奇数次为 `+1`、其余为 `-1`；二级在 `n mod 3` 非零时为 `+1`、否则为 `-1`。令基准末级中心码为 `round(40 sin(2π·19n/512))+64d1+16d2`，每次允许它或它加 `1`，两级粗判决均固定为零。这样设定是数字压力记录，使理想的 dither 数字副本可抵消；它不声称这些五字段组合可由目标 ADC 的同一模拟输入实现。

两级初始 Q22 累加器均为单位系数。每次对两个可能观测都计算校正码与下一状态，再把八个累加器分别取上下界供下次使用。只保存每次最终整数码的上下界和最后的状态范围，不保存完整历史。另取“每次都选较低末级码”和“每次都选较高末级码”两条具体轨迹，用现有 `correct_and_update_fixed` 独立逐次计算，检查其码及终态被包含。它们只是两个检查点，不能代表其余混合历史的极值。复现命令见[实验入口](../../../experiments/exp_033_fixed_online_box/README.md)。

## 结果

| 项目 | 值 |
|---|---:|
| 每次可能观测 | 2 |
| 512 次最终码区间宽度 | 全部为 1 码 |
| 最终第一级四个 Q22 累加器区间宽度 | `538/0/0/0` |
| 最终第二级四个 Q22 累加器区间宽度 | `2175/7581/13027/57665` |
| Parseval SNDR 下界 | `26.555 dB` |
| Parseval SFDR 下界 | `28.051 dBc` |
| 逐频点 SFDR 下界 | `30.891 dBc` |
| 两条具体轨迹的 SNDR/SFDR | 均为 `39.983 dB / 50.922 dBc` |

两个频谱上界在当前保守公式下均无穷大，故只报告有限下界。全部码与状态包含检查通过。逐频点 SFDR 下界比 Parseval 下界高约 `2.839 dB`；这是界限方法在该合成记录上的差别，不是算法性能提高。两条端点轨迹指标恰好相同，不能据此推断所有混合历史也相同；逐点码选择仍可能改变非直流谱线。

## 解释与限制

该例说明，完整历史数随二选一转换指数增长时，整数状态区间仍可在线性记录长度内给出**有覆盖性**的候选码范围，并形成一个非空的频谱下界。范围合并允许不同系数和观测的虚构组合，所以给出的下界可比实际最差轨迹低；真实极值未被求出。

所有数字观测、dither 日程及步长均由研究者设定。没有真实主辅模拟范围、四路抽取规则、芯片数值位宽或综合成本，也没有 FFT 浮点向外舍入证书。因此 `26.555/30.891` 不能表述为芯片 SNDR/SFDR 保证。只有先取得有覆盖依据的观测集合并核对真实更新时序，才能考虑把此方法用于物理条件。

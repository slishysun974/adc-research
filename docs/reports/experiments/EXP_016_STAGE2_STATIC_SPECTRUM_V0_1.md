# EXP-016：阶段二独立静态单音频谱预测

> 实验日期：2026-09-16
> 正式运行：`static_spectrum_v0_1_20260916_r1`
> 结论：通过

## 摘要

本实验先确定正弦输入在一个周期内何时落入 EXP-015 算出的各输出码区间，再直接积分计算
连续周期的复傅里叶系数和功率；同时由理论分段直接生成有限相干记录，按冻结的
共同指标协议计算 SNDR、SNR、THD、SFDR 和 ENOB。核心理论模块不导入或调用
逐样本参考平台。

正式留出包含 3 种输入峰值、2 个互质相干频点和 3 类静态条件，共 18 条记录、
589824 个平台样本。理论码、`correctable` 状态、全频点功率和频谱指标全部与
平台一致；代码不一致数、状态不一致数、频谱功率误差和 dB 指标误差均为零。
静态模型在两个频点间的最坏 SNDR 极差为 `4.8383e-08 dB`，SFDR 极差为
`3.1264e-12 dB`。连续精确 SNDR 与 32768 点有限记录的最坏差为
`0.0059906 dB`，低于预先规定的 `0.20 dB` 门限。

## 1. 研究问题与独立性

输入为静态分段

$$
q(x)=c_j,\qquad x\in[l_j,u_j),
$$

以及 $x(\theta)=x_0+A\sin\theta$。预测器首先求每个落在摆幅内的输入边界所
对应的两个相位交点，再在相邻交点之间定位常码区间。若区间为
$[a_r,b_r)$、码为 $c_r$，则

$$
C_h=\frac{1}{2\pi}\sum_r c_r
\frac{e^{-jha_r}-e^{-jhb_r}}{jh},\qquad h>0.
$$

DC 和均方值直接由相位宽度积分，总交流功率由 Parseval 核算。有限记录则在
$\theta_n=2\pi kn/M+\phi$ 上查询理论分段，再独立执行 FFT。

理论与平台只共享经审查的架构/非理想参数和指标定义。平台输出在理论边界、
连续积分和有限记录预测完成后才用于标签比较，未用于拟合或修正理论。

## 2. 连续周期与有限记录的口径

连续周期函数是含无限多条谱线的阶梯波。请求有限个傅里叶系数即可精确得到
DC、基波、指定谐波，以及通过相位积分得到的全部交流功率，从而计算无限带宽
SNDR、SNR、THD 和 ENOB；但有限谐波子集不足以证明全局最大杂散。因此本实验
不报告所谓“连续精确 SFDR”。

SFDR 只对长度 $M$ 的有限记录按第一奈奎斯特区报告。这一区分避免把未计算的
高次谐波静默排除，也使结果与阶段一指标协议保持一致。连续与有限 SNDR 的差异
被明确记为相位网格求积和高次谐波折叠误差，而不是模型结构误差。

## 3. 验证设计

- 采样率：3 GS/s；
- 记录长度：32768；
- 相干频点：997 和 10923，对应约 91.278 MHz 与 999.969 MHz；
- 归一化输入峰值：`0.499`、`0.901`、`0.999`；
- 初相：`0.2718281828459045 rad`；
- 谐波：二至五次；
- 条件：理想、比较器阈值/CDAC/线性增益组合，再加入两级预设模拟非线性传输；
- 最终码：未经数字后台校准的 12-bit 静态输出。

运行前冻结的验收门包括逐码和状态零不一致、全频点功率零误差、dB 指标误差
不超过 `1e-10 dB`、频点间 SNDR/SFDR 极差不超过 `0.01 dB`，以及连续/有限
SNDR 差不超过 `0.20 dB`。

解析单元基线另使用两电平阶梯 $q(x)=1[x\ge0]$，正确得到
$C_0=1/2$、$C_1=-j/\pi$、$C_2=0$、$C_3=-j/(3\pi)$ 和
$P_{ac}=1/4$。

理想近满量程记录的 SNDR 为 `73.9857 dB`、ENOB 为 `11.9976 bit`，与

下降不依赖输入频率；这正是无记忆静态模型应满足的限制性特征，不应解释为实际
ADC 在 1 GHz 仍无动态退化。

| 单条记录不可纠正样本数 | 0 | 0 | 通过 |
| 全频点功率绝对误差 | 0 | 0 | 通过 |
| SNDR/SNR/THD/SFDR 最大绝对误差 | 0 dB | `1e-10 dB` | 通过 |
| 两频点 SNDR 最大极差 | `4.8383e-08 dB` | `0.01 dB` | 通过 |

连续积分相对有限记录的最坏 DC 差为 `0.0011502 code`，基波 RMS 差为
`0.0010071 code`，基波复系数差为 `0.0011946 code`。这些差异与码和频谱的
平台对比误差为零同时出现，说明它们属于有限相位网格误差，而不是静态结构预测
错误。

## 6. 结论与适用边界

EXP-016 关闭了阶段二的首个静态频谱门：固定静态参数、无数字后台校准时，
完整区间传播与正弦相位积分能够在不依赖平台频谱或拟合系数的条件下，预测连续
功率和有限相干频谱。EXP-015 的静态传输结论因而已从 DNL/INL 延伸到
SNDR、SNR、THD、SFDR 和 ENOB。

本结论不包含随机噪声、随机 dither、开环放大器有限建立、记忆、双路径采样
时刻差、输入缓冲器或 SHA-less 时序。尤其是本实验观测到的频率不变性是静态
模型的正确极限，不是对芯片高频性能的预测。下一步应优先冻结首个动态扩展；
Q-014 中论文报告的 11 GHz/100 ps 可作参数参考，适合先比较一阶有限建立
模型与压摆受限、不同记忆机制的候选，再决定是否加入 Q-013 双路径采样时刻差。

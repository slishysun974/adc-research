# EXP-042：受约束相关零点、门控自洽与性能目标

> 2026-10-09。正式摘要：`artifacts/runs/EXP_042/roots_v4/summary.json`。复用既有六组 115200 次转换，无新训练、Cadence 或算法修改。12 项定向检查及全项目 255 项测试通过。

固定两级第三、第四段系数为单位值后，**三组随机 dither 记录的后级相关方程均无精确零点**，相关量通过门控跳变越过零。周期复位条件有完整均值零点和局部稳定盒，但量化后的正弦 SNDR 从单位系数的 46.954 dB 降到 43.464 dB。结果表明，相关零点存在、局部稳定和正确性能目标必须分别检验。

[本轮推导](../../theory/CONSTRAINED_CORRELATION_ROOTS_AND_JUMPS_V1.md)给出精确扫描、子空间门限保护及统一局部收缩证明，还用离线目标相关量解释零点偏差。不把有限记录无根称为 Gu 普遍失败，也不把局部均值收缩称为 Q22 或芯片收敛。

## 研究条件和信息边界

六组记录来自 EXP-039：随机／周期 255 dither，复位／两相／直接保持三种人工历史模型。前 96 个窗口、11520 条数字观测用于求根；后 32 个随机输入窗口、3840 条记录以及原 32 个在线正弦窗口另作固定根检查。后两部分留出于**本次求根**，此前已经被研究，并非全项目盲测。

每级第一、第二段系数自由，第三、第四段固定为 1。各自由系数严格在 `(0,2)` 内。求根只接收数字 PWL 输入和 dither；理想整数码不进入求根器或解析均值，只用于单独的离线评分和恒等式核对。

利用后级到前级结构，先解后级的两条相关方程，再对每个后级解求前级。第一方程线性消元后，第二相关量的全部门限交点、开区间及等值点用精确有理数枚举。共检查 2699 个开区间、2690 个域内门限交点，全部六组四参数搜索完成，没有退化主方程或零区间。

## 2. 周期复位：真实零点与局部不变盒

这组根的系数顺序为后级四项、前级四项：

`(1.067264154, 1.012280252, 1, 1; 0.968502771, 0.995295081, 1, 1)`。

所有八相关量精确为零，所有固定高段门均闭。自由方向的最大系数扰动为 `ρ=1/32768` 时，全盒门控、前级选择段、数字域和系数域均保持；解析更新转移的统一无穷范数上界为

`q = 24571121/24576000 ≈ 0.999801473 < 1`。

因此对**始终使用这批拟合记录的经验均值映射**，该四维盒不变，扰动按 `q^n` 衰减，盒内根唯一。原 Gu 的经验均值映射在这个固定高段的盒上有相同行为。这不是八个方向都严格收缩，也不覆盖实际每窗口不同的记录。

最近 Q22 状态导出的 Q1.10 系数距离根约 `0.000415061`，为盒半径的 13.60 倍。Q1.10 的半个系数 LSB 为盒半径的 16 倍，当前证明容纳不了导出误差。实际整数均值换算的虚拟 120 转换请求为

`(3, 467, 0, 0; 0, 9, 0, 0)` 个 Q22 LSB。

所以连续相关零点没有变成定点停更状态。该虚拟请求来自整批均值，并非真实某一个四路窗口的请求；非零也不单独证明整数算法发散。

## 3. 直接保持：受约束根不等于原 Gu 不动点

四个前级根的前两系数分别为

`(0.965533,0.999406)`、`(0.962566,1.003426)`、`(0.233669,1.991387)`、`(0.228174,1.998835)`。

后级根相同，前两系数约为 `(1.067927,1.008715)`。全部四个解的后级第三相关量均约为 `−3.027433`，所以对应高段仍请求更新；它们都不是原 Gu 的八相关均值不动点。

前两个根的人为固定高段映射有收缩盒，半径分别为 `1/16384`、`1/8192`，统一范数上界同为 `49141883/49152000≈0.999794169`。后两个根未通过无穷范数收缩充分条件，不把未通过说成已证明不稳定。

这些根包含后级第三门等值。在全参数空间不是正规开邻域，但对固定高段的自由方向，该等值门恒开，故可以证明相对这个子空间的解析关系。示例 raw=80、dither=16、固定第三系数为 1 时，学习输出始终等于第三门限。此处的子空间证明不能替代允许第三系数移动时的分析。

## 4. 真正零点为什么仍可能改善不了性能

以下全部评分保持系数冻结，使用同一 Q22 初始化、Q1.10/Q3 数字链和最终整数码；对照为单位系数，不是 EXP-039 持续在线算法轨迹。正弦为原 3840 点、第 67 基波、全速 3 GS/s，频谱是浮点评估，未经数值认证。全部候选及对照最终码裁剪数均为零。

周期复位根与单位系数的结果：

| 固定评分记录 | 单位系数平均绝对码误差 | 相关根量化后的平均绝对码误差 |
|---|---:|---:|
| 拟合记录 | 4.461458 | 7.090104 |
| 随机输入后段 | 4.468750 | 7.104948 |
| 在线正弦记录 | 4.078125 | 6.687240 |

正弦 SNDR 为 `46.954152 → 43.463933 dB`，降低约 `3.490219 dB`；SFDR 为 `54.504011 → 50.937478 dBc`。同一数据下，相关零点的定点评分比单位系数差，不能据此宣布 Gu 算法普遍比单位系数差。

解释来自一个精确离线分解。用理想整数码 I 和前级粗码 q1 定义目标局部码 `t=I−2048−512q1`、连续误差 `e=y1−t`，则每段相关量为

`C1,i = mean(d1*t*G1,i) + mean(d1*e*G1,i)`。

在拟合记录中，前两个目标信号相关量为 `42401/180≈235.561111`、`4934/45≈109.644444` 码平方；误差相关量精确为其相反数。**零相关量由非零信号项和非零误差项抵消形成。**理想目标只用于该诊断，未喂给正在检验的算法。

固定这个根后，后段随机输入与正弦记录的前级第一相关量分别变为约 `−96.174843`、`−364.981532`。第一门恒开，其目标信号相关量从拟合时的 `+235.561111`，变为 `+135.933333`、`−152.083333`。有限输入与 dither 的相关状态改变，不能把拟合分布的根直接当下一条件的目标。

直接保持四个根的正弦平均绝对码误差约为 `6.8641、6.9557、49.0245、49.2870`，对应单位系数为 `4.0664`；根与性能目标不同的现象在这些受约束解中也出现。全部根保留，没有按频谱选择一个最好根再宣布改进。

理论函数不导入模拟平台；数字输入与离线目标评分保持分开。13 份本轮依赖源码摘要及六份输出摘要已保存，原始 EXP-039 数据和来源源码读取前后保持不变。精确扫描、单侧跳值、根残差、加权均值及 60 项离线相关分解恒等式均通过。

# EXP-032：逐转换在线 Gu 候选 RTL 的系数轨迹核对

> 2026-10-03。检验仓库明示的逐转换定点候选；**不是**论文芯片的抽取、四路系数更新或位级复现。

## 本次回答的问题

[EXP-031](EXP_031_TWO_STAGE_RTL_V1.md)只验证冻结系数时的最终码。本实验把同次转换的两级局部学习输出和 dither 数字副本接到门控更新，检查每个有效输入之后的八个系数累加器是否与[既有 Python 参考](../../../src/adc_research/calibration/fixed_adaptive_two_stage.py)一致。这样，最终码和系数轨迹均有逐次核对；不能用终点指标相近代替功能一致。

## 冻结的候选规则

- 输入是候选 A 的两级 `q=-4…4`、8 位 SAR 码和两路 dither 正负标记；不声称它们是芯片校准引擎的实际字。
- 每条有效数字记录先使用**更新前**的 Q1.10 系数，经过后级先校正、两级局部 dither 扣除、重构、裁剪和最近偶数整数化，输出本次最终码。两级局部学习输出分别是 `stage1_corrected_q3-D1` 与 `stage2_corrected_q3-D2`。
- 两级四段门限由更新前系数形成，幅值**大于或等于**门限时门控有效，遵循论文式 (7) 的写法。Fig. 10 的严格大于写法仍是原文歧义。四段同时按本次对齐的 `D·Y` 更新。
- 本候选每个时钟周期接受至多一条转换记录；有效转换在上升沿同时更新两级 Q22 累加器，下一条记录才使用新系数。域外或非法符号的记录不更新。此时钟约定不映射到论文的 3 GS/s 四路物理时钟，也不定义每路 30:1 抽取。
- Q22 累加器取 `0…2047·2^12`，向 Q1.10 输出时最近偶数舍入。所有更新也最近偶数舍入并饱和。归一化步长与 EXP-026 的 22 位组相同，为 `0.001/0.003/0.006/0.012`，分别除以本级 `512²` 或 `128²` 码平方。

令本级 Q3 dither 和学习输出的整数分别为 `D,Y`，四段的步长分子为 `j=1,3,6,12`。与 Python 的有理数更新式化简后，第一级请求增量为 `round_even(-jDY/4000)`，第二级为 `round_even(-jDY/250)`。RTL 的有符号除法先取幅值再舍入，使正负值保持同一最近偶数规则。累加器为 23 位无符号；乘积和更新中间量扩展到 32/64 位。以上位宽、饱和位置和单转换时序均为研究选择，未从论文推断为芯片实现。

## 逐次核对

[数字向量生成器](../../../experiments/exp_032_online_lms_rtl/generate_vectors.py)从单位系数状态出发，用固定种子生成 8263 条连续压力记录，并以 `correct_and_update_fixed` 顺序计算参考。每条记录在时钟沿前检查有效标记、最终 12 位码、两级四段门控和有效记录的学习输出；时钟沿后检查两级各四个 Q22 累加器。无效记录也保留在序列中，检查状态不变。命令见[实验入口](../../../experiments/exp_032_online_lms_rtl/README.md)。

| 覆盖项 | 数量 |
|---|---:|
| 连续数字记录 | 8263 |
| 有效／无效记录 | 7215／1048 |
| 第一级四段门控次数 | 7215／5457／3577／1736 |
| 第二级四段门控次数 | 7215／5409／3679／1834 |
| 第一级／第二级门限等值事件 | 5／20 |
| 有效记录中的低端／高端最终码裁剪 | 479／486 |

两级每个系数码在记录中都发生变化；第二级第四段累加器达到候选上限 `8384512`。用 Icarus Verilog 10.3 的 `-Wall` 编译没有警告，仿真输出 `two_stage_adaptive_candidate_a 8263 sequential oracle vectors passed`。因此这些给定数字记录下，两个实现的**逐次**结果相同。

本步长和 Q3 dither 副本还使更新增量的精确半整数情况不可能出现：第一级 `D=±512`，其增量分子含 32 的因子，而分母 4000 的半数 2000 不是 32 的倍数；第二级 `D=±128`，分子为偶数，而分母 250 的半数 125 为奇数。测试仍使用最近偶数逻辑，但该记录中的更新舍入半等值次数为零。门限**比较**等值则已发生，不能混淆两种等值。

## 证据边界与下一步

生成器的 `q`、SAR 和 dither 组合是数字压力输入。无效、裁剪及饱和数量不能解释为模拟电路的发生率。当前只运行 Icarus 功能仿真；环境中没有 Yosys，尚无综合网表、面积、最高频率或功耗结果。常数除法的综合代价也未评估。

本实验闭合了**一个明示逐转换候选**的 Python/RTL 系数轨迹。真实芯片仍缺校准字、dither 对齐、四路抽取统计量、系数广播/生效周期、主辅传输和动态波形证据。后续先按[数字提取记录协议](../../stages/03_gu_baseline/DIGITAL_EXTRACTION_TRACE_PROTOCOL_V1.md)取得这些字段，再决定是否替换本候选时序；取得可核查的模拟范围后，才可对物理性能给范围结论。

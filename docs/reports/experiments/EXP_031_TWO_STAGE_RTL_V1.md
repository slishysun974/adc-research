# EXP-031：冻结系数两级 Gu 数字校正的 RTL 核对

> 2026-10-03。把两级四段 PWL 校正、局部 dither 扣除、重构、裁剪和最终整数化连接到同一候选 RTL；**不含在线系数更新**。

## 协议

[两级模块](../../../rtl/gu_baseline/two_stage_fixed_candidate_a.sv)接收两级候选九态符号、8 位 SAR 原始码、两路 dither 正负标记和八个 Q1.10 系数码。数字顺序为 `f2(c3) → +128q2 → -D2 → f1 → +512q1 → -D1 → +2048`。默认数字 dither 副本为 `±16/±64` 码；Q3 中分别为 `±128/±512`。输出先限在 `0…4095` 码的 Q3 表示，再按最近偶数舍入为 12 位整数；因裁剪端点均为整数码，此顺序与软件的“先对未裁剪值舍入、再裁剪”给出相同最终码。以上几何量已与冻结的 `gu_behavioral_v1` 配置自动生成的 Python 基线核对一致。域外状态明确置 `valid_out=0`，不伪造最终码。

[数字向量生成器](../../../experiments/exp_031_two_stage_rtl/generate_vectors.py)使用四组成对的固定系数，穷举每组的第二级 `q2=-4…4`、SAR `0…255` 和第二级 dither 两极；第一级符号与 dither 按固定公式变化。参考结果来自 `correct_two_stage_fixed_observed`；域外分支由单级 `correct_fixed` 算出第一级输入后单独标记。向量是数字压力输入，未要求它们来自某条物理 ADC 轨迹。命令见[实验入口](../../../experiments/exp_031_two_stage_rtl/README.md)。

## 结果与结论

**18432 条**向量逐项通过 RTL/软件比对：`16050` 条处于两级定义域内，`2382` 条使第一级输入越域；有效向量中有 `1033/1047` 条分别触发低/高端最终裁剪，`828` 条落在最终整数舍入的半码位置。比较项包括两级校正码、第一级原始码、有效标记、裁剪后 Q3 码、12 位整数码及裁剪标记。测试平台另验证全局无效输入和两级非法符号均被拒绝。仿真输出：`two_stage_fixed_candidate_a 18432 oracle vectors passed`。

这建立了当前**冻结系数候选数字链**的逐码参考，避免以后只比较 SNDR/SFDR 均值。它没有抽取器、四路系数共享、更新累加器、时钟和实际芯片字长；上述压力向量中的越域或裁剪比例不代表电路发生率。下一步若继续候选 RTL，应先把逐转换门控乘积与明确选择的更新时序、定点累加规则接上，再在同一数字记录上核对系数轨迹；仍不得称为 Gu 芯片复现。

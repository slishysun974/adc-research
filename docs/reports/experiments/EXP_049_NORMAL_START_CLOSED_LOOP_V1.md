# EXP-049：正常单位初值的闭环损失与留出验证

> 2026-10-10。正式产物：`artifacts/runs/EXP_049/closed_loop_v1/summary.json`及`verification_and_propagation.json`。[协议](../../../experiments/exp_049_normal_start_closed_loop/protocol.json)在计算前固定，原Gu核心和RTL未改。

**正常路径没有进入此前较差平均解的低系数区域，但固定四点抽取在输入改变后的实际在线路径中出现明显损失。**新的四组均匀训练条件中，训练终点冻结SNDR比继续在线高6.02–7.26 dB。固定相同数字记录、分别更换前后级状态后，主要损失来自前级状态变化。这比“较差平均根存在”更直接地指向下一步应检查的有限窗口选样问题。

这个结论限于声明的合成条件和有限记录。两组曲线共享输入／dither流，不能把四组当四次独立统计重复；目标信号项的精确分解也不能单独证明全部损失都由它造成。点抽取在另一些条件下仍比完整聚合好，不据此宣布完整聚合普遍优越。

## 实验范围

第一部分只读复用EXP-039六组19200条记录，回放完整聚合与固定点抽取，从单位系数开始，原128个训练窗口和32个在线正弦窗口不延长。两级旧／新状态、实际请求和全部正弦最终码与原记录一致，共1920个旧窗口。保存39份原来源指纹，运行末全部未变。

第二部分生成八组新人工条件，153600次平台转换，形成16条数字路径。每条仍训练15360次，随后接入3840点正弦并继续学习；另冻结同一训练终点，对同一正弦数字记录评分。物理历史不在输入切换处复位。

## 较差平均分支在正常路径中的优先级

旧12条路径的前级第一导出系数最小为`0.9931640625`；全部28条路径最小为`0.9833984375`。EXP-047较差分支的该系数约0.227，第二门选入所有内段的充分条件为≤0.25。当前4480个窗口的正常路径没有进入这个区域。

因此保留此前反例和局部均值稳定性的数学结论，降低“正常运行落入该较差分支”作为当前主要瓶颈的优先级。这个有限观察不证明未来、其他输入或其他曲线永远无法进入。

旧记录也显示终点评分与在线评分必须分开：随机三组训练终点冻结收益为完整聚合0.86–0.93 dB、点抽取3.68–4.44 dB；周期三组冻结收益分别为−0.34至−0.18 dB、−2.23至−1.40 dB。继续在线后，周期复位点抽取从45.554升到47.721 dB。这些方向与新留出不同，不将输入切换必然称为损害。

## 实际窗口如何把目标项带进系数

前级学习输出按实际Q3门分为“理想整数码对应的目标”与“相对于该目标的误差”。两项请求、舍入差及裁剪差逐窗口精确相加，复原训练和正弦的前级四状态变化；[恒等式](../../theory/NORMAL_START_WINDOW_ATTRIBUTION_AND_CODE_EFFECTS_V1.md)列出适用条件。

四组新均匀条件的32个正弦窗口中，点抽取第一系数的目标项累计约为`−0.006921`（Q22状态换算的斜率单位），误差项为`+0.001086至+0.001395`，实际净变化为`−0.005836至−0.005526`。完整聚合在同一输入／标签流中的第一系数目标项约为`+0.000977`。第一门始终打开，因此此处已经有有限选样造成的目标相关差，无须第二段门才出现。

在当前点抽取旧状态上额外计算完整120条乘积和：第一系数16/32个窗口、第二系数18/32个窗口的点抽取请求与完整请求反向。点抽取第一系数21/32个窗口的总相关量与误差相关量反向；第二系数为24–26/32。第二门还选中16条零自身第二基函数的行，占所选门开行约27%–29%。这些计数说明相位选样、目标项和门支撑已在正常路径中实际参与更新。

这批流的目标项是有限记录统计，不据此证明总体条件均值有偏或输入与dither不独立。误差相关量不是最终码MSE梯度；同窗口新状态冻结评分既有误差增大，也有误差减小，不能把每次反向都记成有害更新。

## 前后级状态到最终码的分离

在同一正弦数字记录上，把两级分别设为训练终点状态或各窗口当前状态。保留四组合和交互项，按**最终整数码误差平方和**作精确相加；SNDR差不作加法。

以弱压缩／均匀／复位点抽取为例，冻结训练终点SNDR为59.939 dB。只换当前前级降到52.946 dB，只换当前后级升到61.425 dB，两级当前状态为53.512 dB。最终码误差平方和变化为

\[
22150\;\text{（前级单独）}-1635\;\text{（后级单独）}-1776\;\text{（交互）}=18739.
\]

对应均方误差从1.527升到6.407码平方。其余三组均匀条件的前级单独平方和增量为26655／29646／33898，均占主要正增量；后级及交互均另保留。这支持本实验主要损失经过前级状态传播，但不能仅凭状态干预把全部损失归因于一种污染项。

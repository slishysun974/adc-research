# EXP-063：逐级固定比较器偏移的安全范围、学习支持与短预检

> 2026-10-10。完成D-093／094、静态计划5b的推导与独立短预检；必要长期配对尚未执行。正式记录：[preflight_v1](../../../artifacts/runs/EXP_063/preflight_v1)，运行前方法见[协议](../../../experiments/exp_063_static_comparator_preflight/protocol.json)，推导见[主辅／阈值理论§13](../../theory/DUAL_PATH_EFFECTIVE_THRESHOLDS_AND_PHASES_V1.md)。原平台、在线Gu和RTL保持，新增代码是离线理论控制及专用预检。

## 结果及主要解释

固定小比较器偏移可以改变第三段的局部门和共同支持，但本次幅度没有产生第四段读出支持。理想固定单位状态下，两级分别偏移都改变内部判决，却在全部2048点网格中保持最终码不变；学习后状态离开单位，输出抵消不再保证。

当前同输入四点合同还存在一个确定性的选样限制：一周期30720转换中，第一级偏移改变92次$q_1$，四点选中的1024相位却全部避开这些位置。由于周期是120槽窗口的整数倍，可逐窗口归纳证明，在静态合法读出条件下，只改第一级时四点Q22系数／导出轨迹对全部未来窗口都等于名义路径，不需假设已收敛或dither独立。未入选输出仍可以改变。这是当前输入／偏移／选样的条件结果，不是所有工作输入或芯片的不可辨识结论。

36条32窗口路径、138240次实际转换、2304次单bank提交全独立重放；46080个零偏移输出和对应状态前缀匹配已有EXP-062。18432固定网格、1008条全链路边界／工作端点／例子、432个独立后级节点和432个直接等值／nextafter比较器控制通过，精确数学与原双精度差异为0。无过载、系数饱和或输出裁剪，391项回归通过。短记录不报告长期SNDR或收敛。

## 偏移来源与冻结条件

沿EXP-062三原主路条件：理想；两级线性0.975／0.98；两级平滑(0.975,−0.055)／(0.98,−0.04)。辅助判决路静态匹配第一级主路。每组分别零偏移、只改第一级、只改第二级，共九条件，不启用两级同时失配。

逐比较器向量直接复用[EXP-007合成配置](../../../configs/nonidealities/gu_gate_d_static_v0_1.yaml)：第一级$(3,-2,1,-3,2,-1,3,-2)/2000$，第二级$(-2,3,-1,2,-3,1,-2,3)/2000$。归一化单位为各自flash输入坐标，幅度0.0005—0.0015，最大为0.25码间隔的0.6%。实际最小阈值间隔0.2475，保持有序。偏移没有随机分布、概率、芯片提取或漂移来源，不缩放幅度开高段。

CDAC电平、dither、主辅传输、末级SAR8、原Q3／Q1.10／Q22及门／步长／提交时序固定。在线更新仍只接收`DigitalCalibrationSample`，偏移／输入真值仅在平台与离线控制出现。零偏移是必要退化控制，不重新运行EXP-062长期训练。

短路径用EXP-062实际保存的一周期双精度正弦表、原种子621／622和全局标签源，每条32窗口=3840实际转换。四点每级128学习观测、完整3840，所有未选槽位仍转换并输出。全36路径合计每bank71424个学习观测、1152次双bank提交；保留所有原始读出、掩码、相关和、请求、前后Q22状态及输出。

## 安全范围与第四段

解析结果$|v-q/4|\le1/8+\beta$、$|z|\le5/8+4\beta$给最大名义放大输出0.631，三原奇单调传输及末级均在声明域内。后级SAR中心码幅不超过81，小于第四基函数的96码起点，所以本控制的后级第四基函数对任意数字状态为零；这并不证明任意状态第四门也关闭。

固定单位后级时，前级raw界由$512M_1+128(|a_2-1|Z_2+|b_2|Z_2^3)+1$给出。各组三条件最大值为理想324.072、线性317.5952、平滑311.770293，小于384；后级系数改变后该单位状态界不再保证前级第四段。当前全部短路径的前／后级第四段门、基函数及共同支持均为0，分析没有把它升级为一般八状态证明。

手算与原接口控制都通过：理想$x=0.1255,d_1=d_2=+1$，第一级偏移使前级局部码−255→257、第三门关→开，最终码均2305；两级线性$x=1/2400,d_1=+1,d_2=-1$，第二级偏移使$q_2=0→1$。连续正确逆增益第三門仍闭，SAR后开门；Q1.10导出1045／1024及Q3给局部−65.625、门限65.3125，共同支持保留。等值归较高码，全部本次数学／双精度端点都一致。

开门和实际改变还要分开：平滑第二级偏移的完整路径后级第三门合计打开3次，共同支持0，却发生3次隐藏Q22改变、1次导出改变。原Gu相关更新没有乘本段基函数，“本段共同支持0”不能被写成“没有更新”。全部读出及入选支持原始计数见`validation.json`和`analysis.json`。

第一级偏移在每条3840转换短路径改变11次$q_1$，四点入选变化均0。因此三主路×两种子的四点全部旧／新Q22状态逐窗口等于名义状态，不只是终点接近；未入选最终整数码仍分别改变18／22／22条（各模型两种子合计），学习后理想Q3最大差21.875码。完整累计入选这些事件，全部六条路径在32窗口内已有27个窗口的提交后状态不同。这不能用“最终理想码抵消”推断实际学习输出或轨迹始终相同。

完整周期离线检查又给92个判决改变相位、1024个入选相位中0个改变；所选存储数到两组阈值的最小精确余量为`86341726136529/72057594037927936`，约0.001198232归一化。按[§13.6](../../theory/DUAL_PATH_EFFECTIVE_THRESHOLDS_AND_PHASES_V1.md)归纳可延伸状态恒等式到当前固定周期的未来窗口，但不能延伸到动态历史、换输入或其他偏移向量。它是算法保留统计的限制，原ADC的全转换数字流仍含变化，不能冒称物理观测全都不可区分。

第二级偏移还改变依赖$d_1$的后级判决；两个种子在四点入选中分别看到1／0次线性及平滑$q_2$改变，轨迹因此可分离。两级失配不能以一个“高段样本增加”概括，需后续同输入长输出评价。

# EXP-072：正常状态位置与后续更新的有限干预

> 2026-10-12冻结与运行；2026-10-13整理交付。D-136授权范围内的误差原因／能力边界研究，保留Gu合同，不进入新算法阶段。

本轮把旧同字参照差推进到有限未来路径：**在这一个正常八块区间，初始化位置与后续持续更新都影响误差，更新效应依赖起始状态。** 前缀平均状态保持不变时，两倍率的全部五种子均比从同状态继续Gu更新损失小；从原实际状态出发，继续更新却有3个配对比保持不变更好。因此不能把后期误差全归于持续更新，也不能据此宣布停更方案普遍优胜。

## 3. 哪种机制判断得到支持

本次同未来干预支持：从预定前缀平均导出位置开始，在这一八块期限内持续Gu提交能产生显著损失增量；该参照本身无需评价目标或未来状态形成。它比旧同字反事实多了逐窗反馈证据。

替代解释仍存在。原实际起始位置的保持损失较大时，未来更新可能起修正作用，3个配对确实如此；前缀位置也不是每种子都比原起点更好。初始化和继续效应存在交互，不能分成两个与顺序无关的“主因贡献百分比”。两bank都按自己的反馈重算，不等于已经识别某一级、某个门或量化的独立贡献。结论条件于这里的源／起点／前缀规则／期限，长期输入改变仍可能使保持状态变差。

用$p=0,1$表示原／前缀位置、$u=0,1$表示保持／继续，四损失$L_{pu}$满足

$$I=(L_{11}-L_{10})-(L_{01}-L_{00})=(L_{11}-L_{01})-(L_{10}-L_{00}).$$

这是初始化×未来更新的四格，不是NG-27的前bank×后bank同字四格。实际继续相对前缀保持的差，可按两种顺序表示：$(L_{01}-L_{00})+(L_{00}-L_{10})$，或$(L_{01}-L_{11})+(L_{11}-L_{10})$；顺序改变会移交$I$，所以各项不被命名为唯一因果贡献。原§13—14的两bank交互与同字目标交叉保持。

## 4. 能力关系：完整历史不自动给目标排序

[NG-38完整证明](../../theory/OBSERVATION_CORRECTION_LIMITS_V1.md)在**同一平滑模型**下构造相同数字历史与当前字、不同理想目标的两个允许输入世界；两个合法Gu导出状态分别给整数2048和2049，两世界的更优参照相反。当前单次确定性最坏超额MSE至少1/16，随机策略至少1/32，有可达到的上下界。

这推进了NG-31的固定能力与在线识别区别：旧抽象状态例没有给实际模拟源，这次给了精确输入／传输／完整历史。它同时比EXP-020的训练相同、留出不同问题更接近当前输出选择。然而此反例允许任意因果新输入，**不能拿来声称这条已知相干正弦的前缀参照不可识别**，也不能据其下限解释本表损失大小。需要单独声明输入／相位可知程度、模型不确定性及策略集合。

## 摘要

本实验建立了阶段二第一个不依赖逐样本平台构造的性能预测器。预测器从两级
flash、辅助判决路径、CDAC、静态增益、合成模拟 PWL 近似和 8-bit SAR 的边界方程
出发，递归生成完整输入区间划分，直接得到每个分段的逐级码路径、最终 12-bit
输出码和可纠正状态。均匀输入下的码宽、DNL、累计码密度偏差与缺失码由这些区间的测度
直接计算，不需要先生成斜坡样本。

理想链得到 4096 个等宽分段、零 DNL、零转换电平 INL、零缺码、零负向步和零不可
纠正输入宽度。理想、轻度静态非理想、组合 PWL 非理想和冗余边界失效四类
条件各使用 65536 个未参与建模的留出输入点；共 262144 次理论/平台比较中，
输出码和 `correctable` 状态均为零不一致。EXP-004 的边界反例被理论预测为
不可纠正输入宽度 `0.0064834025`，占完整输入域的 `0.324170%`；平台留出网格
检出 208 个失败点，对应宽度估计 `0.0063476563`。

## 1. 研究问题与范围

本轮回答的问题是：固定所有静态物理参数后，能否不运行完整逐样本 ADC 仿真，
直接由逐级结构预测最终静态传输和 DNL/INL？研究范围不含数字校准、随机噪声、
有限建立、采样时刻差和其他记忆效应。固定 dither 符号只作为单独确定性状态，
不在不同状态间隐式平均。

问题定义、方程、独立性约束和预设验收条件见
`docs/specifications/STAGE2_STATIC_PREDICTION_SPEC_V0_1.md`。

## 2. 独立预测方法

核心预测器位于 `src/adc_research/theory/static_transfer.py`，不导入
`adc_research.platform`。它只读取经过审查的声明式 YAML 参数，并在理论侧
独立完成以下计算：

1. 将辅助 flash 阈值反解到主路径输入坐标；
2. 在固定判决区间内代入 CDAC 电平和 dither，组合线性增益；
3. 在奇对称 PWL 的正负分段边界处继续切分和组合仿射式；
4. 递归传播至第二级和末级 SAR 阈值；
5. 执行独立的 `512/128/1` 重构、dither 数字副本扣除和端点裁剪；
6. 累加映射至每个输出码的输入区间宽度，得到 DNL 和转换边界 INL。

平台仅在预测完成后对留出输入点提供外部标签。留出网格采用固定黄金分割相位，
避免与码中心或常用二进制边界系统重合；这些样本没有用于移动理论边界、估计
参数或拟合误差项。

## 3. 验证条件

| 条件 | 启用机制 | 目的 |
|---|---|---|
| ideal | 全部静态非理想关闭，无 dither | 检查理想极限与 12-bit 恒等 |
| light_static_holdout | threshold、CDAC、线性 gain | 检查轻度静态参数组合 |
| combined_pwl_holdout | 再加入两级 PWL truth | 检查分段非线性递归组合 |
| redundancy_boundary_failure | `rho=0.964, o=-0.08, d=(+1,+1)` | 检查已知冗余失效反例 |

每个条件使用 65536 个留出点，同时比较最终输出码和可纠正状态。不可纠正输入
宽度另外用理论区间测度和平台均匀网格频数独立估计。

## 4. 结果

> 2026-09-16 理论审查勘误：下表原列名为“最大绝对 INL”。其中有负向步的条件
> 不存在按码序排列的单一物理转换电平；原数值是累计 DNL 得到的**码密度偏差**。
> 数值本身没有改变，只有物理解释收紧。理想条件单调，其值同时是转换电平 INL。

| 条件 | 理论分段 | 缺失码 | 负向步 | 最大绝对累计码密度偏差 (LSB) | 理论不可纠正宽度 | 平台失败点 | 码/状态不一致 |
|---|---:|---:|---:|---:|---:|---:|---:|
| ideal | 4096 | 0 | 0 | 0 | 0 | 0 | 0 / 0 |
| light_static_holdout | 4133 | 8 | 8 | 3.822475 | 0.0017000 | 56 | 0 / 0 |
| combined_pwl_holdout | 4153 | 9 | 2 | 10.861359 | 0.0017000 | 56 | 0 / 0 |
| redundancy_boundary_failure | 4120 | 8 | 0 | 1.659751 | 0.0064834 | 208 | 0 / 0 |

理想结果不是对平台斜坡统计的复述：4096 个码宽由理论反解的边界直接得到，
数值上每个宽度均为 `2/4096`，因此 DNL 和累计 INL 均为零。

轻度静态组合出现 8 个缺失码和 8 个局部负向步，说明阈值、CDAC 码相关误差
和两级增益误差即使幅度不大，也可在冗余边界附近改变相邻路径的数字等价关系。
加入当前合成 PWL truth 后，最大绝对累计码密度偏差增至约 `10.8614 LSB`，
但负向步减为 2；因此码密度偏差、缺失码和单调性是不同性质，不能互相替代。

冗余失效条件出现 8 个缺失码但没有负向步，说明该反例主要表现为前向跳码和
过载区，而不是码序倒置。理论宽度与平台网格估计相差 `0.0001357462` 归一化
单位，小于预设的 `0.0002`；差异符合有限验证网格对多个窄失效区间的计数误差。

## 5. 验收判断

正式运行满足全部预设条件：理想 DNL/转换电平 INL、缺码、负向步和不可纠正宽度均为
零；四个条件在全部留出点上的输出码和状态均一致；已知边界反例由理论和平台
同时检出；不可纠正宽度差小于显式网格容限。因此 EXP-015 首轮通过。

完整回归测试增加到 104 项并全部通过。其中项目结构测试继续强制理论模块不得
导入平台模块；新增测试还覆盖理想 4096 码、组合 PWL 留出网格、冗余失效分段
和隐藏非理想配置拒绝。

## 6. 结论边界

- Gate-D 参数是结构验证用的合成参数，不代表硅后失配分布或良率；
- “不可纠正输入宽度”是确定性输入域测度，不是失效概率；只有指定均匀输入
  分布时，其除以域宽后才可解释为输入占比；
- 当前算法要求局部静态斜率为正，尚未处理非单调模拟 PWL 段；
- 结果只覆盖无记忆静态链，不能预测频率升高导致的性能下降；
- 固定 dither 状态的预测不等于随机 dither 混合分布的长期统计。

## 推导与可检验预测

[已有跟踪理论§8](../../theory/EXCITATION_AND_CONSTRAINED_STABILITY_V1.md)新增窗口接续归纳证明：同Q22边界状态、全局标签和未来数字观测给逐窗口完全相同的输出／状态。相同Q1.10导出不足以承接隐藏Q22，等值附近一LSB的手算反例已核对。切换后首窗口仍用承接旧状态，不能把其输出改善称作已经在新输入上适应。

本次无记忆前馈平台下，承接与同新输入单位初值路径的未来完整数字观测相同。两者输出／更新可以不同，有限MSE差必须保留参考误差与输出差的交叉；两条状态接近不能代替净收益。幅度降低也不使CDAC折叠残差单调减小，理论给出0.2→0.1时残差幅值0.2→0.4的最小反例。一般八状态收缩、恢复时间和物理输入覆盖未证明。

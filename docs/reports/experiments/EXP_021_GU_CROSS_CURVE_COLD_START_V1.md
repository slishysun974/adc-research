# EXP-021：Gu 候选算法在平滑模拟曲线上的冷启动

> 2026-10-01。阶段一新增平滑模拟测试传输，阶段三首次按相同在线配置检查 Gu 候选算法的跨曲线冷启动。以下均为静态、浮点、合成行为实验；不代表真实芯片或 RTL。

## 主要结论

从全 1 系数开始、沿用 EXP-010 的数字分段和步长，Gu 候选算法在两条预先指定的**三次多项式模拟曲线**上都改善了留出随机输入的码误差及正弦频谱。它们不是数字 PWL 所假设的模拟分段直线。训练仅向更新函数送入五字段数字观测，没有送入曲线参数或 oracle。

但改善幅度随曲线而变。压缩曲线在第 2 轮验证误差达到 `0.82` 码，之后回升至第 64 轮的 `1.06` 码。验证集的事后系数替换显示，这次回升主要对**第一级第一段系数**敏感；第二级第三段虽然只有 `194` 次门控，替换它并未恢复误差。其余曲线在第 64 轮仍继续改善，因此本实验没有建立统一的稳态或收敛时间。

## 固定协议

候选架构为 `gu_behavioral_v1`。在线分段宽度 `128/32` 码只由候选架构位宽确定；四个归一化步长固定为 `0.001, 0.003, 0.006, 0.012`，系数限制为 `[0,2]`。每条曲线分别从单位系数冷启动，训练 64 轮；每轮遍历 4096 个输入码中心和四种 dither 符号组合，即每级共 `1,048,576` 次样本更新。轮内随机顺序在曲线间相同。没有从历史 PWL 曲线迁移系数，也没有根据三次曲线重新选参数。

历史 PWL 曲线作为程序和口径对照。两条新曲线在第二级名义输出坐标 $z=4w$ 下均取 $g(z)=az+bz^3$，第一、二级参数分别如下：

| 曲线 | 第一级 $(a,b)$ | 第二级 $(a,b)$ | 用途 |
|---|---|---|---|
| 历史 PWL | 见 `gu_gate_d_static_v0_1.yaml` | 同左 | 历史对照 |
| 三次压缩 | $(1.00,-0.08)$ | $(1.00,-0.06)$ | 预先指定的新模拟形状 |
| 三次混合 | $(1.02,-0.04)$ | $(0.98,+0.02)$ | 预先指定的新模拟形状 |

两条三次曲线在 $|z|\le1$ 连续、可导、奇对称且严格递增；平台在模型域内检查导数下界。它们只是合成测试曲线，未经 Cadence 或测量锚定。第一级辅路仍按当前候选架构由主路输出的仿射副本表示。

训练检查点用独立的 2048 个随机输入观察误差轨迹，不据此更改步长或预先固定的 64 轮终点。最终评分另用独立种子的 4096 个随机输入，范围为 `[-0.95,0.95]`，以及幅度 `0.901`、8192 点、频点 `251` 的相干正弦。正弦 dither 用固定种子随机选择四种符号组合，所有曲线共用同一序列。每条曲线都与其自身的**单位系数**结果比较；正弦指标按同一个完整 FFT 协议计算。

## 留出结果

| 模拟曲线 | 随机输入 MAE：单位→训练后（码） | 改善倍数 | 正弦 SNDR：单位→训练后 | 正弦 SFDR：单位→训练后 |
|---|---:|---:|---:|---:|
| 历史 PWL | 5.3923 → 0.4229 | 12.75 | 46.33 → 69.01 dB | 53.75 → 87.03 dBc |
| 三次压缩 | 2.0298 → 1.0432 | 1.95 | 51.02 → 60.09 dB | 59.92 → 71.37 dBc |
| 三次混合 | 1.7834 → 0.5233 | 3.41 | 56.09 → 67.12 dB | 62.86 → 77.10 dBc |

三种曲线的训练、验证和最终留出记录均未触发平台物理过载；最终留出也无数字输出饱和。实验“通过”表示数据流和物理有效性检查通过，**不**表示预设的性能门或芯片保证。不同曲线原有失真程度不同，因此上表不能单靠改善倍数判断哪种曲线更适合该算法。

## 收敛和激励诊断

| 曲线 | 验证 MAE：第 0 / 2 / 32 / 64 轮（码） | 一级第三/四段门控次数 | 二级第三/四段门控次数 |
|---|---:|---:|---:|
| 历史 PWL | 5.49 / 5.12 / 0.69 / 0.41 | 0 / 0 | 10496 / 0 |
| 三次压缩 | 1.97 / 0.82 / 0.90 / 1.06 | 0 / 0 | 194 / 0 |
| 三次混合 | 1.78 / 1.18 / 0.67 / 0.54 | 15181 / 0 | 334 / 0 |

每级第一段均有 `1,048,576` 次样本门控；相比之下，高段更新很少或完全没有。压缩曲线的第 64 轮仍好于单位系数，但从第 2 轮起的误差回升说明“训练更久必然更好”在此固定配置下不成立。

为区分回升与高段门控，在**同一验证集**上作了事后单系数替换；以下不是新算法或独立留出结果：

| 压缩曲线系数方案 | 验证 MAE（码） |
|---|---:|
| 第 32 轮全部系数 | 0.9020 |
| 第 64 轮全部系数 | 1.0594 |
| 第 64 轮，仅把第二级第三段系数换回第 32 轮 | 1.0623 |
| 第 64 轮，仅把第一级第一段系数换回第 32 轮 | 0.8868 |
| 第 64 轮，仅把第一级第二段系数换回第 32 轮 | 1.0669 |

第一级第一段系数从第 32 轮约 `1.008912` 增至第 64 轮约 `1.011689`。在固定其他系数的验证集消融里，换回旧值几乎消除了第 32 到 64 轮的误差差距；第二级第三段替换则没有。这定位了本例**码误差对哪个系数敏感**。高段缺少激励仍是另一项独立问题。

进一步固定第 64 轮其余系数，重新遍历**训练码中心**，计算第一级第一段更新所用的平均 `dither × 校正后局部输出`。把 $k_1$ 换成第 32 轮值时，该平均量约为 `-2.228`，按更新式会推动 $k_1$ 增大；第 64 轮原值时约为 `+3.458`，会推动它减小。两者之间的零点约为 `k_1=1.010001`，该点的验证 MAE 为 `0.9489` 码；较小的第 32 轮 $k_1=1.008912$ 配合第 64 轮其余系数时，验证 MAE 反而只有 `0.8868` 码。因此在这组**固定其余系数、训练分布与验证分布已指定**的条件下，训练去相关量为零并不等于验证码误差最小。它可能涉及训练／验证分布、量化或数字 PWL 表示，尚不能从本例分清。这里求的是冻结其他系数后的单变量相关零点，不是全算法的稳态固定点。

完整事后结果在 `artifacts/runs/EXP_021/frozen_v1_20261001/validation_diagnostic_v6.json`；诊断脚本只读取训练和验证条件，未重算最终留出。该曲线是在发现误差回升后选作诊断对象，结论须在新曲线和随机种子上复验。

## 证据范围与复现

本实验把“未知模拟曲线”落到两条预设的平滑测试曲线，并用相同在线参数分别冷启动；它没有证明任意未知曲线的鲁棒性。两条曲线与历史 PWL 对照的失真幅度、系数最优值并未配平，因此不能把性能差完全归因于“平滑 versus PWL”。64 轮反复使用同一组码中心，不等于芯片连续运行中的稳态统计。当前模型还没有独立辅路非线性、热噪声、时钟抖动、PVT 漂移、真实 PRNG/抽取时序、定点或 RTL 成本。

完整结果在 `artifacts/runs/EXP_021/frozen_v1_20261001/summary.json`，所列关键源码与配置的本次 SHA-256 摘要为 `93dd1fc3393befefe86afdb8b08d044d9579bc50d70b1e23b4b71ee45fbe7749`。运行说明见[EXP-021 目录](../../../experiments/exp_021_gu_cross_curve_cold_start/README.md)。

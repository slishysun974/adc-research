## 1. 结论

候选 A 的两个 radix-4 前级、4 路 8-bit TI-SAR 后端和
`512/128/1` 数字重构通过 Gate C。对 4096 个 12-bit 码中心，平台输出
依次严格覆盖 `0...4095`，无错码、无缺码，且传输单调。平台逐样本结果
与独立表达式 `floor(2048*(x+1))` 相等。

默认 dither 解释采用放大前 `+/-1/32`，数字副本为 64/16。对全部
4096 个码中心、两级 dither 的四种符号组合，以及第二级 flash 辅助输入
取 `rho=0.97` 或 `rho=1.03`，共检查 32768 个组合，输出码错误和不可
纠正事件均为 0。替代的峰峰值解释采用放大前 `+/-1/64` 和 32/8 数字
副本；四种符号组合共检查 16384 次，错误为 0。后一个结果只证明配置
接口和整数平移关系闭合，不提高该解释的来源置信度。

## 4. 新发现：辅助坐标越界不等于信息丢失

初始 Gate C 平台语义测试曾把一个通用压力场景中 `rho=1.03` 时满量程
附近的辅助判决输入小于 `-1` 标记为 `correctable=False`。审计 trace 后
确认：此时主输入仍在 `[-1,1)`，辅助 flash 仍选择端部状态，两级
residue 与 SAR 均未过载，最终码也精确。因此需要区分：

1. 主信号输入或 residue/SAR 越界，这可能丢失信息；
2. 增益缩放后的辅助比较器坐标越过名义分析域，但端部判决和主 residue
   仍有效。

平台现分别记录 `main_input_overload_*` 与辅助 quantizer 的
`overload_*`。最终 `correctable` 由主路径、级间 residue、SAR 和输出
裁剪决定，不再把辅助坐标的单独越界误报为不可纠正。该修订有专门回归
测试覆盖。

复核 OJSSCS Fig. 13 后，正式 Gu EXP-003 只把约 3% 的第一 inter-stage
主/辅增益差施加到第二级 flash 判决输入；不把它施加到第一级输入 flash。
上述坐标越界用例保留为通用平台语义压力测试，不作为 Gu 物理路径声明。

## 5. 适用范围与限制

本次通过的是候选 A 的静态行为基线，不是 Gu 芯片的 bit-true 复刻。
flash/CDAC 物理开关表、PRNG 物理极性和 dither `1/16` 的逐字峰值定义
仍未由公开资料闭合。TI-SAR 当前只建模通道归属；通道失配、动态时序、
噪声、有限建立和非线性均未启用。

Gate C 证明名义结构及两种明确 dither 假设在数字代数上自洽。它不证明
两种 dither 解释同样符合硅实现，也不证明未校准增益/CDAC 误差不会改变
最终传输。

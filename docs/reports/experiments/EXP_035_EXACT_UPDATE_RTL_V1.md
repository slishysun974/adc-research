# EXP-035：Gu 候选 Q22 更新的等价整数 RTL

> 2026-10-04。运行目录：`artifacts/runs/EXP_035/exact_v1`。本实验沿用 EXP-032 的数字候选，按 EXP-034 的综合边界比较，不增加模拟电路假设。

保持同一更新规则后，在线链的通用逻辑单元由 `200629` 降为 `21121`，减少 `89.4726%`，八个 Q22 累加器仍占 `184` 位。RTL 的增量、门控、最终码和状态检查通过。这说明此前的宽整数直接实现存在明显可消除的逻辑开销，不能把它全部算作 Gu 算法不可避免的成本。没有目标工艺和约束，本结果不表示芯片面积、频率或功耗改善。

## 实现范围与保持的行为

新增[专用更新模块](../../../rtl/gu_baseline/fixed_gated_lms_exact_candidate_a.sv)及[两级连接](../../../rtl/gu_baseline/two_stage_adaptive_exact_candidate_a.sv)。原有五个 RTL 文件、Python 数值参考及历史实验不修改；综合前检查其 SHA-256 与 EXP-034 一致。

专用接口只接收 dither 极性。第一级数字副本固定为 `±512`，第二级为 `±128`；有效学习输出分别限定在 `[-8700,8698]` 和 `[-2175,2159]`。这些范围由既有 Q1.10 系数、数字 PWL 输入域与端部规则导出，见[整数关系及范围证明](../../stages/03_gu_baseline/CANDIDATE_A_EXACT_UPDATE_ARITHMETIC_V1.md)。不将此模块替代任意 16 位 dither 输入的通用 LMS 接口。

以下行为全部保持：Q22 状态和 `[0,8384512]` 饱和范围；Q1.10 系数输出的最近偶数舍入；步长分子 `1/3/6/12`；高段 `≥` 门控；负满量程末段延伸；非法数字观测停更；本次旧系数评分、上升沿两级同时更新、下一转换生效。最终码校正链直接使用原模块。

门控有效时，以 `d=±1` 表示极性，两级请求增量分别计算

\[
T_1=-16djY_1,\qquad T_2=-64djY_2,\qquad
\Delta=\operatorname{sgn}(T)\left\lfloor\frac{|T|+62}{125}\right\rfloor.
\]

22 位有符号分子、21 位无符号加偏置幅值、14 位商、15 位有符号增量及 25 位饱和前和，分别覆盖已证明的范围。源码在乘法、取负、移位及加法之前扩展位宽。21 位除法实现精确整数商，没有引入倒数近似或截断原更新精度。

## 等价关系怎样延伸到连续记录

若两条链在复位后八个状态相同，则导出的系数相同；相同数字观测进入同一个校正器，得到相同有效标记、最终码及学习输出。有效记录的学习输出满足上述范围，两种实现的门控和请求增量相同；25 位和不溢出，饱和后状态也相同。无效记录及空闲周期均保持状态，复位均设为单位状态。因此可按转换次数归纳：在此数字合同与复位规则下，两条候选的状态和输出相同。

这段归纳使用整数关系、已证明的位宽与保持的门控／校正规则。它不声称 Yosys SAT 已证明全部综合网表等价，也不涉及真实四路抽取或芯片总线。下面的有限测试另检查具体 RTL 的表达式位宽和综合结果。

## 同流程结构比较

两条在线顶层均有 21 位输入、13 位输出、八个内部 23 位状态。输入包括时钟、同步复位、有效标记和候选五字段。诊断门控及学习输出不在综合边界内；四路抽取、广播和 flash 适配器也不在其中。工具为同一 YoWASP Yosys 0.69、同一依赖包、关闭 ABC 与 ALUMACC 的分步映射函数；综合入口自动检查这些条件。

| 指标 | EXP-034 原在线链 | EXP-035 专用在线链 |
|---|---:|---:|
| 通用单元总数 | 200629 | 21121 |
| 组合单元 | 200445 | 20937 |
| 状态位数 | 184 | 184 |
| AND / OR / XOR | 77024 / 45240 / 28269 | 8394 / 3647 / 3835 |
| NOT / MUX | 23923 / 25989 | 1929 / 3132 |
| 最长组合拓扑路径单元数 | 1178 | 382 |
| 粗综合网表的更新除法 | 八个 64 位 `$div` | 八个 21 位 `$div` |
| 粗综合网表的更新取余 | 八个 64 位 `$mod` | 无 |

统计中原有校正器的乘法仍保留，未把系数绑为常数。单元数量不等于标准单元面积；拓扑路径上的单元个数不等于延迟。`89.4726%` 仅是本流程、本边界下的总单元数减少比例。此次同时采用固定极性接口、精确约分和有依据的中间位宽，不能再把这个比例分摊给其中某一项而不做额外比较。

## 主线判断与下一门

现有证据足以建立一个保持数字行为的较小硬件候选，也纠正了“原宽算术成本可能就是 Gu 固有瓶颈”的判断。算法没有变，不能宣称收敛或 SNDR/SFDR 改善，更没有进入新算法比较。

内部宽算术问题至此已有可复现实现和同流程比较，不继续任意缩位、换步长或延长训练。下一优先级仍是取得真实抽取器两侧同步字、四路聚合／广播、系数生效时刻，以及有覆盖证据的主辅模拟范围。若取得目标工艺库／器件和约束，可把原链与专用链同口径映射并检查时序和功耗；当前不给这三项数值。重现命令见[实验入口](../../../experiments/exp_035_exact_update_rtl/README.md)。所有修改与运行产物保存在 ADC 项目。

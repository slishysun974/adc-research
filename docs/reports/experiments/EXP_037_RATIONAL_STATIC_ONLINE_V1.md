# EXP-037：精确静态扫描到定点在线码范围

> 2026-10-05。摘要：`artifacts/runs/EXP_037/rational_v1/summary.json`；逐转换判决、最终码与八状态：同目录 `records.json`。来源全部为人工合成，未取得新的 Cadence／芯片资料。

已把 EXP-036 的精确扫描范围接到**精确电压判决及 Q22 在线整数状态传播**。128 次转换的两条人工电路轨迹，共 256 组观测、最终码与更新后八个累加器全部被包含。771 组末级边界及端点定向检查通过；198 项项目测试通过，其中 8 项为此次新增。

最终码区间仍宽 `23–101` 码。这项结果补足从扫描到最终码这段的数值舍入检查；没有取得更精细的物理范围，也没有给数值认证的频谱或芯片性能。

## 目的与实现

EXP-036 的扫描锥形范围采用精确有理数，浮点适配器能向外转换函数输出端点，但前后级电压加减与量化仍使用浮点。此次新增[有理数静态入口](../../../src/adc_research/theory/rational_static_reachability.py)，要求输入、阈值、CDAC、dither 与路径输出保持 `Fraction`；复用原逐级分支包含算法。在已有架构对象中保留显式 `Fraction` CDAC 点值，原浮点调用方式仍按其原规则处理。

[扫描入口](../../../src/adc_research/evaluation/physical_scan_package.py)新增 `rational_path_envelope`：选择条件后，用有理数完成伏特／归一化换算和范围并集。新增 `propagate_rational_static_fixed_online_codes` 将生成的整数数字观测接入已有状态区间算法。所有模拟资料仅用于离线生成观测集合，运行中的 LMS 仍只接收五字段数字观测。

条件性包含证明和回调审查边界见[理论记录](../../theory/RATIONAL_STATIC_TO_FIXED_CODE_BOUNDS_V1.md)。端点类型检查不认证自定义回调内部算术；扫描适配及共享分支计算已单独检查。没有进行全输入形式验证。

## 冻结的人工条件

三条扫描复用 EXP-036 的两组解析三次函数、21 个建立点／20 个独立留出及输入／输出误差；来源明确为 `synthetic`。不修改原 EXP-036 运行资料，新副本写入本实验目录。两条件选择后在三路分别取并集；这会丢失条件、主辅和跨转换相关性，是保守范围而非两条轨迹的精确集合。

架构从原 YAML 的数值字符串直接读为有理数，使用 `gu_behavioral_v1` 的阈值、CDAC、8 位末级及等值判高规则。输入序列在范围计算前固定为

\[
x_n=-\frac3{25}+\frac6{25}\frac{n+37/100}{128},\quad n=0,\ldots,127.
\]

第一级 dither 标记在奇数次为 `+1`，其余为 `-1`；第二级在 `n mod 3 != 0` 时为 `+1`，其余为 `-1`。两级放大前模拟 dither 均为标记的 `1/32` 归一化单位，数字副本沿 EXP-032 为 Q3 的 `±512/±128`。这只是已有候选合同，不识别芯片真实 dither 开关。

在线采用 EXP-032 的单位系数初值、Q22、步长、`≥` 门控、最近偶数舍入及饱和顺序。本次旧系数产生码，上升沿所代表的更新后状态从下次生效。逐步范围传播和整条记录组合入口给出完全相同的码端点及最终状态。

独立点参考直接计算解析电压，并显式枚举比较器／SAR 阈值，不读取网格范围。另使用已有逐样本放大器、stage 与 SAR 平台原语，检查两个实现的数字观测一致。点参考与平台各沿固定人工条件续跑校准，逐次检查码和全部八状态是否落入传播范围。

定向边界测试取 `ε=10^-80`。人工恒等链在 `x=1/8-ε` 时给两级符号 `-1/-1`、末级中心码 `15`；若先把这个输入舍入为双精度 `0.125`，判决成为 `+1/+1`、中心码 `16`。它说明必须明确原始输入表示及误差区间，不表示实际电压分辨率或错误概率。

新增测试还检查非二进制有限小数电平的精确加减、384 个带 CDAC／dither／flash 区间和非均匀 SAR 阈值的独立点组合，以及 2 条短在线分支的最终码／状态包含。浮点输入、架构端点或回调输出会被精确入口拒绝；留出未通过的资料和域外查询也拒绝。

## 结论与边界

在可信覆盖的静态三路范围、明确阈值／码制、对齐 dither 和既定整数更新合同下，电压到数字判决再到在线码／状态的包含关系可以保持精确算术。程序测试支持这一实现，不认证这些物理前提。

`23–101` 码的宽度来自当前人为范围和保守合并，未分离各项贡献。本次增加 dither 与在线更新，不能与 EXP-036 的无 dither 冻结系数宽度直接作配对比较。精确算术不能替代更密的有依据扫描、较小的真实误差或相关性证据。

数值范围止于最终整数码和累加器。现有 FFT／三角函数及分贝公式仍没有完整向外数值认证；此次不计算 SNDR/SFDR。真实主辅资料、动态状态、四路抽取与系数广播及目标工艺仍开放。重现命令见[实验入口](../../../experiments/exp_037_rational_static_online/README.md)。

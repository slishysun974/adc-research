# EXP-012：定点 PWL 校正数据通路

> 状态：浮点对照下的定点行为级通过；芯片舍入和总位宽仍未公开  
> 架构配置：`gu_behavioral_v1`  
> PWL truth：`gu_gate_d_static_v0_1`

> 术语说明：本报告的 `oracle` 仅指已知预设模拟传输下的浮点逆校正参考，并非可直接由芯片获得的系数。数字 PWL 与模拟传输分开讨论。见[研究文档术语约定](../../TECHNICAL_WRITING_CONVENTIONS_V1.md)。

## 1. 论文给出的定点信息

Gu et al. 在 OJSSCS 扩展论文 Sec. II-A 中说明：示例 PWL 校正器的原始码为
9-bit，四段 PWL 的 `b0=128`，`DLSB` 为 7-bit；校正系数 `k_i` 使用 11-bit
定点数，取值范围写为 `[0,2]`，含 10 个小数位，从而在与 `b0` 和 `DLSB`
相乘后保证 3 个小数位的数字精度。Sec. III-C 进一步说明，四个数字处理单元
在全部计算中保持 3 个小数位。[^1]

论文没有公开以下实现细节：

- 系数写入 11-bit 字时采用截断还是舍入；
- 乘法结果缩减到 3 个小数位时的舍入规则；
- 式 (3) 中 `b_n=b0*sum(k_i)` 是先求和再舍入，还是各项舍入后求和；
- 中间总位宽、保护位和饱和位置；
- 内部 3 个小数位最终转换为 12-bit 整数码的规则。

按照常规无符号二进制定点解释，11-bit、10 个小数位的最大有限值为
`2047/1024=1.9990234375`，不能精确表示 2。论文给出的 `[0,2]` 是数值范围说明，
还是包含端点 2 的特殊编码，目前没有证据。本实验使用常规定点编码，并显式
提供溢出报错或饱和两种策略；本次 oracle 系数均小于 1.1，没有触发该端点。

## 2. 定点数据通路

数据通路统一采用 3 个小数位。整数原始码、粗量化符号权重和 dither 数字副本
进入数据通路时乘以 8；PWL 局部码与 Q1.10 系数相乘后，将结果恢复到 3 个
小数位。两级顺序保持为：

```text
stage2 PWL -> subtract Dd2 -> form stage1 raw code
stage1 PWL -> subtract Dd1 -> form final centered code
```

本实验使用无溢出的 Python 整数保存乘法和累加结果，同时记录每类中间结果实际
需要的位数。这样可以先测量舍入误差，再单独决定硬件总位宽，避免由过早饱和
混入额外误差。

## 3. 舍入规则比较

4096 个输入码中心和四种 dither 符号组合共 16384 个检查点。两种偏移量舍入
位置在当前系数组合下结果相同，因此下表按系数和乘法舍入规则合并展示：

| 系数量化 | 乘法缩位 | 内部 Q3 MAE (code) | 最大误差 (code) | 相对浮点的平均绝对差 (code) |
|---|---|---:|---:|---:|
| 舍入到最近偶数 | 舍入到最近偶数 | 0.22620 | 0.750 | 0.05608 |
| 舍入到最近偶数 | 向下取整 | 0.25574 | 0.875 | 0.11681 |
| 向下取整 | 舍入到最近偶数 | 0.26038 | 0.750 | 0.11328 |
| 向下取整 | 向下取整 | 0.30194 | 1.000 | 0.19694 |

浮点 oracle 的内部 MAE/最大误差为 `0.23018/0.63520` code。第一种定点组合
的内部 MAE 略低于浮点值，但最大误差更高。这是有限码中心和 Q3 网格共同产生
的结果，不能解释为定点系数比连续 oracle 更准确。相对于同一点的浮点输出，
第一种组合的平均绝对差为 `0.05608` code，最大绝对差为 `0.21880` code。

第一种组合得到的系数码为：

| 级 | 11-bit 系数码 | 量化后系数 | 最大系数量化误差 |
|---|---|---|---:|
| stage1 | 1106, 963, 1055, 973 | 1.080078, 0.940430, 1.030273, 0.950195 | 0.000430 |
| stage2 | 942, 1085, 1004, 1065 | 0.919922, 1.059570, 0.980469, 1.040039 | 0.000469 |

所有八种组合均无系数饱和、无负向码阶跃、无物理过载。当前 oracle 系数下，
“系数求和后统一舍入”和“每个系数项舍入后求和”数值完全相同；这只是当前
`b0`、系数码和舍入规则的结果，不能推广为两种实现恒等。

## 4. 最终整数码

论文没有说明内部 Q3 输出如何转换为最终整数码。本实验分别比较舍入到最近偶数
和向下取整：

| 数据通路 | 最终整数化 | MAE (code) | 平均误差 (code) | 最大误差 (code) |
|---|---|---:|---:|---:|
| 浮点 oracle | 舍入到最近偶数 | 0.03613 | -0.03613 | 1 |
| 定点 PWL，乘法舍入到最近偶数 | 舍入到最近偶数 | 0.08350 | -0.01221 | 1 |
| 浮点 oracle | 向下取整 | 0.50037 | -0.50037 | 1 |
| 定点 PWL，乘法舍入到最近偶数 | 向下取整 | 0.41449 | -0.41449 | 1 |

在同样采用舍入到最近偶数时，定点 PWL 相比浮点 oracle 增加 `0.04736` code
的整数码 MAE。向下取整产生明显负偏差，因此在获得芯片规则前，不应把两种最终
整数化方式混用。后续 DNL/INL 和频谱协议必须把最终整数化规则作为配置字段。

## 5. 中间位宽和单调性

在 16384 个完整链检查点上观察到的最大位宽需求为：

| 中间结果 | stage1 | stage2 |
|---|---:|---:|
| 局部码与系数的无符号全精度乘积 | 21 bit | 19 bit |
| PWL 偏移量的无符号全精度乘积 | 22 bit | 19 bit |
| 完整链有符号 Q3 数据 | 16 bit | 全链共同统计为 16 bit |

这些数值是当前输入范围和系数范围下的观测下限，不是芯片位宽。若后续允许系数
接近 2、加入电容权重误差或改变内部码缩放，应重新计算最坏情况位宽。

第一种定点组合在完整链上出现 592 个相邻输入码中心输出相等的情况，但没有负向
阶跃。最终采用舍入到最近偶数时，相邻输出相等的次数为 1136。单级 PWL 的量化
步长为 0、1 或 2 个 Q3 最低有效位，三个分段边界处的步长均为 1 个 Q3 最低
有效位。输出码占用和 DNL/INL 需要在下一阶段按明确的码密度或传输边界协议
计算，不能只由相邻码中心统计替代。

## 6. 结论

EXP-012 在行为级范围内完成了以下工作：

1. 实现 11-bit、10 个小数位系数和 3 个小数位数据通路；
2. 保留论文未公开的系数、乘法、偏移量和最终整数化舍入选项；
3. 验证两级局部 dither 扣除顺序在整数运算中保持不变；
4. 给出当前配置所需的中间位宽和舍入误差范围；
5. 选择“系数和乘法均舍入到最近偶数、偏移量在系数求和后统一舍入”作为误差
   较低的行为级默认配置，但不将其认定为芯片实现。

下一项工作是定点化 LMS 系数更新。需要特别区分校正器使用的 Q1.10 系数与系数
提取单元内部累加器的分辨率；如果每个微小更新都立即舍入到 Q1.10，可能出现
更新量小于一个系数最低有效位而无法累积的问题。

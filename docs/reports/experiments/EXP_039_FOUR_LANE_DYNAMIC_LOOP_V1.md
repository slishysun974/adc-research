# EXP-039：四路窗口更新与主辅动态的闭环机制

> 2026-10-09。摘要：`artifacts/runs/EXP_039/window_v1/summary.json`；交叉诊断：同目录 `cross_effects.json`。无 Cadence，来源全部为声明的人工电路和数字合同。

已把四路共享系数的窗口候选与两相主辅动态接成在线闭环。关键发现是：**辅助判决即使被冗余吸收、没有改变当前最终码，也能改变第二级局部学习输出和高段门控；点抽取再决定哪些激励进入后续系数。**这给“主辅历史如何影响后台校准”建立了具体传播路径。

名义候选的两条冗余分支都输出 2047，但第二级学习输出为 `63/−65`，第三段门控分别关闭／开启。完整聚合与点抽取又在同一动态记录上表现出不同的历史敏感性。全部 225 项项目测试通过，其中新增 14 项覆盖窗口时序、选样、整数算术和两相状态。

## 冻结的研究合同

每路 P=30，共 M=120 条连续转换编号，按 `n mod 4` 分路。两级八个共享 Q22 累加器在整个窗口内固定，所有最终码、局部学习输出及 `≥` 门控都使用窗口开始的旧系数。窗口结束时同时写入两级状态，新系数从下一个窗口生效；广播延迟设为零。这是明示候选，不称芯片抽取实现。

三种方法共享基础步长、Q1.10／Q3／Q22 及最终最近偶数舍入／12 位裁剪：

| 方法 | 相关量与状态生效 |
|---|---|
| sequential | 沿用既有逐转换更新，每条记录舍入／饱和，新状态从下条生效 |
| all_products | 120 条门控乘积相加，使用基础步长，末端一次舍入／饱和 |
| point_products | 每路固定取相位 0 的一条，共四条；乘积和乘 30，末端一次舍入／饱和 |

因此完整／点抽取的每窗口时间尺度相同。高段未激活样本贡献零，不除以高段激活次数。学习抽取只改变更新统计量；频谱仍评分全部转换输出。

模拟平台按完整转换顺序维护同一组前级主辅状态，不给四路数字单元分别建立模拟前级。每条路径先跟踪再放大：

\[
 r_n^-=b+\rho_r(r_{n-1}^+-b),\qquad
 r_n^+=G(u_n)+\rho_a(r_n^--G(u_n)).
\]

三路放大剩余因子固定为 `(0.001,0.03,0.001)`，跟踪平衡值为零，跟踪因子分别选 `0/0.1/1`，对应复位、两相中间条件和直接保持。前级主路的静态真值为 `0.98z−0.06z³`，第二级主路为 `0.97z−0.05z³`，独立辅路为 `z+0.02z³`，`z=4u`。这些是预先固定的人工平滑曲线及状态假设，不是论文芯片识别参数。

输入训练 15360 次（128 个窗口），用固定种子的均匀输入 `[-0.82,0.82]`；随后连续接入幅度 0.82、3840 点、相干频点 67 的正弦，并继续在线更新 32 个窗口。模拟历史与两级 dither 连续，不在输入分布改变处复位。频轴按候选 3 GS/s 标注，不对应论文选路测量输出。

激励包括独立随机 ±1，以及两张各含 127 个 +1、128 个 −1、精确周期为 255 的固定打乱符号表。后者不是宣称使用芯片 PRNG。输入种子 `20261009`，独立 dither 种子 `20261010`，周期表种子 `20261040/20261041`。两种激励的完整序列和有限符号均值也不同，不能把它们之间的所有性能差值仅归因于周期。

## 输出与学习量可以分离

独立原行为平台和数字更新器核对下述名义例子：`x=−1/2048`、两级 dither 均为 +1，第一级主输出为 `63/512`；辅助偏移分别为 0 和 `1/256`。

| 结果 | 辅助偏移 0 | 辅助偏移 1/256 |
|---|---:|---:|
| 第二级符号 | 0 | 1 |
| 末级中心码 | 79 | −49 |
| 最终整数码 | 2047 | 2047 |
| 第二级局部学习输出 | 63 | −65 |
| 第三段门控（门限 64） | 关 | 开 |
| 第三段请求 Q22 增量 | 0 | +1597 |

粗码增加 1 与末级中心码减少 128 在最终重构中抵消，但第二级局部学习量不包含粗码。这个区别解释了为何主辅判决路径能影响系数，即使当前码正确。它不要求模拟曲线为 PWL，也不表示上述偏移已在芯片测到。

另一个人工合法数字记录验证选样机制：120 条第二级第一段完整乘积和为 0，点抽取四条的乘积和为 32768；乘 30 后请求 Q22 增量为 −3932。两种方法对本窗口的码完全相同，新状态仅在下一窗口生效。

## 配对在线结果

下表为输入改变后的 3840 点**持续在线更新**记录的近似 SNDR／SFDR。不是冻结终点评分、稳态或数值认证范围。每一行三种方法使用相同原始数字记录。

| 激励／跟踪条件 | 逐转换 SNDR / SFDR | 完整聚合 SNDR / SFDR | 点抽取 SNDR / SFDR |
|---|---:|---:|---:|
| 随机／复位 | 48.549 / 56.558 | 48.526 / 56.527 | 50.232 / 59.208 |
| 随机／两相 0.1 | 48.561 / 56.547 | 48.551 / 56.531 | 50.224 / 59.243 |
| 随机／直接保持 | 48.540 / 56.368 | 48.511 / 56.333 | 49.085 / 58.712 |
| 周期 255／复位 | 47.590 / 55.166 | 47.539 / 55.112 | 47.721 / 56.439 |
| 周期 255／两相 0.1 | 47.578 / 55.149 | 47.527 / 55.105 | 47.510 / 56.125 |
| 周期 255／直接保持 | 47.710 / 55.179 | 47.653 / 55.114 | 46.636 / 55.129 |

完整聚合的 SNDR 与逐转换差值在本组六种条件中约为 `0.009–0.052 dB`，不表示两者一般等价。点抽取在随机输入的本种子下更高，周期复位条件下也略高；不能声称完整聚合普遍优于点抽取。

但点抽取对两相历史更敏感：随机激励下，从复位换到直接保持，点抽取 SNDR 下降约 1.147 dB，完整聚合只下降约 0.015 dB；周期激励下，点抽取下降约 1.085 dB，完整聚合反而提高约 0.115 dB。这些方向仅属于当前曲线、输入和有限窗口。

所有六组共 115200 次模拟转换均无物理过载，18 条训练／在线路径均无累加器请求被饱和裁掉。因此本次差异不由统计范围中的过载或系数裁剪解释。有限训练结束不表示已经收敛。

## 相位和稀少门控的具体证据

周期 255 时，点抽取的每路只访问 17 个周期相位，四路并集为 68 个。15360 次训练的全记录与所选 512 条记录的 dither 均值为：

| 数字标记 | 全记录均值 | 点抽取均值 |
|---|---:|---:|
| 第一级 | −13/3840 | −13/128 |
| 第二级 | −31/7680 | −15/64 |

选样没有保持这批记录的符号均值；门控相关量还取决于学习输出，不能只凭均值独自预测性能。

在 `periodic255_direct_hold` 的第一个窗口，第三段只有转换 **70、104** 激活，门控乘积和为 −133120，完整聚合请求 +3195。点抽取选择 0--3，第三段乘积和与请求均为 0。复位模型的同一窗口没有第三段激励。这里窗口开始系数均为单位值，先出现的差别来自物理历史／数字判决和选样，随后才会改变系数。

## 固定记录／固定系数的交叉诊断

另做冻结评分：分别取复位和直接保持训练后的系数，将它们交叉用于两套正弦数字记录。改变记录时固定系数，改变系数时固定记录。此诊断与上表的持续在线评分分开。

以周期 255、点抽取为例，交叉 SNDR 为：

| 正弦数字记录 | 复位条件训练系数 | 直接保持条件训练系数 |
|---|---:|---:|
| 复位记录 | 45.554270 | 44.712712 |
| 直接保持记录 | 45.561033 | 44.721359 |

固定复位系数，仅改变动态生成的数字记录，SNDR 变化约 **+0.006763 dB**；固定复位数字记录，仅换训练所得系数，变化约 **−0.841559 dB**，1558 个最终整数码改变。两因素交互约 +0.001884 dB。这支持“该冻结诊断的主要差异经学习状态传播”，不把 −0.841559 dB 当成完整解释上表在线差值。

完整聚合的同项固定记录换系数效应约 +0.164782 dB，243 个码改变。随机激励的点抽取也呈训练状态效应：固定记录换系数约 −0.572992 dB，固定复位系数换记录约 −0.119295 dB。两种激励下均需保留系数轨迹这一传播路径，但不能外推到全部未知电路。

## 验证、实现与研究判断

新增数字模块只读取 `DigitalCalibrationSample`、转换号与路号；独立两相平台保留模拟真值。测试包括：所有窗口评分均用旧状态、下一窗口生效、逐路求和与重排不变性、门限等值、一次／逐次舍入区别、边界饱和、缺样／错位拒绝、两相状态递推、直接保持退化及独立辅路非线性。原逐转换实现和历史产物保持原样。

项目回归 **225 项通过**。输入／输出／方法产物和源码摘要均保存，交叉审计只读原始记录并先检查摘要；普通浮点电压和频谱误差没有在本轮认证。没有新 RTL、综合结果或真实四路时序证据。

当前已经定位到一个应继续研究的瓶颈：**主辅有效边界变化引起局部残差／高段门控变化，选样又可能漏掉这些激励，并通过学习状态改变后续码。**下一项应在这个机制上建立窗口平均更新与门控余量的条件性关系，并检验适用条件；不是继续延长同一训练或等待 Cadence。现有结果仍属于 Gu 候选机制分析，尚不足以进入新算法普遍优劣结论。

# EXP-048：成对扰动能消掉信号项，但仍会漏掉失真

> 2026-10-10。正式产物：`artifacts/runs/EXP_048/pairs_v1/`。复用六组旧记录，额外构造精确数学反例；没有新训练、ADC平台转换、Cadence或原Gu／RTL修改。完整公式见[推导](../../theory/PAIRED_DITHER_CANCELLATION_AND_PERIODIC_ERRORS_V1.md)。

**成对正负dither有用，但还不足以保证校正正确。**同一信号、同一历史、同一选样规则时，目标信号项可以逐对精确消掉；固定一种扰动幅度却可能完全漏掉周期性失真。

## 已证明的有效部分

两次读出分别注入+64／−64码的微小扰动。若目标相同，两侧共同开门或共同关门，目标信号相关项严格为零，无需依赖长记录中的独立性。

若仅一侧开门，即使目标相同也会重新出现信号项；若目标不同，即使共同门也会留下目标差。因此需要实际配对条件和共同门，不能把两条符号相反的普通记录直接拼起来。

## 仍然漏掉什么

构造了一条连续且一阶导数连续、严格单调、奇对称并经过零点的非线性传输。它的误差周期恰好是扰动幅度的两倍。

| 单级人工反例，67对读出 | 结果 |
|---|---:|
| 每对校正输出之差 | 全部精确0 |
| 成对特征矩阵秩 | 4，四个系数全部能确定 |
| 唯一数字对比解 | 四个单位系数 |
| 实际连续输出均方误差 | 5.0001码平方 |
| 最大绝对输出误差 | 3.0762码 |

原因很直接：两次读出碰到相同的周期误差，相减时误差也消失了。内部差值变好，并不等于每次输出变准确。原Q3舍入和单级校正器核对后，67对差值仍全零，输出误差仍存在。

另一个独立反例同时使用64／80两种幅度，仍漏掉周期32码的误差。不能只说“增加一种扰动就解决了”。有限输入支持还可能留下多个互不连接的误差分量，需要绝对参照或可信函数条件。

![成对扰动的误差遗漏和支持条件](../../../artifacts/runs/EXP_048/pairs_v1/paired_dither_limits.png)

这些是条件性单级数学反例，不是电路波形或全ADC频谱，也不假定真实放大器具有这种周期形状。

## 旧数据能否直接检验

六组各11520条拟合记录都没有满足“记录输入相同、三路有效跟踪初态相同、后级扰动相同”的正负前级扰动对。两组复位正弦仅有2／3对；两相和直接保持都没有。

周期复位的三对数据，在同一后级下冻结A／B前级，成对残差的均方值约为49.30／770.21码平方。它们能区分这两组预定系数，但只覆盖少数目标值，特征矩阵秩2，不能据此识别全部系数或宣称新算法有效。所用配对元数据也没有出现在现有五字段在线接口中。

## 本轮结论和下一步

成对相减消除的是共同信号项；校正系数是否有足够激励、周期误差是否漏过、绝对读出是否有参照，以及如何取得真正的配对数据，仍是不同问题。下一步研究有限支持下多幅度扰动、误差锚点与函数误差界的配合，并核对实现所需的信息和成本。

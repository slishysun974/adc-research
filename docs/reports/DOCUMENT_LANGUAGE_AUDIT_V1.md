# 研究文档可读性与学术表述审查 v1

> 日期：2026-09-17
> 范围：仓库内 84 个 Markdown/TeX 源文档；其中 `docs/` 内 49 个为现行研究文档，仓库其他位置 30 个为项目和实验入口，`legacy/pre_charter_v0_1/` 内 5 个为历史归档。计数不含本审查记录。
> 目的：让电路读者先识别信号节点、判决条件、测试量和证据范围，再阅读抽象数学定义。本文是术语与论证审查，不改变原实验数据或模型方程。

## 审查方法与统一原则

对所有源文档检索“胞腔、仿射、原像、泛函、等价类、观测等价、均值场、拓扑”等跨领域词，以及 `truth / oracle / Gate / slice occupancy / gate count / 锚点` 等实验内部叫法。随后逐处判断它是正文论述、数学定义、源码标识、运行编号还是历史记录。现行理论、阶段二规格及报告按[术语约定](../TECHNICAL_WRITING_CONVENTIONS_V1.md)改写；历史文件保留可复现名称，并在相关入口和重点报告解释。

本文使用以下写作顺序：**物理信号与操作 → 必要假设 → 公式与符号 → 可计算结果 → 验证方式及外推边界**。例如，先说“第二级 flash 的阈值沿辅路传输反算到 ADC 输入端”，再在定义或证明中用“阈值原像”。先说“固定判决码的一段连续输入范围”，再说明其数学名称“路径胞腔”。

## 主要问题与处理

| 原表达或问题 | 容易造成的误读 | 现行写法与位置 |
|---|---|---|
| “胞腔”“细化胞腔”先于电路定义出现 | 读者难以知道它是输入范围还是芯片单元 | [理论导读 3.3](../theory/STAGE2_READER_GUIDE_V1.md)、[理论框架](../theory/ADC_PERFORMANCE_PREDICTION_THEORY_FRAMEWORK.tex)先给“各级判决不变的连续输入区间”；仅在严格定义中保留数学名词。 |
| “仿射闭包”易被读成放大器或数字校正必为 PWL | 混淆未知物理放大器 $g_i$、测试用模拟近似 $\widehat g_i$ 和数字 PWL $f_i$ | 先写“在预设的局部分段一次模拟传输条件下，残余电压对输入呈斜率加偏置关系”；明确该条件不从数字 PWL 校正推出。 |
| “阈值原像”“码域测度”“性能泛函”直接写在结论里 | 看不到实际计算的边界、宽度或频谱指标 | 分别写“反算到输入端的阈值位置”“每码对应的输入总宽度”“从谱线功率计算 SNDR/SFDR 的规则”。数学表达保留在推导处。 |
| “拓扑不变”“观测等价”“均值场”缺少检验条件 | 容易把局部数学条件当成一般电路结论 | 写明码边界的数量和顺序、所用激励与观测量、LMS 平均更新所依据的输入与 dither 分布。 |
| `truth`、`oracle` 和 “PWL 放大器” | 误把预设模拟测试传输、已知传输下的逆校正当作芯片实测或电路结构 | [EXP-006](experiments/EXP_006_TWO_STAGE_PWL_TRUTH_V1.md)等历史报告文首解释代码旧名；正文优先用“预设模拟传输”“理想逆校正”。 |
| `Gate`、`slice occupancy`、`gate count` | 把项目验收编号、分段访问次数、系数有效更新次数混用 | [实验报告入口](experiments/README.md)说明；涉及可辨识性的 [EXP-009](experiments/EXP_009_ADAPTIVE_GATED_LMS_IDENTIFIABILITY_V1.md)在文首单独区分。 |
| “锚点”“通过”“准确”“显著”未说明证据范围 | 数学、同模型双实现、电路瞬态和硅后测量被当作同一级证据 | 优先给论文参数的数值与换算假设；用“指定行为模型下、多少样本、比较哪个量”限定结论。 |

## 保留术语与后续写作检查

傅里叶系数、相干采样、DNL、INL、SNDR、SFDR、ENOB、PWL、LMS 等属于本课题常用术语，可以保留。严格定理中的“仿射”“原像”“胞腔”有精确定义价值；要求在首次出现处给出电路含义，并在摘要、章节题目和实验结论中优先使用具体电压、阈值或输入区间。运行名、源文件名、配置键和表格字段不得为了文字一致而改名，否则会破坏复现路径。

后续新增文档按[术语约定](../TECHNICAL_WRITING_CONVENTIONS_V1.md)审阅：公式的适用条件是否写在公式前；输出是否指最终整数码还是中间残余电压；`g_i`、$\widehat g_i$、$f_i$ 是否混淆；对论文参数的换算是否注明额外动态假设；“验证通过”是否给出独立性、样本范围与尚缺的物理证据。

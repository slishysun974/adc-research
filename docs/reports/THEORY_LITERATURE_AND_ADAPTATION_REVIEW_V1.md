# 理论文献与适配性审查 v1

> 日期：2026-09-16  
> 范围：阶段二性能预测与阶段三校准性能传播  
> 原则：只借用假设成立的局部结构；流水线 ADC 特有缺口由项目工作理论补齐并保持可证伪

## 结论摘要

没有一套现成理论可以直接覆盖“逐级硬判决、数字冗余、模拟记忆、确定性量化谱和
自适应校准闭环”。合适的理论架构不是选一个万能模型，而是把对象分层：

1. 用分段仿射/混合系统描述固定判决路径内的 residue 与路径切换；
2. 用精确码域原像和相位原像处理确定性量化谱；
3. 用连续时间状态方程描述模拟记忆，并显式推导离散状态、周期稳态和静态极限；
4. 只在连续弱非线性模拟子块中使用 Volterra 类展开；
5. 用随机逼近描述校准状态分布，再经 ADC 的硬边界与复谱线灵敏度传播到性能。

## 项目原创或重构的工作理论

### 1. 逐级路径胞腔与冗余等价类

固定路径内各级 residue 的仿射闭包来自分段仿射系统；本项目新增的是按流水线
级联阈值原像递归构造输入胞腔，并用数字重构相同定义路径等价类。它同时连接
码域宽度、DNL/INL、缺失码和不可纠正输入测度。

可证伪条件：若胞腔内存在未建模多值、随机或非仿射映射，或路径边界不能由有限
不等式描述，则必须扩大状态或改用更一般的局部函数族。

### 2. 动态模型的观测等价

不同物理模型只有在选定输入实验和观测协议下输出完全相同时才属于同一观测
等价类。这避免仅凭一个 11 GHz/100 ps 终点同时宣称识别了复位、保持或极点结构。

可证伪条件：找到能产生可重复输出差异的同当前目标、不同前序 residue 实验，即可
打破固定复位与跨样本保持的等价。

### 3. 边界--内部谱灵敏度分解

对由参数移动的相位分区积分应用 Leibniz 法则，谱线导数被严格分为两项：胞腔
内部映射变化和码跳变乘边界位移。普通光滑 Jacobian 只包含第一项，因此会漏掉
判决边界移动带来的有限跳变贡献。

可证伪条件：边界相切、合并、产生或消失时普通导数可能不存在；此时必须使用
单侧导数、广义导数或有限变化分析。下一实验 EXP-018 将独立检查两项。

### 4. 校准分布到谱线功率的连接

随机逼近提供校准状态误差的局部均值和协方差；边界--内部谱灵敏度提供从状态到
复谱线的 Jacobian。两者组合后得到谱线均值、协方差和期望功率的一阶近似，从而
区分校准偏差造成的确定性 spur 与状态波动造成的平均功率抬升。

可证伪条件：最大 spur 身份频繁切换、状态分布跨越多个判决拓扑、均值场不稳定或
线性化范围不足时，必须改为分段或全分布传播，不能只传播均值。

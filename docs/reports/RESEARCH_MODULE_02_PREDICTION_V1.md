# 模块二：信号链建模与性能预测

> 编写：2026-10-16；证据截至2026-10-15。依据用户确认的[七模块分类](PROJECT_STRUCTURE_AND_RESEARCH_REVIEW_2026-10-16.md)。
> 2026-10-19补充可计算数学模型，并完整整合校准算法对性能的影响推导。历史ADC实验证据截至2026-10-15；补充轮只做公式小例核对，没有重新运行原ADC实验或生成芯片性能预测。

项目已经建立从逐级电压与判决计算最终码，再连接静态指标和频谱的方法。**给定模拟传输时，可以作具体预测；只知道可信范围时，可以作条件性范围判断。真实传输缺少足够约束时，目前不能给出唯一的芯片性能。**

完整数学模型由[理论框架第三节](../theory/UNKNOWN_GAIN_END_TO_END_FRAMEWORK_V0_1.md#三从信号链到码和频谱哪些关系仍然成立)与[第五节校准影响](../theory/UNKNOWN_GAIN_END_TO_END_FRAMEWORK_V0_1.md#五校准闭环误差机制与条件理论)共同组成：第三节建立电压到性能的可计算链，第五节把校准更新、真实系数历史、输出误差与性能变化完整接入。两节给出公式推导、条件、求解流程和手算例，本报告解释用途与证据边界。

## 1. 为什么不能只看仿真曲线

逐样本仿真回答“这些输入经过模型得到什么输出”。理论预测还需要说明：哪些输入会改变判决边界，哪些误差会被冗余抵消，以及未知参数如何影响结果。独立推导能够检查程序，也能指出一条漂亮频谱没有揭示的条件。

本模块因此经历了两个层次。早期先固定模拟曲线，研究能否直接计算转换特性。后续把传输、阈值或在线状态的不确定性纳入，研究当前证据能保证多窄的结果。后一层比重复一个确定性模型更接近未知增益问题，但尚未完成一般解。

## 2. 从信号链走到性能

### 2.1 先把数字读出写成确定运算

模型分别保留第一主路、第一辅路和第二主路；第二级判决读辅路，第二级CDAC处理主路。理论§3.1—3.3给出阈值标签、CDAC、模拟／数字dither、数字PWL、最近偶数舍入和饱和规则。模拟传输是离线模型输入，在线校正器只接收数字观测与自身系数。

数字PWL从四个累计基函数构造，推导出“前段累计偏移加当前段乘积”，再接成后级先校正、扣后级dither、重构前级、前级校正、扣前级dither、最终整数化的确定链。在理想条件下，消去内部粗码后严格退回

\[
Y=2048+\lfloor2048x\rfloor.
\]

这项推导同时检查单位、dither符号和冗余抵消。所有后续预测都使用同一读出顺序，定点模型还保留偏移／乘积分别舍入。

### 2.2 反算阈值，得到完整静态转换

理论§3.4把每条路径写为全部判决不等式的交集，再逐层反算。令 $h_i=D_i(q_i)-d_i$；连续严格递增分支上的第二级flash阈值和末级SAR阈值分别回到输入端的

\[
x_2(t)=h_1+(g_1^a)^{-1}(t),\qquad
x_3(t)=h_1+(g_1^m)^{-1}\!\left(h_2+(g_2^m)^{-1}(t)\right).
\]

逆函数没有闭式就用有根包含保证的二分法，给出达到输入精度所需的迭代数；一般非单调函数按已知单调段取原像并集，仿射特例直接解一次不等式。理论证明全部量化格的互斥与完备性，保证分区不会漏掉允许输入；不以有限扫描代替找全根。

理论§3.5随后合计同一码的所有输入区间宽度 $W_k$，得到 $\mathrm{DNL}_k=W_k/\Delta_x-1$。只有整体按码序单调时，累计码密度偏差才解释为单一转换边界INL。辅路切换、最终码跳变和过载分别记录。

### 2.3 从码边界积分出谱和功率

理论§3.6先把输入边界映到正弦相位，再对每个恒码相位段积分。若段内码为 $y_j$、两端相位为 $\phi_j,\phi_{j+1}$，则

\[
c_m=\frac{1}{2\pi im}\sum_j y_j
(e^{-im\phi_j}-e^{-im\phi_{j+1}}),\quad m\ne0.
\]

总功率直接由 $\sum_jy_j^2(\phi_{j+1}-\phi_j)/(2\pi)$计算，扣除DC和基波就是全部噪声失真功率，因而计算连续SNDR无需截断无限谐波，也无需白量化噪声假设。连续全局SFDR则需要控制未计算的尾部最大谱线，不能只取有限阶最大值冒充全局值。

理论§3.7另给有限DFT、单边RMS归一化、Nyquist权重和谐波折叠，明确连续周期谱与有限记录谱的区别。§3.8通过隐函数求导、相位求导和跳变谱求导，连接参数、边界及谱线变化；边界碰撞、极值切触或码值改变时改用重新分区／包含界。

### 2.4 把动态和学习真正接到输出

理论§3.9从指定一阶建立方程推导离散递推、有限几何和与已知周期目标下的周期初态；同时给出独立三路状态的转换顺序。原Gu候选的Q22隐藏状态、Q1.10导出、门控相关和、原步长／倍率、四字或全槽采用、窗口末双bank同时提交都写成确定公式。

理论第五节进一步解释这条算法怎样改善或损害性能，而不只生成一条输出记录。§5.2从相关和推到实际导出变化，保留请求取整、饱和及相邻导出误差；§5.3—5.4解析展开两级系数变化，得到纠偏交叉、两级乘积、算术及其交叉共同组成的净MSE。相关根与最小码误差需要不同目标矩，相关下降不自动保证误差下降。

§5.5—5.6证明早期请求在输出前平均位置中权重更大，并区分固定评价矩阵上的协方差代价与真实后台的状态—输入交叉。§5.7提供一个完整标量解析特例，从输入／量化矩、学习率和采用样本数，算到有限均值、方差、稳态及独立评价输出损失；§5.8明确两级推广所需的保护邻域、相关导数、源规律及余项，不能把标量闭式冒充一般八状态理论。

§5.9—5.11直接对校准与参考的真实码差进行谱分解，分别计算基波功率变化、余谱功率变化和每根杂散的相干交叉，再得到SNDR／SFDR变化。系数时间变化经与数字基函数的乘积形成旁带；同方差不意味着同杂散。随机性能还保留完整时间协方差，并区分平均功率、平均dB和最大谱线。

§5.12给冻结校准的码标签／DNL关系和后台联合码密度；§5.13汇总从算法参数到性能差的求解顺序，§5.14有纠偏正反、两级零均值乘积和MSE下降但SNDR下降的手算例。因此有限记录与指定统计特例已在框架内闭合，一般长期收敛、在线取得较好系数和真实芯片动态仍保留各自条件。

### 2.5 传输未知时，计算的是包含范围

理论§3.10从有限扫描误差区间与可信全域斜率界推导连续输出包络，并给数据自洽的有限判据。之后枚举所有允许判决，联合传播模拟／数字状态，以归纳法证明每次最终码属于 $[L_n,U_n]$。主辅分别取极值或合并状态会放宽范围，不能删掉不利分支。

理论§3.11再从码范围通过Parseval和三角不等式推导SNDR／SFDR界、逐频点界，并反推所需码精度。例如参考基波和余谱RMS为 $S_0,D_0$，要通过统一RMS界证明SNDR至少 $T$，令 $\gamma=10^{T/20}$，足够条件是

\[
\epsilon\le\frac{S_0-\gamma D_0}{1+\gamma},\qquad S_0>\gamma D_0.
\]

其中 $\epsilon$来自逐点码范围的RMS半径，不是任意指定的噪声参数。若资料不够窄，结论可以是宽界、无穷上界或指标未必有定义。

### 2.6 怎样按模型求解和核对

理论§3.12给三套算法的输入、步骤、终点和计算成本：冻结静态分区／积分、指定动态后台有限递推、允许模型族的范围传播。§3.13有两个可手算例，分别把独立主辅链推到16码全零DNL／INL，以及把两段周期码推到完整失真功率和连续SFDR。

第三节模型展开时的小控制通过：262个有理数输入的独立前向／反算、18个非空路径区间及16码宽、32个PWL点、最近偶数等值规则、32点直接DFT／FFT／Parseval、全部27条不确定码记录的频谱包含和11步一阶状态核对。第五节校准影响另核对8组两级变化／32次数字读出、4窗时间权重、两个标量读出与两档步长的256条三窗路径、1024个独立评分配对，以及32点谱交叉／旁带／窗口保持与4条记录的完整时间协方差。两轮都只检查公式与算术，没有新增物理代表性或重新验收旧实验。

## 3. 已经得到什么

EXP-015的独立静态预测，在四类固定条件、共262,144个未参与构建的测试输入上，与平台最终码和可纠正状态一致。它还预测了冗余失效对应的输入宽度。这里验证的是指定模型的计算关系，未使用校准后的性能相近来替代边界检查。

EXP-016把静态转换连接到频谱。18条有限记录、589,824个平台样本的码和评分与理论实现一致。连续周期SNDR与有限记录仍有小差别，因为有限采样与高次谐波折叠改变了观察口径。只计算有限个连续谐波，也不能声称已经找到无限谐波中的最大杂散。

EXP-017—019进一步加入一阶有限建立、码边界灵敏度和独立辅路的周期建立。这些结果说明：在明确动态假设下，可以分析历史状态如何改变后续判决。实际电路是否按这种方式复位、保持或建立，仍需波形或测量支持。

后续EXP-033、036—038把观测范围、定点在线状态和频谱连接起来。EXP-038对一条人工静态扫描来源的128点记录，给出SNDR不低于7.395246 dB、SFDR不低于8.684082 dBc的数值认证下界，上界仍为无穷。

这个例子的重要性在于：**计算严谨并不会自动使证据变窄。** 它证明所传播的宽范围确实包含允许结果；较低下界不等于真实性能很差，个别较好轨迹也不能代表整族性能。更高算术精度和更充分物理信息解决的是不同问题。

## 4. 测量方式也是条件

EXP-029研究单路抽取输出与全速频谱的信息差。抽取可能把不同频率映到同一位置，也可能漏掉交织杂散。因此，论文某一路的测量频谱与项目全转换码的频谱，不能只按数值接近就宣布复现。

同样，输出码均方误差小，不唯一决定SFDR：相同误差功率可以集中成一根杂散，也可以分散到多个频点。静态码宽、总误差和最大杂散需要各自评价。

## 5. 当前限制与课题意义

目前扫描接入和频谱认证中的数据是人工合成控制，并非已有Cadence或硅后扫描。要把有限网格扩展到网格之间，还需要有来源的最大斜率等条件；要覆盖真实主辅路径，还要明确节点、负载、历史、阈值和工作条件。

旧TeX／PDF主要保存给定传输和指定动态的条件性推导。现行理论第三、五节已补齐可计算的条件模型及校准影响推导；未知曲线的物理覆盖、一般两级长期收敛和在线达到性仍开放。普通浮点FFT、有限记录数值认证与芯片物理保证也必须分别说明。

本模块的阶段成果是建立了“假设或证据能支持多强性能判断”的方法。它既能在条件充分时预测，也能在条件不足时明确不能唯一预测的原因，为其他模块评价校准收益提供边界。

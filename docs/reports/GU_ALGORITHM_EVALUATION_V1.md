## 1. 评价结论与适用范围

**Gu方案确实有校准能力，也有明确的工程价值。** 它把复杂的非线性校正拆成几段较简单的数字计算，并在ADC工作时继续调整系数。原论文展示了芯片校准后的改善；本项目的原理控制和部分长期实验也支持这一点。

但“能够学习”不等于“在任何输入下都学得准”。学习数据是否足够、每次调整多大、数字量化如何处理，都会影响结果。在我们的候选实现中，系数平均上朝正确方向变化，仍可能因持续波动而降低输出质量；某些输入下，平均更新停止的位置也未必使误差最小。

因此，**Gu适合作为正式比较基线，现有证据不支持将它概括为总体学习方向错误。** 项目实验揭示了一些需要研究的限制，但所用模型和更新时序并非原芯片的完整复现。真实抽取器保留什么数据、内部累加精度多高、dither序列如何产生、系数何时生效，仍有公开资料缺口。

## 2. Gu算法解决什么问题

流水线ADC先完成粗量化，再把尚未量化的残余电压放大后送给后一级。开环放大器有利于速度和能效，但放大倍数可能随信号大小改变，给最终数字码带来误差。Gu的目标是在数字端补偿这部分误差。[P1，§I—II]

LMS是“最小均方”自适应方法的简称，系数随数据逐步调整。Gu采用门控LMS，也就是按输出幅度决定哪些样本参与某个系数的更新；它的具体学习量见第2.3节。

方法分成两个部分：

1. **校正器决定怎样重构数字码。** 把内部数字码幅度分成若干段，各段使用一个斜率系数，再调整段间偏移，保持数字校正函数连续。
2. **系数提取器决定怎样学习斜率。** 注入已知的微小扰动，称为dither。完成数字校正并扣除扰动副本后，观察输出是否仍随扰动正负发生系统性变化；用这一统计关系调整系数。

分段线性（PWL）是数字校正函数的表示方式。它不要求真实模拟放大器本来就是分段直线，也不要求运行中的算法知道放大器传输曲线。

论文的ADC是12位、3 GS/s、三级流水线结构。前两级先由并行比较器量化器（flash）做粗判决，再通过电容式数模转换器（CDAC）扣除相应电压，并放大残余。末级采用四通道8位逐次逼近（SAR）转换器。[P1，第6—9页，Fig.13]

第一级主放大路驱动第二级CDAC，辅助路驱动第二级flash。四路数字处理只是把连续样本分流、并行计算，不能当作四套独立的前级模拟链。[P1，Fig.13、18]

### 2.1 校正顺序及信号边界

论文数字引擎先处理SAR和后级误差，再重构供前级校正的数字量。分级校正的核心顺序可表示为：

```mermaid
flowchart LR
    A[后端数字码及前级判决] --> B[后级PWL校正]
    B --> C[扣除后级dither副本]
    C --> D[重构前级局部数字量]
    D --> E[前级PWL校正]
    E --> F[扣除前级dither副本]
    F --> G[组合最终输出码]
```

这是算法顺序的简图，省略电容权重、SAR通道增益／偏置等处理。论文实际引擎还校准这些误差，电容权重在正式转换前由片外提取，再写入芯片。这类预先操作称为前景校准；运行期间继续调整称为后台校准。因此，该系统仍包含前景步骤。[P1，§III-C、§IV]

算法使用的是内部数字码、对齐的dither副本和已有系数。真实输入、模拟增益曲线、理想目标码或离线最优系数只属于研究者的控制与评分信息，不是本项目在线算法的输入。

### 2.2 PWL校正为什么计算较简单

在一个数字段内，局部码乘对应系数；段起点的偏移由前面各段累计得到。等宽段的累计偏移满足

\[
b_j=b_0\sum_{i=1}^{j}k_i.
\]

这里$b_0$是数字段宽，$k_i$是该段的斜率校正系数。前一段乘法改变了段末数值，后一段起点也要相应移动，否则数字校正曲线会在段界跳变；$b_j$就是为保持连续而计算的起点，也用于更新门限。

论文的四段校正块使用一个乘法器、一个加法器和两个4选1选择器。段起点可由斜率算出，不需要再独立学习一套偏移参数。[P1，第3页，式(2)—(3)、Fig.2—3]

正负输入共用系数适用于对称校正结构。原文讨论在偶次失真重要时分别使用正／负系数；本项目主要候选仍采用对称四段表示，因此不能宣称已经覆盖任意非对称模拟非线性。[P1，第4—5页；本项目候选定义]

### 2.3 门控LMS实际更新的量

当校正不充分时，扣除数字dither副本后，输出仍可能随dither正负改变。算法把这种残留统计关系用于调整系数；后续段只在输出幅度足够大时参加更新。

公式中，$D[n]$为数字dither副本，$Y[n]$为该级校正并扣dither后的局部输出；$\mu_i$是步长，决定调整大小；$G_i[n]$是更新门，取0或1。论文原理更新为

\[
k_i[n+1]=k_i[n]-\mu_i D[n]Y[n]G_i[n].
\]

第一系数使用全部学习样本；后续系数在局部输出幅度超过相应累计下限时更新。第一系数不仅影响第一段，还进入高段的累计偏移，所以不能只用第一段内的样本更新它。后续门也不是“只选本段”的上下限带通门。[P1，第4页式(5)—(7)、第5页Fig.10]

更新中的$Y$不是“输出减理想目标”的误差，因为运行中的算法没有理想目标码。它依靠dither相关量提供的间接误差信息。因此，相关量变小是否也让最终码更准确，需要另外检查。

原文式(7)使用`≥`，Fig.10及相邻文字使用`>`，等值规则存在不一致。本项目冻结为`≥`。连续输入下的等值点和量化码中的等值事件不能混为一谈；芯片真实比较规则仍待证据，不通过悄然改门限来修正旧实验。[来源与信息审计](../stages/03_gu_baseline/DECIMATION_INFORMATION_REQUIREMENTS_V1.md)

### 3.2 抽取测量的边界必须保留

论文先将四个连续样本分流，由四个750 MHz数字处理单元并行校正，再抽取30用于后台系数提取；测量端经4选1选择一路，最终输出抽取率120。DNL／INL则结合四路输出计算。[P1，第9—10页，Fig.18]

原文明确承认，这种频谱观察方式不能直接看到交织杂散。作者根据末级转换保持信号、后台通道增益／偏置校准及Monte Carlo结果解释其影响较小；相关“3σ杂散低于−90 dB”属于仿真依据，不能写成完整交织谱的直接测量。[P1，第10页]

因此应保留论文测得的校准收益，同时避免把某一路抽取频谱等同于本项目保存的全转换整数码频谱。两个观察协议不同，不适合仅凭SNDR数值接近就宣称复现成功。[测量信息边界](../theory/MEASUREMENT_PATH_INFORMATION_BOUNDARY_V1.md)

### 3.3 原文资源比较说明到哪一层

原文用9位原始码、四段PWL及明确系数精度比较校正块：PWL约700 gates，三阶多项式约2500 gates；报告面积／功耗约70%的节省与约60%的关键路径缩短。[P1，第3页]

这支持PWL校正块的计算结构优势。比较对象是指定精度的校正块，不是全ADC、完整系数提取引擎或本项目RTL。门数、面积、功耗、时序必须在相同实现边界和约束下分别比较；不能用700 gates去除本项目整个两级更新链的逻辑单元数。

## 5. 校准方向、平均系数与持续波动

### 5.1 原理正向控制支持Gu的校准方向

[EXP-055](experiments/EXP_055_MODEL_DITHER_AUDIT_V1.md)依据原文Fig.6的两段传输、输入与步长，完成500万样本的连续标量控制。最终系数接近对应逆斜率，固定网格误差从0.0041141降至约$2.018\times10^{-7}$。该控制保留未量化、端部延伸等补足条件，支持原理更新和符号正确，不能称Fig.6或芯片逐位复现。

这一证据也修正了早期短实验的解释：某次更新使误差增大，不足以证明平均学习方向错误。即使在平均方向正确的标量模型中，有限随机数据仍可产生许多不利单次更新。

### 5.2 平均校正正确，仍可能被固定步长波动抵消

为判断学习是否有净收益，本项目设置了“单位不更新参考”：所有数字斜率保持为1，不继续学习，其余输入、dither和数字重构保持相同。后面的净收益都是相对明确参照计算，不能只看校准后的绝对指标。

[EXP-056](experiments/EXP_056_MILLION_SCALAR_STATISTICS_V1.md)在无门、无动态、单斜率和明确独立输入／dither条件下，推导并核对平均与二阶统计。连续模型的平均位置可接近正确逆增益，但固定步长仍使系数持续波动。

在该宽范围控制中，同转换时长下，四点乘30的状态波动明显大于完整120点累计；即使平均校正位置正确，四点稳态期望码MSE仍可能大于单位不更新参考。它是严格限定的统计反例，不可直接移植为八系数两级Gu的全部噪声模型。

这里MSE是输出码与理想目标差值的平方平均，越小越好。波动小和误差小不是同一件事：若理想码为1000，始终输出998比在999／1001之间变化更稳定，却更不准确。这个例子只用于解释两种指标的区别。

四点乘30只调整平均更新尺度，不生成额外观测。上述标量控制中，完整累计降低有限估计波动，但同转换时长下每级多30倍学习观测／相关贡献；其收益不能自动算作同成本算法优胜。有门、两级耦合及相关输入时，统计关系须另验。

### 5.3 量化与输入会改变平均相关平衡位置

“平衡位置”指平均更新量为0时的系数值。它不一定是输出误差最小的位置。

EXP-056的增益0.975、小摆幅／直流量化控制中，相关平衡系数为1.024，而连续正确逆增益约1.025641。延长记录后五种子在各自解析位置附近波动，没有靠学习量消掉这项量化偏差。

这说明二值dither并不自动令量化误差与其独立，也不保证所有输入支持下都得到相同平衡系数。Gu原文已讨论直流／小摆幅的更新不足，并用额外大信号线性化dither作概念示例；不能把该示例当成本项目或实测芯片已经启用的免费功能。[P1，第6页Fig.12；EXP-056]

### 5.4 相关量为零与最小码误差不是同一个条件

固定后级及数字记录时，Gu平均相关方程与最小码MSE方程一般使用不同的权重；共同状态下还涉及输出方向、目标交叉和更高阶项。已有条件推导及反例证明，相关为零不能单独保证最终码误差最小。[两级理论§8—11](../theory/STATIC_CASCADE_MILLION_SUPPORT_AND_PROJECTION_V1.md)

这给出了一个评价边界，而不是正常长期损失的完整归因。部分例子使用特定数字字或离线目标，不代表Gu实际轨迹达到这些状态；仍需正常运行证据判断哪个因素重要。当前不能用反例或约半数不利更新，把Gu总体目标判定为错误。

### 5.5 数字表示与有限观测本身也有能力边界

四段PWL近似不能对任意未知模拟非线性保证精确逆校正。原文针对选定传输与电路仿真展示增加段数的精度收益，同时指出段数增加会提高数字代价、减少高段有效样本并延长学习；这些是指定条件下的权衡，不能外推为任意曲线的统一精度规律。[P1，第5—6页，Fig.7—9]

本项目EXP-057使用同一四段数字表示的离线参考，仍可比正常学习状态取得较低误差，说明当前损失不全来自表示能力。该参考读取理想目标，不能免费转成在线新算法；固定后级投影残差也包含后级误差与量化，不能全部命名为PWL表示误差。[EXP-057](experiments/EXP_057_STATIC_TWO_STAGE_MILLION_V1.md)

有限训练数字观测也不能唯一决定未见条件的性能。EXP-020构造的两个允许传输在训练记录中完全相同，却能在留出记录中改变末级码；这是信息边界，不是Gu特有的学习缺陷。若要给未知实际放大器的唯一性能，需要新增覆盖、可信物理约束或继续观察。[EXP-020](experiments/EXP_020_UNKNOWN_GAIN_IDENTIFIABILITY_V1.md)

### 5.6 学习率决定速度与波动，但稳定不等于净收益

2026-10-11按用户新要求补充，详细推导见[标量统计§7—13](../theory/MILLION_SAMPLE_SCALAR_MEAN_NOISE_AND_QUANTIZATION_V1.md)。Gu第5—6页明确讨论更新尺度、收敛时间与系数**方差**的权衡；两段原理例的学习率不能当作四段芯片参数，也不能和项目码尺度直接比大小。

在独立、无记忆单斜率控制中，定义平均反馈强度$u=\mu pmE[DR]$和归一化相关噪声$\gamma=\operatorname{Var}(DR)/(mE[DR]^2)$。平均收敛要求$0<u<2$，二阶稳定却要求$0<u<2/(1+\gamma)$。噪声非零时，恒步长可使平均系数趋于相关根，同时保留正的稳态方差；根不必是最小输出误差位置。

复用EXP-056连续宽输入控制的基础步长，解析减半后四点稳态新评分MSE从31.683575降到15.824876码²，略低于单位不更新的16.213333；平均误差降到初始1%的时间从2517增至5036窗口。四点原步长距离该标量二阶失稳上界很远，却仍损失输出质量，故不能把此损失叫作发散。完整累计同时间采用30倍观测，保持分开比较。

减小步长在固定总体矩中不消除量化相关根偏差，继续减小还可能令Q22请求舍为0。真实Gu高段门随状态变化，两级相关矩一般不是对称的输入Gram矩阵；固定窗口门导数与总体移动门界导数也不同。因此普通LMS上界不能无条件作为八状态证明。

原EXP-051步长/4的两级短结果相对基准20/24格改善，却有最差−3.7813 dB，只有12/24格胜过单位参考。这是已有实际收益与限制，不由本次标量表改写为“最佳步长”。11项独立精确控制及499项回归通过，记录在`artifacts/research/gu_learning_rate_20261011_v1`；该次解析核对没有新增ADC转换、训练或FFT。随后EXP-069完成必要同流两级倍率矩阵，见§5.7；芯片实际学习率和一般八状态证明继续开放。

### 5.7 EXP-069：小步长有实际净收益，仍不能宣布收敛

2026-10-11按D-116及项目EXP顺序接续，[EXP-069](experiments/EXP_069_GU_LEARNING_RATE_V1.md)固定比较1/4、1/2、1、2四档共同倍率，保持原三静态模型／五种子／同正弦／Q3／Q1.10／Q22／120槽合同。原数字流只读复用，每档生成自己的完整门、系数和输出；三新倍率90条长路径与30条原倍率1分别计数。

1/4四点线性／平滑后期MSE为9.287640／10.165769码²，低于原步长33.945151／34.405914和单位15.827377／32.175739，均5/5种子改善；净SNDR为+3.977640／+6.675108 dB。因此原步长配置下的四点损失不能代表所有Gu学习率。理想链全部倍率仍不如单位，完整同时间多30倍观测；已见条件的1/4优势不选择为芯片或未见曲线的最优参数。

完整1/4后期误差更低，前24块却不如1/2和原步长，启动／波动冲突有实际证据。线性四点1/2净dB平均+1.004499，MSE仍比单位差，保持双口径评价。三新四点非零相关和舍零次数0，与最小请求界一致；收益不是完全停更。

120路径19条曾满足原经验稳定判据，之后19条都再次违反、末尾120条全部不满足。不称已收敛或发散，也不由零饱和／越界认证一般理论。707788800新码、5898240双bank提交、全部计数和34560评分块独立核对；499回归、155来源及81原数据指纹保持。实验定义／报告／运行按原目录职责保存于EXP-069，下一正式实验从EXP-070接续，新算法寻找仍后置。

### 5.8 时间平均与后来违反：原判据主要仍受系数变化影响

按D-117补充的[学习率理论§15](../theory/MILLION_SAMPLE_SCALAR_MEAN_NOISE_AND_QUANTIZATION_V1.md)说明：在明确独立标量条件下，相邻窗口及组均值保留时间相关；小步长降低单窗方差，同时减慢相关衰减。方差较小不保证固定时长的平均位置按同倍率更准确，实际两级记录尚无可套用的独立样本置信区间。

只读核对EXP-069全部120路径的原3600区间，318个后来违反区间分为仅SNDR19、仅系数90、二者209。前后级第二系数分别参与199／247次系数违反；只有6区间出现首次通过时尚未纳入的违反系数。原支持集合变化不能解释大部分违反，但这项统计只定位判据触发组成，没有唯一分解输出MSE原因，也不估独立失败率。

尾段组内／组间方差采用精确整数矩：线性完整累计1/4前后级第二系数组间占比52.85%／51.88%，原步长19.51%／18.92%；平滑对应57.14%／60.35%与22.07%／23.75%。总波动已下降，较慢的组均值变化仍需单列，不据此认定确定漂移或共同根。18个第三坐标全程共同支持0仍有隐藏改变，支持0也不是停更。

8项精确控制、30720组均值分量／1920方差恒等式及507回归通过，155原执行源码／157使用数据保持。核对范围为原状态、元数据和保存评分，未重新验证全部输出二进制或ADC源字；新增转换／学习／输出／FFT0。记录保存于`artifacts/research/gu_learning_rate_diagnostics_20261011_v1`，结果补入[原实验报告§8](experiments/EXP_069_GU_LEARNING_RATE_V1.md)，不建立平行Gu报告或新实验。下一具体启动／持续适应或跟踪合同尚未制定，新算法选择继续后置。

## 6. 两级支持、主辅失配与有限字长


### 6.1 高段是否有效学习，要看三个量

本项目分别统计：某段数字基函数是否参与读出、更新门是否打开、两者是否在同一入选样本上发生。三者不能互换。Gu请求没有直接乘本段基函数，故“共同支持为0”也不等于该系数从未更新。

数字基函数非零，表示该段系数会影响这个样本的重构结果；更新门打开，表示这个样本会参与该系数的学习。一个样本影响输出，却没有被用于相应更新，是两种判断不一致的情况。反过来，门打开也不保证样本直接提供本段斜率信息。

EXP-057／059在部分匹配压缩条件中出现第三段参与读出但对应学习支持很少或为0；条件范围推导解释了扣dither后局部输出与门限的差别。它可以留下误差，但现有控制中其量级不能解释全部损失。第四段在这些预定条件下常无支持，不说明任意芯片状态下第四段无用，也不说明未动系数已学对。[EXP-057](experiments/EXP_057_STATIC_TWO_STAGE_MILLION_V1.md)、[EXP-059](experiments/EXP_059_STATIC_FIXED_MILLION_V1.md)

### 6.2 主辅或比较器改变支持，不保证增加净收益

主辅路径的改变可能先改变flash判决及局部学习门，理想后级重构又能抵消部分当次数字输出差。因此“当前码相同”不保证下一次学习轨迹相同。[EXP-060](experiments/EXP_060_STATIC_AUXILIARY_PREFLIGHT_V1.md)

必要长期配对中，主辅失配在部分线性条件增加第三段支持并有少量平均改善，另一些平滑条件支持增加却退步。比较器偏移也未取得一致额外收益：EXP-064的线性后级完整累计第三段共同支持1779→18998，在线SNDR相对名义却平均下降约0.033 dB。高段计数只能作为机制证据，不能作为校准成功判据。[EXP-061](experiments/EXP_061_STATIC_AUXILIARY_MILLION_V1.md)、[EXP-064](experiments/EXP_064_STATIC_COMPARATOR_BACKGROUND_V1.md)

这些参数是合成失配控制，并非该芯片的失配分布、PVT或实际前景修调残差。

### 6.3 定点没有改变这批控制的主要判断

EXP-059在原五模型、五种子、固定预算下逐项加入Q3数据、Q1.10导出和Q22更新。两级平滑条件终点继续在线的整数SNDR，四点／完整Q22均值为48.519／59.669 dB，同口径浮点为48.513／59.670 dB。均值接近表明这一批控制的主要差距不是加入这些有限字长规则后才出现；不能外推为任意位宽、输入或反馈轨迹的定点损失很小。

为观察前级系数变化的影响，EXP-059暂时固定后级，用保存的前级系数重构同一验证网格。在这个诊断中，系数的联合起伏传到输出后造成的额外MSE，四点方法约占总MSE的93.0%，完整累计约占53.5%。这项计算称为状态协方差传播。

它支持继续研究系数波动，但简化条件必须保留：后级固定、前级采用未舍入的连续数字函数。不能据此说实际运行中93.0%的频谱噪声来自前级，或已经把两级全部损失独立分清。

同批有3408510次隐藏Q22改变而Q1.10导出不变。导出平台段并非完全停更；内部累加精度和生效时刻必须另核对。早期EXP-013已证明，在特定项目步长下直接用10小数位累加会让请求全舍为0，不能把论文的10小数位系数接口当作已公开的内部LMS累加精度。[EXP-013](experiments/EXP_013_FIXED_LMS_ACCUMULATOR_V1.md)、[定点理论](../theory/STATIC_FIXED_POINT_ERROR_AND_LEARNING_V1.md)

## 7. 正常后台输出、启动、跟踪与动态

### 7.1 同输入连续后台是主要性能证据

EXP-059等先均匀输入学习、再切换正弦的冻结／继续在线评分有诊断价值，但不能替代从工作输入启动的后台输出。EXP-062从单位初值起，始终使用同一相干正弦并持续更新，保存每个转换的最终整数码。

下表为三已见静态模型、五种子、每路径7864320实际转换的后半段结果。输入幅度0.82，30720点周期、频点127；四点每级262144学习观测，完整每级7864320。数值为分块dB算术平均相对同输入单位不更新参考的差，不是平均功率后取dB。

按名义3 GS/s换算，该工作正弦约12.402 MHz；这批低频、无热噪声／孔径抖动的合成控制，不能用于声称已经复现论文1—1.5 GHz实测性能。测试条件相同是性能比较的前提。

|---|---:|---:|---|
| 理想链 | −24.765 dB | −10.718 dB | 本来无需增益校正，持续更新仍有代价 |
| 两级线性误差 | −2.115 dB | +11.305 dB | 四点5/5退步；完整5/5改善 |

四点平滑的平均MSE由32.175739升到34.405914码²，而dB平均SNDR为正。原因是评价与汇总方式不同：SNDR去DC并比较基波与残余谱功率，MSE保留输出直流及全部码误差；平均dB和平均误差功率也不同。因此报告必须同时看MSE、DC、SNDR、SFDR及残余功率，不能由一个平均dB值宣布一致收益。

### 7.2 有输出改善，也不能直接宣布已经收敛

EXP-062的30条路径中，29条预算内从未满足预定经验稳定判据；另1条首次满足后，又在后续13个检查区间违反。判据看连续三组8块的SNDR和有效系数组均值变化；它是本项目的离线操作定义，不是Gu论文定理。

未满足该判据不证明发散，有净收益也不要求该判据已经满足。当前缺少一般八状态平均位置、平稳分布和统一收缩证明；后段协方差还可能包含时间相关、低频变化和漂移，不能全部命名为独立白噪声。

### 7.3 输入改变后的有限跟踪仍有边界

EXP-066在幅度0.82→0.41时承接系数及全局标签，与新幅度从单位状态启动的路径比较。完整累计在两级线性／平滑中，后期相对自身单位参考平均净SNDR约+9.88／+12.35 dB，均5/5改善；四点两有误差模型的平均MSE均退步。

30组配对未达到预定恢复判据。承接和新初值的后期平均谱接近，不能单独证明恢复完成；该结果也不证明算法不能跟踪任何输入变化。已有一个幅度切换、同一频点、三已见模型，尚无一般输入变化／PVT跟踪覆盖。[EXP-066](experiments/EXP_066_INPUT_SWITCH_TRACKING_V1.md)

### 7.4 动态历史控制有收益，也有持续波动

EXP-068加入三路合成历史递推，区分复位与保持，全部转换推进历史。三模型、两历史、五种子、两方法60条路径，各3932160实际转换。动态参数是机制假设，不是测量识别的芯片极点或建立初值。

完整累计的两级线性净SNDR，复位／保持约+12.45／+10.85 dB；两级平滑约+13.06／+11.67 dB，相对各自同动态单位参考均有收益。但全部60路径未满足冻结经验稳定判据，完整仍多30倍学习观测。

四点平滑保持条件的dB均值约+1.109 dB、5/5改善，平均MSE却从34.725771升至39.756432码²、仅1/5改善。动态增加第三段支持也不保证净收益增加。[EXP-068](experiments/EXP_068_DYNAMIC_BACKGROUND_V1.md)

白输入标量历史理论已经给出相关平衡位置与最小MSE位置不一致的例子；其白输入、无门、无量化条件不适合直接预测这里的相干两级结果。[窗口理论§6](../theory/FOUR_LANE_WINDOW_DYNAMIC_LEARNING_V1.md)

## 8. 硬件基线及公平资源比较

本项目已有PWL校正、两级重构、在线Q22更新的Python／RTL／通用综合网表核对。它证明指定数字候选内的功能一致性，不包含完整真实四路抽取／广播、目标工艺PPA或芯片位级证据。[RTL入口](../../rtl/README.md)

EXP-035通过保持更新规则的精确整数约分与有依据位宽，将同流程通用逻辑单元从200629降到21121，状态仍184位。算法没有改变，这个约89.47%的结构下降说明粗糙宽算术实现会夸大基线成本；不能把可消除的实现冗余当作Gu固有瓶颈。[EXP-035](experiments/EXP_035_EXACT_UPDATE_RTL_V1.md)

这些逻辑单元还没有映射到指定芯片工艺。单元数量较少，不保证面积、最高时钟和功耗按同一比例改善；软件或HDL仿真用时也不是电路吞吐率。当前缺少目标工艺库、时钟、完整四路实现及功耗活动条件，尚不能判断Gu与新算法的芯片成本胜负。这类面积、功耗与性能比较常称为PPA评价。

| 比较口径 | 必须固定或分别列出的量 |
|---|---|
| 相同转换时长 | 实际转换数、全部输出、每级实际学习数；完整累计多30倍观测单列 |
| 相同学习量 | 每级入选观测、窗口数与经过的转换时长；不能只对齐终点观测数 |
| 相同数字资源 | 码位宽、系数／累加精度、相关乘积和门、状态、提交／广播、额外控制源 |
| 相同性能评价 | 工作输入、单位不更新／原Gu参照、启动与后期区间、整数输出、MSE／DC／SNDR／SFDR／功率 |
| 硬件PPA | 相同目标工艺／器件、时钟／吞吐、综合及布局条件、活动／功耗口径 |

原窗口合同下，四点每窗最多32个门控贡献、共享八和192位；完整累计最多960个贡献、八和224位，系数Q22状态184位。贡献次数并不等于独立乘法器数；dither符号和常数尺度可共用／移位，真实窗口与广播实现仍待核对。[窗口成本§7](../theory/FOUR_LANE_WINDOW_DYNAMIC_LEARNING_V1.md)

## 9. 对Gu的综合评价

### 9.1 有证据支持的优点

- **数字校正结构简单。** 固定数字分段和累计偏移使校正连续，原文同精度综合及实测引擎证明工程可实现性。
- **确有后台误差信息。** dither相关可以在没有在线理想目标码时提取增益／斜率误差信息，原理正向控制和芯片测量均支持这一点。
- **系统级收益经过硅后展示。** 指定芯片的线性度、谐波和SNDR改善明确，三颗芯片PVT测试提供有限范围的实际重复性证据。
- **局部数字判断适合流水线处理。** 自适应下限门与后级先校正的结构有明确数字实现，现有候选也能建立独立定点／RTL参考。

### 9.2 已知条件限制与当前待补证据

| 评价问题 | 当前能支持的判断 | 尚不能支持的判断 |
|---|---|---|
| 学习效率与波动 | 记录长度、步长、dither幅度和实际观测影响速度／波动；稀疏估计可能抵消校正收益 | 任意输入／八系数的一般收敛速度或稳态保证 |
| 输入与量化 | 原文有小摆幅限制，条件模型有输入相关量化平衡偏差 | 二值dither使全部量化误差独立；加样本即可消偏 |
| 高段信息 | 原候选某些段的读出与学习支持不匹配；开门并非净收益 | Gu芯片第四段一定无效；打开高段即可修复全部误差 |
| 最终性能目标 | 相关平衡与码误差最优需额外条件；完整输出须单独评分 | Gu平均目标总体有害，或相关为零即可判最优 |
| 跟踪与PVT | 论文有限PVT测量及项目有限幅度／动态控制存在收益 | 任意动态／温变、所有失配及芯片级跟踪覆盖 |
| 位级与时序 | 候选的原子步骤和保存记录可以独立重放 | 候选120槽／Q22／PRNG就是Gu芯片内部实现 |
| 硬件成本 | PWL原文校正块有优势；候选等价算术可降结构开销 | 当前已证明相对新算法的目标工艺面积／时序／功耗胜负 |

### 9.3 当前证据怎样指导后续问题选择

已有正常运行记录支持优先研究两个问题：用于学习的数据有限，以及持续更新本身给输出带来的代价。与此同时，量化可能移动平均系数位置，四段数字函数也可能留下无法表示的误差，高段还可能没有足够学习数据。这些问题不能全部叫作“噪声”。

后级重构结果会成为前级的输入，所以两级一起变化时，输出还包含交互影响。只看某一级是否更稳定，或统计有多少次更新使误差增大，都不足以判断整条ADC链的性能。

NG-24—28的选样／概率／四格分析帮助明确这些评价条件，但它们是固定旧窗口的机制诊断和候选准备，不能作为Gu原文芯片失败证据。本轮按用户新安排将候选研究退出当前执行优先级；已有记录保留，不继续从旧分数寻找最佳偏移或参数。

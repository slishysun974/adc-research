## 数学审查的实质发现与处理

| 发现 | 最小反例或检验 | 处理 |
|---|---|---|
| 判决码路径未包含模拟模型的局部分段，却声称整条路径上的 residue 仿射 | 同一判决码路径跨越合成模拟近似 $A(x)=x$ 与 $A(x)=2x$ 的拐点 | v1.1 将模拟模型分段标签和末级码加入完整路径；[EXP-015 实现](../../src/adc_research/theory/static_transfer.py)原本已按合成模拟 PWL 近似与 SAR 边界切分。该 PWL 不是数字校正函数。 |
| 动态段只固定前两级判决，却将最终整数码写成单一仿射读出 | 前级判决固定、末级 $b=\mathbf1\{x\ge0\}$ | v1.1 将状态的分段仿射递推与固定完整路径上的离散码读出分开。 |
| 谱灵敏度命题的逐点可微条件不足以交换微分与积分 | 局部尖峰函数可逐点导数为零而积分出现尖点 | v1.1 增加稳定有限分区、边界与局部输出连续可微及一致有界的充分条件。 |
| 非单调传输的累计 DNL 被解释为转换电平 INL | 三等宽区间依次输出 $0,2,1$：累计偏差为零但有负向步 | 修订[指标协议](../specifications/ADC_METRICS_PROTOCOL_V1.md)、[EXP-015 报告](experiments/EXP_015_STAGE2_STATIC_TRANSFER_V0_1.md)和代码文档；历史数值不变，非单调条件改称码密度偏差。 |
| 可纠正域公式漏列最终数字裁剪 | 模拟 residue 不过载，但未裁剪码为 4096 并裁成 4095 | v1.1 的安全域显式要求模拟状态不过载且最终重构码未裁剪。 |
| 负斜率的阈值原像不能统一写成左闭右开 | $s=-x$、$Q(s)=\mathbf1\{s\ge0\}$ 的高码区为 $[-1,0]$ | v1.1 保留一般理论的端点开闭要求，并注明现有预测器的已验证范围限于正局部斜率。 |
| 唯一周期解证明只适用于已给定的周期目标 | 有反馈的分段状态系统可以有多个稳定周期解 | v1.1 将证明限定于标量递推；当前前馈两级可按级归纳，不外推任意混合系统。 |

独立复核没有发现分段傅里叶积分、跳变量谱公式、移动边界项符号及给定周期目标的一阶标量周期解中的代数符号错误。数学修订收紧了这些结果的条件，未单独推翻 EXP-015～017 在指定行为模型下的代码一致性。

## 实验证据的实际层级

- **EXP-015**：区间解析与逐样本平台是两种实现，四类条件的留出点一致；两者仍共享候选 A 架构和合成参数，且有限网格无法穷尽所有边界。
- **EXP-016**：有限码序列一致后，两侧调用共同的频谱指标函数，全频点功率与 dB 指标一致是派生结果。连续闭式积分另有两电平手算例和连续/有限记录比较，但硅级静态谱尚无锚定。
- **EXP-017**：周期解析解和预热逐样本平台使用同一一阶跨样本状态方程，支持该假设下的交叉求解一致；论文 11 GHz/100 ps 终点不能识别固定复位、跨样本保持、压摆或高阶极点。

后续动态识别应对相同当前目标设置不同前序状态，观察每级主 residue 在相位起点、20 ps、60 ps 和 100 ps 的轨迹。11 GHz 单极点保持模型预测轨迹差约为起始差的 `0.251/0.0158/0.000996`；固定复位从起点即重合。压摆与高阶模型需结合跃变大小和多时间点曲线区分。此实验优先使用电路瞬态或可访问内部节点的测量。

## 对下一项实验的修正

固定长度整数码 DFT 对足够小的阈值扰动通常局部恒定，不能作为连续相位 Fourier 导数的差分真值。最终整数码在固定分段内的内部项为零。[EXP-018 第一门](experiments/EXP_018_STAGE2_BOUNDARY_SENSITIVITY_PHASE1_V0_1.md)因而先隔离单个阈值的边界项：两电平手算导数、完整 ADC 连续积分差分和平台边界码跳变均通过。多边界移动、连续内部读出和拓扑事件留作后续独立验证。

本次使用的是任务分离的 agent 审查，未把“换模型生成第二份相同文档”当作验收标准。下一轮若引入不同模型或人工专家，仍应要求可复算的推导、明确反例、独立数据或高保真物理观测，而非意见票数。

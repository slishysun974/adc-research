# ADC 课题研究章程

> 文档状态：已批准基线 v1.0  
> 最近更新：2026-09-14  
> 性质：可演化的研究共识，不是不可修改的任务合同

## 1. 文档用途

本章程用于记录课题当前已经形成的共同认识，使后续会话能够理解研究目标、阶段关系、方法边界和当前仍未确定的问题。

本章程允许随研究进展修改。后续发现新的证据、论文信息、建模困难或更合适的方法时，可以调整研究问题、技术路线、模型保真度、阶段顺序和交付内容。重要修改应说明修改原因，并在决策记录中保留简要依据。

本章程中的内容分为三类：

- **当前共识**：现阶段应遵守的研究方向；
- **工作方案**：用于启动研究的默认方案，可以被实验结果修改；
- **开放问题**：尚未作出最终决定，需要后续讨论或研究验证。

## 2. 当前研究目标

课题暂定研究方向为：

**建立面向流水线 ADC 的结构化性能预测理论，并进一步研究数字后台校准算法如何通过参数估计、数字校正和附加激励影响 ADC 的频谱性能指标。**

课题不只评价某个校准算法，也不满足于用黑箱拟合直接预测 SFDR/SNDR。希望逐步解释：

1. 输入信号如何经过逐级采样、判决、DAC 重构、残差产生和后级量化形成最终数字输出；
2. 流水线结构、冗余机制和电路非理想如何改变输出频谱；
3. 在不运行完整逐样本仿真的条件下，能够在多大范围内解析或半解析地预测性能指标；
4. 数字后台校准算法的估计误差、收敛过程、门控、dither 和实现限制如何传递到最终性能；
5. 哪些结论可以从行为级模型推广，哪些必须依赖高保真电路或测量数据验证。

## 3. 总体研究结构

当前采用三个依次衔接、但允许迭代返回的研究阶段。

### 阶段一：建立 Gu et al. 架构的 Python 实验平台

以 Gu et al. 的 12-bit、3-GS/s 流水线 ADC 为主要参考对象，建立可逐级观测、可配置非理想、可插拔校准模块的 Python 实验平台。

目前从论文中确认的主要结构包括：

- SHA-less 三级流水线结构；
- 前两级均由 3-bit flash 与开环 MDAC 构成；
- 前两级名义级间增益约为 4，并提供 1-bit 冗余；
- 第三级为 4 通道、8-bit TI-SAR 后端；
- 前两级存在主放大路径和辅助判决路径；
- 数字校准模块包含电容权重、级间增益和分段线性增益非线性校正。

实验平台的首要用途是生成可信的对照数据、检查逐级机制以及验证后续理论，而不是代替理论预测。

工作方案：

1. 建立架构规格表，区分论文明确给出的参数、根据论文推导的参数和研究中自行选择的参数；
2. 首先实现理想静态信号链和数字冗余，再逐项增加非理想；
3. 保存逐级判决、CDAC 输出、residue、冗余状态、最终重构码和频谱结果；
4. 支持无校准、已知参数校正和自适应后台校准等运行模式；
5. 用解析恒等式、边界测试和独立实现进行验证，避免仅凭最终频谱看起来合理就认为模型正确。

阶段性验收条件：

- 理想结构的码转换和数字重构关系可以解释并通过测试；
- 冗余可纠正范围及其失效边界能够被单独验证；
- 每一种非理想均有独立开关、参数定义和可追踪影响；
- 相同配置和随机种子可以复现实验结果；
- 论文未公开的细节均显式记录为假设。

### 阶段二：建立不含数字后台校准的性能预测理论

研究对象是固定物理参数下的流水线 ADC 本体。理论需要从 ADC 的逐级结构出发，而不是先由仿真数据拟合一个灵敏度矩阵，再把该矩阵解释为 ADC 理论。

当前候选路线是：

1. 将量化判决表示为输入区间上的分段映射；
2. 递归传播可行输入区间、逐级码路径和 residue；
3. 推导理想及非理想条件下的数字重构关系；
4. 分析冗余机制对应的码等价关系、可纠正条件和失效边界；
5. 将完整静态信号链组合成分段仿射或分段非线性传输函数；
6. 对给定输入解析或半解析计算复频谱，再由频谱计算 SFDR、SNDR 等指标；
7. 在参数变化导致判决边界移动时，同时考虑区间内部变化和边界变化；
8. 在静态理论验证后，再评估有限建立时间、记忆效应、采样误差等动态扩展。

这里的“解析或半解析预测”允许符号运算、确定性数值积分、区间算法和可证明误差的数值方法；关键要求是预测器不依赖实验平台预先生成的频谱、数值 Jacobian 或拟合系数。

阶段性验收条件：

- 理论预测器与逐样本实验平台采用独立实现；
- 至少在理想、轻度非理想和边界失效三类条件下给出可检验预测；
- 能说明预测误差来自理论近似、参数不确定性还是实验平台保真度；
- 在留出的输入频率、幅度和非理想参数上验证，而不只拟合已知工作点。

本阶段可以根据需要使用 Deep Research，对 ADC 冗余、分段系统频谱、量化器谐波、混合系统灵敏度和动态非线性建模进行专题研究。

### 阶段三：建立数字后台校准对性能指标影响的预测理论

在阶段二的 ADC 本体理论基础上，引入校准观测、dither、门控、参数更新、数字校正和有限字长实现。

工作方案：

1. 先复现 Gu et al. 的 gated-LMS 分段线性校准，作为主要基准；
2. 区分校准结构的表达能力、真实系数已知时的理想校正效果，以及自适应算法的估计效果；
3. 建立校准参数的瞬态偏差、随机波动、稳态误差、收敛时间和非平稳跟踪模型；
4. 审计统计学习理论中的独立性、平稳性、无偏梯度、持续激励、小步长和时间尺度分离等假设；
5. 研究参数误差的统计分布如何通过阶段二的结构化模型传递到输出频谱和性能指标；
6. 在已知仿真结构和主动干预条件下，研究算法总效应、经参数估计传递的效应以及 dither、门控等直接影响；
7. 评估相关理论在行为模型、较高保真模型和硅后观测数据中的不同可识别范围。

统计机器学习和因果推断是本阶段的候选理论工具，不预先承诺某一种方法一定适用。采用任何现有定理之前，都需要检查其假设在具体 ADC 校准闭环中是否成立。本阶段可以按专题使用 Deep Research。

阶段性验收条件：

- 能区分校准参数精度与最终性能指标，不用参数 MSE 直接代替 ADC 性能；
- 对收敛过程和稳态性能均给出预测，而不是只给出单一稳态结果；
- 理论预测经过不同输入、随机种子、算法超参数和非理想强度验证；
- 对不满足的理论假设和不能识别的效应作出明确说明。

## 4. 当前研究原则

以下内容是现阶段的方法原则，但仍可在有充分理由时修订：

1. **实验平台与理论预测器相互独立。** 两者可以共享经过审查的架构参数，但理论预测器不直接调用实验平台生成的灵敏度或输出结果。
2. **先解释结构，再增加算法复杂度。** 在 ADC 本体和冗余机制尚未验证前，不急于比较大量校准算法。
3. **所有参数均可追溯。** 参数应标记为论文给定、外部证据、推导结果、拟合结果或研究假设。
4. **逐层增加保真度。** 从理想静态结构开始，再增加静态非理想、动态非理想、校准闭环和高保真锚点。
5. **避免循环验证。** 不能用同一段实现同时产生基准结果和证明理论正确。
6. **结论必须限定适用条件。** 单个输入、单个 mismatch realization 或单个 PVT 点不能支持普遍结论。
7. **允许理论失败。** 如果某条候选理论不能改善留出数据上的预测，应缩小其适用范围或更换方法。

## 5. 保持弹性的内容

下列内容目前不是固定承诺，可以随着研究修改：

- 课题最终标题和论文叙事重点；
- Gu 架构中未公开部分的具体实现选择；
- 非理想因素的优先级和参数范围；
- 阶段二采用分段积分、级数展开、算子方法或其他数学工具的具体组合；
- 阶段三除 Gu 算法以外是否加入以及加入哪一种对照算法；
- 统计机器学习和因果推断各自在最终成果中的比重；
- 是否以及何时加入 Cadence、晶体管级或测量数据；
- 阶段的时间安排、交付形式和阶段之间的迭代次数。

修改这些内容不表示研究偏离方向，只要修改有证据、有记录，并且仍服务于核心研究问题。

## 6. 当前开放问题

正式开展研究前后，需要逐步回答：

1. Gu 论文公开信息能够支持多高保真度的架构复现？
2. 前两级 flash 阈值、CDAC switching 和数字重构权重的精确定义是否需要额外文献或作者信息？
3. 第一版实验平台是否先忽略 SHA-less 时序和双路径动态差异？
4. 静态解析传输函数的分段数量是否可以通过冗余等价类有效压缩？
5. SNDR 中随机噪声和确定性量化误差应采用怎样的统一测试条件？
6. Gu 校准算法中哪些更新细节和定点实现可以由公开资料完整复现？
7. 后续是否具备可用于锚定的 Cadence 模型、网表或硅后数据？

开放问题应在研究过程中逐项转化为已记录的决策、验证实验或明确保留的限制。

# ADC 课题研究章程

> 版本：v2.0，2026-09-17。四阶段方向已经讨论确认；具体算法和未知增益理论仍待研究。

## 一句话目标

针对事先未知的残差放大器非线性，研究 ADC 内部**实际能观测到什么、数字校正能做到什么、剩余误差怎样影响最终性能**；在此基础上，尝试设计一种在性能、收敛速度和硬件开销之间优于 Gu et al. 基线的后台校准算法。

“更优”是待检验目标，不是既定结果。Gu 论文提供电路与算法基线，不规定真实模拟增益曲线的数学形状。

## 必须守住的边界

1. 模拟放大传输记作 $g$。它对正在运行的数字校准算法**未知**。测试平台可以在幕后设定 $g$，或使用 Cadence 提取的曲线，但算法只接收目标硬件能够提供的码、dither 和状态等信号。
2. Gu 的分段线性函数是**数字校正器**的表示形式；模拟电路不因此成为分段线性电路。旧代码中的合成模拟 PWL 仅是一个已知真值的测试例。
3. 若既不知道 $g$，又没有足以约束它的观测或可信物理条件，就不能给实际 ADC 的唯一 SNDR/SFDR 数值。理论应指出无法确定的原因、所需的新观测，或在条件允许时给出范围。
4. 数学推导成立、两个程序在相同假设下结果一致、结果适用于目标芯片，是三种不同的证据。后两者不能互相替代。
5. 保留 Gu 架构公开信息之外的未知项，例如主辅路径、采样时序、前景修调、噪声及内部位宽。任何自行补足之处必须标为研究假设。

## 四个阶段

### 阶段一：建立并扩展实验平台

保留现有 Gu 候选架构的逐级 Python 平台、历史验收和可复现实验。平台记录逐级判决、主辅输出、CDAC、dither、末级码与最终频谱，用于检查机制和评价算法。现有 Gate A--E 证明的是指定行为模型内的实现一致性，不是目标芯片的完整复刻。

接下来扩充模拟测试条件：不与数字 PWL 分段对齐的平滑曲线、局部强非线性、不同输入分布、噪声和有来源的电路数据。将用于调试／选择算法的情况与最终留出测试分开；算法不得读取后台真值或 oracle 系数。

**产出与验收：**可复现的训练／测试协议、逐级 trace 和独立的理想极限／边界测试。新曲线和动态机制是否代表电路，须另有 Cadence 或测量证据。

### 阶段二：重建完整信号链与校准闭环理论

把旧“无校准 ADC 理论”和旧“校准影响理论”合成**同一阶段**，使理论从输入、逐级主辅残余电压与判决，一直连到数字观测、系数更新、校正输出和性能指标。一般模型中不预设 $g$ 为仿射或 PWL，也不预设一种动态初值机制。

依次回答：

1. 在规定输入和 dither 下，实际可用的数字观测能否区分不同的模拟误差？这里的“可辨识”就是能否凭数据把两种情况分开。
2. 即使数据和系数都理想，给定数字校正函数、码宽与量化规则，哪些误差仍无法消除？
3. 校准系数怎样随样本变化，何时会停滞、波动或发散？这些变化如何经整个信号链进入码边界、频谱和 SNDR/SFDR？
4. 在未知 $g$ 时，哪些结论对所有允许的曲线成立，哪些需要测得的曲线、误差界、输入覆盖或动态证据？

现有仿射区间反算、闭式谱积分和一阶周期解保留为**给定传输或指定动态模型下的特例及验证工具**，不是未知增益问题的通用解。旧 TeX/PDF 和 EXP-015--019 的原始结果不改写为新的物理证据。当前理论入口为 [未知增益完整链路框架](theory/UNKNOWN_GAIN_END_TO_END_FRAMEWORK_V0_1.md)，其中未完成的定理必须标明状态。

**产出与验收：**一般信号链和校准信息边界、不能识别的反例、有条件的性能关系／界限，以及能在非 PWL 留出条件下检验的理论预测。没有足够信息时，诚实给出“不能唯一预测”。

### 阶段三：深入分析并实现 Gu 基线

以 Gu 的 gated-LMS 数字 PWL 校准为主要比较对象。先核对公开公式、观测总线和更新顺序；论文未公开的位级和时序语义采用明确标记的候选实现。结合阶段二研究各段有效激励、收敛时间、稳态误差、输入分布改变和有限字长影响，并把系数诊断与最终 ADC 性能分开报告。

实现公平的浮点、定点和可综合 RTL/Verilog 基线。硬件比较须说明时钟、吞吐量、位宽、目标工艺或器件与综合约束；软件运行时间或单独的 RTL 功能仿真不能代替面积、时序与功耗评估。

**产出与验收：**可复现的 Gu 算法基线、理论与实验对照、硬件成本基准和经过证据筛选的改进问题。不把仅在合成 PWL 上有效的现象说成普遍规律。

### 阶段四：设计并检验新算法

根据第二阶段揭示的能力边界和第三阶段发现的真实瓶颈，提出一个或多个候选算法。方向可以涉及激励、门控、更新、数字表示或它们的配合，但不预先指定“新算法必定有效”，也不能让候选算法访问 Gu 基线没有的信号而不计成本。

在预先冻结的指标和相同资源约束下比较：未见过的模拟曲线／PVT／输入条件上的 SNDR、SFDR、收敛样本数、失效概率、面积、关键路径、功耗和实现复杂度。若只在已知合成曲线上胜出，须收窄结论或放弃方案。

**产出与验收：**经过独立留出、定点和硬件评估的新算法；若没有稳健收益，也要给出明确的失败原因和适用范围。

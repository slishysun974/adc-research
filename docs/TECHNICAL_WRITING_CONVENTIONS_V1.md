# 研究文档术语与写作约定 v1

本项目面向电路、ADC 测试和数字校准读者。正文先说明信号从哪个节点到哪个节点、哪一个判决或测量量改变，再引入数学记号。数学术语在证明中可以保留；首次出现时须给出其电路含义和适用条件。历史实验编号、配置键和源码字段保持原样，以便复现。

## 信号链和模型对象

| 统一写法 | 首次出现时说明 | 避免的歧义 |
|---|---|---|
| 级间残余电压（residue） | 前级判决并经 CDAC 扣除后，送往后级的模拟电压；必要时区分放大前与放大后 | 不把 `residue` 当成最终数字输出，也不把两条主辅路径合成一路 |
| 主路、辅助判决路 | 主路输出送后级 CDAC，辅助路输出送后级 flash；明确采样时刻 | “辅路是主路副本”仅是已命名行为近似 |
| 模拟放大传输 $g_i$ | 电路决定、目前未知的输入残余电压到输出电压关系 | 不能把数字 PWL 校正的分段当作放大器的物理拐点 |
| 测试用模拟近似 $\widehat g_i$ | 为检查预测算法而预设的模拟传输；当前部分实验选用分段一次函数 | `truth` 是实验内部名称，不是芯片真值 |
| 数字校正函数 $f_i$ | 量化后对内部数字码作用的 PWL 函数，系数由后台 LMS 更新 | 与模拟 $g_i$、测试用 $\widehat g_i$ 分开 |
| 已知传输下的理想逆校正 | 从预设模拟传输反推的比较上限 | `oracle` 是实验内部名称，不表示可在芯片运行时获得 |

## 预测与验证用语

| 数学或实验术语 | 面向电路读者的首次表述 | 后续使用 |
|---|---|---|
| 路径胞腔 | 固定各级判决和末级码的连续输入区间；若还固定模拟近似的分段，称细分输入区间 | 优先写“判决输入区间”或“细分输入区间”；数学定义处可注明“胞腔” |
| 仿射映射 | 斜率加偏置的一次关系 $y=ax+b$ | 证明或公式可用“仿射”，结论写清哪个电压对哪个输入呈一次关系 |
| 阈值原像 | 把后级阈值沿模拟信号链反算到 ADC 输入端得到的边界 | 优先写“输入端阈值位置”或“反算的输入边界” |
| 码域测度 | 一个输出码对应的输入总宽度；给定输入概率分布后才可转为出现概率 | 报告结果时写宽度及其单位 |
| 性能泛函 | 由输出谱线计算 SNDR、SFDR 等指标的规则 | 指标名称优先；只在讨论函数对函数的映射时用“泛函” |
| 观测等价 | 在指定激励和观测量下，两种电路模型给出相同结果，因而该测试无法区分它们 | 写明激励、观测量和所缺的区分实验 |
| 拓扑不变 | 参数变化时，码转换边界的个数及先后顺序不变 | 优先写出这两个可检查条件 |
| 均值场 | LMS 在固定系数下的平均更新方向 | 首次给出平均所依据的输入和 dither 分布 |
| 留出条件 | 未用于建立模型或选择参数、只用于核对预测的输入或参数组合 | 写明留出什么、样本数及比较量 |
| 锚点 | 论文报告或电路测量提供的参数参考值 | 直接写来源、数值和换算所需的附加假设 |
| Gate A/B 等 | 项目内部的验收阶段编号 | 首次写“验收阶段 A/B（Gate A/B）” |

正弦相位区间、复傅里叶系数、DNL、INL、SNDR、SFDR、ENOB、PWL 和 LMS 是所用分析或 ADC 测试的标准术语，可以保留；在跨领域章节首次出现时说明计算对象、单位和条件。`truth`、`oracle`、`slice occupancy`、`gate count` 仅在源码标识、配置键或引用历史运行字段时原样保留，正文分别写“预设模拟传输”“理想逆校正”“分段访问次数”“有效更新次数”。

## 段落与证据表述

1. 每个公式前写清电路入口、要求解的量和采用的假设；公式后说明该量怎样影响下一级判决或最终码。
2. 数学恒等式、同一行为模型下的双实现一致、电路瞬态或硅后测量属于不同证据。结论写到实际达到的层级，并给出条件和样本范围。
3. 实验段先报告结果，再给比较对象、单位、误差和不能外推的范围。避免“显著”“准确”“物理验证通过”等无对应证据的判断。
4. 对未知模拟传输，只能给出有条件的预测。使用局部近似时说明近似如何确定、有效输入范围和误差界；没有这些信息时，不给出芯片级 SNDR/SFDR 精度声明。
5. 版本化历史报告保留原始实验编号和数据。后续概念修订写在文首勘误或新的审查文档中，不悄然改写原运行结论。

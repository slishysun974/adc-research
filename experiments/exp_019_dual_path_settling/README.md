# EXP-019：第一级独立辅路的判决与周期建立

对照 Gu 候选 A 的仿射辅路约简，建立两个单独的第一级模拟输出：主路驱动第二级 CDAC，辅路驱动第二级 flash。此实验验证**指定行为假设**的数学和实现，并量化两种模型何时给出不同内部判决和最终码。

## 行为假设

- 两路共享第一级逻辑 CDAC 求和节点；辅路静态目标为该节点的独立线性增益加 offset。若主路使用合成模拟 PWL truth，辅路不继承该 PWL 失真。
- 第一级主、辅与第二级主各自采用一阶跨样本保持递推；带宽与相位时间通过 $\rho=\exp(-2\pi BT)$ 换算。论文数值只作条件参数锚点，不证明芯片采用单极点或跨样本保持。
- 不启用数字后台校准。沿用 `gu_behavioral_v1` 的候选 flash/CDAC 码制、dither 约定和末级重构。

## 验证门

1. 以可手算的 0.125 阈值反例确认主、辅末值可位于阈值两侧。
2. 静态主路合成 PWL 条件下，独立区间预测器按辅路阈值原像切分；用留出输入比较 $q_2$、最终码和可纠正状态。
3. 对正负 3% 辅路增益、两个幅度、两个相干频点和三组建立条件，理论直接求三个状态的周期边界；逐样本平台从隐藏初值预热。比较两路输出、第二级判决、后级输出和最终码。
4. 主、辅建立因子相等且静态传输仿射相关时，双路径结果须退化到旧约简模型；分路条件下应出现至少一个不同的 $q_2$。

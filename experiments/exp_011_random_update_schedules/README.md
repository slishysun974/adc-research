# EXP-011：随机更新调度与稳态方差

本实验在 EXP-010 的两级浮点自适应校正基础上，引入两个相互独立的软件伪随机
序列，并比较三种更新方式：

1. 每个样本使用瞬时相关量更新；
2. 每 30 个样本选取一个瞬时相关量更新；
3. 每 30 个样本使用一次分块平均相关量更新。

三种方式对每个重复试验使用相同的输入码和 dither 符号序列，以减少比较方差。
后两种方式的单次更新步长设为逐样本方式的 30 倍，使平均系数变化速率在一阶
近似下按 ADC 输入样本数归一化。该步长调整和分块平均方式属于研究设定；论文
只报告四路 750 MHz 处理和按 30 抽取，没有公开系数提取单元的完整时序与累加
规则。

运行：

```powershell
$env:PYTHONPATH='src'
python experiments/exp_011_random_update_schedules/run.py --run-id <unique-run-id>
```

输出包括每次重复试验的最终系数、分段更新次数、收敛记录、稳态系数方差、
dither 互相关、跨级相关量和全码评估结果。

正式稳态运行从 EXP-010 的两级自适应结果初始化，并丢弃前 60000 个样本后再
计算稳态统计。另保留从单位系数初始化的探索性运行，用于比较收敛轨迹；两类
运行不混用“收敛速度”和“稳态方差”的统计口径。

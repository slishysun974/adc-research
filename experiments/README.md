# 可复现实验

实验用于核对明确的理论问题和候选机制。当前任务看 [STATUS](../docs/STATUS.md)，全部已有工作看 [实验报告索引](../docs/reports/experiments/README.md)，理论及结果分析的组织方式见 [CONTRIBUTING](../CONTRIBUTING.md)。本页不重复维护近期指标和下一阶段。

## 一个正式实验的结构

```text
exp_NNN_short_name/
  README.md
  config.yaml 或 protocol.json
  run.py 或 run.ps1
  必要的 verify/analyze 等核对入口
```

README说明问题、假设与来源、对应理论推导、控制变量、预算、指标、验收和复跑命令。新协议说明检验什么命题、预期什么及哪些结果会收窄判断；不要给历史冻结协议补写新字段。

运行入口优先调用正式源码。EXP-056／057这类实验局部加速实现属于明示例外：必须先与原平台／更新器独立核对，保存端点、门限、舍入、生效时刻和来源指纹；不能因加速而换模型或把它自动提升成正式源码。不同入口格式不要求强行改名。

## 信息与运行边界

平台含模拟真值；通过 `evaluation/observations.py` 缩为数字观测后才能进入在线校准。`evaluation/oracle.py`、真实输入和目标码只能用于离线控制／评分。历史EXP-010／011／013的配置来源修订见 [审计](../docs/stages/03_gu_baseline/ONLINE_INFORMATION_BOUNDARY_AUDIT_V1.md)。

运行结果保存到 `artifacts/runs/<实验>/<运行>/`；选择新的运行目录，不覆盖成功或失败记录。专用配置随实验，共享架构／非理想配置进入configs。保留实际学习观测、转换、提交、每段有效支持及资源计数；同学习量与同转换时长分别比较。

先预检，再做必要运行；全部种子、裁剪和失败保留。实验报告解释预测和结果的关系，证明写在理论文档，阶段分析写在报告目录。理论或只读分析不必为形式另设EXP编号；已有EXP-029的结果由测量信息理论文档承载。

原实验编号和路径保持。EXP-015—019及早期模拟PWL控制只证明指定模型内的关系，不自动成为未知增益或芯片证据。EXP-055—057已有结果请先复用，不因读取当前计划而自动重新运行。

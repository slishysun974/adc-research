# EXP-023：统一全链路整数码比较

本实验固定候选数字总线、Gu 浮点更新、连续随机训练流、独立验证及最终留出记录，比较同一个含 dither 物理链上的名义重构输出和 Gu 校准输出。它是静态合成模型的协议检验。

- 在线输入恰为两级符号码、末级中心码、两级 dither 标记。算法不接收模拟传输、输入真值、物理过载标记或目标码。总线是当前候选实现，尚未由芯片内部资料核实。
- 物理模型固定为静态、无噪声；两级辅助比较路径采用架构配置中的主路仿射副本，dither 每次转换独立抽取一对符号。它们是当前行为假设，不是芯片的已测时序或主辅传输。
- 名义基线是平台按架构权重重构、扣除数字 dither 副本的整数最终码。Gu 路径对相同五字段记录先做第二级再做第一级 PWL 校正，并用最近偶数舍入和 `[0,4095]` 裁剪形成整数最终码。
- 训练为每条曲线从全 1 系数开始的 131072 个独立连续随机输入；两级 dither 符号对随机抽取。步长、分段和范围沿用 EXP-021，不按新曲线重选。
- 验证集只在预定样本数检查整数码 MAE。首次达到名义验证 MAE 的一半，且此后**所有已采样检查点**保持达标的样本数，记为“观察到的持续达标检查点”；它不是精确收敛时间或稳态证明。
- 最终 4096 点随机输入和 8192 点相干正弦用独立种子，只在训练终点评分。两路径的最终码、MAE、SNDR/SFDR 使用同一记录。历史 PWL 为开发对照，两个新三次曲线是预先固定的合成形状。

已审查的结果与适用范围见[EXP-023 报告](../../docs/reports/experiments/EXP_023_FULL_CHAIN_PROTOCOL_V1.md)。

当前模型未包含噪声、独立非线性辅路、真实 PRNG/抽取时序、定点或 RTL。即使三条曲线均通过，也不能推断真实芯片或任意未知曲线的表现。

# EXP-024：独立辅路对 Gu 全链路结果的影响

沿用 EXP-023 的同一架构、两条三次主路模拟曲线、训练输入／dither 序列、步长、验证检查点、最终随机及正弦留出。每条曲线各从全 1 系数冷启动两套 Gu 状态：

1. **仿射副本**：第二级 flash 输入为第一级主输出乘固定比例再加 offset，即 EXP-023 行为约简。
2. **独立线性辅路**：辅路观察同一个第一级 CDAC 放大前节点，以独立线性放大得到第二级 flash 输入；第一级主路仍取既定三次曲线。主路和第二级模拟传输、量化器、dither、输入序列均与仿射副本相同。三个建立因子固定为零，因此这是纯静态路径敏感性实验，不是芯片动态模型。

另有理想线性控制：主路也为名义线性，两个候选必须逐样本恢复相同的第二级判决、后端码、最终码、Gu 系数及评分。两个三次曲线用于测量路径差异。训练只向 Gu 更新提供相同结构的五字段数字样本；主辅模拟输出仅用于离线比较。最终输出按最近偶数舍入及 `[0,4095]` 裁剪的整数码评价。

```powershell
$env:PYTHONPATH = 'src'
python experiments/exp_024_independent_auxiliary/run.py --run-id <unique-run-id>
```

结果位于 `artifacts/runs/EXP_024/<run-id>/summary.json`。物理过载／数字饱和为有效性门，性能改善不作为通过条件。独立辅路取线性只是可证伪的合成假设，不能据此推断真实芯片辅路一定线性。

结果、交叉系数诊断及限制见[EXP-024 报告](../../docs/reports/experiments/EXP_024_INDEPENDENT_AUXILIARY_V1.md)。

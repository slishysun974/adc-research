# EXP-012：定点 PWL 校正数据通路

本实验把两级已知系数 PWL 校正从浮点参考实现转换为整数定点实现。论文明确
报告校正系数为 11-bit、10 个小数位，数字处理单元在全部计算中保持 3 个小数
位，但没有公开乘法舍入、偏移量累加、负数右移、中间总位宽和最终整数码舍入
规则。

实验穷举比较以下规则：

- 系数量化：向下取整、舍入到最近偶数；
- 乘法和缩位：向下取整、舍入到最近偶数；
- PWL 偏移量：系数求和后统一舍入、每个系数项分别舍入后求和；
- 最终整数码：向下取整、舍入到最近偶数。

所有组合都保留两级局部 dither 扣除顺序，并在 4096 个输入码中心和四种 dither
符号组合上检查误差、单调性、饱和与实际所需中间位宽。

运行：

```powershell
$env:PYTHONPATH='src'
python experiments/exp_012_fixed_point_pwl/run.py --run-id <unique-run-id>
```

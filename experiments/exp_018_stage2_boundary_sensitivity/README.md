# EXP-018：静态码谱的边界灵敏度，第一验证门

本实验先验证最终整数码的**连续相位 Fourier 系数**对单个前级 flash 阈值偏移的导数。固定局部输出码不随参数变化，因而只检验移动边界项。非零内部项使用单独定义的连续读出手算基线展示，不并入整数码结果。

1. 两电平阈值量化器提供 $c_0'$、$c_1'$ 的封闭答案，以及正弦峰值相切时的病态趋势。
2. 在 Gu 候选 A 的轻度静态非理想条件下，选择第一级两个不与邻近码边界重合的阈值，先由完整传输取得边界两侧码，再按两个正弦相位交点计算解析导数。
3. 用独立重建的 $\alpha+h$ 和 $\alpha-h$ 静态传输及连续相位积分做中心差分；逐样本平台只核对边界两侧的最终码跳变。
4. 展示固定长度码记录在足够小的阈值扰动下局部恒定，说明它不能充当连续导数的差分真值。

范围限于冻结的静态行为模型和拓扑不变的参数邻域。该门通过后，再处理其他参数导致的多边界移动、连续内部读出的内部项及拓扑事件。预设问题、限制和判定见 [规格](../../docs/specifications/STAGE2_BOUNDARY_SENSITIVITY_SPEC_V0_1.md)。

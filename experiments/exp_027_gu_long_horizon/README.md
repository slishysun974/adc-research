# EXP-027：Gu 逐转换更新的有限长续跑

## 问题和固定条件

EXP-025 的 131072 次转换终点具有明显种子差异和验证误差反弹。本实验检查把同一候选继续训练三倍长度后，终点之间的差异及单条轨迹的后段波动是否仍存在。它沿用 EXP-023 的独立随机验证、随机留出与 8192 点相干正弦，并沿用 EXP-025 的两条合成三次主路、独立线性辅路、四个种子、逐转换更新、浮点系数及固定步长。

从 EXP-025 保存的 `every_sample` 状态继续到累计 524288 次转换。每个种子仍使用原来的随机数流；前 131072 次只消耗随机数，不重复更新。起点重新评分必须逐项复现 EXP-025 的最终验证 MAE、随机留出和正弦留出。模拟曲线只用于生成记录和离线评分；在线更新只读五字段数字观测。

## 变量、指标与验收

唯一变化量是累计训练长度。每 65536 次记录独立验证集的最终整数码 MAE、两级系数及门控次数；在 131072、262144、393216、524288 次另测随机留出 MAE 和正弦 SNDR/SFDR。每个阶段保留每个种子的原始结果，不从验证结果挑选最优系数。协议门要求起点精确重现、检查点和更新计数一致、系数有限且在界内、零物理过载和零留出数字饱和。

这是有限窗口稳定性诊断。即使后段变化变小，也不称为随机逼近的稳态或芯片收敛；四个种子不能估计失败概率，芯片真实四路抽取时序、逐位总线与主辅动态没有在本实验实现。

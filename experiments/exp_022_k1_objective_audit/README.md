# EXP-022：第一段去相关目标与码误差目标

本实验是 EXP-021 三次压缩曲线的**事后机制诊断**。固定第 64 轮两级数字 PWL 系数，仅改变第一级第一段斜率 `k1`。模拟传输、输入和理想目标码只用于离线评分，不进入在线 Gu 更新。

比较三批样本：原训练的 4096 个码中心乘四组平衡 dither；每个码内取一个固定种子随机偏移并复制四组 dither；以及 EXP-021 使用的 2048 条随机验证输入。前两批各 16384 条，能在相同分布和 dither 配对下比较去相关零点与最小平均绝对码误差。第三批用于核对已报告的验证码误差，因每个输入只配一组随机 dither，不把它的经验相关零点解释为平衡 dither 的平均更新方向。

固定其余系数时，第一段斜率的码响应为严格仿射，故去相关零点可由一次方程求出，平均绝对码误差的极小值可由加权中位数求出。推导、结果及限制见[正式报告](../../docs/reports/experiments/EXP_022_K1_OBJECTIVE_AUDIT_V1.md)。

从项目根目录运行：

```powershell
$env:PYTHONPATH='src'
python experiments/exp_022_k1_objective_audit/run.py --run-id frozen_v2_20261001
```

运行产物写入 `artifacts/runs/EXP_022/<run-id>/summary.json`。配置内保留 EXP-021 第 64 轮系数的数值副本，避免复现依赖被忽略的历史运行产物。脚本拒绝覆盖已有运行编号。

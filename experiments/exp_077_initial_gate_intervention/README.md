# EXP-077：原合法初态连续影子第二门的有限反馈

本实验只回答一个信息问题：EXP-076的有限门源收益，能否在不使用未来均值的预定初态参照中出现。固定625前缀／1/4、原八Q22初态、后级保持、full120和[128,136)八块；原模型、输入顺序和终点不变。不是新算法验收。

## 预运行推导、信息与预测

原完整数字初态导出为K0=(1048,1067,1024,1024,1081,1089,1024,1024)，前级连续影子系数κ0=K0前四/1024。后级仍按原Q3重构同一个当前数字字，得到前级raw和四基函数ψ。唯一替换的门为

$$G_{0,ws}=\mathbf1\{|\psi_{ws}^{T}\kappa_0-64d_{1,ws}|\ge128\kappa_{0,1}\}.$$

κ0只由运行前已可见的原八数字初态确定，不读取未来平均、目标或模拟真值，不按成绩选择。当前字及原数字几何确定ψ，因此本定义的门逐字可由因果数字信息构造。它的连续前级影子不同于初态Q3门；即使系数在合法格点，连续读出127.96875与Q3读出128仍能处于门阈值两侧。它也不同于把当前实际数值与初态阈值比较。

新路径A0与原完整Q22初态相同。每窗用自己的Q1.10导出重新计算真实Q3数值、其他三个门及完整四个前级请求，第二请求只替换为64d1·Y1_Q3·G0；按原1/4步长、120槽、一次最近偶数Q22舍入／裁剪提交。所有120输出用提交前状态。后级保持；高段请求与裁剪全部计算并报告。

原源不依赖前级数字系数，按[两级§38](../../docs/theory/STATIC_CASCADE_MILLION_SUPPORT_AND_PROJECTION_V1.md#38-均值影子第二门的有限反馈收益ng-204046补证)的窗口归纳，同初态／同字／同门参照确定唯一完整反馈路径。改变κ̄为κ0只改变门参数来源，其他转移合同相同；若两门对所有字相同则两路径逐窗完全相同，若有门差则需重算反馈，不能直接减旧门向量或推断收益。

预定主预测为新路径−原full的整期整数MSE<0，使用原目标半径认证。若成立，只支持此例这种有限改善不必知道未来均值；若增损或跨0，仅否定／限制此初态参照，不推所有在线策略必须知未来。新路径−保持、新路径−原均值影子以及原full−保持为预定配对，共用输入不当独立样本。

原full120保留四字30倍观察。影子后级Q3、连续前级、四基函数、门和245760字节掩码缓存另外计成本。预计算缓存是离线执行方法；逐字因果可构造性不等于已实现同成本线上方案。目标与原均值路径输出仅作离线配对评分。

## 执行与停止

从仓库根依次运行`python experiments/exp_077_initial_gate_intervention/run.py prepare --out <新目录>`，再按顺序运行`run`、`verify`、`check --out <同目录>`。prepare冻结协议／参数、源／执行SHA、所有阶段预算及八有界控制。复用EXP-076参数化向量转移与独立标量重建核，不改旧源码／数据。

两窗旧full重放及Fraction／正式读出、原bank未改坐标与独立第二请求先通过；主路径只到原2048窗终点。独立标量数字—导出分组重建全部输出／请求／状态／门，固定0／1024／2047窗另作正式探针，精确相位评分与独立八块bigint残差平方核对四条输出及四配对区间。失败前缀／全部超额和未认证保持，不按成绩扩种子、期限、政策或目标精度，不使用6007／8009。

协议冻结、预检、实验、独立核对和报告分别记录。完成这一例主预测及必要配对就停止，回到学习信息怎样产生实际剩余误差和可改善空间的主问题。

本定义已完成，原运行不重跑。结果见[报告](../../docs/reports/experiments/EXP_077_INITIAL_GATE_INTERVENTION_V1.md)：整数MSE3.445446，较原full增损+0.111519，预定改善预测被否定；对未来均值影子增损+0.385534，原目标条件均认证。全路径及独立评分一致，成本审计漏项补账后超原限，完整资源合同失败保留，不将原计数器布尔值当完整预算通过。没有新算法、留出消费或参照搜索。

# EXP-020：有限数字观测下的增益不可辨识反例

本实验回答一个限定的问题：即使训练覆盖候选架构的全部 4096 个理想输入码中心和四种 dither 符号组合，训练时的数字记录是否足以唯一确定另一条输入记录的输出性能？本例的答案是否定的。

## 条件与方法

- 使用冻结的 `gu_behavioral_v1` 静态行为架构。第一级、辅路、第二级判决、CDAC、末级 SAR 和码制均保持相同；只改变第二级主路的静态模拟传输。
- 参考传输为理想增益。另一条传输在第二级**理想输出幅值** `0.50390625` 至 `0.51171875` 内加入高度 `0.0005` 的局部扰动，区间外与参考完全相同。该区间位于数字 PWL 的 `0.5` 和 `0.75` 分段边界之间，并不沿数字分段边界构造。其相对名义增益的各段斜率系数为 `1, 1.128, 0.872, 1`，故在模型域内连续、奇对称且严格单调。这是人为构造的反例，不是芯片测得的曲线。
- 训练记录固定为 4096 个输入码中心乘四种 dither 组合，共 16384 个样本。逐样本比较算法允许读取的五个数字字段，以及未经 PWL 校正的最终码。两个模型的训练输入和 dither 也完全相同。
- 留出记录为 8192 点相干正弦，幅度 `0.901`、频点 `251`、相位 `0.2718281828459045`；四种 dither 组合周期轮换。比较末级码、最终码和同一 FFT 口径下的 SNDR/SFDR。

运行：

```powershell
$env:PYTHONPATH='src'
python experiments/exp_020_unknown_gain_identifiability/run.py --run-id <unique-run-id>
```

脚本把完整条件、源码摘要、验收结果和首个不同码保存到 `artifacts/runs/EXP_020/<run-id>/summary.json`。正式结果和理论范围见[实验报告](../../docs/reports/experiments/EXP_020_UNKNOWN_GAIN_IDENTIFIABILITY_V1.md)。

另有[条件性范围脚本](bound_family.py)，只在名义与扰动传输的插值族内，沿末级 SAR 电压区间、所有可能末级码、冻结单位 Gu 校正和最终频谱逐步求范围。运行 `python experiments/exp_020_unknown_gain_identifiability/bound_family.py --run-id <unique-run-id>`；解释与冻结结果见[有限记录性能界限](../../docs/theory/FINITE_RECORD_PERFORMANCE_BOUNDS_V1.md)。它没有把两条合成曲线变成芯片的物理误差范围。

## 结论范围

训练记录相同意味着任何只读这些记录、从同一初始状态出发的确定性数字校准器在训练后状态相同。这不能保证两条曲线在未见输入上的原始码或性能相同。本实验展示这一点；它没有运行 Gu 在线更新，也没有证明 Gu 算法在持续测试或真实芯片上无法适应。记录上的频谱差异也不代表典型芯片误差规模。

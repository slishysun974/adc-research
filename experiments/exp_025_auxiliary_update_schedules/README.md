# EXP-025：独立辅路下的更新时序与随机种子

## 问题

EXP-024 只使用一条随机训练序列，并在每次转换后更新系数。这里保留 EXP-023 冻结的两条三次主路、独立线性第一级辅路、五字段数字观测、训练长度、验证与留出记录、最终整数码规则；改变更新时序与训练随机种子。比较的对象是同一候选 Gu 校准器在给定行为模型中的有限训练结果。

## 冻结协议

- 训练种子预先固定为 `20261011, 20261021, 20261031, 20261041`。每个曲线／种子的三种时序读取完全相同的模拟转换与 dither 序列。
- `every_sample`：每次转换形成观测并更新，使用 EXP-023 原步长。
- `one_sample_per_30`：每 30 次转换只取末尾一次的瞬时观测来更新，步长乘 30。
- `block_mean_30`：每 30 次转换在同一系数状态形成 30 个观测，对门控学习量取块平均后更新，步长乘 30。末尾不足一块的两个样本不更新。
- 步长乘 30 是按原始转换次数归一化**一阶平均漂移**的研究选择，不是论文披露的硬件数值。单序列取样与块平均都只是对已披露抽取节奏的候选解释；没有实现四路单元的逐周期相位、芯片系数提取器或输出端 4:1 多路复用。
- 固定验证检查点为 `0, 4096, 16384, 32768, 65536, 131072` 次转换。验证记录、独立随机留出和相干正弦留出均沿用 EXP-023，所有种子共用，不据留出评分调参。

`run.py` 通过 `platform/dual_path_settling.py` 生成独立辅路转换，经 `evaluation/observations.py` 压缩到五字段后调用正式 `calibration/` 更新实现。训练不读取模拟 truth、预期最终码或留出答案。物理过载必须为零；数字饱和、MAE、SNDR/SFDR 均作为结果如实报告，不预设改进方向。

## 运行

在仓库根目录执行：

```powershell
$env:PYTHONPATH='src'
python experiments/exp_025_auxiliary_update_schedules/run.py --run-id frozen_v1_20261001
```

结果位于 `artifacts/runs/EXP_025/<run-id>/summary.json`。运行入口拒绝覆盖已有结果。正式解释见 [EXP-025 报告](../../docs/reports/experiments/EXP_025_AUXILIARY_UPDATE_SCHEDULES_V1.md)。

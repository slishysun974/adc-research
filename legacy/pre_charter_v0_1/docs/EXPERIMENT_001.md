# Experiment 001：无校准流水线 ADC 的全因子干预基线

## 1. 目的

建立第一个可复现基准，回答两个最基础的问题：

1. 结构非理想是否能通过逐级模型形成可测的 SFDR/SNDR 退化和 residue folding？
2. 在固定输入与固定 mismatch realization 下，能否把组合性能损失一致地归因给各个被主动干预的因素？

本实验不包含数字后台校准，因而是后续“校准前—校准后”比较的零点。

## 2. 配置

- 两级行为模型：前级 3 bit，后级 9 bit；
- 输入：幅度 0.90 FS 的相干正弦；
- 记录长度：32768；输入 bin：127；
- 随机种子：20260914；
- 活跃干预强度：级间增益误差 1.5%，CDAC 码相关误差 0.08 前级 LSB RMS，比较器阈值失调 0.06 前级 LSB 标度；
- 三个因素的全部 `2^3=8` 个组合共享同一个随机方向，即共同随机数设计；
- 后级量程外的残差被末端码饱和，并记录为 folding/overload event。

CDAC 误差方向已去除最佳 affine offset/gain 分量，因此该因素主要代表码相关非线性；级间增益误差由独立因素承担。

## 3. 结果

| 干预 | SFDR / dB | SNDR / dB | 阈值跨越率 | folding/overload 率 |
|---|---:|---:|---:|---:|
| ideal | 97.90 | 73.06 | 0.0000% | 0.0000% |
| CDAC mismatch | 35.30 | 30.60 | 0.0000% | 6.8420% |
| comparator offset | 69.73 | 54.86 | 2.8748% | 2.8778% |
| gain error | 64.00 | 56.31 | 0.0000% | 1.1780% |
| CDAC + comparator | 35.55 | 30.65 | 2.8748% | 7.8674% |
| CDAC + gain | 35.18 | 30.46 | 0.0000% | 7.6416% |
| comparator + gain | 63.06 | 52.68 | 2.8748% | 3.4607% |
| all active | 35.43 | 30.51 | 2.8748% | 8.4290% |

理想 SNDR 为 73.06 dB，与 12-bit 理想量化器约 74 dB 的常见量级一致，可作为第一层 sanity check。这里将 `|residue| = 1` 视作合法满量程端点，只有严格超出后级量程才记为 folding/overload。

## 4. 干预归因

以“相对理想情况损失了多少 dB”为 value function，对完整全因子响应面计算精确 Shapley 值：

| 因素 | SFDR 损失归因 / dB | SNDR 损失归因 / dB |
|---|---:|---:|
| gain error | 12.474 | 6.017 |
| CDAC mismatch | 40.578 | 29.887 |
| comparator offset | 9.424 | 6.648 |
| 合计 | 62.476 | 42.552 |

合计分别等于 ideal 与 all-active 的实际 SFDR/SNDR 差值，说明归因计算满足效率恒等式。

## 5. 当前结论

- 模型已经把三类结构参数、判决码变化、残差越界和频谱指标连成一条可观测链路。
- 在**当前强度与当前 seed**下，CDAC 码相关 mismatch 主导性能损失；由于 SFDR 取最大 spur，其他误差加入后不一定继续线性降低 SFDR。
- comparator offset 产生明确的阈值跨越事件；gain error 不改前级判决，但会通过残差放大造成后级越界。
- 组合响应明显不是单因素损失的简单相加，因此下一阶段必须保留交互项和边界项。

## 6. 不能从本实验推出的结论

- 不能断言真实芯片中 CDAC mismatch 必然占主导；三个扰动的单位与强度尚未由具体工艺锚定。
- 不能用一个 seed 推断统计分布或置信区间。
- Shapley 值是这个已知仿真干预面上的精确归因，不是从纯观测硅后数据识别出的因果效应。
- 当前模型未区分回折、饱和和数字纠错冗余失效的全部物理细节。

## 7. 下一实验

Experiment 002 将做输入幅度 × 非理想强度 × mismatch seed 扫描，并把事件样本分为：

- 只改变连续残差、不改变离散码的 smooth samples；
- 发生阈值跨越的 decision-boundary samples；
- 发生后级量程越界的 folding samples。

随后分别计算三类样本对复频谱 bin 的贡献，用于检验 H2：普通局部 Jacobian 在边界附近的误差是否能由事件项解释。

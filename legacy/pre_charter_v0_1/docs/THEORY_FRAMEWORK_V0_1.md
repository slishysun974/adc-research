# 统一理论框架 v0.1

## 1. ADC 作为混合系统

设第 `l` 级输入余量为 `r_l[n]`，离散判决为 `d_l[n]`。一个包含阈值失调、DAC mismatch 与残差非线性的通用级模型为

```text
d_l[n] = Q_l(r_l[n]; τ_l + Δτ_l)
u_l[n] = DAC_l(d_l[n]; w_l + Δw_l)
r_{l+1}[n] = G_l(r_l[n] - u_l[n]; g_l, a_l) + η_l[n]
```

其中 `Q_l` 是分段常数映射，`τ_l` 为判决阈值，`w_l` 为 DAC 元件权重，`g_l` 为残差增益，`a_l` 表示非线性参数。由于 `Q_l` 在阈值处不光滑，ADC 不能在全工作区内只用一个普通 Jacobian 描述。

将物理参数写成

```text
φ = [Δg, Δw, Δτ, a, ...]^T.
```

最终数字输出是 `y[n] = F(x[0:n], φ, θ̂[0:n])`，其中 `θ̂` 是数字校准参数轨迹。

## 2. 光滑项、边界项与交叉项

对固定输入序列与 FFT 记录，输出复频谱向量记为 `c`。在不发生判决拓扑改变的局部区域内，使用一阶展开：

```text
c ≈ c₀ + Γ_ADC Δφ + Π_cal Δθ.
```

但当扰动让样本跨越阈值或让残差进入/离开后级量程时，必须加入事件项和物理—校准交叉项：

```text
c ≈ c₀
    + Γ_ADC Δφ
    + Π_cal Δθ
    + B_φθ(Δφ, Δθ)
    + c_boundary(E; Δφ, Δθ).
```

- `Γ_ADC`：ADC 结构非理想到频谱的物理灵敏度核；
- `Π_cal`：校准参数误差到频谱的算法输出核；
- `B_φθ`：物理状态改变校准参数作用方式形成的双线性/高阶项；
- `E`：阈值穿越、码切换或残差越界事件集合；
- `c_boundary`：普通小信号线性化漏掉的非光滑贡献。

旧有的 `Π_out = M_pipe Π_intr` 可以保留，但它现在只是 `Π_cal` 的一个结构化分解，而不再代表整个 ADC 的性能理论。

## 3. 事件感知灵敏度

对于参数 `φ_j` 的小扰动 `δ`，将样本分成两组：

```text
S_smooth = {n: 所有级的判决码与越界状态均不变}
S_event  = {n: 至少一个判决码或越界状态改变}.
```

于是频谱变化可经验分解为

```text
Δc_j = FFT(Δy · 1_{S_smooth}) + FFT(Δy · 1_{S_event}).
```

第一项用于估计光滑核，第二项形成边界核。这个定义可直接由仿真验证，也避免在 v0.1 阶段把连续时间 saltation 公式未经证明地照搬到离散量化器。

边界风险可用阈值裕量分布描述。令

```text
m_l[n] = min_k |r_l[n] - τ_{l,k}|,
```

则 `P(m_l < ε)`、跨越率和 residue overload rate 是解释频谱模型何时失效的关键协变量。

## 4. 从参数统计到频谱指标

设校准误差 `e[n] = θ̂[n] - θ*`。稳态近似可写为

```text
e[n+1] = A(λ, z[n])e[n] + ξ[n],
```

其中 `λ` 包括步长、门控阈值和 dither 幅度。若使用平均线性模型，可由离散 Lyapunov 方程得到稳态协方差 `Σ_e`，但这只回答稳态二阶统计。

本课题还需显式研究：

- 有限时间偏差 `E[e[n]]`；
- 有限时间协方差 `Σ_e[n]`；
- 达到目标性能的首次时间 `T_target`；
- PVT 漂移下的跟踪误差；
- 门控导致的状态相关激励与非高斯稳态分布。

在局部线性区，复频谱协方差近似为

```text
Σ_c ≈ Π_cal Σ_e Π_calᴴ.
```

SFDR 是最大值与比值构成的非光滑统计量，不能仅把 `E[c]` 代入。可采用：

1. 从 `e` 的近似稳态/有限时分布采样，再通过结构频谱模型计算指标；
2. 对主导 spur 已知的局部区域使用 delta method；
3. 在 spur 身份切换处使用分段模型或分位数报告。

## 5. 因果图与可识别目标

建议的结构因果图为：

```text
φ, PVT ─→ 余量/边界事件 ─→ 原始输出频谱 ─────────────→ 指标
  │             │
  │             └→ 校准观测 ─→ θ̂[n] ─→ 校正后频谱 ─→ 指标
  │
λ ─→ dither/门控 ───────────→ 校准观测
│             └──────────────────────────────→ 指标（直接开销）
└────────────────→ θ̂[n]
```

由于仿真器的生成拓扑已知，首选**设计型干预**而不是从输出数据反推因果图。主要 estimand 为：

- 单一物理非理想的平均干预效应；
- 非理想之间的交互效应；
- 算法相对无校准的总效应；
- 经 `θ̂` 传递的中介效应；
- dither/门控/实现路径产生的直接效应。

在 v0.1 无校准基线中，使用所有因素组合和共同随机数计算精确 Shapley 归因；它是已知干预函数上的归因恒等式，不应被表述为纯观测数据中的因果识别。

## 6. 验证矩阵

| 层级 | 输入变化 | 观测量 | 通过条件 |
|---|---|---|---|
| 量化器 | 阈值偏移 | 码切换样本 | 与解析阈值方向一致 |
| MDAC | 增益/DAC mismatch | residue、越界率 | 单因素扫描连续且可复现 |
| 频谱 | 幅度、tone bin | spur bin、SFDR/SNDR | coherent sampling 下理想基线稳定 |
| 联合核 | 多因素扰动 | 复频谱残差 | 加交互/边界项后留出误差降低 |
| 校准 | 步长、门控、dither | `θ̂[n]`、T_target | 有限时间预测覆盖 Monte Carlo 区间 |
| 因果 | 随机化干预 | 总/直接/中介效应 | 效应和与观测总差一致 |

## 7. 当前尚未声称的内容

- 不声称行为级 mismatch 参数已经与具体工艺尺寸一一对应；
- 不声称事件感知有限差分已经构成严格的量化器 saltation 定理；
- 不声称仿真中的干预归因可直接迁移到无随机化的硅后观测数据；
- 不用单次 seed 或单一输入 bin 支撑普遍结论。

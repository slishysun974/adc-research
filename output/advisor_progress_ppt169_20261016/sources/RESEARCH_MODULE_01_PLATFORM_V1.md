# 模块一：实验平台与信号链核对

> 编写：2026-10-16；证据截至2026-10-15。依据用户确认的[七模块分类](PROJECT_STRUCTURE_AND_RESEARCH_REVIEW_2026-10-16.md)。
> 本文综合既有研究，不增加实验或重新验收原始数据。

项目已经建立了能够保存逐级信号、控制非理想因素并重复运行的ADC行为平台。现有核对说明：**程序在声明的模型和测试条件内实现一致，可以支撑机制研究。真实芯片的模拟传输和未公开时序仍需独立证据。**

## 1. 为什么先研究平台

流水线ADC的最终码由多个环节共同决定。前级先作粗判决，减去对应的数模转换电平，再把剩余电压放大送往后级；末级完成较细量化，数字端把各级结果重构成输出码。这里的“剩余电压”就是级间残余电压。

如果某一级的判决规则、码尺度或扰动扣除顺序写错，最终频谱也可能出现类似增益非线性的失真。因此，评价校准算法以前，必须先确认平台计算的是所声明的信号链，并且能把实现错误与模型本身的限制分开。

Gu架构还有主放大路和辅助判决路：主路把高精度残余信息传给后级，辅路帮助后级作粗判决。两路的用途不同。早期平台用主路的比例与偏移近似辅助坐标；后续才加入独立静态路径和带历史的动态候选，不能把这些不同版本合称同一套已验证电路。

## 2. 怎样建立和核对

平台按信号流分层，分别处理模拟链、在线数字校准和离线评分。

```mermaid
flowchart LR
    A[输入与测试用模拟传输] --> B[逐级判决与残余放大]
    B --> C[内部数字码和扰动标签]
    C --> D[在线校正与系数更新]
    D --> E[最终输出码]
    A -. 只供离线评分 .-> F[误差和频谱评价]
    E --> F
```

研究者可以设置模拟传输曲线，知道输入的理想值；在线算法只能接收内部数字码、已知扰动标签及自身状态。这种分层使后续实验能够检验未知模拟条件下的学习，而不会把答案直接交给算法。

核对从简单条件开始：先检查单级判决、数模转换和残余范围，再检查三级理想数字重构。随后分别开启比较器偏移、电容式数模转换失配、增益误差和模拟非线性，确认每种因素在正确的节点产生作用。最后用人工信号核对静态指标和频谱评分。

## 3. 已经得到什么

**理想信号链与失效边界已经能够逐项检查。** EXP-003穷举4096个理想码中心，核对最终重构、单调性和缺失码；EXP-004检查主辅路径的联合安全余量，包含超出可纠正范围的反例。正确输出与过载、裁剪、不可纠正状态分别记录，避免用饱和后的合法码掩盖上游失效。

**数字校正的连续性和级联顺序已有对照。** EXP-005、006检查分段线性数字函数及已知模拟曲线下的理想逆校正。后者用于验证链路和提供离线参照，不能当成在线算法已掌握真实模拟曲线。EXP-008进一步说明，改变内部码缩放不会创造原本不存在的模拟幅度覆盖。

**后续性能比较有了统一口径。** EXP-014建立码密度与单音频谱指标，EXP-023统一全链路整数码比较。静态指标中，DNL描述每个码对应的电压宽度是否均匀，INL描述转换曲线相对参考直线的偏离。频谱指标则从输出序列计算，不能替代码制和边界核对。

**Simulink已经提供可查看的独立实现。** 最终一致性验收覆盖23组、82,343次转换。输入、模拟／判决、数字输出和学习状态四类记录，在冻结条件下与Python逐样本数值相等。模型可展开查看逐级信号与校准反馈，适合研究沟通；这项核对没有新增芯片物理证据。

## 4. 结论成立到哪里

早期静态行为平台已经通过当时的验收，后续扩展也有各自测试。验收对象是明确的候选模型，论文未公开的码制、主辅关系、舍入和时序仍须标为候选约定。平滑三次曲线和动态参数是受控研究输入，尚非该芯片提取结果。

Simulink当前核对的是浮点行为实现。定点、RTL和后期窗口更新硬件有不同的验收对象，不能将浮点演示的频谱直接标成硬件已经实现的性能。新增噪声、抖动、真实主辅传输或更复杂建立过程，也需要相应资料和检查。

少量旧实验曾通过模拟理想参照对象建立数字分段配置。项目随后改为由数字架构生成分段，并明确在线五字段接口；旧结果保留其配置来源限定，不能一并改称未知曲线下的严格在线证据。

## 5. 对整体课题的意义

这一模块提供了后续研究的共同实验语言：知道误差在哪个节点注入，算法实际收到什么，哪些状态随时间变化，以及最终码怎样评分。有了这些条件，模块四至七才能讨论信息、学习和误差原因。

平台已足以开展明确假设内的研究。下一步是否增加某种非理想，应由它能否检验具体主线判断决定；模型越复杂，并不自动越接近目标芯片。

# 模块七：剩余误差来源与改善空间

> 编写：2026-10-16；证据截至2026-10-15。依据用户确认的[七模块分类](PROJECT_STRUCTURE_AND_RESEARCH_REVIEW_2026-10-16.md)。
> 本文综合EXP-072—077及其补分析，不新增归因计算、参照、路径或评分。

对原有限场景，研究已经能够解释若干主要关系：**四样本采用范围带来重要代价，系数平均位置与持续变化共同影响误差，门和两级反馈会改变学习历史。现有数字表示仍能做得更好，但原在线算法怎样取得这种改善尚未证明。**

## 1. 从性能观察转向原因判断

发现某条路径误差很大，不能立即知道原因。可能是系数平均值不合适，也可能平均值有益、持续变化却抵消了收益；后级还会通过前级的学习量和门影响后续系数。

本模块采用受控对照：从相同完整初态开始，使用相同未来数字字和固定终点，只改变是否更新、某条学习连接或某个门的来源。活动级重新计算自己的读出、门、请求及状态。这样才能判断改变该因素后的有限效果，不能只在已经形成的历史里删一个代数项。

主要对象是原平滑模型、五个种子、两种学习率倍率、两个起点及固定八块记录，共20个案例。后续有些细致分析只检查其中一例。结论依赖这些对象，不代表未知输入或芯片的一般因果规律。

## 2. 两级反馈不是一个可以统一删除的坏因素

EXP-072先比较正常状态与不同未来更新方式。EXP-073再分别保持前级或后级，分离后级直接改变输出的作用，以及后级通过前级学习历史传播的作用。

在当前静态前馈数字候选中，后级更新不依赖前级数字系数，前级学习却依赖后级校正后的数字量。这个单向关系使特定连接干预可以清楚定义；它不表示模拟前级不会影响后级输入。

结果显示，后级传导既有益也有害。即使后级保持，原前缀起点的10个配对中，前级独立学习仍都增加误差，因此这些增损不需要后级持续更新才能出现。

EXP-074把后级进入前级学习的作用再分成学习数值和采用门。多数配对中，改变第二低段采用门的通道更大，但门作用有正有负。先改变哪一项也会影响分配，说明存在交互，不能将其直接写成唯一物理贡献百分比。

## 3. 增加采用样本有多大作用

EXP-075保持后级，从每例相同完整初态重新运行前级反馈。每120次转换采用全部样本，相比只采用4个样本，在20/20案例中都降低了最终整数码均方误差，持续变化的条件项也都减轻。

这一对照支持有限选样有重要受控代价。但全样本使用30倍前级学习观测，不能当作同成本改进；而且它仍有6例比保持系数更差，所以“多看数据就能消除本批全部增损”不成立。

这6例又分成两种情况：4例的平均位置与持续变化都不利，另2例的平均位置有益，却被持续变化抵消。因而不能将全部剩余误差解释成同一种偏差或纯随机噪声。

## 4. 平均系数不理想，也不等于已经收敛到坏位置

后续把实际平均位置、固定位置的学习方向，以及真实请求怎样累积成历史放在一起检查。

四个不利平均位置中，同位置固定连续学习方向有2处增加误差、2处减小误差；四处平均相关量都非零，局部统计也能区分原低两段参数。因此，不能统一解释为学习方向错误、参数不可区分，或已经到达某个错误收敛点。

固定位置的有益方向，也未必在移动历史中形成有益平均值。较早的请求会影响更多后续输出，对实际平均位置的权重更大；门又会随状态改变，重新选择采用样本。原分析中，一个案例由这种时间权重即可出现方向翻转，另一个案例还必须保留自身门变化。

这些关系分别解释不同环节。请求方向的投影排序、平均位置的损失和完整反馈后的均方误差，并非同一指标，不能互换为一套误差份额。

## 5. 一个深入案例怎样检验门的作用

原种子尾号625、前缀起点、1/4步长的一例，在全样本前级学习下仍增损。研究只替换第二低段采用门的来源，再重新传播前级反馈，得到以下整期整数输出均方误差：

| 比较方式 | MSE，码² |
|---|---:|
| 原全样本前级学习 | 3.3339 |
| 使用原未来平均系数计算第二门 | 3.0599 |
| 使用原合法初态系数计算第二门 | 3.4454 |
| 两级系数保持 | 3.1948 |
| 已有离线较好合法固定系数 | 1.9201 |

EXP-076的未来均值门对照改善了整期误差，并低于保持。但它使用了原记录未来平均系数，只能作为离线诊断，额外读出与存储也有成本，不能直接投入原在线算法。

EXP-077改用当前可见的合法初态构造门，改善预测反而失败。这个失败限制了该参照，不证明所有有益在线门都必须知道未来。原有不利时间块也保留，整期改善不等于每一块都改善。

表中离线固定系数更好，说明当前表示仍有空间。它依赖离线目标，初始低两段系数也与学习路径不同，不能据此宣布同初态在线策略已能达到1.9201码²。

## 6. 目前最关键的未决关系

最新综合分析已经排除了若干统一解释，不需要先求解一般八状态长期根，才能交付这一批有限结论。后续是否研究，应看能否推进以下关系：原可见信息或可信输入条件，能否判断有益方向；算法能否从相同初态发现、达到并维持它；收益是否满足相同成本和更广输入条件。

当前有条件地评价一个给定方向，与算法自己发现该方向仍有距离。较好表示存在、局部参数能区分、目标方向能评价，以及真实历史有收益，分别需要证据。

因此，继续同例的更紧数值界、纯量化拆分或追加训练，并不是当前结论自动要求的下一步。它们只有在能改变主要判断或修复正确性时才值得继续。

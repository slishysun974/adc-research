## 资料与源文件

- `notes/`：每页的说明与原始证据路径，已写入PPT备注。
- `svg_output/`：可维护的逐页设计源，文字、表格和数据图均由可编辑对象构成。
- `svg_final/`：由源文件导出的自包含SVG预览。
- `sources/`：本次汇报使用的提纲、七模块报告副本，以及只从旧结果摘出的展示数值。
- `exports/`：原始导出文件。
- `deliverables/`：最终阅读版PPT。
- `analysis/`：版式、图表与输出核对记录，不作为新增科学研究证据。
- `design_spec.md`、`spec_lock.md`：本版设计与逐页内容安排。

`sources/`中的报告副本保留制作时原文，相对链接以原`docs/reports/`位置为基准；阅读现行报告请从项目[阅读指南](../../docs/README.md)进入。

现行科学主线和当前进展继续由项目原有文档维护。本次制作不新增ADC转换、学习、性能评分、FFT或算法，不将既有数值核对改称成本或物理验收通过。

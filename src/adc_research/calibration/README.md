# 在线数字校准代码

`observation.py` 定义在线模块能看到的五个数字字段：两级判决码、末级码和两级 dither 标记。浮点与定点的 `adaptive_two_stage.py`、`fixed_adaptive_two_stage.py` 只接收这种数字样本。`gu_baseline.py` 从架构配置中的数字位宽建立 Gu 候选的分段宽度与初始单位系数，不读取模拟测试真值。

浮点／定点的数字校正接口分别为 `two_stage.py`、`fixed_pwl.py` 中的 `*_observed`。接收完整平台轨迹、读取物理过载标记的评分接口在 `evaluation/scoring.py`；`fixed_pwl.py` 和 `known_truth.py` 仅保留旧脚本的兼容入口。新的在线实验不得调用这些旧入口。

注意：这里的硬件“可见”是候选行为级信号清单；真实芯片的总线、更新时刻、字长尚未全部核实。代码输入隔离不等于芯片可实现性证明。

`fixed_four_lane_window.py` 是四路共享 Q22 窗口候选：只接收数字样本及转换号／路号，窗口内使用旧系数形成局部学习输出和门控乘积，边界一次舍入／饱和，新系数从下一窗口生效。完整聚合与固定四点估计使用同一时间尺度的步长。它不读取两相模拟状态，也不指定真实芯片抽取规则。

`window_phase_selection.py`仅提供固定、5位轮换及32位移位异或的窗口相位调度，不接收样本或离线目标。EXP-050按同四点预算检验这些调度，两种简单改法均未通过预定稳健性门；它们不改变原Gu核心，也不证明真实芯片选择器成本。

`fixed_filtered_window.py`是固定1/4相关量平滑的数字候选，新增两组各四个有符号滤波状态，保留120转换窗口、四个选样及原步长。统计使用旧系数和实际Gu门，当前门全闭时过去统计仍可能请求更新。只有数字样本进入核心，理想目标影子递推位于EXP-051离线入口。模块显式限制Q1.10／Q3／Q22与dither副本，范围检查不饱和掉非法滤波状态。
